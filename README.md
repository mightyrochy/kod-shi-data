# kod-shi-data

Репозиторій «Код Ші» — стилістка в браузері з каталогом речей українських крамниць.
Опублікований продукт: https://mightyrochy.github.io/kod-shi-data/index.html
(збирає бот `.github/workflows/zbirka.yml` на кожен push у `main`, що торкається джерел).

| Де | Що |
|---|---|
| `джерела/` | код продукту (Python під Pyodide, `показ.html`, `worker.js`), прилади, проби `проби/*.py`, корпус правил і звіти в `джерела/аудит/` |
| `index.html` | зібраний продукт — лише зі збірки, руками не правиться |
| `AGENTS.md` | ядро для всіх моделей: роль → адаптер → задача; механіка — `CLAUDE.md`, `GEMINI.md`, `аудит/CHATGPT.md` |
| `аудит/` | координація: файли ролей, `КАРТИНА.md` (модель системи й корені), `ПЛАН.md` (кроки й порядок), `наряди/` (черга), `БЕКЛОГ.md` і `дошка/` (відомі проблеми), `СТАН.md`, `ПРОДУКТ.md`, `РІШЕННЯ_ВЛАСНИКА.md`, `СТАНДАРТ_КОДУ.md`; решта — історія (`аудит/README.md`) |
| `zhnyvarka/` | жнива каталогу з крамниць і розвідка (workflows `zhnyva.yml`, `zhnyvarka.yml`, `rozvidka.yml`) |
| `open-source-stylist/` | колишній окремий репозиторій «Open Source Stylist»: перевдягання людини на фото (ComfyUI, Qwen-Image-Edit, маски ATR, вимір кольору). Перенесено 18.09.2026 з історією; зображення й ваги моделей лежать лише на диску — див. його `.gitignore` і `README.md` |
| `.gemini/` | налаштування рецензента Gemini Code Assist: `config.yaml` (що й скільки рецензувати), `styleguide.md` (правила рецензії) |
| `шрифти/` | шрифти показу, яких нема на CDN (`ПРО_ШРИФТИ.md`) |
| `каталог_повний.xml.gz` | фід каталогу; розпакований `каталог_повний.xml` — у `.gitignore` |
| `каталог_записи_v1.jsonl.gz`, `каталог_звіт_v1.json` | записи схеми v1, з яких `zhnyvarka/складальник.py` складає каталог, і знімок його звіту «записано → прочитано» (рядок 5651) |
| `каталог_маніфест_кадрів.json.gz` | маніфест кадрів каталогу (статус, тип за сигнатурою, ш×в, sha256, dHash/aHash на адресу): за ним складальник знімає службові картинки й дублі розміру з `<picture>`; `zhnyvarka/кадри_маніфест.py --зняти` (рядок 5654) |
| `збирання.txt` | адреса опублікованого продукту й нотатки про збірку |
