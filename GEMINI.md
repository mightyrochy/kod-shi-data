# Адаптер Antigravity CLI (`agy`)

Ядро — `AGENTS.md`; якщо його текст не завантажений, прочитай. Роль задає наряд, а не модель усередині `agy`.
Це механіка виконавчого CLI; рецензент Gemini Code Assist має окрему `.gemini/config.yaml`.

- Команда — `agy -p` з `--dangerously-skip-permissions` лише в уже дозволеній ізоляції ОС (власник). До її
  перевірки запуск заборонений: інакше повні права діють на комп'ютері власника.
- Ізоляція: сеанс користувача Windows `gemini` через зміну користувача, не `runas`; клон без входу в GitHub.
  Перед запуском: `whoami` — `gemini`, `net session` відмовляє, тек власника й інших дисків не видно, у `env:`
  нема KEY/TOKEN/SECRET/PASSWORD. Не так — блокер. Ізоляцію налаштовує власник.
- Гілка — `gemini/<крок>`. Передача результату — `git bundle` у `C:\Users\Public\gemini\`. Публікація з чистого
  клону власника: лише `git fetch` бандла, нічого з теки агента під власником не запускати; дифф без `.github/`,
  пуш лише `gemini/*`. До реалізованого наряду запуску без руки цю механіку виконує власник за рядками диспетчера;
  запускач сам `agy` не запускає. Нового брокера чи іншого механізму публікації тут немає.
- Звіт ролі — останні рядки виводу: той, хто запускав `agy`, передає їх диспетчерові, а диспетчер відкриває PR з
  опублікованої гілки (чернетку; PR пачки — ні), тіло — останній коміт. Договір виконавця той самий; відсутність прямого
  пушу не означає, що результат уже опубліковано.
- Квота — `/usage` у `agy`; Claude-моделі там — група «Claude & GPT» Google. Числа контексту, якщо CLI їх не
  віддає, недоступні; сила моделей — `аудит/МОДЕЛІ.md`, поточний стан — `аудит/СТАН.md`.
- Нема механізму постійного листування чи підписки для призначеної ролі — повідомити блокер доступного каналу;
  цей адаптер не обіцяє підтримки диспетчера або сторожа засобами `agy`.
