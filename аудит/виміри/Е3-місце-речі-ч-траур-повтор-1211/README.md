## Докази й відтворення

`підсумок.json` містить коди, команди, SHA збірок, час і результати всіх пар сцен.
`архіви.json` зіставляє **107 архівів** у `докази/` з вихідними файлами та їхніми SHA-256:
повні журнали команд, голови й бази, запити з помилок повтору, знімки звірок і бази порівняння.
Кожен архів розпаковано й перевірено за розміром і SHA-256. Окремо — журнали обох збірок
`збірка-голова.log.gz`, `збірка-main.log.gz` і команди `збірки.json`.

Середовище: Windows 11, Node 22.23.4, збирач Python 3.12.10, компілятор байткоду CPython 3.12.1,
Pyodide 0.26.4. У CI збирач Python 3.11; локальний прилад також перевірено Python 3.11.9.
Невдале в підготовці: системний `bash` вів у відсутній WSL, тому кеш наповнено наявним Git Bash;
PowerShell перервав першу спробу збірки на `SyntaxWarning`, остаточні збірки виконано через
`subprocess` із повним захопленням виводу. Стенду та записів для цього не змінювали.

Підготовка — `npm ci --ignore-scripts --no-audit --no-fund` у `джерела/`, Chromium Playwright,
кеш зі скрипту `аудит/проби/стенд_pyodide_кеш.sh`, відокремлене дерево бази й готові збірки.
Збирачам передано `LYUSTERKO_CATALOG=повний` і `LYUSTERKO_PYC_PYTHON=<CPython 3.12.1>`.
У дереві бази `node_modules` підключено до тих самих установлених залежностей для повної jsdom-перевірки.
Парний повтор запускається так (вихідна тека має бути новою):

```powershell
python -X utf8 аудит/виміри/Е3-місце-речі-ч-траур-повтор-1211/відтворити.py `
  "$env:TEMP/pokaz" "$env:TEMP/main-pokaz" "$env:TEMP/main-replay" `
  "$env:TEMP/pyodide" "$env:TEMP/replay-ci"
```

Скрипт використовує незмінені команди приймання з `.github/workflows/zbirka.yml` та
`REPLAY_BASE_BUILD` / `REPLAY_BASE_ROOT`, архівує обидва виводи й звіряє запити.
