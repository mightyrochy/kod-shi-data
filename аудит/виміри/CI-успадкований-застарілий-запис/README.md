`артефакти.json` містить для **всіх десяти сцен** виклики, повні SHA-256 запитів голови й бази та
шляхи розбіжностей. `артефакти-докази.json.gz` зберігає незмінені `звірки.json`, `вимір-бази.json`
й помилки відтворення з повними запитами обох запусків. Скрипт повторно обчислює хеші й звіряє їх
зі знімками; нічого в запитах перед порівнянням хешів не вилучає.

Результат: 10/10 пар зупинилися на виклику 1; 0/10 мають однаковий хеш; 10/10 відрізняються лише
`.messages.0.content.0.text:json.profiles.0.id`. Раніших чи пізніших викликів у цьому прогоні немає;
регресій 0. П'ять сцен наряду входять у частину 0; частина 1 має ще п'ять з тим самим результатом.
Тому історичний прогін не доводить успадкованість за строгим правилом «сцена + виклик + запит».
