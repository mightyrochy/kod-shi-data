## Правка й зразки

Порівнювач зберігає повний хеш і пріоритет регресу. Стан названо `застарів у main`;
приймання пише `СПІЛЬНИЙ ПРОГІН: <id> — перезаписати застарілий у main вхід моделі`
в консоль та `GITHUB_STEP_SUMMARY`, а також попередження GitHub. Зміна голови лишає вимогу погодження.
Дублювання правила в перевірці погодження немає.

`node аудит/проби/перевірити_храповик_базу.js` створює дві штучні сцени у тимчасовому дереві,
підставляє лише результати дочірнього браузера та виконує справжні CLI приймання й погодження.
Живі записи не читає. Перевіряє 20 кодів погодження для 10 варіантів: успадкована застарілість,
нова, раніший/пізніший виклик, інший запит, брак запиту голови/бази, відсутній вимір main та два
поєднання з регресом. Порядок ключів запиту голови й бази різний; зміст і хеш успадкованої пари однакові.
Ідентичність сцен перевіряється різними запитами двох зразків. Перевіряються консоль, резюме,
попередження й запуск без події GitHub. Проба викликається з `перевірити_храповик.js`, який уже є в CI.

ДО виміряно тим самим скриптом із чотирма файлами приймання з 98fea0483858dbc3965a6642982cfaea813d2867:
для порівняння скрипт приймає їхню теку першим аргументом. Це копія чотирьох модулів зі зразками,
а не клон репозиторію. Журнали — `зразки-до.txt.gz`, `зразки-після.txt.gz`.

| Мірило зразків | ДО | ПІСЛЯ |
|---|---|---|
| Стан успадкованої застарілості | запис застарів на базі | застарів у main |
| Код без погодження / з погодженням для успадкованої | 0 / 0 | 0 / 0 |
| Рядків спільного прогону для двох сцен | 0 | 2 |
| Код нової чи зсунутої без рядка / з рядком | 1 / 0 | 1 / 0 |
| Код регресу без рядка / з рядком | 1 / 1 | 1 / 1 |

Це не новий дозвіл пропускати застарілий запис: саме порівняння вже працювало.
Історичний червоний CI пояснює попередній випадковий id; ця правка доповнює звіт і приймання на зразках.

`нова_звірка.txt.gz` — код 1; `погодження_push.txt.gz` — код 1. Вони підставляли статичний журнал

дерево зі своїм заданим набором баз. Старі проби мають лише базу того концерту, чий журнал
підставляють; нова проба успадкованості — дві цілком штучні сцени. Актуальні нічні записи до
вибору цих фікстур більше не потрапляють. Код приймання, критерії й очікувані коди старих проб
не послаблено; виправлено середовище зразків. Самі живі записи не змінені.
