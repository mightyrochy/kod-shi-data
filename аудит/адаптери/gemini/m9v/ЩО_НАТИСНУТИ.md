# Що натиснути (М.9-В) — ~15 хв біля ноутбука

**Коли: після злиття PR-2, диспетчер скаже** (PR-2 міняє `gemini_run.ps1`; одне UAC ставить уже нову обгортку).
Ноутбук увімкнений, ти під своїм обліковим записом. Копіюй рядок, натискай Enter. Паролі й входи — лише в системних вікнах.
Gemini CLI не ставимо (для Google One його замінено Antigravity; рушій Gemini — наявний `agy`). Node.js не потрібен.
Рушії черги: Gemini — `agy` (квоту читає сам, без витрат, лише на agy ≥ 1.1.11), GPT — локальний Codex; каскад за залишком пулу обирає обгортка.

**1. Свій PowerShell** (Пуск → PowerShell, звичайний). Встав один рядок:

```powershell
$m="$env:USERPROFILE\m9v"; New-Item -ItemType Directory -Force $m|Out-Null; $b='https://raw.githubusercontent.com/mightyrochy/kod-shi-data/main/аудит/адаптери/gemini/m9v'; '0_власник.ps1','1_адмін.ps1','хеші.psd1'|%{iwr "$b/$_" -OutFile "$m\$_" -UseBasicParsing}; powershell -NoProfile -ExecutionPolicy Bypass -File "$m\0_власник.ps1"
```

- Успіх: зелене «ГОТОВО: частина власника пройдена», «-DryRun: код 0, відмов 0», «Хеші збіглися».
- Червоне «СТОП» — скопіюй текст диспетчерові (ЗАБЛОКОВАНО). Далі не йди. «claude … не відповів» — встанови за підказкою в тексті. «gh auth status» — `gh auth login`.

**2. Адмінський PowerShell:** Пуск → PowerShell → правий клік → «Запуск від імені адміністратора» → **UAC: «Так»**. Встав:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\m9v\1_адмін.ps1"
```

- Спливе системне вікно з паролем: введи **той пароль `gemini`, що вже є** (з ним зареєстровані задачі М.2). Скрипт його не бачить і не пише. Пароль не міняй; лише якщо `gemini` входить без пароля — Win+L → `gemini` → Ctrl+Alt+Del → «Змінити пароль» (крок 4 `НАЛАШТУВАННЯ.md`).
- Успіх: зелене «ГОТОВО: кроки 3 і 5»; у таблиці `gemini-run`/`gemini-publish` — `Password`/`Interactive`, `PT15M`/`PT1M`. Жовте «тривалість не порожня» — виправ у Планувальнику за підказкою.

**3. Win+L → користувач `gemini`** (один перехід). PowerShell, встав:

```powershell
iwr 'https://raw.githubusercontent.com/mightyrochy/kod-shi-data/main/аудит/адаптери/gemini/m9v/2_під_gemini.ps1' -OutFile "$env:TEMP\2.ps1" -UseBasicParsing; powershell -NoProfile -ExecutionPolicy Bypass -File "$env:TEMP\2.ps1"
```

- Відкриється браузер для ChatGPT (`codex login`): увійди. Без браузера: `codex login --device-auth`.
- Успіх: «Запис у обгортку відхилено — як і треба», «isolation: OK», список `agy models`, зелене «ГОТОВО».
- «СТОП: обгортки … нема» — не зроблено крок 2. Червоне `isolation=…` — код пояснено в тексті; скопіюй диспетчерові.

**4. Win+L → назад до себе** і більше нічого: диспетчер сам перевірить heartbeat, пошле пробу й напише результат.

Помилки з Планувальником (`0x80070569`, `0x8007052E` тощо) — таблиця «Якщо щось не так» у `НАЛАШТУВАННЯ.md`.
Усе вимкнути: адмінський PowerShell → `Disable-ScheduledTask gemini-run, gemini-publish, gemini-watch`.
