## Що змінено

Спільні читачі JSONL працюють із простим і gzip-файлом та діагностують пошкоджений рядок, зберігаючи цілих сусідів. Ініціалізація зведення, читання/запис JSON-курсора та атомарна заміна TSV проходять спільними функціями. Читач v1 перевіряє шапку. Інвентаризація за методикою перевірки-2069-4: обходів спільного механізму **7 → 0**, команда `python аудит/жнива_5_3/читачі_повтор.py`, дослівний результат — `10682_ДО_ПІСЛЯ.txt`.

Обхід звіряє рецепт до рішення пропустити завершену крамницю. Відбиток враховує рецепти й код розбору/складання. SQLite повертає DONE до PENDING, JSON скидає підтвердження кінця; історія лишається. Проба `каталог_рецепт_повтор.py`: SQLite `(1, 1) → (1, 0)`, JSON `True → False`.

HTML-поля обходу читає `факти_з_картки` 5.1 з селекторами крамниці; JSON — чинні `факти_shopify`/`факти_woo`. Новий `жнива_каталог.py` застосовує лише результати «картка», зберігає ід, не стирає старий склад без нового виміру й називає це `NOT_MEASURED_RETAINED`. Варіанти без окремої адреси не зливає. Параметр обходу `--оновити-каталог` з'єднує записи v1, XML і чинну чергу `жнива_кадри.py --галереї --черга-вихід`; під час цієї спроби він не застосовувався. Фікстура повного збирання: ід 1 → 1; склад збережено; повторних оновлень 0.
