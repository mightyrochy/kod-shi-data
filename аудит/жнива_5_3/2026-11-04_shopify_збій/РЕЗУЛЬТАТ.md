## Що змінено

Штатні відсутність параметра, явне «невідомо» й коректний JSON без підтвердження зберігають попередню поведінку.

Результати — `збій_до.log`, `збій_після.log`, `прилад_е2_після.log`, `прилад_річ_після.log`.

## Невдалі спроби й підготовка середовища

Перша версія нової проби помилково вимагала відмови кольору для старого запису без параметра власності;
очікування звірено з попереднім договором: для старого запису лишається попередній шлях, для явного невідомого — відмова.

Перший повний храповик: 20 коренів без зростання, зокрема Е2 **30 → 30**, Річ **49 → 48** відносно `main`;
три червоні повідомлення — відсутні файли sparse-checkout кореня Річ-запис-речі та збій декодування
ізольованого дочірнього Python кореня Річ-колір-межі на обох деревах (`храповик_перший.log`).
Потрібний sparse-шлях викладено. У Windows ізольований `python -I` ігнорує `PYTHONUTF8` й друкує CP1251,
тому його читач у режимі UTF-8 діставав `stdout=None` після збою декодування.
Для повного повтору узгоджено системне кодування дочірнього процесу й читача (`PYTHONUTF8=0`),
а зовнішній stdout залишено UTF-8 (`PYTHONIOENCODING=utf-8`). Окремий виклик незміненої `таблиця_г2`
у цьому середовищі успішно прочитав обидві таблиці. Повтор — `храповик_після.log`.
У повторі Річ-колір-межі пройдено **396 → 396**, але повний вердикт знову червоний:
на обох деревах Річ-запис-речі дочірній Node не завершився за штатні 30 с,
а Річ-ознаки-обличчя — за штатні 900 с. Інші 20 коренів — без зростання, включно з мірилом доробки.
Після завершення батареї виконано послідовний повтор усіх 22 коренів:
`храповик_послідовно.py --база bc7c89bc40830d3104bd8b6c4ac5ff92e33aed13`.
Обгортка задає лише одного працівника штатному `ThreadPoolExecutor`: список паспортів, обидва дерева,
команди, правила порівняння та межі часу незмінені. Джерела храповика й приладів не редагуються.
У Windows для цього запуску також `PYTHONUTF8=0`, `PYTHONIOENCODING=utf-8`.
**Повний результат: зелений, червоних 0, код 0** (`храповик_послідовно.log`).
Відносно `main` `bc7c89bc40830d3104bd8b6c4ac5ff92e33aed13`: Е2-збій-без-сліду **30 → 30**,
Річ-кадр-варіант **49 → 48**; решта 20 коренів без зростання. Зокрема Річ-запис-речі **6 → 6**,

Повна батарея дійшла до кінця. Єдиний провал — §117: процес `import траса_петлі` не завершився за 10 с;

## Що лишилось

Це доробка збою, а не закриття кореня. Нового каталогу й виміру кольору немає;
продуктовий файл фактів досі містить 0 з 11 084 відомих варіантів. Перенесення доказів для решти форматів,
повний свіжий перезбір із чергою вимірів та загальне каталожне й живе мірило — наступні кроки паспорта.
Наряд збережено, бо прилад не 0. Вад поза мірилом доробки не знайдено.
