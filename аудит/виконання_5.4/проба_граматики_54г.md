# ПРОБА ГРАМАТИКИ 5.4 (наряд 5.4-Г) — команди для ноутбука

Гілка `claude/5-4-g-hramatyka` (PR-чернетка в `codex/5-4-kody-slotu-typu-oznak`), форма відповіді V4
(`CATALOG_PARSE_V4`: три рядки `evidence` / `codes` / `features`, рішення менеджера (1)). Модель та сама, що в
частині 1: MamayLM-Gemma-3-12B Q4_K_M, граматика ввімкнена (без `--без-граматики`). Усе — з `джерела/`.
Інваріант без моделі: `python3 проби/межа_відповіді_54г.py <tokenizer.json MamayLM>` — найдовша допустима
відповідь 2 377 ≤ 2 430 (0,9 × `МАКС_ТОКЕНІВ` 2 700); найдовший промпт 5 350 + 2 700 = 8 050 ≤ 8 192 (слот).

## 0. Пам'ять відеокарти — контекст слота 8 192

```
lms unload --all
lms load <MamayLM> --context-length 16384 --parallel 2 --gpu max
nvidia-smi --query-gpu=name,memory.used,memory.total --format=csv
lms ps
```

Чекаємо: `lms ps` — контекст 16 384, паралельно 2; `memory.used` < `memory.total` без вивантаження шарів на
процесор (журнал LM Studio — «offload» усіх шарів). Не влазить — `--context-length 8192 --parallel 1` (той
самий слот 8 192, удвічі повільніше стіною) і `--паралельно 1` у командах нижче; число пам'яті в обох — у звіт.

```

python3 проби/каталог_розбір_лічба.py <тека проби>
```

Мірило менеджера: обрізаних (invalid_json) серед 50 обрізаних ≤1 % (0 з 50) — у V4 обрізання неможливе за
побудовою, тож будь-яке invalid_json — вада граматики чи сервера (журнал LM Studio — у звіт); розібраних з тими
самими кодами — 50 з 50 (розбіжні поля друкує проба: розбіжність через цитату, довшу за 50 знаків, чи код без
рядка `evidence` — назвати); с/річ — медіана, середнє, найбільше (частина 1 — 34,6 с/річ стіною). Рядок
ГОДИННИК — токени виходу разом: на 100 викликів їх ≤ 100 × 2 700, середнє на виклик — у звіт. Тека — НОВА:
відповіді V3 у нову схему не влазять, їх докат однаково не візьме.

## 3. Еталон 404 (60 речей) — не гірше за А, поріг slot=unknown (а)

```
python3 каталог_розбір_прогін.py --модель <ід MamayLM> --еталон проби/еталон_розбору.json --куди <тека 404_г>
python3 каталог_розбір_прогін.py --зібрати <тека 404_г>
python3 проби/еталон_частки.py <тека 404_г>/розбір.json
python3 проби/еталон_частки.py <тека 404_а3>/розбір.json       # А — той самий суд над старим розбором
```

Мірило менеджера: «в» (вигадано) — 0 у кожному полі; правильних кодів — не менше, ніж в А. Поріг (а): у рядку
`slot` — «м» (мовчання, unknown) серед речей, де в еталоні слот є, ≤5 %; «х» (хибно) не більше, ніж в А. Понад
5 % — розклад за типами (які типи, що в цитатах) і правка промпта чи переліку разом із формою V4, щоб перерозбір
був один; запасного шляху словами нема. 22 речі частини 1 з item_type=not_applicable (тіло PR #1773) — чи еталон
каже «не вдягається»; так — slot not_applicable замість unknown (код, без перерозбору).
