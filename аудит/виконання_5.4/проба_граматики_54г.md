MamayLM-Gemma-3-12B Q4_K_M, граматика ввімкнена (без `--без-граматики`). Усе — з `джерела/`.

## 1. Списки id (100 речей)

- 50 розібраних — `аудит/виконання_5.4/проба_граматики_розібрані50.txt`
  (`random.Random(17).sample(sorted(коди), 50)` з `каталог_розбір_коди.json.gz` на 2c1b3c6b; слоти: dress 11,
  top 11, shoes 10, bottom 7, unknown 5, outerwear 4, headwear 1, set 1).
- 50 обрізаних — з `прогін.json` теки частини 1 на ноутбуці (той самий сід; має збігтися з таблицею
  «ПРИЧИНА ОБРІЗАННЯ» у #1690):

```
python3 -c "import json,random,sys; р=json.load(open(sys.argv[1]+'/прогін.json'))['речі']; о=sorted(x['id'] for x in р if str(x.get('впало') or '').startswith('invalid_json')); print('\n'.join(random.Random(17).sample(о,50)))" <тека частини 1> > ../аудит/виконання_5.4/проба_граматики_обрізані50.txt
```

## 2. Проба 50 + 50

```
lms load <MamayLM> --context-length 12288 --parallel 2 --gpu max
cat ../аудит/виконання_5.4/проба_граматики_розібрані50.txt ../аудит/виконання_5.4/проба_граматики_обрізані50.txt > /tmp/ід100.txt
python3 каталог_розбір_прогін.py --модель <ід MamayLM> --еталон /tmp/ід100.txt --куди <тека проби>
python3 проби/проба_граматики_54г.py <тека проби> ../аудит/виконання_5.4/проба_граматики_розібрані50.txt ../аудит/виконання_5.4/проба_граматики_обрізані50.txt
python3 проби/каталог_розбір_лічба.py <тека проби>
```

Мірило менеджера: обрізаних (invalid_json) серед 50 обрізаних ≤1 % (0 з 50); розібраних з тими самими кодами —
50 з 50 (розбіжні поля друкує проба); с/річ — медіана, середнє, найбільше (частина 1 — 34,6 с/річ стіною).
`--куди` — НОВА тека: граматика інша, а докат бере з теки лише відповіді, що проходять нову схему.

## 3. Еталон 404 (60 речей) — не гірше за А, поріг slot=unknown (а)

```
python3 каталог_розбір_прогін.py --модель <ід MamayLM> --еталон проби/еталон_розбору.json --куди <тека 404_г>
python3 каталог_розбір_прогін.py --зібрати <тека 404_г>
python3 проби/еталон_частки.py <тека 404_г>/розбір.json
python3 проби/еталон_частки.py <тека 404_а3>/розбір.json       # А — той самий суд над старим розбором
```

Поріг (а): у рядку `slot` — «м» (мовчання, unknown) серед речей, де в еталоні слот є, ≤5 %; «х» (хибно) не більше,
ніж в А; «в» (вигадано) — 0. Понад 5 % — розклад за типами (які типи, що в цитатах) і правка промпта чи переліку
до частини 2; запасного шляху словами нема.
