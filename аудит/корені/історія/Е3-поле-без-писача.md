## Крок 01–02.11.2026 UTC — сонце

Перелік кроку — лише `сонце`; інші десять полів і мертвий варіант активності не змінювались. Рішення для поля —
вхід від мовної моделі з її слів, а без нього — названий пункт чекліста. Доказ змісту — K-WEA-03,
`джерела/тема-4_композиція-і-когерентність-EN.md:543`: потрібне саме пряме сонце на людину, а не температура чи
відсутність дощу. Слова сцени `ж1_екскурсія_бруківка` («+12 °C, без дощу») цього не несуть; за ними поле невідоме.
Назване пряме сонце або тінь мовна модель може передати кодами `yes` / `no`, з уривком її слів.

Мірило: `python джерела/прилади/корінь_е3_поле_без_писача.py --тихо` — ДО на
`ce3a1bb62628bb4b5f2509b184a1e96db6bc6ddd` `місць: 19`, ПІСЛЯ на дереві кроку `місць: 17`.
Два місця `сонце` (`суд_погода.погода`, `сценарій.день_кодами`) — 2 → 0; прилад і його база не змінювались.

Зроблено: поле `direct_sun` у схемі мовного шару й описах промпта; розбір коду в паспорт у `паспорт_з_шару`,
звідти — через `з_показу` до суду й `день_кодами`. Невідоме не стає False; явне False доходить до дроту.
Схема `ВИПАДОК`, коди відсутнього входу оцінки й породжений `внутрішня_мова.schema.json` узгоджені з полем;
дріт випадку зберігає False й не дублює його, коли `direct_sun` уже є в дні.
У погодному суді без сонця надворі — питання K-WEA-03 без ваги. Пункт 21 чекліста `суд_образу` називає `сонце`,
відрізняє відоме значення від «без входу» й не ховає брак полів самої речі, який назвало правило.

Проба `cd джерела; python проби/wea_сонце_писач.py`: `yes → True → пройдено`, `no → False → пройдено`,
`unknown → None → без входу not_given:сонце`. Вона проходить через розбір відповіді мовної моделі, паспорт,
сценарій, дріт і суд; словесного розбору в коді немає.

Наявна проба `cd джерела; python проби/wea_K-WEA-03.py` на реальному каталозі: для вибраної темної приталеної
сукні з L*=14 при `сонце=True` K-WEA-03 дає `soft 0.50`, при `сонце=False` знахідки немає. Це перевірка фізичної
гілки на одній речі, а не живе приймання чи оцінка всіх образів каталогу.

## Крок 02.11.2026 UTC — господар і креативне

Зроблено: `host_context`, `creative_environment` у єдиному описі полів паспорта, схемі мовного шару,

записує True / False у паспорт; відсутність факту лишається невідомою. Явне заперечення й попередній факт
