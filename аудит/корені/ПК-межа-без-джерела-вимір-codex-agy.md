## Час і обмеження джерел

Codex: для кожного здорового прогону з `codex.events.tsv` узято різниці **сусідніх рядків у початковому порядку**,
без сортування й перестрибування подій, потім максимум у секундах. Перевірено невід'ємність кожної різниці.
Із 1852 прогонів 1389 не мають цього журналу; серед 232 здорових таких 23. Решта 463 мають щонайменше дві
часові мітки, з них здорових 209. Порожніх чи однорядкових наявних журналів у цьому знімку немає.
TSV зберігає максимум кожного здорового прогону й обидві події з номерами рядків, а також максимум усередині ходу.

`agy`: у `agy.jsonl` немає абсолютних часових міток `user_input` і `result`. **Абсолютний початок та кінець
кожного ходу не виміряно: ці мітки не записані.** Натомість кожен із 62 здорових ходів має безпосередньо
записане `result.duration_seconds` зі статусом `SUCCESS`; число результатів звірено з `out/<id>.json:turns`.
У кожному рядку TSV поле `усі_ходи` зберігає всі ці тривалості, номери ходів і рядки початку/кінця,
а основні колонки — найдовший хід. У 2 нездорових прогонів `agy.jsonl` відсутній; серед здорових пропусків немає.
Відсутність абсолютних міток не підмінено відсутністю записаної тривалості.

`wrapper.log` дає **межі прогону**, а не точні межі ходу. Для максимуму `agy`:

- `wrapper.log:744`: 2026-10-28 **06:27:55**, запуск працівника `20261028-062755-c0a801cb925a`;
- `wrapper.log:777`: 2026-10-28 **08:10:48**, `DONE, ходів 1, комітів 12`.

Цей зовнішній інтервал — 102.88 хв: містить підготовку, хід і завершення. За тривалість ходу взято
**6161.5047763 / 60 = 102.6917462717 хв**, а не зовнішній інтервал, округлене `minutes` результату,
суму тривалостей кроків чи різницю дат зміни файлів. Точний час початку з кінцевого рядка обгортки не виводиться.

Часи подій і `wrapper.log` — місцеві, без записаного UTC-зсуву (`Get-Date`, код обгортки
`gemini_run.ps1:91,139`). Дату й годину наведено як у джерелі; UTC позначено лише для часу цього знімка.
Тривалості округлено до двох знаків **після** обчислення максимуму; точні секунди теж збережено у TSV.

Відмов доступу під час читання джерел **не було**, права не змінювалися. Відсутній файл позначено як
відсутність даних, а не відмову доступу. Нездорові прогони, навіть із довшими паузами, у максимум не входять.
Журнали активної обгортки можуть зростати після знімка; коди й числа звіту відповідають записаному TSV.
`sha256_журналу` — SHA-256 прочитаного журналу після зняття BOM і нормалізації CRLF у LF, у кодуванні UTF-8.

## Перевірка і відтворення

Окремий повторний розрахунок із первинних файлів підтвердив **усі 209 максимумів Codex, усі 61 максимумів
`agy` (62 ходи), 23 відсутні здорові журнали Codex, 1951 унікальний id**. Числа нездорових рядків порожні.
Нижче команда перевірки максимумів із кореня репозиторію (PowerShell, Python 3.12; тільки читання):

```powershell
@'
import csv, json
from datetime import datetime
from pathlib import Path
root = Path(r'C:\Users\gemini\gemini-runs')
rows = list(csv.reader(next(Path.cwd().rglob('*codex-agy.tsv')).open(encoding='utf-8'), delimiter='\t'))
assert len(rows) == 1952 and len({r[0] for r in rows[1:]}) == 1951
checked = {'codex': 0, 'agy': 0}
for r in rows[1:]:
    if r[2] != 'DONE':
        assert not r[3]
        continue
    if not r[3]:
        assert r[1] == 'codex' and not (root/r[0]/'codex.events.tsv').exists()
        continue
    if r[1] == 'codex':
        ev = [s.split('\t')[0] for s in (root/r[0]/'codex.events.tsv').read_text(encoding='utf-8-sig').splitlines()]
        seconds = max((datetime.fromisoformat(b)-datetime.fromisoformat(a)).total_seconds() for a,b in zip(ev,ev[1:]))
    else:
        ev = [json.loads(s) for s in (root/r[0]/'agy.jsonl').read_text(encoding='utf-8-sig').splitlines()]
        turns = [e['result']['duration_seconds'] for e in ev if e.get('event') == 'result']
        assert len(turns) == int(r[10])
        seconds = max(turns)
    assert float(r[16]) == seconds and r[3] == f'{seconds/60:.2f}', r[0]
    checked[r[1]] += 1
assert checked == {'codex': 209, 'agy': 61}, checked
print(checked)
'@ | python -X utf8 -
```

ДО: для Codex і `agy` виміру під Admin не було через відмову доступу.
ПІСЛЯ: під `gemini` прочитано весь перелік тек прогонів, отримано максимуми **21.87 / 102.69 хв**
за доступними здоровими записами, пропуски перелічено в TSV. Зі старого звіту Claude числа не переносилися.
Лишається диспетчерові використати вимір у кроці обгортки; абсолютні мітки ходів `agy` й відсутні історичні
журнали Codex цим читанням не відновлюються. Вад поза мірилом не знайдено; нових номерів дошки не використано.
