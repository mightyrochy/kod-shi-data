## Рішення менеджера 19.11 — за двома оцінками: не поле за полем, а один прохід моделі з фото

Корінь іде кроками по одному полю (останній — 15938), тверджень без опори наживо побільшало (0,5 → 1,5 на образ). Fable
називає запис речі причиною номер один і радить один прохід: кожну річ один раз читає модель, що бачить фото, запис зі
сталим набором полів і джерелом кожного, словники зі слів крамниць видаляються, вибірку 300 речей переглядає людина
(зміна 2; Ґ3). Каталог із кредитів API — рішення власника 2; до його слова кроків «ще одне поле» нема, крім вад, які
жінка бачить у прогоні через міст. Джерело — `аудит/ПЛАН.md`, «Як працюємо», «Корені за двома оцінками 18.11».
