## Загальний храповик у середовищі ноутбука

Виконано `python джерела/прилади/храповик_кореня.py --база 72eae2b9d608306e80beba87f2e2d755422015b1`.
Він бачить 20 коренів із приладом і друкує для Е2-усе-з-розмови **53 → 53**.
Увесь запуск завершився кодом 1, з 11 червоними повідомленнями; зеленим його не оголошено.

- Власні причини усунено: попередній `тест_е2_обробники.py` включено до бази класу;
  BOM прибрано з Python-файлів (чотири повідомлення двох сусідніх приладів на голові/базі).
  Попередній API інвентарю збережено, його 2 тести пройдено.
- Два повідомлення про відсутні дані стосувалися sparse-checkout: `аудит/проби/б1`,
  `аудит/проби/річ_запис_каталог_2026_10_30/вибірка_п3.json` та `html`.
  Потрібні теки викладено через sparse-checkout; це не зміна відстежуваних даних.
- Річ-колір-межі на обох деревах: `AttributeError: 'NoneType' object has no attribute 'strip'`
  у читанні `вих.stdout` із підпроцесу. Причину цим кроком не встановлено й прилад сусіднього кореня не змінено.
- Річ-ознаки-обличчя на обох деревах: не закінчив за 900 с у загальному паралельному запуску.
  Це факт цього середовища, не висновок про причину чи результат у CI.

Після виправлення власних причин повторено саме Е2 (код нижче), а не весь довгий набір сусідніх коренів.
Глобальний зелений CI має звірити диспетчер перед злиттям; цей звіт не дозволяє злиття на червоному CI.

## Відтворення ізольованого включення Е2

Зберегти наступний Python-код у тимчасовому файлі й виконати з кореня репозиторію.
Храповик не змінюється: звужено тільки перелік паспортів цього прогону; решту правил він виконує сам.
Це не заміна повного CI.

```python
import sys
from pathlib import Path
from unittest.mock import patch
sys.path.insert(0, str(Path.cwd() / 'джерела/прилади'))
import храповик_кореня as х
назва = 'Е2-усе-з-розмови'
база = '72eae2b9d608306e80beba87f2e2d755422015b1'
голова, попередні = х.паспорти_голови, х.паспорти_бази
with patch.object(х, 'паспорти_голови', lambda р: {
        к: в for к, в in голова(р).items() if к == назва}), \
     patch.object(х, 'паспорти_бази', lambda р, ш: {
        к: в for к, в in попередні(р, ш).items() if к == назва}):
    рядки, червоні, стенд = х.храповик(str(Path.cwd()), база)
print('\n'.join(рядки))
print('\n'.join('ЧЕРВОНИЙ ' + р for р in червоні))
print('червоних:', len(червоні))
sys.exit(bool(червоні))
```
