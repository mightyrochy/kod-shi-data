### Доробка #4184: «опис без кадрів» ставить лише виклик, що пише пояснення (17.11, гілка `claude/Е2-опора-пояснення-кадри-руки-3-4-доробка`; дошка 16357, 16358)

**Причина.** Після #4184 прапор `описБезКадрів` у руках 3–4 ставила `модельПРуки` за будь-яким викликом без фото, зокрема за
допоміжним переліком речей (`перелікРуки`, `item_list_prompt`), що кадрів не несе за будовою. У бойовому шляху перелік є
завжди, тож прапор рук 3–4 був true в кожному прогоні, хоч прозу написано з кадрами. Звірки `тест_показу.js` цього не
бачили: у їхній сцені не було `перелік_прози`, і перелік не кликався (16358).

**Зроблено.** Рід виклику — одне визначення `РІД_ВИКЛИКУ_П` (`пояснення` / `допоміжний`, `джерела/показ/збирання_руки.js`);
`модельПРуки` ставить прапор в одному рядку — лише для виклику роду «пояснення», чиї кадри не дійшли чи їх не було від
початку. Роду за замовчуванням нема: виклик руки 3–4 без роду — збій `call_kind_missing`. Виклики рук 3–4 (усі чотири
місця): проза руки (`стадіяСкладання`), перепис мови, повтор руки «опис не образ» — «пояснення»; перелік речей —
«допоміжний». Руки 1–2 прапор далі ставить `стадіяОпису` (`позначитиОписБезКадрів`), без змін. Сцени рук 3–4 у
`тест_показу.js` ідуть шляхом продукту з переліком; нові звірки: кадри дійшли → false (руки 3 і 4), виклик без роду —
збій. На коді `main` 55bb94a4 ці звірки й стара звірка 16216 (тепер з переліком) — червоні (ВПАЛО 3).

**Мірило ДО → ПІСЛЯ** (`node аудит/проби/Е2-опора-пояснення-кадри-руки-3-4-доробка/руки_3_4_перелік.js [код]`, ДО — код
`main` 55bb94a4): кадри прози дійшли, руки 3 і 4, також з переписом мови й з повтором руки — true → false; кадри йшли й
не дійшли — true → true; без жодного кадру від початку — true → true; викликів `item_list_prompt`, що поставили прапор,
4 → 0 (місць у коді: 1 → 0). Руки 1–2: шість сцен `картка_без_фото.js` — без змін. Прилад кореня — 0 → 0.

**Що лишилось.** Живе мірило — сцена функції `ж7_опис_без_фото_речей` (рядок `ЖИВИЙ ПІСЛЯ` у PR): рука 3–4 з її річчю з
фото на картці. Інших місць, де прапор рук 3–4 видно, нема: поле картки `опис_без_фото` лише за фото на картці.
