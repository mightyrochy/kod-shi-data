# Перелік правил класу кореня ПК-дотримання-правил

Паспорт — `аудит/корені/ПК-дотримання-правил.md`; прилад — `джерела/прилади/корінь_пк_дотримання.py` (код у стовпці
«слід» — `К…` — лічить прилад з подій сесій Claude; `git` — з комітів і PR; `журнал` — з журналу обгортки; `вибірка` —
дії, яких сліди не показують, оцінює модель іншого постачальника за `аудит/корені/ПК-дотримання-правил-вибірка.md`;
`—` — правило не має дії, яку видно). Складено 30.10 за правилом класу з паспорта: місце — правило, яке в мить дії не
перевіряє нічого, крім пам'яті сесії. Джерела — 11 файлів: `AGENTS.md`, `CLAUDE.md`, `аудит/МЕНЕДЖЕР.md`,
`аудит/ДИСПЕТЧЕР.md`, `аудит/ВИКОНАВЕЦЬ.md`, `аудит/ПЕРЕВІРКА.md`, `аудит/НОУТБУК.md`,
`аудит/адаптери/CLAUDE_КЕРУВАННЯ.md`, `аудит/CHATGPT.md`, `GEMINI.md`, `аудит/адаптери/gemini/ЧЕРГА.md`.

Покриття лічить скрипт приладу (режим `--перелік`): кожне речення цих файлів стоїть у рядку одної з двох таблиць за
адресою `файл ‹початок› … ‹кінець› #відбиток` — цитати початку й кінця тексту правила (рядки без відступів, пробіли
стиснуто) і перші 6 знаків sha256 тексту між ними; непокрите речення — вада приладу. Номерів рядків адреса не має:
вставка чи правка деінде у файлі її не зсуває; правка самого правила — вада «текст правила змінено» з адресою, а адресу
нового чи зміненого правила друкує `корінь_пк_дотримання.py --адреса <файл>:<від>–<до>`. Стовпець «тримає»: `пам'ять`, `хук:<ім'я>`,
`CI:<ім'я>`, `дозвіл`, `обгортка`, `платформа`. Стовпець «проба» — код проби з таблиці «Проби» або `нема`. Правило
під механізмом без проби — місце, як і правило лише під пам'яттю (паспорт, «Клас місць»).

## Проби механізмів

| код | команда | що показує |
|---|---|---|
| П1 | `python3 -I аудит/проби/хук_листи_менеджерові.py` | лист диспетчера менеджерові поза переліком відхиляється хуком; перелік, час «СЛОВО ВЛАСНИКА», інтервал «ЗВЕДЕННЯ» |
| П2 | `python3 -I аудит/проби/хук_час_слова_власника.py` | час «СЛОВО ВЛАСНИКА» береться з транскрипту, не з пам'яті |
| П3 | `python3 -I аудит/проби/хук_слова_власника.py` | після стиснення хук вкладає слова власника з чату сесії, крім субагентів |
| П4 | `python3 -I аудит/проби/хук_фонові_завдання.py` | фонове завдання-чекач відхиляється, коротке — на передній план |
| П5 | `python3 -I джерела/проби/хук_слова_час.py` | нагадування хука після стиснення (файл ролі, наряд, стан) і час слів |
| П6 | `python3 -I джерела/прилади/корінь_пк_дотримання.py --проби-конфігу` | `.claude/settings.json`: заборонені інструменти й хуки точок дії є; у слідах доби заборонений інструмент не виконаний (К29) |
| П7 | `python3 -I джерела/прилади/стенд_храповика_кореня.py` | храповик кореня в CI червоніє, коли число місць росте чи прилад міняють разом із виправленням |
| П8 | `python3 джерела/проби/дошка_поля_проба.py && python3 -I джерела/проби/дошка_згортання_проба.py` | поля рядка дошки й дати: рядки без полів і хибні закриття відхиляються, правильні проходять |
| П10 | `bash аудит/адаптери/gemini/перевірка/запустити_стенд.sh сценарії_черги.sh` | стенд обгортки: повтор позначки, позначка зникла, відхилений пуш, ізоляція (`ISOLATION_FAILED`); потребує pwsh, у хмарі Linux не ганяється — його запускає CI `obhortka` (Windows) |
| П11 | `bash аудит/адаптери/gemini/перевірка/запустити_стенд.sh сценарії_claude.sh` | стенд обгортки: `CLAUDE_NOT_LAPTOP`, `MODEL_INVALID`; запускає CI `obhortka` |
| П9 | `python3 -I джерела/прилади/журнал_і_розмір_правил.py --самоперевірка` | показ розміру файлів правил і цитат журналу працює (показ, не гейт: порушення не зупиняє) |
