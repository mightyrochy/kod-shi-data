## 2. Скільки рядків може закрити одна зміна причини

Один рядок має один первинний корінь. `Прямо` — оцінка рядків, для яких запропонована цілісна зміна є достатнім
механізмом виправлення **після зазначеного приймання**. Це не вимір уже виправленого продукту і не гарантія.
`Ще` — рядки тієї ж причини, яким потрібні залежності, нові дані, рішення або живе приймання; додавати їх до
ефекту одного PR не можна. Частина прямих рядків — ремонт вимірника чи приймання, а не зміна якості образу.
«Одна зміна» тут — один архітектурний крок із міграцією читачів, не обіцянка однорядкової латки чи одного дня.

### Причини, зміни й мірило

Перші десять нижче — десять найбільших за прямим ефектом. Код посилається на зафіксований SHA. Числа з дошки
позначено «за рядком/дошкою»; власні нові виміри — [виміри.json](дошка_розбір_chatgpt/результат/виміри.json).
Жодного живого модельного або нового очного фото-приймання цей наряд не підміняє.

**Одна зміна:** Один версійований словник кодів/відтінків і побудова вікон лише з перевірених пар слово↔той самий варіант; пілот і продукт читають один контракт.

**Мірило:** ДО: окремі ЛЕКСИКОН/ВЖИТОК/сім’ї й додані коди пілота; 6671 одна назва дає різні коди. ПІСЛЯ: 0 розходжень переліків, одна назва з тим самим контекстом має один код; frozen40 ≥38 правильних, вікна не вчаться на чужих кадрах.

**Межа:** Р01 перед перенавчанням вікон; не підганяти межі під старі неправильні пари.

## 3. Що повертається після закриття

Історію пройдено по першому батьку `main`: це порядок потрапляння записів у спільну гілку. Час появи рядка

## 4. Звідки вади приходять і які PR їх вносять

Мітки `виявлено` і `внесено` є лише у **71/2014 (3,53%)** рядків; для 1 943 їх немає.
За датою першої появи у main 15–18.10 — **686** рядків, з міткою внесення **49/686 (7,14%)**.
Це не повтор виміру 10/641 із картини: там інший зріз/період, а тут дата злиття й пізніші дописи стану.
Заміна пропуску на «давнє» приховала б проблему, тому пропуски не домислювались.

`поява_sha` та `поява_коміт` для всіх рядків — адреса **реєстрації**, не внесення вади. Наприклад,

## 8. Відтворення й межі

```bash
python3 аудит/дошка_розбір_chatgpt/розбір.py --вихід /tmp/д1
python3 аудит/дошка_розбір_chatgpt/виміри.py > /tmp/д1-виміри.json
```

Перший скрипт бере зафіксований SHA через `git show`, а не невідомий робочий файл. Потрібна повна git-історія.
Другий міряє поточний checkout і записує його SHA та hash каталогу; для точного повтору потрібен той самий SHA.
Усі тимчасові каталоги — в `/tmp`. Моделі, мережа, жнива, зміни дошки й нові гейти не запускаються.
Підготовлені файли в `результат/` — компактний контрольний вивід; повні докази кожного рядка генеруються
в `/tmp/д1/усі_рядки.tsv`, активні — `/tmp/д1/активні.tsv`.

Оцінки «закриє N» не є результатом внесеної правки: код продукту цей наряд не міняв. Живі цифри, які тут
переказано з дошки, не переміряні; причинність там, де потрібне A/B моделі чи фото, позначена як умова.
