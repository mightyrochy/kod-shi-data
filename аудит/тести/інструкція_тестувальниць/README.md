# Інструкція для тестувальниць — джерело

Готовий документ: `аудит/тести/інструкція_тестувальниць_2026-09.pdf` (A4, 23 сторінки).
Наряд ІН-1, вересень 2026. Коду продукту цей PR не міняє.

## Що тут лежить

| файл | що це |
|---|---|
| `інструкція.html` | текст і верстка документа |
| `стиль.css` | верстка під A4; тони й шрифти — ті самі, що в продукті (`джерела/показ.html`, токени `:root`) |
| `знімки/` | знімки екранів, уже нарізані під документ |
| `шрифти/` | Fixel Text (MacPaw, OFL) — ті самі файли, що тягне продукт із jsDelivr; лежать поруч, щоб документ верстався однаково й без мережі. Kyiv\*Type береться з `шрифти/` у корені репозиторію, незміненим (NoDerivates) |
| `нарізка.py` | звідки взято кожен знімок і як обрізано |
| `рендер.js` | друк `інструкція.html` у PDF через Chromium (`page.pdf`) |
| `зібрати.py` | увесь збір: знімки → рендер → номери сторінок у зміст → рендер ще раз |

## Як перезібрати PDF

```sh
cd аудит/тести/інструкція_тестувальниць
CHROMIUM=/opt/pw-browsers/chromium NODE_PATH=/opt/node22/lib/node_modules \
  python3 зібрати.py
```

Потрібен `pypdfium2` (`pip install pypdfium2`) — ним читаються номери сторінок
розділів із готового PDF. Мережа не потрібна: шрифти лежать поруч.

## Звідки знімки

Обидва проходи — на збірці з `main`:

```sh
cd джерела && LYUSTERKO_CATALOG=повний python3 build_артефакт.py . /tmp/стенд/index.html показ-повний
```

1. **Живий прохід стенда** — `аудит/проби/рв6_стенд.js` з `ZHYVA=sonnet` (CLAUDE.md п.15),
   `FOTO=1`, `ZNIMKY=/tmp/znimky_zh`, `ZVIT_OUT=…`. Звідти все, де на екрані стоять
   СЛОВА моделі: палітра з поясненнями схем, картка образу, картка «Оціни мій образ».
2. **Короткий власний скрипт Playwright** на тій самій збірці — знайомство, порожній
   сценарій, картка сценарію рядками, аркуші правки, блок вивантаження вердиктів,
   профіль. Моделі там не треба: це чиста розкладка показу. На час кадру ховається
   нижня панель (`#ніг`, `position: fixed`) — інакше вона лягає смугою впоперек
   довгого знімка. Скрипт одноразовий, у репозиторій не кладеться; що саме взято з
   якого файла, записано в `нарізка.py`.

Знімки живого проходу — 1×, 350–390 px завширшки; у документі вони стоять на 41 мм,
тобто близько 215 dpi. Знімки власного скрипта — 2×.
