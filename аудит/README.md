що де лежить.

## Історія — на старті не читати

`ПЕРЕДАЧА.md` (старий журнал, ~417 КБ), `ПЛАН_СЕСІЙ.md`, `НАРЯДИ.md`, `ЗАВДАННЯ_ЦІЛЬОВА_ЛОГІКА.md`,
`ЗАВДАННЯ_ВІЗУАЛІЗАЦІЯ.md`, `ДІАГНОЗ.md`, `РЕЦЕНЗІЯ_ОПИСУ_СИСТЕМИ.md`, `ФАЗА2_ПІДСУМОК.md`, `ФАЗА2_ЗНАХІДКИ.md`,
`РЕВІЗІЯ_0.md`…`РЕВІЗІЯ_6.md`, `НАПРАЦЮВАННЯ_OSS.md`, `СТАН_ДО_ЗЛИТТЯ.md`, `план_роботи.md`,
`ноутбук_збагачення_v2_звіт.md`, теки замірів, знімків і живих прогонів (`живі_*`, `знімки*`, `перевірк*`, …). Їх
цитують коментарі коду й рядки дошки, тому їх не переносять і не правлять; чинне з них уже перенесено в живі файли.

`правила_ролей.md` і `правила_ролей/` — звіт і докази М.5 та М.7 (`м7/`), не нові правила сесій.
Вкладений `open-source-stylist/AGENTS.md` задає предметний додаток для будь-якої моделі; його старий Claude-SOP
більше не є другим договором ролі. Історичні файли можуть казати «чинний» у старому тексті — це не повертає їм
повноважень. Новий наряд посилається на чинний договір, а не відновлює стару чергу чи правила з журналу.
