# Аудит — карта теки

Хто що читає — `AGENTS.md` (корінь), «Розподіл роботи»: кожна роль читає свій файл і те, що він називає. Тут — лише
що де лежить.

## Живі файли

| файл | що | веде |
|---|---|---|
| `МЕНЕДЖЕР.md`, `ДИСПЕТЧЕР.md`, `ВИКОНАВЕЦЬ.md`, `ПЕРЕВІРКА.md`, `ЗАПУСКАЧ.md`, `НОУТБУК.md`, `CHATGPT.md` | ремесло ролей | менеджер |
| `КАРТИНА.md` | модель системи, корені вад, програма (порядок кроків), вимір якості | менеджер |
| `наряди/` | черга: готовий наряд — файл на крок; PR виконавця видаляє свій | менеджер |
| `БЕКЛОГ.md`, `дошка/` | дошка симптомів: PR пишуть у `дошка/<гілка>.md`, CI згортає | PR, CI |
| `СТАН.md` | адреси ролей, що йде, реєстр очікувань | диспетчер |
| `ПРОДУКТ.md` | рішення власника про продукт, мова в коді (п.12) | менеджер за словом власника |
| `РІШЕННЯ_ВЛАСНИКА.md` | слово власника з датою й цитатою | менеджер |
| `СТАНДАРТ_КОДУ.md` | стандарт коду | менеджер |
| `передачі/` | журнал передач менеджерів і диспетчерів | хто передає |
| `проби/` | стенд `рв6_стенд.js`, живі сцени й порядок прогонів | виконавці, перевірка |

Теки, на які посилаються живі файли (`витрати/`, `айдентика/` тощо), — довідка за посиланням.
