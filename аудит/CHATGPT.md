# Адаптер ChatGPT (Codex)

Ядро — `AGENTS.md`; договір — файл призначеної ролі. Тут лише GitHub-механіка (п.22).

- Наряд коду запускає диспетчер (власник 23.10): новий issue на наряд — посилання на файл наряду з повним SHA `main`
  і сила з його першого рядка; окремим коментарем — «@codex Виконай наряд за посиланням з опису issue за `AGENTS.md`
  і `аудит/CHATGPT.md` з `main`: гілка `codex/…`, PR-чернетка в `main`». Які модель і зусилля бере Codex за
  коментарем — заміряє перший запуск (6.2-Б). Один наряд — один запуск: є відповідь Codex чи PR — не повторювати.
  Із задачі Codex не пушить (нема Git remote, автоперевірка блокує push; #1577, #1578, 23.10): PR відкриває клік
  власника «Create PR» — рядок дії йому, щойно Codex відповів. Доробку PR Codex (зауваження перевірки, червоний CI)
  веде сесія Claude за силою наряду в тій самій гілці (менеджер 23.10): у Codex кожна доробка — ще клік власника.
  30 хв без відповіді й реакції — «ЗАБЛОКОВАНО» власникові, і окрему сесію запускає він: модель і зусилля — з першого
  рядка наряду, промпт — «Виконай `аудит/наряди/<файл>` з `main` за `AGENTS.md`». Задача ChatGPT за подією PR —
  лише якщо цей шлях провалиться: разом вони дублюють запуск.
- Префікс гілки — `codex/`. Гілка, тип PR і зміст звіту — за договором ролі; створення через наявний GitHub-інструмент
  або `gh pr create --base main --draft --head <гілка> --body-file <файл>`. Для PR пачки `--draft` не додають.
  Багаторядкове тіло — файлом або структурованим аргументом. Тіло містить наряд чи посилання на нього.
- Сесіям Claude Codex не пише: звіт ролі («ГОТОВО», «ПЕРЕВІРЕНО», «ЗАБЛОКОВАНО», «ЗНАХІДКА») з повним SHA, робоча
  переписка й виправлення — у своєму PR; його бачить пульс диспетчера. Новий стан — новим коментарем: правки
  коментарів не сповіщають. Підписки й самопробудження нема: вихід — PR і кінцева відповідь сесії.
- Сесія ChatGPT на ноутбуці бере команди — коментарі `НОУТБУК:` у #996 — лише за постійним дорученням власника у своєму
  чаті (власник): це виняток із «не бере черги». Сам коментар не створює сесію й не доводить доставку.
- Хмара ChatGPT отримувала 403 на фото крамниць. Потрібні фото — передати запит на очне приймання через ноутбук;
  недоступний і він — блокер адресатові ролі. Поріг приймання не змінюється через транспорт.
- Вимірник ліміту й контексту — числа платформи чи її повідомлення про вичерпання.
