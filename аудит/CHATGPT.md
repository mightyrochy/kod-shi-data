# Адаптер ChatGPT (Codex)

Ядро — `AGENTS.md`; договір — файл призначеної ролі. Тут лише GitHub-механіка (п.22).

- Наряд коду й доробку PR Codex запускає диспетчер без власника (власник 23.10: «Я не буду нічого робити сам»). Наряд —
  PR з гілки `codex/<наряд>` (порожній коміт від `main`; тіло — посилання на наряд із повним SHA `main`), доробка — той
  самий PR; коментар: «@codex Виконай наряд з опису PR (доробка — що виправити) за `AGENTS.md` з `main`. Пушу в тебе
  нема: кінцева відповідь — повний `git diff <SHA голови PR>` блоком diff, без скорочень, і `git hash-object` кожного
  зміненого файлу». У задачі Codex нема віддаленого `origin` (проба пушу 24.10, #1621), тож diff з відповіді
  `chatgpt-codex-connector[bot]` переносить сесія Claude сили «код»: U+FFFD (кирилиця ламається в дорозі, #1558) у
  контексті й «−» — з голови, тоді `git apply --3way --recount`, у «+» — за змістом, доки `git hash-object` файлів не
  збіжиться з відповіддю; коміт із посиланням на відповідь, пуш у гілку PR; далі — як PR виконавця. Година без
  відповіді, diff не ліг чи хеш не збігся — наряд бере Claude чи `agy` з того ж рядка `аудит/МОДЕЛІ.md`.
- Модель і зусилля — у кожному коментарі запуску й доробки, з `аудит/МОДЕЛІ.md` (власник 24.10: «продовжуй задавати»).
- Перевірка — розділ «Наряд Codex» в описі PR, що перевіряють (SHA, ризик, пункти `аудит/ПЕРЕВІРКА.md`); коментар:
  «@codex Виконай розділ «Наряд Codex» з опису PR за `AGENTS.md` з `main`. Модель — …, зусилля — …. Пушу в тебе
  нема й правок коду не треба: кінцева відповідь — список знахідок за пунктами розділу з номерами рядків і доказом».
  Слова «перевір»/«review» Codex бере як вбудований огляд без доказів (#1625) — це рецензент. Пачки він не збирає:
  за «ПЕРЕВІРЕНО» PR зливає диспетчер.
- Наряд коду — з diff до ~20 КіБ (`-U1`): більший відповідь не вміщає чи обрізає — такий бере Claude.
- Префікс гілки — `codex/`. Гілка, тип PR і зміст звіту — за договором ролі; створення через наявний GitHub-інструмент
  або `gh pr create --base main --draft --head <гілка> --body-file <файл>`. Для PR пачки `--draft` не додають.
  Багаторядкове тіло — файлом або структурованим аргументом. Тіло містить наряд чи посилання на нього.
- Сесіям Claude Codex не пише: звіт ролі («ГОТОВО», «ПЕРЕВІРЕНО», «ЗАБЛОКОВАНО», «ЗНАХІДКА») з повним SHA, робоча
  переписка й виправлення — у своєму PR; його бачить пульс диспетчера. Новий стан — новим коментарем: правки
  коментарів не сповіщають. Підписки й самопробудження нема: вихід — PR і кінцева відповідь сесії.
- Сесія ChatGPT на ноутбуці бере команди — коментарі `НОУТБУК:` у #996 — лише за постійним дорученням власника у своєму
  чаті (власник): це виняток із «не бере черги». Сам коментар не створює сесію й не доводить доставку.
- Хмара ChatGPT отримувала 403 на фото крамниць. Потрібні фото — передати запит на очне приймання через ноутбук;
  недоступний і він — блокер адресатові ролі. Поріг приймання не змінюється через транспорт.
- Вимірник ліміту й контексту — числа платформи чи її повідомлення про вичерпання.
