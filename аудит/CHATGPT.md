# Адаптер ChatGPT (Codex)

Ядро — `AGENTS.md`; договір — файл призначеної ролі. Тут лише механіка запуску (п.22).

- Codex — рушій обгортки ноутбука (власник 26.10: «Ми працюємо новим каналом кодекс, не через легасі, тут ніяких
  обмежень ні по моделях ні по розміру задач немає і бути не може»). Наряд, доробку й перевірку диспетчер ставить
  позначкою `gemini-queue/<наряд>/gpt-<модель>-<зусилля>/<спроба>` за `аудит/адаптери/gemini/ЧЕРГА.md`: рушій — `codex
  exec -m` у клоні під `gemini`, агент — виконавець за `AGENTS.md` і `аудит/ВИКОНАВЕЦЬ.md` з нарядом у промпті, гілку
  `gemini/<наряд>` публікує обгортка, рядок «GEMINI ОБГОРТКА: …» — диспетчерові. Модель — з `аудит/МОДЕЛІ.md` (назву для
  `-m` і фактичну модель Astra й Terra перевіряє перший наряд з кожною); розмір і вид наряду не обмежені: код, перевірка
  (наряд зі звітом у коміті, шаблон — `аудит/наряди/автоперевірка.md`), батарея. Координатора ChatGPT нема (власник
  20.10): окрема сесія виконує призначене, не бере черги й не чекає пробуджень.
- Легасі-канал Codex заборонено, бо там доступні лише старі моделі, а хмарний Codex не заборонено: хмарна задача Codex —
  дозволений канал, коли її фактична модель — з таблиці `аудит/МОДЕЛІ.md`; модель і шлях запуску перевіряє перший наряд,
  доти звичний канал — обгортка (менеджер 19.11 за словом власника 19.11). Хмарний Codex — носії з міткою `codex-cloud`,
  запуск, продовження, зупинку, CI, перевірку й злиття — веде диспетчер (`аудит/ДИСПЕТЧЕР.md`): роль диспетчера на
  стороні Codex, дану сесії «Dot» 19.11, знято — «Дот кодексу не справляється з роботою деспетчера» (власник 24.11).
  Широку роботу диспетчер дає Codex, а з менеджером на стороні Codex говорить текстом носія чи PR: «Запускай широку
  роботу в кодекс. За потреби комунікуй з менеджером кодекс» (власник 24.11).
- «@codex» у GitHub — легасі: нарядів, доробок і перевірок ним не запускають (менеджер 26.10 за словом власника 26.10);
  документація OpenAI відносить інтеграцію GitHub до «Codex Cloud (Legacy)», і проба 19.11 згадкою в issue відповіді не
  дала. Лишається рецензія PR — `аудит/ПЕРЕВІРКА.md`. Новий хмарний Codex запускають із застосунку ChatGPT («Work in →
  Cloud» — дія власника в його акаунті) чи `codex cloud` у CLI; перша така задача — проба.
- Команд коментарями в GitHub сесіям ChatGPT нема: коментар не створює сесію й не доводить доставку.
- Фото крамниць хмарі ChatGPT — 403: запит на очне приймання — через ноутбук; недоступний і він — блокер адресатові
  ролі. Поріг приймання транспорт не змінює.
- Вимірник ліміту й контексту — числа платформи чи її повідомлення про вичерпання.
