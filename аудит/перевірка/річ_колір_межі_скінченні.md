# Річ-колір-межі: скінченні H/C-грані біля V=0/10

2026-10-30 UTC. Вхідна голова `75ce5541e4983c68ceccd0570cd5933d22fc2b66`,
гілка `gemini/Річ-колір-межі`. Частина пункту 1 паспорта, наряд Р3.
Це власна числова перевірка виконавця; незалежного приймання сімей,
зшитої оболонки й продуктової зміни цей крок не заявляє.

## Зміна й мірило

Лабораторний метод `джерела/лабораторія/колір_сім_ї_скінченні.py`
породжує однойменний JSON для всього наступного геометричного класу:
скінченні H/C-грані з краєм V=0 або V=10, без уже перенесених C=0
та нижніх C<2-граней. Вибір за геометрією, без ручних ID.
У джерелі це **33 грані: 16 H і 17 C**.

ДО → ПІСЛЯ: точних процедурних відображень цього класу **0 → 33**;
відкладених граней **70 → 37**. Повний облік:
**123 попередні перенесення + 35 кінцевих описів + 6 нижніх часткових
відображень + 33 нові процедурні поверхні + 37 відкладених = 234**.
Ці доданки мають різні види подання; їхня сума не означає кількість
повних трикутних поверхонь. Попередні генератори й виходи не змінені.

## Метод та область

Кожна грань зберігає повний замкнений прямокутник джерела. Параметри
H-грані — V/C; C-грані — H/V. Для довільної точки всього прямокутника
`перетворити_грань` задає точний процедурний образ через попередній
метод Colour 0.4.6 renotation C → XYZ → Bradford D65 → Lab → чинне
коло художника. Нових формул простору, меж сімей та класифікатора немає.

Область часткового відображення — точки зі станом `визначено`.
Її доповнення повертає `невизначено` з причиною, без Lab або θ/L*/C*.
Перевірка області має дві послідовні частини:

1. Чинна гілка V після канонічного запису з 12 значущими цифрами:
   якщо бібліотечний `is_integer(V12)` істинний, потрібний овоїд
   `round(V12)` у 1…9; інакше `floor(V12)` має бути у 1…9.
   Площини V=0/10 відхиляються. Неціла гілка V>9 використовує
   верхній нейтральний V=10, тоді як округлення самого V до 10
   потребувало б відсутнього хроматичного овоїда.
2. Сам попередній метод: наявність потрібних renotation-даних та
   скінченність і невід'ємність XYZ. Очікувані `AssertionError`/
   `ValueError` методу дають явну невизначеність з текстом відмови.
   Помилки параметрів, іншого класу й неочікувані винятки поширюються
   викликачу. Стеля C сама по собі не вважається фізичною областю.

Підстава — [первинний код Colour 0.4.6](https://colour.readthedocs.io/en/v0.4.6/_modules/colour/notation/munsell.html),
функції `_munsell_specification_to_xyY`, `munsell_specification_to_xy`
та `xy_from_renotation_ovoid`; локальні файли зафіксовано транзитивними
SHA-256 LF. Предикат V звірено прямими викликами бібліотеки, зокрема
для сусідніх float обабіч порогів округлення. V та C не затискаються;
початковий V визначає Y, край не підміняється сусіднім кольором.

Це **процедурне** подання цілих часткових поверхонь: запит образу
обчислюється точним методом, свідки не інтерполюються. Межі області
не виводяться із сітки свідків. Немає нової похибки апроксимації
між пробами або нової заявленої межі похибки самого renotation.
Числові свідки в JSON округлено до 9 десяткових знаків попереднім
записувачем; вони служать відтворенню, не визначають поверхню.

## Перевірка

Вісім перевірок у `аудит/перевірка/річ_колір_межі_скінченні.py`:

- Незалежний вибір класу з усіх раніше відкладених граней, рівно
  33 нові; усі 234 номери без дублів і пропусків, у решти 37 — C=+∞.
- Повні вихідні параметричні області та їхні замкнені краї.
- **825** інших внутрішніх проб: **755 прийнять / 70 відмов**;
  області узгоджені з прямим Colour, Lab — з бібліотечними Bradford
  та XYZ_to_Lab (розходження <10⁻¹⁰).
- **990** проб округлення V: **453 прийняття / 537 відмов**,
  усі узгоджені з прямим методом, включно з V=0/10 і сусідніми float.
- **771** записаний свідок: **474 визначених / 297 невизначених**;
  найбільша різниця Lab через округлення — **7.62·10⁻¹⁰**.
- Транзитивне походження, відмова на підміну вже обробленого джерела
  та підміну попереднього артефакту.
- Явні відмови на непридатні параметри, C=0 та інший клас;
  неочікуваний RuntimeError не перетворюється на невизначений образ.
- **90** спільних точок H/C-граней та **21** проба циклічного
  шва H=1/101: образи тотожні. Це сумісність точного відображення,
  не доказ топологічного зшивання сіток.

## Відтворення

Із кореня, PowerShell, Python 3.12.10. Залежності із зафіксованого
`джерела/лабораторія/колір_сім_ї_контури.requirements.txt`:
Colour 0.4.6 / NumPy 2.2.6 / SciPy 1.15.3.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
python -m pip install --disable-pip-version-check --target "$env:TEMP\числові" -r джерела/лабораторія/колір_сім_ї_контури.requirements.txt
$env:PYTHONPATH="$env:TEMP\числові"

```

До використання попереднього обліку звіряються всі його класи, джерела,
номери та транзитивні SHA-256. Вихід містить хеш нового генератора,
попереднього методу/виходу та всього ланцюга залежностей. Точні
залежності встановлено в тимчасову теку задачі; вони не входять у коміт.

Запис, перевірка та повторне породження завершилися кодом 0;
повторний вихід побайтово збігся. JSON — **129 341 байт LF**,
SHA-256 `d56fb2f7ec14e3505ce29e40f943fa8a268b0921fb6fb0e8c9befe23db2a1e18`.
Попередні шість перевірок (поверхні, C-контури, H/V-контури, нейтраль,
кінці, низ) виконано одним послідовним пакетом із кореня, усі — код 0:
**8/8, 12/12, 10/10, 8/8, 6/6, 8/8**, разом **52 перевірки**.
