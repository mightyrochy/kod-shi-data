# 4920 — слово варіанта: результат виконавця для Claude

База: `54ec4bad4c351dea597b4c0dee0b1a7073bcc254`, PR #959, гілка `codex/4920-slovo-varianta`.
Стан: код і вимір передано на незалежну перевірку; **очний критерій заблоковано**, самоприймання немає.

Причина ж-02639@sunwin-store.com: артикул `2840 блакитний`, але в каталозі лише одна сестра;
поле бази `блакитний, бургунді`, повний `~колір` — `блакитний, бургунді, капучино, молочний, чорний`.
Сім'я виміру `срібний` вибирала `капучино`, хоча фото-вимір `#b0b3ad` (Lab 72.55, −2.17, 2.68)
лежить і у вікні слова `блакитний`; при C*=3.4 тон не розрізняється.
Тепер слово артикула, коли воно в переліку й тримає вимір, розрізняє перекриті вікна:
**капучино → блакитний**. Слова переліку спершу звіряються з чинним `verify.перевірити`,
світлотою самого слова й модифікатором світлоти; далі свідки — сім'я файла/виміру.
Єдине придатне слово може вибратись без збігу сім'ї. Коли однозначного кандидата нема,
старий свідок лишається для наступного суду спору. Нових слів, вікон чи порогів не додано.

## Факти виміру

`cd джерела && python3 проби/слово_варіанта_4920.py` — 35 рядків, без моделей і мережі.
Проба бере повний XML, поля з ≥2 непорожніми частинами через кому, той самий поділ обраного
слова, що споживач; порівнює базову й поточну `слово_варіанта` на тих самих даних.
Придатність збагачення й відкидання чужого кадру — чинні правила фіду.
Критерій невідповідності — вибране слово не читається лексиконом або `verify.перевірити`
відкидає вимір. Центр слова за неузгодженого hex позначено джерелом: це не піксельний вимір.

ФАКТ · ДО 196, ПІСЛЯ 174; змінених слів 29; без придатного збагачення 23
