## Незалежні CLI на справжньому тимчасовому Git

`qa-fixture.py` створює окремий локальний Git-репозиторій і запускає незмінений CLI через subprocess. Модуль, його функції та відповіді Git не підміняються. Код і реєстр сцен скопійовано через `git show` з перевіреної голови; SHA256 коду `0ffd411e32a589967b1b55f2e05a1c0e2fcc830cb363650bfa37194841a776fa`.

У Git є чотири чотирипольові `код.txt`: старий повний з фото, ближчий повний без фото, найближча розмова з оманливим заголовком «показ ПОВНИЙ», запис із таким самим заголовком і FOTO=1 без виконаного шляху.

- Режим реєстру `повне` обирає ближчий повний без FOTO=1; розмова й невідомий шлях виключені.
- `повне +фото` обирає старіший повний з FOTO=1; ближчий без фото виключено.
- `розмова` обирає найближчу розмову.
- Лише запис без доказу режиму: `без доказу режиму 1`, явне «Порівняння не виконано», exit 1.
- Для `функція` немає кандидата: exit 1. Невідомий параметр режиму: явна помилка аргументів, exit 2.
- Старий виклик лише з id сцени й виклик з явним SHA HEAD повертають однаковий вивід, exit 0.
- Перевірка рухомого ref: wrapper виконує справжній `git for-each-ref`, потім пересуває локальний ref на інший справжній коміт ще до наступного читання. CLI читає попередній SHA, обирає попередній сумісний запис; вивід байт у байт збігається з запуском без пересування. Трасування `git-moved-ref-trace.jsonl` підтверджує читання артефактів лише за SHA. Підсумок і конкретні SHA — `fixture-summary.json`.
