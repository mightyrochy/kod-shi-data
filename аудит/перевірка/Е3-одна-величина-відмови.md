# Е3-одна-величина, Г8 — відмови на дроті

Крок від `4f33b5c44c6943e4fa41ee6c37812f9d61cfa93b`, ризик Р3.
Величина — перелік `she_refuses`; клас паспорта — п.3, кілька писачів одного входу моделі.

## Що змінено

`дріт_моделі.межі_на_дріт` визначає перелік один раз: прибирає порожні
значення й крайні пробіли, кодує наявним словником `слово_межі`, усуває повтори
після кодування, зберігає порядок і незнайомі слова. Нових словників чи
продуктових меж немає. Складання, вердикт ремонту, вибору й повноти та опис
читають це визначення. Власних алгоритмів поза ним: 4 → 0 (обмеження,
вердикт, опис, перевизначення в уважному виборі).

Уважний вибір передає явні відмови у вхід пакета, перш ніж читати його дріт.
Тому оцінка речей і турнір успадковують також вилучення повтору, уже переданого
в `case.refusals`. Копіюються пакет і словник обмежень; вхід викликача не змінюється.
Відсутність окремого `she_refuses`, коли всі відмови вже є в `case.refusals`,
зберігає наявне стиснення пакета й не означає відсутності відмови.

## ДО → ПІСЛЯ

Незмінний прилад:

```text
python джерела/прилади/корінь_е3_одна_величина.py --тихо
місць: 272 → 268
п.3: 15 → 11
```

Решта пунктів: п.1 — 10, п.2 — 60, п.4 — 15, п.5 — 182. Прилад, його база
й храповик не змінені. Корінь і рядок 12011 залишаються відкритими.

```text
cd джерела
python проби/межі_одне_визначення.py
python проби/межі_записаний_дріт.py
```

Перша проба: 15 → 0 розбіжностей у 26 порівняннях. Шість читань дроту,
порожній перелік, відомі слова разом із їхніми кодами, дублікати, пробіли,
незнайома відмова; окремо — успадковані й явні відмови поряд із `case.refusals`.

Друга проба повторює відмови двох записаних запитів вибору сцени
`ж5_співбесіда_без`: архів
`аудит/перевірки/rozbir_0210/ж5_співбесіда_без/відповіді.tar.gz`,
виклики 19 і 27. У них `she_refuses` — `['підбори', 'чорний']`,
а `case.refusals` — `heels`, `black`; опис того самого запису вже несе коди.
Повтор через шість читачів: 8 → 0 розбіжностей у 12 порівняннях.
Це повтор записаного входу дроту, без повторного виклику моделі.

Наскрізний контроль на повному каталозі:
`cd джерела; python проби/межі_дріт_моста.py` — код 0.
На вході без паспорта з `жорстке_ні` та `межі` складання, вибір образу,
оцінка речей, турнір і опис несуть `['heels', 'dress']`. Відсутність
окремого поля в ремонті цього входу залишилась як раніше: цей викликач
не передає аргумент `межі`. Проба друкує це окремо; перевірка кодування
вердикта ремонту з явним аргументом є в короткій пробі вище.
Перша спроба наскрізної проби зупинилась через помилку її фікстури:
для ендпойнта опису брали `id` із пакета, який містить номер `н`.
Виправлена проба бере `id` з `кандидати`, повтор завершився з кодом 0.

Для відтворення ДО обох проб на тих самих залежностях можна виконати з кореня:

```python
import runpy, subprocess, sys, types
sys.path.insert(0, 'джерела')
for ім in ('дріт_моделі', 'уважний_вибір'):
    модуль = types.ModuleType(ім)
    sys.modules[ім] = модуль
    текст = subprocess.check_output([
        'git', 'show', '4f33b5c44:джерела/' + ім + '.py'
    ]).decode('utf-8')
    exec(compile(текст, ім, 'exec'), модуль.__dict__)
runpy.run_path('джерела/проби/межі_одне_визначення.py', run_name='__main__')
# Для другого виміру в окремому процесі замінити останній шлях
# на 'джерела/проби/межі_записаний_дріт.py'.
```

## Межі приймання

ЖИВИЙ ПІСЛЯ: ж5_співбесіда_без — чи її «тільки не чорне, і без підборів»
передається одними кодами у складання, вибір, повноту й опис, а оцінка речей
і турнір читають той самий перелік відмов?

Режим — повне; руки 1–2. `R_bez.json` уже містить цей другий хід;
нова сцена не потрібна. Оцінка речей і турнір додатково перевірені наскрізною
кодовою пробою; відповідний перемикач живого стенда — `MODEL_VYBIR=оцінка`
чи `MODEL_VYBIR=турнір` (`рв6_стенд.js`, розділ «Уважний вибір речей»). `живі_до.py ж5_співбесіда_без 4f33b5c44` не знайшов
сумісного повного прогону на предку серед 26 refs. ДО доведено кодом
і наведеними записаними входами; нового живого ДО не виконано.
Краще — відомі відмови кодами `heels`, `black` на всіх читачах дроту,
без повторного сирого перезапису; повтор у `case.refusals` може бути стиснений.
