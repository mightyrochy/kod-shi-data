## Що змінено

Довжини Python беруться з повернених текстів функцій та аргументів транспорту повідомлень моделі.
Розбір проходить локальні присвоєння, імпорти, виклики збирачів, `join`, `+`, `%`, f-рядки,
`replace`, генератори й вкладені реєстри. Невідомий вхід має порожній текст, невідомі умови — окремі варіанти.
Ідентифікатори варіантів не залежать від номера рядка джерела.

Оголошення проходять продуктовий збирач із маркерами всіх оголошених полів. Маркери значень вилучено з довжини;
ключі, описи, роль, правила, схема та фрази формату лишаються. Це вимір сталої частини виклику, а не довжини
конкретної розмови, фотографій чи каталогу. Вимоги п.1–4 шукаються також у розгорнутих текстових значеннях JSON.
Повтори всередині виклику й ознаки суперечності порівнюються в межах його тексту.

Описи наявності вхідних даних і зображень відсіюються перед лексичним детектором, зокрема в довірених промптах.
Опис `The occasion is not known yet.` більше не є повтором вимоги.

## Залишкові вади

- **11371:** повторний облік розгорнутої вимоги `жнива_збагачення.py:100`; хибна адреса джерела
  `внутрішня_мова.py:2155`. Атрибуція розгорнутого речення зараз наближена, за словами шаблону.
  Обхід умов завершується діагностикою після 256 станів; неповністю розгорнуто
  `заміна_речі.py:87`, `пакет_моделі.py:726`, `:728`, `:786`, `паспорт_нагоди.py:1264`,
  `приміряння.py:130`, `руки_без_коду.py:383`. Це обмеження виміру варіантів, а не доказ відсутності вимог.
- **11372:** JS-повтори `показ/оцінка.js:384`, `:484` і `показ/паспорт.js:116` додаються до тексту,
  отриманого з Python. Довжини Python і двох JS-сталих виміряні окремо; прилад поки не зв'язує обидва боки
  в повну довжину повторного виклику. Вимоги JS бачить лексичний шлях А. Це залишкова форма збирання,
  а не виправлена частина інваріанта «кожен промпт коротший».

## Перевірки

Середовище: Python 3.12.10 локально; CI використовує Python 3.11, його перевіряє диспетчер після публікації.
Самоперевірка п.1–4: 7/7; проба доповнення: 4/4. Повний вивід лічби ДО —
`Е2-промпти-доповнення-до.txt`, ПІСЛЯ — `Е2-промпти-доповнення-вивід.txt`.

```text
python джерела/прилади/храповик_кореня.py --база 8363e96997475c6cacf0f845778ca663344ad492
корінь Е2-промпти: місць 137 → 137
зелений: червоних 0
```

Повний вивід — `Е2-промпти-доповнення-храповик.txt`; код виходу 0, тривалість 744,7 с для всіх чотирьох коренів.
Прямий прогін приладу з `PYTHONHASHSEED=1` — код 0, 137 місць за 75,5 с; те саме число відтворено
храповиком на обох деревах. Формат дошки: 2 нові рядки, 1 зміна стану, 0 помилок. `py_compile` і
`git diff --check` пройшли.

Батарея виконувалась одним послідовним запуском із теки `джерела/` до останньої команди.
На Windows перший запуск `розділи_гейтів.py` зупинився у §120: вкладений UTF-8-вивід читався системним
кодуванням, що дало `UnicodeDecodeError`, а потім `stdout=None`. Для повтору ввімкнено `PYTHONUTF8=1`.
Перший запуск тесту показу не мав `jsdom`; середовище підготовлено командою CI
`npm ci --ignore-scripts --no-audit --no-fund` із lock-файла. Код цих тестів і lock-файл не змінювались.
Повторювалися лише ці дві команди після виправлення середовища.
