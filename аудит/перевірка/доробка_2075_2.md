## Що змінено

Власник формату — `джерела/колір_річ.py`: тип, справжня Lab-точка, збережений hex,
межі інтервалу, провенанс і перевірка явного `colors`. Читачі продукту, приладів,
проб та оглядів звертаються до цього API. `hex_кольору` віддає hex лише виміру;
інтервал із залишковими hex/Lab і невідомий тип не стають точкою.
`вікно_кольору` відрізняє інтервал від точкових меж. Відсутність hex не ламає
аркуші: `прилади/колір_звіту.py` форматує справжню Lab-точку або всі межі.
Контрфактичний центр у діагностиках рахується явно з меж і не записується виміром.

Продукт змінено за відтвореними вадами. На історичному тілі `приміряння.опис_речі`
інтервал і невідоме з залишковим hex передавали його моделі: **2 → 0**;
справжній вимір тотожний. На реальній масці **1600 сірих пікселів** фото-результат
віддавав Lab і `#808080` за невідомого тону. Тепер браузерні `lab`/`hex` порожні;
L*53,59, C*0…8,6, невідомий тон і весь сирий опис поверхні збережені.
Доказ: [межа_продукту.py](2075-2/межа_продукту.py),
[межа-продукту.json](2075-2/межа-продукту.json).
Порівняно точні історичні тіла функцій з основи за тих самих нинішніх залежностей;
це локальне відтворення межі, не окремий живий прогін моделі.

## Кожне місце читання ДО → ПІСЛЯ

[межа-інвентар.md](2075-2/межа-інвентар.md) перелічує файл і рядок кожного
hex-кандидата та кожного обходу інших полів; [JSON](2075-2/межа-інвентар.json)
додає вираз, функцію й контекст. Відтворення:

```powershell
python -X utf8 аудит/перевірка/2075-2/межа_інвентар.py
```

Одиниця Python — AST-вузол читання `[...]` або `.get(...)`, записи відділені;
JS/HTML — текстові кандидати `.hex`, `.lab` і відповідних індексів.
За цим явно визначеним методом початкова лічба **121/258** з наряду має інший
знаменник: тут Python — **119 файлів, 277 hex-читань**;
разом із JS/HTML — **129 файлів, 320 hex-кандидатів**.
Усі вони класифіковані: **170 — колір варіанта,
150 — інше**. Лічба не підганяється під число пошуку з наряду.

Для всіх полів формату (`hex`, `lab`, тип, провенанс, невідомість, вікно)
обходів спільного читача: **604 → 0**.
Залишені прямі hex-кандидати: **174**, з них **8 у власнику API**,
**166 — інші формати**. Це палітри, риси обличчя,
сирі піксельні осі до запису речі, зафіксований історичний алгоритм колонки ДО,
перевірки сирого формату та проєкції API для показу.
Наприклад, у `pair_test.py` дев’ять `hex` — словник шкіра/волосся/очі;
три функції профілю повернені AST-тотожно до бази, два читання кольорів речей
ідуть API ([доказ](2075-2/формат-профілю.json)). Список винятків і причини відкриті
у приладі інвентарю; невідомий читач за замовчуванням рахується обходом.

Міграція охопила не лише початковий `поверхня_212.py`, а й текстовий шлях речі,
фото-порівняння, порядок пулу, історичні порівняння, колірні проби, огляди
`аудит/проби/` та продуктові проєкції. Усі **180** змінених Python-файлів
