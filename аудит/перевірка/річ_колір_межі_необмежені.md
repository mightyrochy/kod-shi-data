2026-10-30 UTC. Вхідна голова `b10012d168c30bd0c3c6ac1200d62c94cce16112`,

Це власна перевірка виконавця; незалежне приймання сімей і зшивання

## Зміна й мірило

Лабораторний метод `джерела/лабораторія/колір_сім_ї_необмежені.py`
породжує однойменний JSON. Геометричний вибір охоплює всі решту
**37 граней з C=+∞: 26 H та 11 V**, без ручних номерів.
Для H-грані параметри — V/C, для V-грані — H/C.
Скінченний інтервал першого параметра й нижній край C замкнені;
нескінченність позначає відкритий напрямок, не точку або колір.

ДО → ПІСЛЯ: процедурних відображень цього класу **0 → 37**,
відкладених граней **37 → 0**. Повний облік:
**123 попередні перенесення + 35 кінцевих описів + 6 нижніх часткових
відображень + 33 скінченні процедурні поверхні + 37 необмежених = 234**.
Це різні види подання; число не означає зшитих трикутних поверхонь.

## Метод та область

Довільна скінченна C ≥ нижнього краю передається попередньому
перетворенню без затиску. Область задає стан чинного renotation C →
XYZ → Bradford D65 → Lab → коло художника. Предикат V, включно з
канонічним записом 12 значущих цифр та округленням, читається з
попереднього методу скінченних граней.

Наявність даних та скінченність і невід'ємність XYZ перевіряє саме
перетворення. Очікувані AssertionError/ValueError дають
`стан=невизначено` з причиною й без Lab/θLC. Непридатні параметри,
інший клас грані та неочікувані винятки поширюються викликачу.
Стелю C з проб або припущення про монотонність області не виводимо.
Підстава — [первинний код Colour 0.4.6](https://colour.readthedocs.io/en/v0.4.6/_modules/colour/notation/munsell.html).

Процедурне подання не інтерполює свідків, тому додаткової похибки
апроксимації між ними немає. Похибка самого renotation не доведена;
попередні апроксимації цим кроком не стали точними або зшитими.
Нових формул простору, сімей та продуктових читачів не додано.
