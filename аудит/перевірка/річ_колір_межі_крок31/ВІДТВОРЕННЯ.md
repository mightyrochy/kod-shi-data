# Стенд кроку 31

ДО — `main` 1be84bd3b8e90c2101916e402d1f004ceb87d635, до правок цієї гілки; знято незміненим
`аудит/перевірка/річ_колір_межі_крок30/пул_металу.py`. ПІСЛЯ — реалізація 1e9e0f62238; скрипт `пул_металу.py` тут
повторює той самий вхід, додаючи до виходу метал палітри та повідомлення про завершений прогін у stderr.
Контрольні суми входу й каталогу — `джерела_виміру.txt`.

Обидва виміри проходять `bridge.виклик("паспорт")` → `bridge.виклик("запити")`, використовують `стенд_вх.json`,
повний каталог, паспорт моделі з `тест_живого_шляху`, conventional, сід 4242. Шість входів: самозвіт відсутній /
золото / срібло × гілка «—» / 0. Моделі й платні API не викликаються. Пул знято в місці виклику композитора до
семплера; знаменник — перші п'ять кандидатів семи ювелірних слотів, як на кроці 30.

З кореня репозиторію:

```python
import subprocess, sys
from pathlib import Path
тека = Path("аудит/перевірка/річ_колір_межі_крок31")
with (тека / "пул_після.json").open("w", encoding="utf-8") as файл:
    subprocess.run([sys.executable, "-W", "ignore", str(тека / "пул_металу.py")], stdout=файл, check=True)
subprocess.run([sys.executable, str(тека / "порівняти.py")], check=True)
subprocess.run([sys.executable, str(тека / "контроль.py")], check=True)
subprocess.run([sys.executable, str(тека / "батарея.py")], check=True)
```

Для стенда й батареї на Windows: `PYTHONUTF8=1`. Прилад кореня й храповик запускаються з `PYTHONUTF8=0` та
`PYTHONIOENCODING=utf-8`: вкладений Python `-I` ігнорує змінні середовища й повертає таблицю в Windows-1251;
батьківський процес мусить декодувати її тим самим кодуванням, а власний звіт пише в UTF-8. Код приладів не змінено.
Для приладу ДО викладено `джерела/` саме коміту ДО в тимчасову теку задачі й передано її шлях аргументом; для ПІСЛЯ
передано поточне дерево. Храповик: `джерела/прилади/храповик_кореня.py --пр --база origin/main`.

`контроль.py` окремо перевіряє ранги й мітки для всіх трьох температур, обидві заяви та перевагу явного бажання,
чергування з рангом кольору 1/2/3, повтори слів, дедуплікацію, вичерпання одного роду, порожній пул і незалежність
A14 та суду металу від старих непевних полів. Металеві речі в цьому контролі мають також виміряний колір, який
влучає в кольоровий рядок: він не переводить їх до роду кольору.
