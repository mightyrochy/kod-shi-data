## Обсяг і подання

`джерела/лабораторія/колір_сім_ї_контури.py` читає попередній вихід методу
`колір_сім_ї_межі.json`. Обирає весь визначений клас: грань сталої C > 0,
обидва кінці V строго між 0 і 10. Це **41 з 234 граней**, без ручного
переліку ID у генераторі. Решта **193** зберігаються в обліку з причиною
відкладення. Коди сімей та орієнтацію обох боків читає з вхідного файла.

Кожну обрану грань покривають повні параметричні прямокутники H/V.
Початковий поділ — у вузлах renotation 2.5H та цілого V; далі адаптивний.
У кожній ділянці два трикутники **Lab**, порядок кутів 00,10,11,01,
діагональ 00–11. Усередині θ/L*/C* обчислюється з інтерполянта Lab
чинними `lch` та `у_коло_художника`; записані θ/L*/C* кутів не можна
інтерполювати окремо. Локальне розгортання θ зберігає шов 0°/360°.
Це параметризована апроксимація поверхні, ще не замкнена зшита оболонка
всіх сімей і не виконуване визначення належності продукту.

Перенесення використовує **Colour 0.4.6**, NumPy **2.2.6**, SciPy **1.15.3**.
Залежності зафіксовано в `колір_сім_ї_контури.requirements.txt`; продуктових
залежностей не додано. Артефакт містить SHA-256 LF-текстів вхідної поверхні,
генератора, алгоритму й повної renotation-таблиці Colour та чинних модулів
Lab, Bradford, освітлювачів і кола художника. Породження після встановлення
залежностей працює офлайн. Дані не переписано вручну.

## Джерело і координати

[RIT, пояснення renotation та all.dat](https://www.rit.edu/science/munsell-color-science-lab-educational-resources)
рекомендує повну таблицю для інтерполяції біля краю області й застерігає,
що серед її вузлів є екстрапольовані, фізично нереальні кольори.
Це не виміри сучасної книги Манселла. Використана таблиця входить до
[Colour 0.4.6, all.py](https://github.com/colour-science/colour/blob/v0.4.6/colour/notation/datasets/munsell/all.py).
Фізичну досяжність тканини чи екранний гамут цей вихід не засвідчує.

[Алгоритм Colour 0.4.6](https://github.com/colour-science/colour/blob/v0.4.6/colour/notation/munsell.py)
перетворює позначення Манселла за ASTM у xyY під C, із поправкою шкали
MgO вже у світлоті ASTM. Тому вихід бібліотеки повторно на 0.975 не
множимо. ASTM H не зсувається на одиницю: 1 → 1R, 10 → 10R,
100 → 10RP, 101 → 1R. Далі xyY → XYZ C → Bradford D65 → єдиний
`from_xyz` → `lch` → чинне відображення кола художника. Саме відображення
кола не переоцінено й новим джерелом практиків тут не оголошено.

Область перевіряється за стелею renotation на кожному початковому
прямокутнику: до V=9 це мінімум чотирьох вузлів H/V, сталий усередині
інтерполяційної смуги; вище 9 мінімум береться на верхньому V, де стеля
монотонно падає. C=0, V=0/10 та необмежені C-промені цим кроком не
екстраполюються. Пряме перетворення непридатних координат відмовляє.

## Контроль похибки та межа висновків

Числові цілі: **0.1 ΔLab76 / 0.25° θ / 0.1 L* / 0.1 C***.
Це цілі апроксимації, не вимір згасання сім'ї, не похибка фото й не
допуск «того самого тону». На кожній ділянці 13 контрольних проб
(сітка 1/4, 1/2, 3/4 та середини країв); поділ приймається з подвійним
запасом до цілей. Ще чотири точки з координатами
0.211324865405187 / 0.788675134594813 не беруть участі у виборі поділу.
Непроходження цих проб або вичерпання глибини завершується відмовою,
без запису успішного артефакту. Перевірка повторно читає вже округлений
JSON та додає інші точки кожної грані.

Усі ці похибки **вибіркові**. Доведеної верхньої межі між пробами тут
немає. Адаптивні ділянки можуть мати висячі вузли; розходження їхніх
інтерполянтів на стиках виміряно окремо. Топологічне зшивання ділянок і
перетинів різних граней ще потрібне перед замкненими областями.
Математично гарантовану похибку, повноту всього θ/L*/C*-тіла та
людське приймання цим результатом не заявляємо.

Перший варіант окремо лінійно інтерполював θ/L*/C* та Lab. На зламах
чинного відображення кола це дало 1 189 ділянок на грані 171 і 474
на грані 176. Прогін зупинено до повного виходу; подання замінено
обчисленням θ/L*/C* із Lab. За тих самих цілей ці грані мають відповідно
130 і 48 ділянок. Пороги під сім'ю не змінювалися.

## Відтворення

Використано Python 3.12.10 на Windows. З кореня репозиторію, після встановлення
числових залежностей у тимчасову теку задачі:

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
python -m pip install --target "$env:TEMP\colour-deps" -r 'джерела/лабораторія/колір_сім_ї_контури.requirements.txt'
$env:PYTHONPATH="$env:TEMP\colour-deps"
python 'джерела/лабораторія/колір_сім_ї_контури.py' --записати
python 'джерела/лабораторія/колір_сім_ї_контури.py'
python 'аудит/перевірка/річ_колір_межі_контури.py'
python 'аудит/перевірка/річ_колір_межі_поверхні.py'
python 'джерела/прилади/корінь_річ_колір_межі.py'
```

Незалежна від числової схеми перевірка покриття розбиває прямокутник
на всі відкриті H-смуги й звіряє повний неперекривний ланцюг V-інтервалів.
Перетворення Bradford/Lab репозиторію зіставляється з окремою реалізацією
Colour. Синтетична поверхня з точними кутами й вигином усередині перевіряє,
що генератор не підміняє поверхню її кутами. Окремо перевірено шов,
відмови, походження та облік усіх вихідних граней.

## Що лишилось

Решта 193 граней: H/V-грані з необмеженими C-променями, нейтральна вісь
та кінці V=0/10. Далі потрібні зшивання й контроль між пробами, незалежний
розгляд таблиці сімей, вимір згасання й температури, одне виконуване
визначення та переведення всіх читачів. Розподіл каталогу з поясненням
переходів, 40 граничних свотчів очима й живе приймання не виконувалися.
Корінь і наряд залишаються відкритими.
