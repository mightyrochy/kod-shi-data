## 3. Детальний розбір Т2 (п.4 наряду): хто знімає нагоду — шов шару чи модель, і що лишає 8760 відкритим

У точці Т2 випробувано дві сцени: `ж2_йога_зранку` (вхід *«йога зранку»*, прогони `D/02` та `E/01`) і `ж2_спорт_коментар` (вхід *«йога зранку, потім кава з подругою»*, прогони `A/02`, `C/02`, `C/03`). На обох сценах у паспорті після розмови `нагода: null`, але механізми втрати різні.

### 3.1. Сцена `ж2_йога_зранку` (`D/02`, `E/01`): діють модель і шов шару разом

1. **Вихід живої моделі** (`D/02/VIDPOVIDI/seed3_01_мовний_шар_хід_розмови.txt`, рядки 414–434; тотожно в `E/01/VIDPOVIDI/seed3_01_мовний_шар_хід_розмови.txt`, рядки 534–552):
   ```json
   "update": {
     "occasion": {"quote": "йога зранку", "value": "sport"},
     "occasion_part": {"quote": "зранку", "value": "other"},
     "movement": {"quote": "йога", "value": "walk"},
     "formality": null,
     "part_of_day": {"quote": "зранку", "value": "morning"}
   }
   ```
   Попри додане в #1558 уточнення в `_ПОЛЯ_EN["occasion_part"]` (`джерела/мовний_шар.py:2902`: *«A clock time or morning/evening is not a different activity: yoga in the morning is still sport»*), жива модель `mamaylm-gemma-3-12b-it-v2.0` все одно записує слово `"зранку"` одночасно і в `part_of_day: "morning"`, і в `occasion_part: "other"`, а для `"йога"` ставить `"movement": "walk"` та `"formality": null`.

2. **Шов мовного шару поруч** (`джерела/мовний_шар.py`, рядки 2051–2060):
   ```python
   конфлікт_нагоди = в.get("occasion_part") == "other" and в.get("occasion") == "sport"
   if конфлікт_нагоди:
       в = {к: x for к, x in в.items() if к != "occasion"}
       _журнал_паспорта(
           "occasion_part_conflict", step="layer", field="occasion",
           model_said="sport", occasion_part="other", code="not_taken",
       )
   elif в.get("occasion") == "sport" and not в.get("movement"):
       в["movement"] = "sport"
       цит["movement"] = цит.get("occasion") or ""
   ```
   Шов `конфлікт_нагоди` безумовно видаляє `occasion: "sport"`, щойно бачить `occasion_part == "other"`, не перевіряючи, що цитата `occasion_part` (`"зранку"`) — це та сама пора доби (`цит.get("part_of_day") == "зранку"`), а не друга подія. Гілка `elif в.get("occasion") == "sport" and not в.get("movement"):` стоїть під `elif` і ніколи не виконується при `occasion_part == "other"` (до того ж модель сама заповнила `movement: "walk"`). У лозі (`D/02/лог.txt:30`, `E/01/лог.txt:30`) фіксується:
   ```text
   passport · occasion_part_conflict · step=layer · field=occasion · model_said=sport · occasion_part=other · code=not_taken
   ```

3. **Побічний наслідок у репліці (нова вада 9870)**: після видалення `occasion` у словнику `в` залишаються `"occasion_part": "other"`, `"movement": "walk"`, `"part_of_day": "morning"`, які передаються в `recorded` промпта `РЕПЛІКА` (`E/01/VIDPOVIDI/seed3_02_мовний_шар_репліка.txt:481`). Модель читає `"occasion_part": "other"` буквально й відповідає жінці в чаті (`E/01/лог.txt:26`):
   > *«Так, я підтвердила, що ти шукаєш образ для іншої нагоди вранці. Розкажи мені детальніше про цю подію — куди саме ти йдеш?»*

4. **Розбіжність у доказах PR #1558**: у коміті 1 PR #1558 (`2dc95bc0`) перевірку `конфлікт_нагоди` було замінено на `if в.get("occasion") == "sport" and not в.get("movement"): в["movement"] = "sport"`, на чому був записаний файл `аудит/проби/3.2-Б/каталог-після.txt` (`Паспорт {"нагода": "спорт", "рух": "спорт"}`). ### 3.2. Сцена `ж2_спорт_коментар` (`A/02`, `C/02`, `C/03`): модель порушує тип `occasion.value`

На вході з двома подіями (*«йога зранку, потім кава з подругою»*) в `A/02/VIDPOVIDI/seed3_01_мовний_шар_хід_розмови.txt:619-628` модель повертає список у полі `occasion.value`:

### 3.3. Що саме лишає рядок 8760 відкритим

## 4. Детальний розбір Т4 (п.5 наряду): чому формат «невідомо» в паспорті і звідки взявся `K-WEA-02`

   Отже, в паспорті й пакеті `C/04` формат справді **`"невідомо"` (`"setting": "unknown"`)**, а в `day` ключа `"setting"` немає взагалі.
