## 3. Ризик поза мірилом

1. **Керування процесами та ресурси ОС**:
   - `запустити_крамниці()` запускає кожен процес у режимі `start_new_session=True` на POSIX-системах, що ізолює піддерево процесів крамниці.
   - Функція `вбити_процес()` примусово зачищає нащадків: на Windows — через `taskkill /F /T /PID <pid>`, на Linux/macOS — через надсилання `os.killpg(proc.pid, signal.SIGKILL)`, після чого виконується `proc.wait(timeout=5)`. Процеси-сироти та зомбі не утворюються.
2. **SQLite-з'єднання**:
   - Утиліти `залишок()` та `черга()` в [`zhnyvarka/обхід.py`](file:///C:/Users/gemini/gemini-runs/w/agy-4/zhnyvarka/обхід.py) відкривають з'єднання до бази SQLite із гарантованим закриттям через блок `try ... finally: з.close()`. Витоків дескрипторів немає.
3. **Кросплатформність (Windows / Linux)**:
   - Обробка сигналів, кодування UTF-8, використання `sys.platform == 'win32'` перевірені та безпечні для обох середовищ.
4. **Цілісність залежних компонентів**:
   - Змінений інтерфейс не зачіпає пайплайн генерації чи показ. `ШАПКА_ЗВЕДЕННЯ` синхронізована між модулями жниварки.
   - Жоден гейт, контракт чи ліміт не послаблено.
