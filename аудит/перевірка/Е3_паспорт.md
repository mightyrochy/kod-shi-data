Початкові місця обходів: `джерела/паспорт_нагоди.py:1438`, `:1825`;
`джерела/показ/бібліотека.js:51`, `:58`, `:81`, `:144`; `джерела/показ/випадок.js:47`, `:49`.
Це два виходи писаря, три місця створення фактів у показі та три зміни плоских полів погоди повз картку.
Внутрішні змінні розбору — кандидати; назовні повертається паспорт після спільного завершення.
Копіювання вже записаної картки для збереження чи відновлення не є новим фактом.
Писарі й шви `мовний_шар.py` (ПС-10) за межею цього наряду; файл не змінено.

Тепер обидва виходи виклику 0 проходять `_завершити_паспорт` → `картка_запиту.завершити`.
Власник відновлює попередню картку, судить кандидатів і застосовує явні дотики. Поточне прочитання моделі має
джерело `reading`, дотик — `hand`, типове — `default`, підтверджене її слово — `her` з уривком.
Сильніший факт відновлює також свою цитату, а новий ручний факт знімає давню цитату. Значення факту й плоска
проєкція мають незалежні вкладені списки та словники.

Показ створює факти через `записатиФактП`; силу джерел і службові поля одержує з Python.
Той самий записувач оновлює сумісні поля й цитати поточного паспорта: обрання відчуття погоди чи числа
не залишає старого факту в його картці. Початковий структурований вибір без давньої картки мігрується як
`hand`, якщо поле не позначене типовим; за наявності картки сама різниця плиток не створює дотику.
Опис полів експортує також поля без елементів форми: відновлення більше не обмежене видимими плитками.
Групи довідника й ознака числового поля для `показ/паспорт.js` походять із того самого опису.
Спільний читач типового в Python довіряє картці перед старою сумісною міткою: типове не стає названим через
`джерело_полів=her`, а ручний нуль не стає типовим через давню `form_default`.

Лічбу відтворює одна команда для обох версій:

```powershell
python аудит/перевірка/Е3_паспорт_лічба.py <корінь_версії>
```

Для ДО використано окреме незмінене дерево `origin/main`; для ПІСЛЯ — поточне дерево.
Числа й початкові адреси: `Е3_паспорт_ДО.json`, `Е3_паспорт_ПІСЛЯ.json` поруч зі звітом.
