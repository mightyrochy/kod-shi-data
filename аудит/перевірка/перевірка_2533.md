# Перевірка #2533 (Е2-вікно, крок 3)

Голова `6a848ce8…`; Р3 (наряд назвав) — код, що міняє вхід моделі; процесні частини (паспорт, дошка) — Р0.

## Дефект (11738)
`джерела/каталог_розбір_прогін.py`, `_вмістити_у_вікно`: `запис = dict(…, оцінка_сира_т=сира, …)` складено до скорочення опису; `надіслати`
вчить `_ПОПРАВКИ[модель] = prompt_tokens / оцінка_сира_т`, а `prompt_tokens` — рушія для вже СКОРОЧЕНОГО тіла.

Вимір цієї перевірки (команда — дослівно):
`cd джерела && python3 -I -` з `К._ВІКНА['m']=6144`, тіло `max_tokens=1500`, опис із 900 речень:
```
промпт скорочено до вікна: опис без 628 останніх речень · tokens≈15596→4631 + max_tokens=1500 ≤ window=6144
{'вікно': 6144, 'стеля_виводу': 1500, 'оцінка_сира_т': 15596, 'оцінка_до_т': 15596, 'скорочено_речень': 628, 'оцінка_т': 4631}
оцінка скороченого тіла: 4631
```
Рушій для надісланих 4631 т. (оцінка) дасть `prompt_tokens`≈4 600 → поправка ≈ 4 600/15 596 ≈ 0,30 (розрахунок, не вивід рушія).
Наступна річ з таким самим довгим описом: 15 596 × 0,30 ≈ 4 700 + 1 500 < 6 144 — скорочення НЕ спрацює, іде повний
промпт ≈ 15,6 тис. т. — HTTP 400, тобто стара відмова, яку крок мав прибрати; поправка при цьому отруює всі подальші речі
прогону. Фальшивий сервер автора такого не бачив: вимір — одна річ за раз, без другої довгої після скороченої.

Виправлення: `оцінка_сира_т` після скорочення = оцінка тіла, що йде (`_оцінка_промпта(тіло)`), `оцінка_до_т` лишити для годинника.
