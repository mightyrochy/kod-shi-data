# Річ-колір-межі: повна нейтральна C=0-грань

2026-10-30 UTC. Власна числова перевірка виконавця, не незалежне приймання.
Вхідна голова `fbcf0f944590b25ff9017aac9c610c99c61f20d7`;
гілка `gemini/Річ-колір-межі`. Частина першого пункту паспорта,
наступний завершений клас із 112 відкладених граней.
Ризик наряду Р3; цей крок — лабораторія, без зміни поведінки продукту.

## Обсяг і метод

Генератор `джерела/лабораторія/колір_сім_ї_нейтраль.py` вибирає
всі грані з віссю C і координатою 0, без ручних ID. У джерелі це
одна грань: H=1…101, V=0…10, боки `null` / `achromatic`.
Усі значення H тут описують ту саму нейтраль, тому вихід має
вимірність 1: повна крива за V із замкненими кінцями 0 і 10.
Поверхні V=0/10 з додатним C цим перенесенням не закрито.

Метод читає нейтраль `N(V)` із Colour 0.4.6 ASTM renotation,
перетворює xyY у XYZ, далі Colour дає Lab під чинним білим C,
а `colorspace.адаптувати_освітлювач` — чинний Bradford у Lab D65.
Це той самий математичний шлях, що для попередніх граней,
із проміжним Lab під C для повторного використання адаптера.
Нової реалізації Bradford, формул Lab або правил сімей немає.
Y береться як є: повторної поправки MgO немає, N10 має Y=1.
Нейтральна гілка, її білий і ASTM-яскравість —
[первинний код Colour 0.4.6](https://colour.readthedocs.io/en/v0.4.6/_modules/colour/notation/munsell.html).

У вузлі записано `[Lab, [null, L*, C*]]`. θ явно невизначений за
C джерела=0; кутову похибку тут не рахують. Чинні білі C в renotation
та в продукті мають різну точність, тому після адаптації лишається
мала C*: максимум **0.007103031**. Цей залишок збережено, без
примусового занулення a*/b* чи вигаданого тону нейтралі.
Це подання виродженої грані, не нове правило нейтральності продукту.

Інтерполюється тільки Lab. Початковий поділ — у цілих V;
подальший — адаптивний із цілями попереднього методу
**0.1 ΔLab76 / 0.1 L* / 0.1 C***. Три контрольні проби приймаються
з подвійним запасом; дві інші проби не беруть участі у виборі поділу.
Повне покриття інтервалу й тотожність вузлів усіх стиків звірено.
Контроль похибки вибірковий: доведеної межі між пробами ще немає.

Перед використанням попереднього обліку звірено склад C/H/V-класів,
джерела кожної грані, повне розбиття 234 номерів та транзитивні
SHA-256 LF. Попередні генератори й артефакти не змінені.
Походження нового виходу включає його алгоритм, вихід H/V-граней,
числові методи бібліотеки й попереднє походження перетворення.
Залежності зафіксовані в чинному
`джерела/лабораторія/колір_сім_ї_контури.requirements.txt`.

## Відтворення

Із кореня, Python **3.12.10**, із `PYTHONUTF8=1`,
`PYTHONIOENCODING=utf-8` та встановленими лабораторними залежностями:

```powershell
python джерела/лабораторія/колір_сім_ї_нейтраль.py --записати
python джерела/лабораторія/колір_сім_ї_нейтраль.py
python аудит/перевірка/річ_колір_межі_нейтраль.py
python аудит/перевірка/річ_колір_межі_поверхні.py
python аудит/перевірка/річ_колір_межі_контури.py
python аудит/перевірка/річ_колір_межі_контури_hv.py
python джерела/прилади/корінь_річ_колір_межі.py
```

Числові залежності встановлено у `$env:TEMP\числові`,
`PYTHONPATH` указує туди. При передаванні українського коду
в stdin Python через PowerShell потрібен також UTF-8 у
`$OutputEncoding`: початкова дослідна команда без нього отримала
`SyntaxError` через заміну кирилиці на `?`; після встановлення
кодування дослід завершився. Алгоритм перенесення не відмовляв,
числові цілі не послаблювали.

## Результат

Повне перенесення нейтрального класу **0 → 1**, вихід —
**12 відрізків**. Загальний облік перенесених граней **122 → 123**,
відкладених **112 → 111**. Повторне породження без `--записати`
завершилося кодом 0 й побайтово збіглося зі збереженим LF-виходом.
Артефакт `джерела/лабораторія/колір_сім_ї_нейтраль.json` —
**24 984 байти**, SHA-256:
`56490f95d14c082f2f5af4bb7f081d95bf8695db5457e4a1f088d210c1941c81`.

Окремо звірено границю C→0 попереднього хроматичного методу:
H=1,11,…,101 та V=1,2.5,5,7.5,9,9.5, разом **198 проб**.
Максимальні розходження Lab для C=10⁻⁴ / 10⁻⁶ / 10⁻⁸:
**0.000920253 / 0.000009203 / 0.000000092**.
Це вибіркова узгодженість границі, не зшивання всіх оболонок.
Чорний має Lab=(0,0,0); білий — L*=100.000024261,
збережену залишкову C* та відсутній θ. Світлота строго зростає
на 1 001 пробі; непридатні V явно відхиляються.
Усі **8** нових перевірок пройшли.
