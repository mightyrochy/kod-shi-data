## Регресія: законні пояснення карток стають «— без тексту» (11290)

Корпус серії 2 (`б1/ДО-2710/*/знімки/картки.txt`, 30 сцен) прогнала крізь сторожа голови:

```
$ node аудит/перевірка/2242/сторож_корпус.js джерела б1/ДО-2710/*/знімки/картки.txt
{"translated":1270,"latin_remainder":4,"polite_form":2}
```

Два `latin_remainder` — це назви речей, які йдуть `назваЖінціП`, тож для екрана вони не важать. Два інші —
пояснення:

- сцена 06: «Я замінила твою сумку … Сromia MINA …»;
- сцена 28: «… пальто casual …».

В обох названо її власну чи зняту з образу річ. Шар такі слова прийняв (`своїВходуП`), а екран їх не знає.
Два `polite_form` — справжні «ваш».

Те саме в Chromium 390×844 на двох збірках `показ-повний` з повним каталогом:

```
$ node аудит/перевірка/2242/знімки.js до.html …     → «— без тексту»: 0 · журнал: []
$ node аудит/перевірка/2242/знімки.js після.html …  → «— без тексту»: 3 · журнал: latin_remainder ×2, polite_form ×1
```

Знімки очима:

- `картка1_ДО.png` — пояснення заміни на місці;
- `картка1_ПІСЛЯ.png` і `картка2_ПІСЛЯ.png` — під заголовком «— без тексту». Жінка не дізнається, що образ
  неповний чи що річ замінено;
- `картка3_ПІСЛЯ.png` — увесь «Чому цей образ» став шаблоном через одне «ваш». Так велить наряд («не пройшов —
  шаблон»), тому окремого рядка тут нема.
