# Латка обгортки: менше прогонів

База: `0e2323210f28bfb488ef37b6b6c6a97e24182326` — свіжий `origin/main` під час перевірки застосування.
Застосовує диспетчер у своїй гілці після незалежної перевірки. Захищені шляхи
`.github/` і `аудит/адаптери/gemini/` у гілці виконавця не змінені.
Інші історичні латки з цього репозиторію повторно не накладати.

| порядок | файл | SHA-256 |
|---|---|---|
| 00 | `00-менше-прогонів.patch` | `98050a5ba7b35191babff478cc0cecd95f7158220721068bf8e4e8422a8319b9` |

Латка містить реалізацію, сценарії, Windows job, опис у НАЛАШТУВАННЯ.md і ЧЕРГА.md та маніфест.
Шаблони `аудит/наряди/автоживий.md`, `автоперевірка.md` й збереження NODE_OPTIONS
у приладі живого прогону змінено безпосередньо в гілці; вони надходять зі злиттям PR.
Так само надходять оновлений нічний стенд і спільний прилад повного переліку стендів
`аудит/проби/доробка_менше_прогонів.py`; застарілий окремий нічний шаблон видалено.

Відтворення у чистому тимчасовому дереві цієї бази, поза робочим репозиторієм:

```powershell
git -C $дерево apply --check $латка
git -C $дерево apply $латка
git -C $дерево add -- аудит/адаптери/gemini
python -X utf8 "$дерево/аудит/адаптери/gemini/перевірка/перевірити_хеші.py"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$дерево/аудит/адаптери/gemini/перевірка/сценарії_менше_прогонів.ps1" -SourceDir "$дерево/аудит/адаптери/gemini"
```

Для виміру ДО той самий новий сценарій запускають із `-SourceDir`, що вказує
на обгортку `906f941e073b13a3fd043a3bdf16833604f8ad1a`. Код має бути 1;
на застосованій латці — 0. Попередній нічний стенд із цього коміту падає з кодом 1,
оновлений прямий стенд на новій латці завершується кодом 0.
Усі наявні shell-стенди запускаються через `перевірка/запустити_стенд.sh <назва.sh>`
у Git Bash із Windows PowerShell 5.1; TMPDIR — окрема тека з ASCII-шляхом.
Транспортні стенди `side.ps1` підміняють лише політику пробудження, щоб перевіряти
повтори й запасний канал незалежно від відбору повідомлень. Новий сценарій перевіряє
справжню політику та нуль мережевих спроб для локальних рядків.
Заглушки трьох рушіїв використовують один `fake_timeline.py`: міжпроцесний замок
зберігає всі одночасні записи часової лінії на Windows і POSIX.

Повний перелік CI й локального приймання виводиться й виконується однією командою
(журнали задавай окремою ASCII-текою):

```powershell
python -X utf8 аудит/проби/доробка_менше_прогонів.py --дерево $дерево --журнали $журнали
```

Прилад знаходить усі `сценарії_*.sh`, непарні `сценарії_*.ps1`, додає нічний стенд
з `аудит/проби/` та перевірку хешів; кожну команду, код і число тверджень зберігає
в `результати.json`, повні виводи — в окремих `.log`. Кожний стенд виконується до кінця,
навіть якщо попередній червоний. CI використовує саме цей перелік.

Результати, лічби й межі доказу — `аудит/перевірка/обгортка_менше_прогонів.md`.
