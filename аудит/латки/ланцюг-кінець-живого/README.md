# Завершення автонаряду за позначкою

База: `88b2d8abc48ca5bd139c358bee32bd21d817fa91`. Застосовує диспетчер; файли обгортки в цій гілці не змінені.

```powershell
git apply --check аудит/латки/ланцюг-кінець-живого/зміни.patch
git apply аудит/латки/ланцюг-кінець-живого/зміни.patch
```

Латка вводить спільні `Get-ChainTaskResults` і `Get-ChainTaskCompletion`: назва наряду — з позначки в стані
публікатора або `claude-run/runs/*/result.json`. Гілка виконавця може бути скорочена. Для старого стану Codex/agy
назва відновлюється за id результату в теці обміну. `slug` переноситься через приймання вихідних, доставку та
зведення. Claude записує результат до появи рядка вихідних, також при ранньому завершенні.

Автоживий закінчують ГОТОВО, ЗАБЛОКОВАНО чи відсутність усіх віддалених позначок активного наряду. Неопублікований
резерв, самі QUOTA_WAIT і LINE_REJECTED та збій GitHub не є доказом завершення. Прийнятий ЗАБЛОКОВАНО квоти
зв'язується з позначкою стану QUOTA_WAIT і теж закінчує активний прогін. Автоперевірка використовує те саме джерело;
лише ГОТОВО пригнічує повтор перевірки голови. Рішення про доставку автозвіту теж бере назву позначки.

ДО → ПІСЛЯ: початковий варіант нового стенда на базовому коді — 23 перевірки, 12 провалів; після виправлення —
жодного провалу в 31 перевірці, з додатковими перевірками перенесення метаданих, ранньої відмови й квоти. Стенди працюють з тимчасовими
репозиторіями, віддаленими ref та підмінами API/рушіїв. Фактичний `chain.json` і закриті стани обгортки не читались.

Команди та повні виводи — у сусідніх журналах і `результати.json`. Маніфест і таблиця SHA-256 оновлені разом.
Усі стенди запускаються на передньому плані до завершення. Докази створені виконавцем; незалежної перевірки тут немає.

останнього штампу після кінця активного прогону, без ручного додавання. Рядки 12265–12266 до цього — ЧАСТКОВО.
