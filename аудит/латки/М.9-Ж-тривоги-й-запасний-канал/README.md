Зміни: спільний модуль `wrapper_health.ps1`, перелік тривог та годинне придушення, доставка того самого рядка через
gh у #1690 після 401 чи 10 хв без підтвердження, окремі бюджети й видимий стан вичерпаних спроб. Обидва планувальники
пишуть UTC heartbeat також під час службових очікувань, стан показує вік кожного джерела. Квота agy — зі структурного
JSON зі спадкуванням назви групи. Копіювання нового модуля проходить ті самі перевірки SHA-256; ACL не послаблюються.

Команди й результати стендів — у `стенди.txt`. Мережеві відправлення #1690/#1856 підмінені CLI; жодних справжніх
коментарів чи змін задач не виконувалося. Час для меж 10 хв, 1 год і застарілості 6 хв пересунуто у фікстурі.
Підтвердження доставки — відповідь CLI; якщо сервер прийняв коментар, але відповідь втрачено, можливий повтор.

Перевірено: стенд здоров'я ДО/ПІСЛЯ та шість стендів сім'ї — доставки, черги, смуг, рушіїв, Claude, m9v.
Точні байти бази на Windows відновлено з `git show HEAD:<шлях>` перед `git apply --check`, щоб налаштування CRLF
робочої копії не змінювали контекст латки. Додатково `git apply --cached --check` перевірив її на точних блобах індексу.
Стенд смуг збережено з першого успішного прогону: його виробничі файли після нього не змінювалися.

ДО → ПІСЛЯ: 401 — 0 → 2 коментарі підробного #1690 (початковий рядок і тривога); agy без входу — 0 → 1
окрема тривога AUTH AGY; UTC час heartbeat — відсутній → присутній від обох задач. Вік зупиненого джерела за
пересунутого часу — 6 хв, активний читач його не освіжає. 10 хв, 1 год, вичерпані бюджети й повторне читання
теки обміну перевірено окремо. Фактична установка й незалежна перевірка лишаються наступним етапом наряду.
