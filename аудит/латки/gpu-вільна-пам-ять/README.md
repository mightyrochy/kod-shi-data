# GPU: вільна пам'ять і обчислення

Латка `зміни.patch` для диспетчера. Виробничі файли `аудит/адаптери/gemini/` у цій гілці не змінено.
База наряду — `f1124acb200baa6fa3ddc3fdb68dca4dc80b7147`; латка перевірена на тих самих виробничих блобах.

## Що змінено

`Get-GpuLoad` вирішує за вільною VRAM і обчислювальним навантаженням з одного знімка драйвера.
`Test-ExternalGpuFree` та `Get-GpuBusyReason` використовують його рішення в обох планувальниках і воркерах.
`GpuIdleMiB`, рішення за переліком compute-apps і виняток для назв робочого столу прибрано.
Тому браузер із 700 MiB і столом 1221 MiB при 0 % більше не блокує запуск.
Нестача VRAM, ненульові обчислення, невідома телеметрія й кілька карт лишають позначку в черзі.

Завантажена неактивна модель LM Studio зменшує залишкову потребу своїм виміряним `DedicatedUsage`.
Без WMI такого зарахування немає. LM Studio й моделі обгортка не закриває та не вивантажує.
Замок GPU збережено; воркер повторює перевірку після його узяття.
Транспорт приймає числові причини `вільно X з потрібних Y MiB` і `навантаження Z %`;
зміна тільки чисел не породжує повторного пробудження. Оновлено обидва описи й три хеші скриптів.

## Джерела й запасний шлях

Паспорт — `аудит/корені/ПК-межа-без-джерела-gpu.md`.
`вимір.py` прочитав 247 первинних журналів за 30.10–01.11 без поточного запуску;
41 числовий знімок збережено у `вимір.json` разом із переліком файлів, їхніми розмірами й SHA-256.
Найбільше спостережене — **8925 MiB**, простій — **0 %**.

**Не виміряно:** безперервний пік живого, пік VRAM жнив/розбору каталогу й відсоток навантаження South of Midnight.
Запасний шлях: бюджет за найбільшим доступним спостереженням живого й затримка при будь-якому ненульовому навантаженні.
Це не доказ місткості для більшої моделі чи піка каталогу. Рушій залишається джерелом фактичної відмови виділення пам'яті;
потрібно записати телеметрію першого спільного прогону й уточнити бюджет.
Анімація браузера з ненульовим навантаженням може затримати запуск — довільного дозволеного відсотка не додано.

## Перевірено

Той самий `сценарії_gpu_память.ps1` на виробничій базі й латці:
**ДО 16 ✓ / 50 ✗ → ПІСЛЯ 66 ✓ / 0 ✗**. Повні відповіді — `до.log`, `після.log`.
Серед сценаріїв: браузер і стіл, гра, чужа неактивна модель понад доступне, точна межа VRAM,
активна/неактивна LM Studio, брак WMI, дубль лічильника, N/A, переповнення числа, відсутній драйвер,
кілька карт, власний наряд, спільний замок, відкидання стороннього тексту транспортом.

Чисте застосування: `git apply --check` і `git apply --index` — код 0;
дерево після латки точно збігається з індексом кандидата (`застосування.json`).
На чистому дереві пройдено п'ять стендів, **188 ✓ / 0 ✗**, у тому числі всі дев'ять хешів і формат смуг:
журнали й точні команди — `чисте-застосування/`.

Незмінений прилад `джерела/прилади/корінь_пк_межа.py`:
**97 місць ДО → 97 ПІСЛЯ**, код 0, повний обсяг правил/конфігу/коду;
`корінь-до.log`, `корінь-після.log`. Це лічба ширшого кореня, не закриття кореня.
Наряд кореня залишено: його прилад ще не показав 0.

## Застосування й приймання

Диспетчер застосовує в окремій чистій копії свіжого main:

```bash
git config core.autocrlf false
git apply --check <шлях>/зміни.patch
git apply --index <шлях>/зміни.patch
python аудит/адаптери/gemini/перевірка/перевірити_хеші.py
```

Латка містить канонічні LF та збережені BOM PowerShell. Байти незмінених файлів не чіпає.
Команда стенда (PowerShell):

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File аудит/адаптери/gemini/перевірка/сценарії_gpu_память.ps1 -SourceDir аудит/адаптери/gemini
```

Для повної батареї використано штатний `аудит/проби/доробка_менше_прогонів.py`;
його `--журнали` має вказувати на ASCII-шлях: Windows `.cmd` заглушки не читають кирилицю шляху.
Тимчасові копії й виходи стендів лежали лише всередині теки цієї задачі.

Приймання після застосування: відкрити браузер зі звичайними вкладками й дочекатися узяття штатного GPU-наряду;
записати позначку, час UTC, вільну VRAM, залишкову потребу й навантаження.
До такого прогону рядок 12240 — **ЧАСТКОВО**; самостійного живого прогону в цьому наряді не було.
Вад поза мірилом не знайдено.
