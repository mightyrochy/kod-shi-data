# Спільний розбір маніфесту обгортки

База: `9d463346f352a373dc08f919cb24bcd4a95e02f9`. Латку `зміна.patch` застосовує диспетчер з кореня репозиторію:

```powershell
git apply --check --index аудит/латки/хеші-маніфест-розбір/зміна.patch
git apply --index аудит/латки/хеші-маніфест-розбір/зміна.patch
```

У цій гілці файли `аудит/адаптери/gemini/` та `.github/` не змінено. Латка містить п'ять файлів:
читач і самооновлення в `wrapper_update.ps1`, спільну звірку `перевірити_хеші.py`, делегування з
`сценарії_m9v.sh`, новий SHA-256 самооновлення в маніфесті й таблиці документації. BOM PowerShell і режим
виконання shell-стенда збережено.

`Read-WrapperManifest` викликає `Import-PowerShellDataFile` й містить єдиний перелік дев'яти обов'язкових файлів.
Самооновлення викликає цю функцію безпосередньо, Python — через PowerShell і JSON. Два незалежні читачі хешів
регулярним виразом замінено одним; читання метаданих інсталятора в shell-стенді теж використовує цю функцію.
Документаційна таблиця й далі читається як Markdown. Звірка без аргументів перевіряє блоби індексу git;
`--диск` зберігає перевірку файлів на диску з нормалізацією CRLF для стенда m9v.

## Вимір 2026-11-01 UTC

Повні виводи: `до.log`, `після.log`, `самооновлення.log`. Проби виконано на окремому дереві адаптера під
тимчасовою текою задачі. Перед кожною пробою маніфест і таблиця додавалися в індекс цього дерева.

| Проба | ДО: Python / m9v | ПІСЛЯ: Python / m9v |
|---|---|---|
| Чинний маніфест | 0 / 0 | 0 / 0 |
| Хибний робочий хеш, правильний у блоковому коментарі | 0 / 0 | 1 / 1 |
| Обов'язковий рядок закоментовано через `#` | 0 / 0 | 1 / 1 |
| Маніфест і таблиця без `claude_run.ps1` | 0 / 0 | 1 / 1 |
| Дубль ключа | 0 / 1 | 1 / 1 |

Команда для повтору на підготовленому окремому git-дереві, що містить адаптер за його звичайним шляхом:

```powershell
$env:PYTHONUTF8 = '1'
$env:TEST_BASH = 'C:/Program Files/Git/bin/bash.exe'
python аудит/латки/хеші-маніфест-розбір/проби.py <тимчасове-дерево> --до
# Застосувати латку до тимчасового дерева й додати змінені файли в його індекс.
python аудит/латки/хеші-маніфест-розбір/проби.py <тимчасове-дерево>
powershell.exe -NoProfile -NonInteractive -ExecutionPolicy Bypass -File <тимчасове-дерево>/аудит/адаптери/gemini/перевірка/сценарії_самооновлення.ps1
```

Кожен запуск проб завершується rc 0 лише за відповідності всіх десяти звірок очікуваним результатам своєї фази.
Наявний повний стенд m9v пройшов на чинному маніфесті; стенд самооновлення — 22 перевірки, rc 0:
перше встановлення, повтор, нова версія, збереження попередньої версії при хибному хеші чи відмові проби,
ACL, відсутній облік і прибирання тимчасових тек. `git apply --check --cached` на індексі вихідної гілки — rc 0.

Середовище: Windows PowerShell 5.1, Python 3.12, Git Bash. Python обирає `pwsh`, якщо він є;
на Windows без нього — `powershell`. Обидва використовують `Import-PowerShellDataFile`.
PowerShell 7 і повну батарею CI тут не запускали; незалежна перевірка та застосування латки залишаються диспетчерові.
Вад поза мірилом не знайдено.
