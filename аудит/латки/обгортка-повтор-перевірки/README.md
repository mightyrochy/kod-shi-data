## Рішення

Позначки для очищення та перенесення читає `Get-ChainMarkers`: точний ref, SHA позначки, числова спроба,
стан смуги. `Get-ChainMarkerState` бере чотири функції читання зі спільної бібліотеки через AST,
без запуску планувальника. `Get-MarkerState` і `Get-StatePath` приймають необов'язкову теку стану;
існуючі виклики смуг зберігають попередню поведінку. Ключ залишається `refs/remotes/origin/<позначка> <SHA>`.

Очищення дублів лишає узяту позначку (`TAKEN`); якщо узятих немає — NEW/WAIT, серед них доступного постачальника,
далі найбільшу числову спробу, далі `Ref` для сталого вибору. Кінцевий стан не заступає нову спробу.
Якщо всі спроби кінцеві, одна лишається кінцевою: новий запуск сам собою не створюється.
Узяту позначку не переносимо до іншого постачальника чи в хмару.

Перенесення між постачальниками та перевірка потреби хмари враховують лише NEW/WAIT.
`Move-BlockedMarkers` читає всі номери спроб; якщо в доступного постачальника вже є кінцева спроба,
створює наступну, щоб не залишити перенесення в уже виконаному стані. Видалення — з lease на прочитаний SHA.
Механізми вимірювання квоти, строки її чекання та GPU-ворота не змінюються.
