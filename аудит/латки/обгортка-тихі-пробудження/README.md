Відтворення у чистому тимчасовому дереві, поза робочим репозиторієм:

```powershell
git -C $дерево apply --check $латка
git -C $дерево apply $латка
git -C $дерево add -- аудит/адаптери/gemini
python -X utf8 "$дерево/аудит/адаптери/gemini/перевірка/перевірити_хеші.py"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$дерево/аудит/адаптери/gemini/перевірка/сценарії_тихі_пробудження.ps1" -SourceDir "$дерево/аудит/адаптери/gemini"
```

Для виміру ДО той самий сценарій запускають із `-SourceDir` на обгортці з `main` без латки: код 1; на застосованій латці — 0.
