# Обгортка: нульова квота рушія будить диспетчера

База: `a13f0b08adcf41a6db492b39090d7555bcce50db` (`origin/main`). Латка — `зміни.patch` (`git apply`); ті самі зміни лежать у файлах PR, щоб CI «обгортка — Windows PowerShell 5.1» міряв їх.

## Що змінено

`gemini_publish.ps1`: `QUOTA0_<ГРУПА>` прибрано з `$script:QuietBlockedCodes` (лишились `STALE`, `REVIEW_API`). `Test-DispatcherAction` для рядка QUOTA0 (одиничного й зведеного «×N») будить, коли вікно групи закрите. Після підтвердженої доставки (`Send-Pending`) `Set-QuotaWindow` відкриває вікно до скидання: хвилини з `_M<хв>`, без них — 360. Вікна — `quota-windows.json` у теці стану обгортки (переживає перезапуск); прострочені записи відкидаються при записі. Недоставлений лист вікна не відкриває.

`ЧЕРГА.md`, `НАЛАШТУВАННЯ.md` — абзац про `Test-DispatcherAction` узгоджено з кодом.
