## Будова області з джерела Colour 0.4.6

Прочитано `colour/notation/munsell.py`: `_munsell_specification_to_xyY` при нецілому V лінійно інтерполює xy за
`luminance_ASTMD1535` між `floor(V)` і `floor(V)+1`. Верх V=10 там — нейтраль (`value_plus == 10`), а низ V=0 відмовляє
в `xy_from_renotation_ovoid` (`1 <= value <= 9`). `munsell_specification_to_xy` при непарній хромі (`chroma % 2 == 0` —
точна рівність) лінійно інтерполює між парними сусідами, при `chroma_minus == 0` — від освітлювача C. `is_integer` —
поріг `1e-3`. Отже xy кусково-лінійний за C і за Y(V) на сталих H, а межі смуг — межі запису 12 цифр і порогу 1e-3.
Це й описує PR. Уточнення без наслідку: лінійність точна за значенням після запису 12 цифр, а не за самим float
параметра (відхилення ~1e-12 у xy, у межах `ЛІНІЙНІСТЬ`).

Джерело даних — renotation 1943, вбудована в Colour 0.4.6 (`MUNSELL_COLOURS_ALL`), без власних таблиць методу.
Умова XYZ ≥ 0 при Y>0 зводиться до x ≥ 0, x+y ≤ 1, y>0 (`xyY_to_XYZ`), як у `допустиме`.

## Строгість доведення XYZ (вибірково)
Код `доведені_знаки` (`колір_сім_ї_ребра_тону.py:215`): знак сталий, якщо |g(m)| > L1·h + запас, або g монотонна (|g'(m)| > L2·h + запас) і знак кінців сталий/змінний. Межі L1, L2 вивів вручну: |g'| ≤ |B| + Σ|w|(|a|+|b|)(|ρ1| + ρ_max|φ1|), |g''| ≤ Σ|w|(|a|+|b|)(2|ρ1φ1| + ρ_max φ1²), ρ_max — на кінцях (ρ афінне) — доведення правильне. Незалежна проба на 3 000 випадкових формах: порушень меж 0 (|g'|/L1 до 0.997), на 20 820 точках 300 форм жодна не суперечить доведеному знаку. Межа суворості: поріг `ЗАПАС = 1e-9` покриває округлення float, але не є інтервальною арифметикою — доведення «строге з запасом на float», не формальне; PR каже «доведено поділом з явними межами», розбіжності з кодом нема.
