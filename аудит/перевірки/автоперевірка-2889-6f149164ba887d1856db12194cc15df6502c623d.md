## 12546 · запуск без знімка повертає залишок моделей

Місце: `аудит/адаптери/gemini/queue_lanes.ps1:683–686`, `Start-GpuModels`;
споживач `Complete-GpuModels:657` повертається одразу, якщо файла немає.
Вага Р2. Джерельне мірило вимагає прибирання після **будь-якого** кінця GPU-наряду.

При ConnectFailure `Start-GpuModels` тепер не пише хибного `before=[]`,
але повертає успіх без будь-якого обліку власності. Worker запускає агента,
який може підняти сервер і завантажити моделі. Немає `gpu-models.json` —
ні finally, ні наступний `Repair-GpuModels` їх не бачать. Власникову модель
цей шлях зберігає, проте причина початкового наряду — залишок моделей — лишається.

Відтворення на фактичних worker обох смуг, з підробними лише REST та агентом:

```powershell
python аудит/перевірки/автоперевірка-2889-6f149164ba887d1856db12194cc15df6502c623d/http_probe.py --source-dir "$env:TEMP/review-2889/аудит/адаптери/gemini"
```

Проба бере штатний стенд голови й змінює лише підробку REST: рівно перший GET
кидає ConnectFailure, після нього HTTP працює. Агент вантажить два ID;
після штатного кінця або `taskkill /T /F` запускається відновлення іншою смугою.

## 12547 · нова перевірка вимкненого сервера читає попередні нагоди

Місце: `аудит/адаптери/gemini/перевірка/сценарії_gpu_моделі.py:267–275`.
Рід — мірило, вага Р2. Перед випадком `down` змінюється `Studio.loaded`,
але `Studio.calls` не очищується й межа поточного виклику не записується.
Умова `not [c for c in Studio.calls ... '/unload']` читає всі попередні нагоди,
зокрема успішне прибирання після порожнього початкового списку.

Фактично виконаний штатний стенд друкує:

```text
✗ gemini: вимкнений LM Studio — наряд без знімка, нічого не вивантажено
✗ claude: вимкнений LM Studio — наряд без знімка, нічого не вивантажено
ПІДСУМОК: провалів 2
```

Проба вище окремо підкладає один історичний unload і записує запити поточної
нагоди. На обох смугах `усіх_unload=1`, `поточних_unload=0`: стара умова False,
умова лише поточної нагоди True. Отже, ці два провали не доводять вивантаження
в поточному випадку; історію треба відмежувати. Сама очікувана поведінка
«залишити моделі наряду» також не є прийманням цілі — це окрема вада 12546.
