```text
git diff --exit-code 7df876a940c7e437c447a6d3942fc698172fa909 refs/review/2867 -- джерела ':!джерела/прилади'
(stdout порожній; код 0)
node аудит/перевірки/перевірка-2867/знімок.cjs ../tmp/pr2867 аудит/перевірки/перевірка-2867
```

Продуктовий код бази й голови однаковий. Тому ДО/ПІСЛЯ зроблено тим самим зібраним шаблоном голови на однаковій фікстурі картки з реальною річчю `ж-00001` із повного каталогу. Це Chromium на вихідному показі з підставленим пакетом, не повна збірка Pyodide й не робота стилістки. Фото крамниці справді завантажувалось мережею (еквівалент FOTO=1); обидва img мають naturalWidth 1000, помилок JavaScript немає. Викликів моделей немає.

Оглянуто [ДО](перевірка-2867/до-390x844.png) й [ПІСЛЯ](перевірка-2867/після-390x844.png), 390×844: біла сукня на фото, підпис речі, ціна й кнопка заміни видимі; зсуву між версіями немає. Повний текст картки й результати завантаження — [знімок.json](перевірка-2867/знімок.json). SHA-256 обох PNG однаковий: `F3E7D55F68014FCA09DCA49F1D685D4FDA54014C1AD118E54D15E6EBF50EE0F5`.

Живе мірило кореня не виконувалось: це наряд на прилад, а не на маску й повернення пікселів. Закриття продуктового кореня або твердження «помилок класу 0» цей звіт не дає. Рядків ЖИВИЙ ПІСЛЯ для незмінного продуктового коду немає. PR не зливався, листів і коментарів від перевірки немає; доставка звіту — обгорткою.
