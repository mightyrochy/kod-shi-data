# Прогін1-неперевірене-зрозуміло — докази

Крок кореня `Е2-текст-жінці`: перелік «неперевіреного» на картці образу — зрозумілий,
короткий, без заяв про дані, яких продукт не збирає (вади 3, 8, 10, 15 живого «як людина»
13.11, `аудит/проби/живий-як-людина-1/вади.md`).

## Що виміряно

Міст (`міст_відповіді`) офлайн на `каталог_повний.xml` — 4 сценарії, по одному образу:

```
cd джерела
python3 ../аудит/перевірки/Прогін1-неперевірене-зрозуміло/пункти.py джерела \
        ../аудит/перевірки/Прогін1-неперевірене-зрозуміло/після.json
python3 ../аудит/перевірки/Прогін1-неперевірене-зрозуміло/лічба.py \
        ../аудит/перевірки/Прогін1-неперевірене-зрозуміло/після.json
```

`пункти.py` будує `в["пункти"]` мостом (`паспорт → запити → від_моделі`); `лічба.py` лічить
рядки картки (без `для_всіх`), заяви жінці, однакові заяви й повтор того самого коду.
`до.json` — на `origin/main` (ddb6890b), `після.json` — на гілці правки.

### Числа ДО → ПІСЛЯ (сума 4 карток)

| мірило | ДО | ПІСЛЯ |
|---|---|---|
| рядків на картці | 96 | **22** |
| заяв жінці | 172 | **25** |
| однакових заяв (дослівно) | 25 | **0** |
| той самий код удруге | 78 | **4** |

ПІСЛЯ на картці лишились лише заяви, які жінка бачить на своїй речі чи може дати сама;
межа системи, звіт виміру, прогалина картки крамниці й наслідки теорії палітри пішли у звіт
власника (`recipient="journal"`), заяви про стопу/голову — лише коли їх закриє поле картки,
і без «питання анкети».

## Знімки 390×844 (зібрана сторінка)

`до-*.png` / `після-*.png` — `весілля_літо` і `мороз_ожеледь_офіс`. Відтворення:

```
cd джерела && NODE_PATH=node_modules node \
  ../аудит/перевірки/Прогін1-неперевірене-зрозуміло/знімок.cjs
```

`знімок.cjs` підставляє шаблон показу (`показ_шаблон.js`), малює картку `рендерКартку` на
зібраній сторінці в Chromium 390×844, блок розгорнуто. Рядки жінці (`лінії.json`) — слова
живої моделі з записаного прогону `живий-як-людина-1` (`укр.json`, ключ код+значення): той
самий словник на обидва боки, різниця тільки в тому, які заяви лишаються. Дві заяви-свідки
кольору (`photo_shows_other_colour`, `colour_word_shop_photo_other`) у записаному наборі не
трапились — їхній рядок перекладено з опису заяви вручну, однаково на обидва боки.

ДО: заголовок кнопки — ціле речення з числом «· 19 / · 24», повтори «Я не можу сказати…»,
«одне з питань анкети», «на рівнях маківки, підборіддя». ПІСЛЯ: заголовок «Що я не змогла
перевірити · 5 / · 6», 5–6 рядків лише про її речі.
