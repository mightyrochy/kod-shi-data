## Знахідки

- **16917** — `Hold-RunCopy` пише `kept.txt`, але не відв'язує копію від гілки (`Remove-TaskCopy` у такому ж разі робить `checkout --detach`). Повтор позначки в новій копії — `checkout -f --ignore-other-worktrees -B gemini/<наряд> <старт>` (рядок 1524 голови) — відкочує спільну гілку, а з нею й HEAD утримуваної копії. Дослід:

  ```text
  git clone --bare src clone; worktree add -b gemini/x ../kept $B; (kept) commit agent1; echo dirty > f.txt
  worktree add --detach ../new $B; (new) checkout -q -f --ignore-other-worktrees -B gemini/x $B
  kept HEAD now: 84decde6… (base 84decde6…, agent 58e6a29f…)
  git branch --contains agent → 0;  f.txt — на місці;  reflog HEAD копії → 58e6a29f…
  ```

  Те саме було й до #4545 на шляху «записане не закомічено» (`kept.txt` без detach), а до PR копію зі збоєм бандла взагалі прибирали — PR стан не погіршує, тож це рядок, не доробка.
- **16918** — ЗНАХІДКА автора з тіла PR (у файлі дошки PR її нема): `--branches --remotes` як «доставлене» в `Close-StoppedRun`, `Clear-TaskCopies` і `Close-TaskCopy` процесу наряду; копію з комітами лише в локальній гілці клону прибирають. Код поза диффом #4545 (рядок 1739 голови — той самий виклик, що й до PR), тож рядок дошки, не обхід цього PR.
