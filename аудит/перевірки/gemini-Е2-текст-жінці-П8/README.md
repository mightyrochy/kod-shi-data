Контрольна картка навмисно містить неприйнятний опис, пораду, назву частини
комплекту, пояснення схеми та матеріалу. Знімки `*-картка-390x844.png` — Chromium,
390×844; це контрольна фікстура, а не результат нової моделі.

`каталог_знімок.cjs` відкриває руку 1 сцени `ж5_співбесіда_без` з чотирма
реальними речами каталогу. ДО підставляє рівно два змінені модулі з бази вище;
решта підготовки однакова. `FOTO=1`: три наявні фото крамниць завантажилися
(шість вузлів разом із колажем і переліком). Фото й тексти картки ДО/ПІСЛЯ
однакові, горизонтального переповнення немає; обидва знімки переглянуто.
У четвертої речі в записі немає фото — показ лишає її порожнє місце.

```powershell
$env:FOTO = '1'
node аудит/перевірки/gemini-Е2-текст-жінці-П8/каталог_знімок.cjs до
node аудит/перевірки/gemini-Е2-текст-жінці-П8/каталог_знімок.cjs після
```

Запуск із кореня репозиторію після `npm ci` в `джерела/`:

```powershell
$env:PYTHONUTF8 = '1'
node аудит/перевірки/gemini-Е2-текст-жінці-П8/відтворити.cjs після
```

Файли повтору та знімок записуються в `$env:TEMP/е2-після/`. Для повтору ДО потрібна
база вище. Повний `replay_сцени.py` і живий прогін не виконувались: ця проба
відтворює кінцевий сторож та вихід на екран. Незалежне приймання — окремо.
