## Заявлене мірило вибору рецензента

Окремою прицільною пробою викликано справжній `Get-ReviewModels` на обох конфігах,
з синтетичним автором `codex/проба` та іменованими групами `pools.json`.
ДО → ПІСЛЯ з виводу цієї проби:

| Gemini Models | Gemini 4 Argon | База | Голова |
|---:|---:|---|---|
| 0 % | 100 % | claude-cloud | gemini-4-argon-high |
| 100 % | 0 % | gemini-3.8-flash-high | claude-cloud |
| 100 % | 100 % | gemini-3.8-flash-high | gemini-4-argon-high |

У всіх випадках `CLAUDEANDGPTMODE=1 %`; виконано по три перевірки на дерево,
усі очікувані результати збіглися, обидва процеси завершилися з кодом 0.
Отже, заявлений вибір Argon за заданими квотами працює; вердикт «ДОРОБИТИ» спричинений
відтвореною регресією наявного стенда.

Відтворення прицільної проби: зберегти наведене як UTF-8 з BOM у тимчасовий `.ps1`
і виконати `powershell.exe -NoProfile -ExecutionPolicy Bypass -File <файл> -TaskSource <тека адаптера> -ProbeRoot <нова тимчасова тека>`
окремо для бази та голови. Це виклик функцій, без запуску моделей чи зовнішнього планувальника.

```powershell
param([string]$TaskSource, [string]$ProbeRoot)
$utf = [Text.UTF8Encoding]::new($false)
. (Join-Path $TaskSource 'gemini_publish.ps1') -WorkDir "$ProbeRoot/pub" -OutDir "$ProbeRoot/out" -OutboxDir "$ProbeRoot/box" -UpdateRoot "$ProbeRoot/update"
foreach ($d in @($WorkDir, "$WorkDir/state", "$WorkDir/engine-models", $OutDir)) {
    [void][IO.Directory]::CreateDirectory($d)
}
$cfg = ConvertFrom-Json ([IO.File]::ReadAllText((Join-Path $TaskSource 'ланцюг.json'), $utf))
$pull = [pscustomobject]@{head=@{ref='codex/проба';sha=('a' * 40)}}
$groups = @(
    @{g='GEMINIMODELS';n='gemini models';left=0;reset=90},
    @{g='CLAUDEANDGPTMODE';n='claude and gpt models';left=1;reset=90},
    @{g='GEMINI4ARGON';n='gemini 4 argon';left=100;reset=90}
)
function Choose([string]$Name, [string]$Expected) {
    [IO.File]::WriteAllText("$OutDir/pools.json", (@{v=1;groups=$groups} | ConvertTo-Json -Depth 5), $utf)
    $got = @(Get-ReviewModels $pull $cfg ([datetimeoffset]'2026-11-01T23:30:00Z'))
    $ok = $got.Count -eq 1 -and $got[0] -ceq $Expected
    "$Name`: $($got -join ','); очікується $Expected; збіг=$ok"
    if (-not $ok) { throw 'Не пройдено мірило вибору рецензента' }
}
$expected = if ($cfg.agy -ceq 'gemini-4-argon-high') { 'gemini-4-argon-high' } else { 'claude-cloud' }
Choose 'Gemini Models 0 %, Argon 100 %' $expected
$groups[0].left = 100; $groups[2].left = 0
$expected = if ($cfg.agy -ceq 'gemini-4-argon-high') { 'claude-cloud' } else { 'gemini-3.8-flash-high' }
Choose 'Gemini Models 100 %, Argon 0 %' $expected
$groups[0].left = 100; $groups[2].left = 100
Choose 'Обидві групи 100 %' $cfg.agy
```
