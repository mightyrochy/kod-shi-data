## Мірило та висновок із коду

1. Порожня або часткова SQLite-схема має бути невідомою, з додатним залишком;
   здорова крамниця виконується, наступний запуск відновлює перервану.
2. Читання черги й метаданих в усіх місцях має однакову поведінку; створення схеми
   та початкових метаданих не залишає часткового підтвердження після обриву.
3. Сім'я проб обходу, сусідні проби журналу та батарея мають завершитися успішно.

`zhnyvarka/журнал_проходу.py:19` перевіряє наявність усіх таблиць, а
`прочитати_чергу()` відкриває URI з `mode=ro`, починає транзакцію знімка, закриває
з'єднання й повертає `None` при помилці SQLite. `ЖурналПроходу.__init__()` ставить
явний `BEGIN` перед DDL і метаданими. `звіт()` використовує спільний підсумок.
`zhnyvarka/обхід.py:40` і `залишок()` застосовують спільний читач; невідома схема
не стає хибним нулем у стартовому фільтрі, рядку зведення чи гілці обриву без зведення.

## Зауваження, вердикт і межі

Вердикт: **ДОРОБИТИ повний результат #2025** — п'ять відомих вад відновлення вище
лишаються на перевіреному SHA. Нових вад: 0; дублювати призначені рядки дошки не потрібно.
Виправлення SQLite (10511) проходить офлайн-мірило наряду доробка-2016; його можна
включити в результат разом із уже призначеними доробками. Зелена батарея не спростовує
відтворень А/Б/В/З2/З4 і не означає приймання повного обходу.

ЖИВИЙ ПІСЛЯ: на копії справжнього журналу поза репозиторієм повторити обхід після обриву
створення SQLite-черги однієї HTML-крамниці. Здорова крамниця має виконатися в тому самому
запуску; невідома черга має додатний залишок; повтор відновлює схему й продовжує перервану.
Спільним прогоном перевірити також завислу першу крамницю за черги довшої за паралельність
і повтор JSON-крамниці після помилки API. Порівнювати `зведення_жнив.tsv`, `обхід_стан.tsv`,
SQLite та останні записи `сирі/*.jsonl`; завершена здорова крамниця не запускається знову.
Це передача диспетчерові для живого приймання після злиття, а не виконаний живий прогін.

Мережевий каталог, фото речей і модель не запускалися: наряд джерела забороняє звернення
до крамниць у цій роботі. Знімки карток 390×844 з `FOTO=1` не зроблено: змін показу,
відбору образів чи входу моделі в дифі немає; їхня якість цим звітом не оцінюється.
Проби виконують справжні методи обходу й журналу із заміщеними мережею/процесом;
контролі атомарності окремо завершують справжній процес. Це не живе приймання каталогу.
CI голови за адаптером під обгорткою звіряє диспетчер перед злиттям.
Коментарі, листи, злиття й публікація не виконувалися; постійний шаблон наряду збережено.

## Відтворення додаткових контролів

Зберегти цей код у тимчасовий файл поза репозиторієм і запустити `python <файл>`
з кореня дерева `2167dcb8492e267a3ae65886065994f1a6f7cd06` у UTF-8.
Початкова спроба цього приладу залишала відкрите тестове з'єднання SQLite й падала
на очищенні тимчасової теки Windows; виправлено лише прилад (`closing`), потім
усі його контролі виконано заново до кінця.

```python
import hashlib, os, sqlite3, subprocess, sys, tempfile
from contextlib import closing
from pathlib import Path
sys.stdout.reconfigure(encoding='utf-8')
root=Path.cwd()  # запуск із кореня дерева перевіреного SHA
sys.path.insert(0,str(root/'zhnyvarka'))
from журнал_проходу import ЖурналПроходу, СХЕМА, прочитати_чергу
if len(sys.argv)>1:
    connect=sqlite3.connect
    def interrupted(*args,**kw):
        db=connect(*args,**kw)
        def trace(sql):
            if sql.startswith(sys.argv[2]): os._exit(7)
        db.set_trace_callback(trace)
        return db
    sqlite3.connect=interrupted
    ЖурналПроходу(sys.argv[1],'hang.com','new')
    raise AssertionError('переривання не сталося')
with tempfile.TemporaryDirectory() as td:
    missing=Path(td)/'відсутня.sqlite3'
    assert прочитати_чергу(missing) is None and not missing.exists()
    print('Відсутня база: None; файл не створено')
for n in range(4):
    with tempfile.TemporaryDirectory() as td:
        folder=Path(td)/'hang.com'; folder.mkdir(); path=folder/'черга.sqlite3'
        with closing(sqlite3.connect(path)) as db:
            for sql in СХЕМА[:n]: db.execute(sql)
            if n>=2: db.execute("INSERT INTO черга VALUES ('https://hang.com/p1','INFLIGHT',NULL)")
            db.commit()
        before=path.read_bytes()
        assert прочитати_чергу(path) == ((1,0,False) if n==3 else None)
        assert path.read_bytes()==before
        journal=ЖурналПроходу(td,'hang.com','new')
        assert journal.звіт()['pending']==(1 if n>=2 else 0)
        assert not journal.звіт()['queue_complete']
        journal.закрити()
        print(f'Стара схема {n}/3: читання не змінює базу; відновлено; pending={1 if n>=2 else 0}')
for prefix in ('CREATE TABLE IF NOT EXISTS мета','CREATE TABLE IF NOT EXISTS черга','CREATE TABLE IF NOT EXISTS відповіді','UPDATE черга',"INSERT OR REPLACE INTO мета VALUES ('відомо'","INSERT OR REPLACE INTO мета VALUES ('відбиток'"):

        path=Path(td)/'hang.com'/'черга.sqlite3'

        journal=ЖурналПроходу(td,'hang.com','new'); journal.перелік(['/p1']); journal.закрити()
        assert прочитати_чергу(path)==(1,0,True)
        print(f'Обрив перед {prefix}: код 7; наступний запис відновлює (1, 0, True)')
with tempfile.TemporaryDirectory() as td:

    body=next(journal.тека.glob('*.body')); original=body.read_bytes(); journal.закрити()
    journal=ЖурналПроходу(td,'hang.com','new')
    assert journal.звіт()['pending']==1 and body.read_bytes()==original

    print('Зміна відбитка: pending=1; відповідей=1; тіло збережено')
```
