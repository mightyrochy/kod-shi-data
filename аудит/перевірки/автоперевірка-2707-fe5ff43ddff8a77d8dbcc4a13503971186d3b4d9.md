## Доведена вада: повтор робить писача зеленим

**[P1] `джерела/прилади/лічба_проб.py:327–333, 349–356` — не зберігається факт первинного запису.**

Коли під час зміни дерева в роботі кілька проб, прилад відновлює файли й додає
проби до `підозрювані`, але не зберігає змінені шляхи як незнятий провал.
Подальше `записати(z)` замінює первинний результат результатом одиночного повтору.
Якщо проба пише лише під час першого запуску, її повтор уже нічого не змінює.
Наприкінці прилад повідомляє нуль писачів і `--гейт` проходить, хоча запис доведено
його власним попереднім повідомленням. Таку умову дає, наприклад, одноразова
ініціалізація з ознакою в тимчасовій теці поза репозиторієм.

Відтворено незмінений `main()` приладу на тимчасовому worktree призначеної голови,
з реальними підпроцесами, без підміни функцій приладу. Дві допоміжні проби додано
до знімка; після перевірки прибрано. Перша проба:

```python
from pathlib import Path
import time
marker = Path('/абсолютна/тимчасова/тека/поза/деревом/once')
target = Path('/абсолютне/дерево/голови/README.md')
if not marker.exists():
    target.write_bytes(target.read_bytes() + b'probe write')
    marker.write_text('write observed')
time.sleep(0.5)
```

Друга проба — `import time; time.sleep(2)`. Перед кожним новим відтворенням
береться нова тека ознаки, щоб первинний запис справді відбувся.
Команда з теки `джерела` (змінні оточення `NYTOK=2`, `STELYA=15`):

```text
python -X utf8 прилади/лічба_проб.py --гейт --лише джерела/проби/review2707_once.py джерела/проби/review2707_neighbor.py
```

ДЕРЕВО ЗМІНЕНО, коли в льоті було кілька проб — підозрюваних 2 жену поодинці: джерела/проби/review2707_neighbor.py, джерела/проби/review2707_once.py
