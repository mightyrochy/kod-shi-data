## Доведені вади приладу

**11363 — `джерела/прилади/корінь_е2_межі.py:601`: відхилення з ненульовим `return` рахується ремонтом.** Умова приймає будь-який `Return` зі значенням, крім `None`, зокрема `False`. Досить такого тіла функції в модулі зі списку `МОДУЛІ_ПРОДУКТУ`:

```python
def читати(об, нотатки):
    if not isinstance(об, str):
        нотатки.append("відхилено: очікувався рядок")
        return False
```

Проба `відхилення_return`: ДО — 0 місць, ПІСЛЯ — 1 місце п.4 на рядку нотатки. Дані відповіді тут не виправляються: функція відхиляє неправильний тип із причиною. Наслідок — коректна гілка відхилення збільшує лічбу ремонту й може зробити храповик червоним. Це нова хибна форма, породжена розширенням В1; не встановлено, що вона вже є серед 108 місць поточного продукту.

**11364 — `джерела/прилади/корінь_е2_межі.py:962,1011–1013`: параметр вкладеної стрілки не утворює власної області для перевірки затінення.** Позиція `т =>` розташована перед тілом стрілки. `блок_що_містить` знаходить зовнішній блок, у якому є присвоєння результату моделі; умова `not any(…)` тому відкидає затінення.

```javascript
async function читати(){
  const т = await модельП();
  const локальна = т => т.replace("а", "б");
  return т;
}
```

Проба `js_параметр`: ДО й ПІСЛЯ — по 1 місцю, п.1=1 і п.4=1. `replace` працює над власним параметром локальної функції, яка тут навіть не викликається, а не над відповіддю моделі. Наслідок — хибні читання й ремонт у лічбі, хоча варіант з локальним `const` уже виправлено. Додаткова проба `js_параметр_і_справжній_читач` дає 2 місця замість одного справжнього читача. Це залишкова форма В2, а не новий пропущений вид джерела.

Номери 11363–11364 взято з наряду джерела, де вони були виділені для нових вад приладу; у переглянутих рядках бази вони не зайняті. Записи — у власному фрагменті `аудит/дошка/gemini/автоперевірка-2320.md`. Що лишилось для наступного кроку приладу: розрізняти повернення виправлених даних і сигнал відхилення; врахувати області параметрів вкладених JS-функцій. Паспорт кореня та реалізацію ця перевірка не змінювала.
