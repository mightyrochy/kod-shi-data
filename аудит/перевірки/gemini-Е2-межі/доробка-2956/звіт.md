Початкова голова — `872c289771bb21ea4ec753ccb6eea538f0d3a8f3`. Наряд вимагає
зберегти мірило підвидів місця та повернути Е2-промпти до числа не більше 110.

Причина: `РЕПЛІКА.not_recorded` брала повний `description` поля сценарію як
його назву. Додане до схеми правило вибору підвиду тому потрапило й до

варіанті `промпт_репліки:вихід1#2`: не коротший та довший за базові 6762 символи.
На початковій голові цей варіант мав 6912 символів.

`паспорт_поля` тепер зберігає коротку назву у стандартній анотації JSON Schema
`title`, а повне правило — у `description`. Перелік `not_recorded` бере
назву, коли вона є, і зберігає попередній опис для решти полів. Перелік підвидів
і їхній опис лишилися спільними для схеми й промпту розмови. Породжений JSON
оновлено командою `python джерела/внутрішня_мова.py`.
Повний опис лишився в обох формах вибору значення: `scenario.place` та
`conversation_turn.update.place.value`. Третє попереднє входження, у назві
коду відмови `not_recorded`, замінено короткою назвою поля.

## Повна звірка коренів і середовище

Перший повний храповик на встановленому Python 3.12.10 завершився кодом 1,
два червоних: невикладені `вибірка_п3.json` та `html` кореня Річ-запис-речі;
прилад ознак обличчя на базі не завершився за 900 с. Інші 20 коренів не

Потрібні дані викладено командою
`git sparse-checkout add '/аудит/проби/річ_запис_каталог_2026_10_30/'`.
Обидва шляхи після цього існують; вміст із Git не змінено.

Дві спроби отримати вбудований Python 3.11.9 з python.org завершилися
таймаутами, ZIP лишився неповним і не виконувався. Python 3.11.9 успішно
встановлено лише до тимчасової теки з офіційного NuGet-пакета.
[Документація CPython](https://docs.python.org/3.11/using/windows.html#the-nuget-org-packages)
визначає цей пакет як середовище для CI; точна адреса пакета, версія й
SHA-256 — `python311.json`. Глобальних налаштувань Python не змінено.

Повний повтор — `храповик-ресурс.py 4 --база 98d4815e613ec23f84d6104c6eab30c7f2280104`
на цьому Python 3.11.9. Джерело нового числа працівників —
`ресурс-повтор.json`: вільно понад 17 ГіБ пам'яті. Порівняння, клас приладів,
самі прилади та їхні таймаути не змінено.

Повтор завершено **кодом 0: 22 корені, червоних 0**. Усі числа на голові
дорівнюють базі: Е2-межі **98 → 98**, Е2-промпти **110 → 110**,
Річ-запис-речі **6 → 6**, Річ-ознаки-обличчя **176 → 176**.
Повний підсумок — `храповик-311.txt`, команда, версія й тривалість —
`храповик-311.json`. Це завершений прогін незміненого храповика на Python 3.11,
не поєднання чисел із різних запусків. Першу червону спробу збережено.
Різниця середовищ не є окремо доведеною причиною першого таймауту:
разом змінені інтерпретатор, доступні дані та організація запуску.

Усі власні процеси перевірки завершені, тимчасові дерева храповика прибрано
самим приладом. CI опублікованої голови перевірятиметься після публікації
обгорткою; пушу, PR чи ручного workflow ця сесія не робила.
