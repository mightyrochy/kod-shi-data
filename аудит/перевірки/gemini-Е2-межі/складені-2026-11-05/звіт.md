# Складені факти після коментаря — крок п.3 Е2-межі

База — `aef9e6cbba0c2b6a0200d7b78b8b50042297c1d8`; код —
`856d46abf9d585a89dac7d7efbc492561730cb33`. Ризик Р3. Незалежного та
живого приймання цей звіт не замінює. Модель і платні API не викликалися.

Коментар міняв плоскі поля, а старі факти картки лишав. Наступний хід
відновлював із них давній список бажань і вето. Окремо картка мігрувала
обчислене `вето_тверде` у факт та повертала його після зняття принта.

Доливання й зняття складених фактів коментарем та розмовою тепер йдуть
через спільного писаря і `картка_запиту.записати`. Запис виконується перед
обчисленням твердих меж. Окремі опори мають значення, вид і свій уривок;
після зняття лишаються опори чинних частин. До стилістки види та уривки
доходять у `sources.*.parts`. Уривки різних ходів не склеюються.
Коди бажань зливаються одним способом; новий уривок не створює дубля.
Порожній список кодів очищає останнє бажання. Обчислені поля виключено
з картки за ознакою `лише_код` реєстру. Вхідний паспорт не змінюється.

## Перевірки та межі доказу

Команда повного прогону:

```powershell
python аудит/перевірки/gemini-Е2-межі/складені-2026-11-05/перевірити.py
```

Прогін завершено до кінця, усі команди та коди — `підсумок.json`.
Каталог розпаковано й очищено штатним підготовником. Дим, живий шлях
6/6, протокол, гейти 575/0/0, контракти й показ 929 звірок у 74 розділах
мають код 0. Чотири проби виду, підвидів і заперечення теж мають код 0.
Дві старі проби — `картка_події.py`, `картка_replay.py` — мають код 1:
чекають `hour:11` та відсутності історичних втрат години. Їх звірено
на модулях бази командою `python .../давні_проби.py`: на базі теж код 1,
останні рядки відмов тотожні (`давні-проби.json`). Повний оркестратор
віддає 1 і не названий повністю зеленим.

Після уточнення походження виконано адресний повтор на остаточному коді:

```powershell
python аудит/перевірки/gemini-Е2-межі/складені-2026-11-05/перевірити.py --остаточно
```

Код 0; команди й результати — `остаточно-підсумок.json`. Повторює вимір

Корпус — 58 ходів, 16 реплік, 8 ходів плиток; усі лічби ДО/ПІСЛЯ
тотожні (`повтор-{до,після}.json`), включно з давніми 4 втратами години

відповіді моделей і не приймання живого мірила кореня.

Локально Python 3.12.10, Node 22.23.4; CI голови ще не запускався тут.
