Наприклад, `джерела/проби/ключ_без_лапок_3462.py:13` відкриває `../аудит/живі_11/Н4/VIDPOVIDI/seed3_40_ОЦІНКА_відповідь.txt`, але сканер шукає його під `джерела/аудит/` і помилково визнає справжній вхід недосяжним. ## Доведення вади та порушення мірила наряду

Наряд `аудит/наряди/чистка-записів-main.md` прямо визначає головне мірило:
> «Головне — нічого живого не видалено: кожен прибраний запис має джерело, що він мертвий.»

1. **Факт використання входу кодом репозиторію:**
   Файл `джерела/проби/ключ_без_лапок_3462.py:13` містить прямий виклик:
   ```python
   в = open("../аудит/живі_11/Н4/VIDPOVIDI/seed3_40_ОЦІНКА_відповідь.txt").read().partition("\n── ВІДПОВІДЬ")[2]
   ```
   Документований запуск із шапки скрипту: `cd джерела && python3 проби/ключ_без_лапок_3462.py`.
   При виконанні з робочого каталогу `джерела/` відносний шлях `../аудит/...` вказує на кореневий каталог `аудит/`.

2. **Причина помилки сканера читачів:**
   У `джерела/прилади/читачі_записів.py:245`:
   ```python
   відносний = posixpath.normpath(posixpath.join(posixpath.dirname(читач), токен))
   ```
   Для `читач = 'джерела/проби/ключ_без_лапок_3462.py'` значення `posixpath.dirname(читач)` дорівнює `'джерела/проби'`.
   Об'єднання з `../аудит/...` дало `'джерела/аудит/живі_11/Н4/VIDPOVIDI/seed3_40_ОЦІНКА_відповідь.txt'`. Такого шляху в репозиторії немає. Сканер не врахував, що для скриптів підпапок робочим каталогом є `джерела/` (або корінь репозиторію), проігнорував наявність файлу й у сирому вимірі `4a38631eb5dfc2b76e2399a7af6c51efc1c5a051:аудит/виміри/чистка-записів-main/читачі.tsv` помилково записав:
   ```text
   аудит/живі_11/Н4/VIDPOVIDI/seed3_40_ОЦІНКА_відповідь.txt	19530	КАНДИДАТ: читача не знайдено
   ```

3. **Наслідок видалення:**
   У коміті `3dfe9fc1523c935717c51d5732c12ff15580f755` файл було видалено:
   - База `27c5d4686ce699a0e799e2c827c6efe94c0e8881`: файл присутній (розмір 19 530 байтів).
   - Голова `75c718a756ea2af7572d0d9c8303271de0e4c1b9`: файл відсутній.
   - Запуск `cd джерела && python проби/ключ_без_лапок_3462.py` на дереві голови аварійно падає з `FileNotFoundError: [Errno 2] No such file or directory: '../аудит/живі_11/Н4/VIDPOVIDI/seed3_40_ОЦІНКА_відповідь.txt'`.

Це є порушенням вимоги «нічого живого не видалено» та поломкою коду, що працював у базі main.
