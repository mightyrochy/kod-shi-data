## Доведене зауваження P1

Місце: `аудит/адаптери/gemini/queue_lanes.ps1:280–302`, особливо рядки 299–301; включення в чергу — `gemini_run.ps1:1069`. Суміжний договір публікатора: `gemini_publish.ps1:297–300`.

`Get-NightlyMarker` записує локальний `RunsDir/nightly/<дата>.json` та повертає об'єкт для `refs/remotes/origin/gemini-queue/Е1-нічний-живий-<дата>/gpt-6.1-sol-high/1/gpu-p8`. Він не створює відповідної гілки на GitHub. Після цього `Start-Markers` запускає об'єкт звичайним шляхом. Але `Get-Line` публікатора перед будь-яким `Publish-Bundle` вимагає, щоб Git ref цієї позначки дорівнював SHA зі стану. Відсутній ref дає `STATE_INVALID`.

Наслідок: автоматична ніч може витратити модельний ресурс і записати коміти, але її записи не будуть опубліковані. Штатного рядка ГОТОВО з гілкою нічного наряду диспетчер не отримає. Це порушує кінцеве мірило нічної черги, попри зелений стенд створення позначки.

Відтворення на точній голові: справжній `Get-NightlyMarker` створив позначку; стан DONE передано справжньому `Get-Line`. Підмінено лише відповідь читання відсутнього Git ref; `Publish-Bundle` замінено аварійною функцією, яка не мала викликатися. Публікація, бандл, GitHub ref і повідомлення не створювалися.
