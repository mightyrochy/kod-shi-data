# Читачі точки кольору: рішення для кожного місця

Переглянуто виклики `точка_кольору` та `_lab_речі` в усіх Python-файлах `джерела/`.
Пошук: `rg -n 'точка_кольору|_lab_речі' джерела -g '*.py'`.
Імпорти, документація й проби не є додатковими виробничими викликачами.
У таблиці перелічено функції, а вкладені функції позначено через `/`.

## Виправлені читачі

| Місце | Рішення |
|---|---|
| `фід_добір.описує_річ` | Відомий запис металу читається через спільний `palettes.колір_металу`; названий матеріал порівнюється з матеріалом рядка. Без названого металу потрібен той самий метал усіх точок меж; точка виміру класифікується без зворотного перетворення через LCh. Широке вікно не стає золотом за центром. |
| `палітра_схеми._lab_речі` | Замінено на `_колір_речі`: повний запис каталогу або речі, якщо відомі межі; невідомо — None. Усі три викликачі нижче передають саме запис. |
| `палітра_схеми.площі_схеми` | Сім'я, слоти й площі визначаються за повним інтервалом; інтервал більше не додає хибне «невиміряні». Геометрія й походження площ не змінені. |
| `палітра_схеми._великі_у_пулі` | Та сама сім'я за тим самим записом, що в `_великі_у_каталозі`; id пулу розгортається через каталог. |
| `палітра_схеми.слова_у_речах` | Слово крамниці враховується, якщо всю сім'ю доведено межами. Пріоритет каталогу за id збережено. |
| `аксесуари_структура.аксесуар_як_структура` | Названий метал та метал усіх меж виключаються з хроматичного бюджету спільними API. Інтервальне золото більше не породжує хибного питання про гучність. |
| `аксесуари_структура.акцентні_поверхні` | Вхід — відомі межі й відсутність доведеної нейтралі. Інтервали доходять до вже наявного тризначного `надточний_збіг`, який не видає слово за точний вимір. |
| `колір_нейтралі.бік_b_біля_обличчя` | Відомі межі доходять до вже наявного `відношення(..., 'warmer')`; невідомо й метал відсіюються так само. |
| `різноманітність_пулу._хрома` | Ранг яскравих речей бере гарантовану нижню межу C*, замість нуля для всіх інтервалів. Це ранг, не відсів; для виміру межі C* збігаються. |
| `palettes.слоти_акценту_схеми` | Гілка без дуги перевіряє відомі межі та доведену ненейтральність. Вигаданого hex для проходження гілки не потрібно. |

## Читачі, які зберігаються

| Місце | Чому точки тут коректні |
|---|---|
| `coordination.пари_близькості` | Вихід — числова відстань двох вимірів у вибраній метриці та ΔE00. Інтервал не має однієї такої відстані. |
| `coordination._хрома_ok_межі`, `coordination.інтенсивність` | Окрема гілка обчислює межі OKLab-хроми інтервалу й тризначний розрив; точка — лише для виміру. |
| `graph.зона` | Вікно перевіряється перед точкою; інтервал переноситься як L/C/h з походженням. |
| `outfit.елементи` | Точкові L/C/h заповнюються лише виміром; тип, вікно, походження та невідоме зберігаються окремо. |
| `palettes.поєднання`, `palettes.палітра_практична` | Це зразки побудованої палітри, а не записи речей зі словом. Числове поєднання й тон зразка потребують точки. |
| `palettes.lab_повної` | API саме точки, а `є_колір` окремо приймає і межі. Виклики цього допоміжного API також переглянуто. |
| `palettes.метал_меж` | Уже має інтервальну гілку сітки; точкова гілка класифікує вимір. |
| `palettes.хроматична_вставка` | Кольори вставки — виміряні кластери кадру; це не вікно назви металу. |
| `аксесуари_структура.C_речі` | Повертає саме C* виміру. Виробничі виклики в `аксесуар_як_структура` та `асиметрія_інтересу` мають попередню інтервальну гілку. |
| `дріт_моделі.річ` | Lab і `color_measurement` описують вимір. Інтервал, кодування й походження передаються окремо, а `має_точку` не робить інтервал виміром. |
| `знання_дріт._точка_посиланням` | Звіряє посилання на конкретне числове значення виміру, не класифікує колір інтервалу. |
| `знання_речі.властивість` | Тип спочатку розрізняється; для інтервалу переноситься вікно, для виміру — точка. |
| `колір_нейтралі.кластери` | Елемент зберігає межі й тип поряд із необов'язковим Lab; інтервали не викидаються. |
| `колір_нейтралі._пара_нейтралей` | Числова ΔE00 тканини — лише для двох вимірів; інтервальні відношення й можливі нейтралі мають окремі гілки. |
| `колір_нейтралі.температура_нейтралі` | За наявності меж перевіряються обидва краї C*, а не точка. |
| `колір_річ.межі_кольору` | Реалізація API: вікно/невідомо розбираються перед точкою. |
| `колір_річ.сім_я_меж`, `нейтраль_меж`, `роди_нейтралі_меж`, `рід_нейтралі` | Власні інтервальні гілки перед точкою або після неї; невідомо не стає виміром. |
| `колір_річ.межі_b`, `найближчі_точки` | Точковий випадок і геометрія найближчих країв інтервалів розведені в реалізації API. |
| `колір_річ.несе_тон` | Вставки — виміряні кластери; колір слова перевіряється власними межами й дугою, окремо від виміру. |
| `колір_хрома.бюджет_хроми`, `_тон_гучного` | Складений запис переносить необов'язковий Lab разом із типом та походженням; нижчі читачі судять межі. |
| `композитор_збирання.зібрати_кроками` | `_уск` — лічба саме вимірів для діагностики охоплення. |
| `композитор_річ.у_річ` | Hex та Lab утворюються лише з виміру; тип і вікно лишаються окремо. |
| `композитор_слоти.влучає`, `кандидати_на_слот/_збір_слота` | `вікно_речі` та частка перетину виконуються перед точковим `підходить`; виправлено їхній читач `описує_річ`. |
| `міст_пакет.цінність_пулу/_суміс` | Числова парна ΔE00 для оцінки різноманіття вимірів; єдиної точки інтервалу немає. |
| `оцінка_образу._без_входу`, `_без_кадру` | Перевіряють наявність конкретного виміру кадру та його числову відстань до слова. Каталожна заміна з інтервалу має інший шлях. |
| `оцінка_образу._слово_сильніше`, `перелік` | Розрізняють безспірний вимір, явно назване слово й новий піксельний дотик; інтервал не є піксельним виміром. |
| `оцінка_образу.суд_кроками` | Поле `вимір` кадру перевіряється точкою; запис зі словом окремо стає інтервалом для суду. |
| `оцінка_образу.речі_для_моделі`, `екземпляри` | `color_measured` і `виміряно` чесно позначають вимір, а не відомий словом колір. |
| `палітра_запити.макіяж_тон_у_тон` | Числова ΔE00 до обраного hex макіяжу визначає силу `1 − ΔE00/5`. Єдиного такого виміру для широкого інтервалу немає; це не відсів сім'ї чи заміни. |
| `палітра_принт.роль_принту` | Нитки принту — точки кольорів від виміру принту; вихід переносить саме ці виміряні нитки. |
| `палітра_схеми._її_річ_несе`, `_на_чому` | Після точки вже є `сім_я_меж`; інтервал не губиться. |
| `помада.суд` | Сходинка помади — зразок, побудований кодом точкою. |
| `регістр_уваги._L_C` | Власна інтервальна гілка після точки: обирає край з гарантованою силою або утримується. |
| `річ_з_фото.кластери`, `звести`, `виміряти_кроками`, `_вимір_плями_кроками`, `фото_за_словом_кроками` | Операції над піксельними вимірами: усереднення кластерів, тінь і безспірний вимір. Не замінюють словесну річ центром. |
| `річ_з_фото.членство_вікна` | Уже є окрема гілка всього вікна перед точковим членством. |
| `річ_з_фото.вердикт`, `запис_каталогу` | Обробляють вимір кадру й окремо записують інтервал/невідоме з походженням. |
| `річ_з_фото.основа_з_речі` | Для `база_hex` потрібен саме вимір зафіксованої речі; вікно не має одного hex. |
| `суд_від_моделі.схема_образу`, `кольори_образу`, `_елемент_точки` | Відомі інтервали не відкидаються; точкові L/C/h — None, тип і межі зберігаються. |
| `суд_чеклісти.колір_виміряний` | Назва й контракт — саме ознака виміру. |
| `суд_інтерес.хрома_інтересу`, `річ_несе_інтерес` | Інтервал має власний тризначний шлях гучності та нейтралі; точка — для виміряного кольору. |
| `траурний_регістр.траурний_регістр_речі` | Частка вікна L×C обчислюється перед точкою. |
| `формальність.нагода_палітра` | До траурного регістру передається повний запис або походження невиміру разом з необов'язковим Lab; попередня інтервальна гілка працює. |
| `фід_добір._від_очей` | Точка — лише частина ключа кешу; вікно також входить до ключа, а рішення приймає `у_відлунні_очей`. |
| `фід_добір.відстань_до_центру` | Перед точкою вже є обернена частка перетину вікон. |
| `фід_добір.покриття_кроками/_сила` | Інтервал проходить часткою вікна. Пошук найближчого виміряного кольору поза порожнім рядком і числовий підпис ΔE00 лишаються точковими діагностиками, а не вимогою входу кандидата. |
| `фід_добір.лексикон`, `Словник.describe`, `Словник.підпис` | Емпіричні медіани вимірів та точна ΔE00 до зразка. Інтервал не є спостереженням для середнього чи точним зразком. |
| `фід_збагачення.накласти_колір` | Вимір сегмента пише Lab; тип, невимір і збережений вимір передаються окремо. |
| `фід_кадр_колір.після_спору` | Порівнює реальний вимір кадру з назвою; вікно не є незалежним фото-виміром. |
| `фід_каталог.прочитати_каталог` | Читання кешованого виміру, передача виміру металу, звірка незмінності фото та збереження `колір_вимір`. Тип остаточного запису не підмінюється точкою. |

Викликачів `_lab_речі` більше немає. Нового центру в Lab не записано.
Проби не змінюють пороги палітри, вікна лексикону чи визначення сім'ї.
