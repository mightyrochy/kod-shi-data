## Що змінено

1. `outfit.елементи` бере числа й походження із самого `colors[*]`, без успадкування
   кольору речі. Старий псевдонім `не_вимір` переноситься без стирання власного явного типу.
   `lab_входу` читає власний Lab перед hex, узгоджено з `точка_кольору`, і враховує старе
   походження `назва_вікно`. Це також виправляє читача сегментів у `траурний_регістр`.
2. `накласти_колір` зберігає явне «невідомо» й походження інтервалу для основного та
   другого сегмента. Слово, обчислене з пікселів, більше не перетворюється на свідка моделі.
   Сирий фото-вимір зберігається окремо з придатністю; невідомий сегмент не дає точки чи меж.
3. `полюси_пулу` читає світлоту лише через API типу, без відновлення точки зі старого hex.
4. Передчасні закриття 1872, 3090, 5664 прибрано. Єдині записи цих станів — у
   `аудит/дошка/gemini-dorobka-1927.md`, усі ЧАСТКОВО до живого ПІСЛЯ.

Оглянуто всіх читачів сегментів `colors` у верхньому рівні ядра: `outfit` та
`траурний_регістр`; `areas` і збагачення — виробники. `дріт_моделі` має інше поле
`accent_families[*].colors`, перелік слів палітри. Оглянуто запасні читання hex поблизу
викликів API точки: у `знання_дріт` це точне кодування вже виміряного окремого факту,
у `пакет_моделі.у_дузі_вікон` тип лишається на записі й остаточний суд іде через API меж,
у `суд_інтерес` запасний шлях обмежено типом «вимір». Інших обходів відмови API точки
на цьому шляху не встановлено.
