## Мірило та доказ

Перший обов'язковий крок наряду — підтвердити через GitHub API автора, репозиторії, базу та точний SHA голови. Наряд вимагає за невідповідності завершити роботу з блокером без перевірки іншої голови.

Команда запиту (HTTPS без входу):

```powershell
$pr = Invoke-RestMethod -Uri 'https://api.github.com/repos/mightyrochy/kod-shi-data/pulls/1985' -Headers @{Accept='application/vnd.github+json'; 'User-Agent'='Codex-independent-review'}
$pr | Select-Object number,state,title,@{n='author';e={$_.user.login}},@{n='base_repo';e={$_.base.repo.full_name}},@{n='base_ref';e={$_.base.ref}},@{n='base_sha';e={$_.base.sha}},@{n='head_repo';e={$_.head.repo.full_name}},@{n='head_ref';e={$_.head.ref}},@{n='head_sha';e={$_.head.sha}},body | ConvertTo-Json -Depth 5
```

Дослівні поля відповіді, потрібні для мірила:

```json
{
    "number":  1985,
    "state":  "closed",
    "author":  "mightyrochy",
    "base_repo":  "mightyrochy/kod-shi-data",
    "base_ref":  "main",
    "base_sha":  "918a982d701c8c5d0b241ac7b035af485785c49b",
    "head_repo":  "mightyrochy/kod-shi-data",
    "head_ref":  "gemini/перевірка-1974-1975",
    "head_sha":  "9e49331018f88a7d09be7d9b7f468cccb23b17fa"
}
```

Автор, обидва репозиторії та база відповідають наряду. SHA голови не відповідає. Стан `closed` зафіксовано як факт відповіді; причиною блокування є саме невідповідність SHA.
