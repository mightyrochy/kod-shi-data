```
$ python3 -I -W ignore /tmp/t/вик.py /tmp/w_main   # ld: color «Чорний», 3 оферти; dom.rows: Колір → Чорний
```

Оферти розмірів — не варіації кольору: `len(варіації) == 1` зберігає колір сторінки, `len(...) > 1` з оферт його
викидає. Наряд велів брати колір «з даних свого варіанта (оферта, варіація зі своїм id і наявністю, свотч цього
варіанта)» — рядок характеристики самої сторінки й `ld.color` цієї ж сторінки цьому не суперечать.

`ricamare_3448` шлях інший — `ricamare_сторінка.py`).
Поза мірилом ризик малий: `наявність`/`колір` картки виконавця далі читає лише лічба повноти полів (`виконавець.py:272`),
не каталог продукту — тому це доробка кроку, а не рядок видимої вади.
