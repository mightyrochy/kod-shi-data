# Два контрольні склади для підписного стенда

Зібрати ДО і ПІСЛЯ з парою SHA, наведеною в PR. Модель, каталог, налаштування профілю та склад конкретної сцени однакові в обох проходах. Обидва склади взято з каталожного виміру. У чистій сесії чатів і шафи порівнювати лише руку продукту з цим складом.

| Шлях | Склад і вхід | Умова зарахування |
|---|---|---|
| `ядро=0` | `ж-08677@giardini-shoes.com` — коричневі велюрові черевики, `ж-00004@vmma.com.ua` — сіра сукня міді у смужку. L* 26,09 і 13,89. Профіль `стенд_вх.json`: шкіра `#deb295` (L* 75,8), волосся `#f1dbaa`, очі `#759087`. Репліка «На каву з подругою о 20:00. Склади образ саме із сірої сукні міді VMMA та коричневих велюрових черевиків Giardini». | При ΔL* 12,20 знахідка `K-SHO-04` має вагу 0,01 ДО й 0,05 ПІСЛЯ. У штатному вердикті рядків 0 → 1. У записі відповіді та на картці ПІСЛЯ перевірити, що зауваження стосується цієї пари і лінії ноги. |
| `ядро=1` | `ж-02122@cooshwear.com` — лляна сорочка, `ж-00024@maxa.ua` — вкорочені джинси з лампасами, `ж-08676@cultboutique.com.ua` — сині босоніжки Sergio Rossi. Репліка «На каву з подругою о 20:00. Склади образ саме із лляної сорочки Coosh, укорочених джинсів Maxa та синіх босоніжок Sergio Rossi з Cult Boutique». | `K-COL-01` (`one_lightness_level_reads_flat`) у `суд.судити` дає 0 → 1 заяв при розмаху 11,9 проти порога 12. Вага заяви ПІСЛЯ 0,05. Перевірити на картці й у вироку зауваження про світлоту цього складу. Цей свідок потрібен через межу проєкції K-SHO-04 в ядрі (17317). |

Якщо модель обрала інші речі, записати фактичний склад і позначити цей прохід як непридатний для порівняння. Обидві ревізії мають спочатку показати потрібний склад у запитах і вердикті. Окремо зберегти картку 390×844 і промпт із вердиктом кожного проходу.

## Команди

На ноутбуці з кореня актуальної гілки #4837 і чинною підпискою `agy`. Підставити точні SHA з PR у `E3_BASE` і `E3_HEAD`. Наведене ім'я моделі відповідає стенду Flash з репозиторію. Якщо диспетчер призначив іншу модель продукту, використати її в обох проходах.

```bash
export E3_BASE=1d8098d4330a5fa210abd0ab1c7cee25747bf980
export E3_HEAD="$(git rev-parse HEAD)"
export E3_REPO="$PWD" E3_RUN="$(mktemp -d)"
export E3_MODEL=gemini-3.8-flash AGY_MODEL=gemini-3.8-flash-high
export NODE_PATH="$E3_REPO/джерела/node_modules"
agy models
for rev in do after; do
  sha="$E3_BASE"; [[ "$rev" == do ]] || sha="$E3_HEAD"
  git worktree add --detach "$E3_RUN/$rev" "$sha"
  mkdir -p "$E3_RUN/build-$rev"
  (cd "$E3_RUN/$rev/джерела" && LYUSTERKO_CATALOG=повний python3 build_артефакт.py . "$E3_RUN/build-$rev/index.html" показ-повний) || break
done
sh аудит/проби/стенд_pyodide_кеш.sh "$E3_RUN/pyodide"
```

Для кожного `rev=do` і `rev=after` з `mode=0` та `mode=1` виконати блок нижче. У вікні Inspector відкрити картку потрібного складу, тоді натиснути **Resume**. Пакет `playwright` і Chromium використовують зі штатного стенда. Порт 8791 має бути вільним перед запуском власного моста.

```bash
rev=do mode=0
run="$E3_RUN/$rev-$mode"
mkdir -p "$run"
python3 "$E3_REPO/аудит/проби/живий-gemini-підписка-1/стенд/міст_agy.py" \
  8791 "$run/модель.jsonl" "$run/записи" "$AGY_MODEL" > "$run/міст.log" 2>&1 &
bridge_pid=$!
node - "$E3_RUN/build-$rev/index.html" "$E3_RUN/pyodide" "$run" "$mode" <<'JS'
const {chromium} = require('playwright');
const {readFileSync} = require('node:fs');
const path = require('node:path');
const [html, pyodide, run, mode] = process.argv.slice(2);
const origin = 'http://127.0.0.1:8765';
(async () => {
  const browser = await chromium.launch({headless: false, executablePath: process.env.CHROMIUM || undefined});
  try {
    const page = await browser.newPage({viewport: {width: 390, height: 844}, deviceScaleFactor: 1,
      isMobile: true, hasTouch: true, locale: 'uk-UA'});
    await page.route(`${origin}/index.html`, route => route.fulfill({path: html, contentType: 'text/html; charset=utf-8'}));
    await page.route('https://cdn.jsdelivr.net/pyodide/**', route => {
      const name = path.basename(new URL(route.request().url()).pathname);
      const type = name.endsWith('.wasm') ? 'application/wasm' : /\.m?js$/.test(name) ? 'application/javascript'
        : name.endsWith('.json') ? 'application/json' : 'application/octet-stream';
      return route.fulfill({body: readFileSync(path.join(pyodide, name)), contentType: type});
    });
    await page.route(url => url.origin === origin && decodeURIComponent(url.pathname) === '/міст', async route => {
      const response = await fetch('http://127.0.0.1:8791/', {method: 'POST', body: route.request().postData(),
        headers: {'content-type': 'application/json', 'x-prohid': encodeURIComponent(path.basename(run))}});
      const headers = {'content-type': 'application/json'};
      for (const name of ['x-model', 'x-images-dropped']) if (response.headers.has(name)) headers[name] = response.headers.get(name);
      await route.fulfill({status: response.status, headers, body: await response.text()});
    });
    const hash = new URLSearchParams({'міст': origin + '/міст', 'т': 'tok-lyudyna', 'модель': process.env.E3_MODEL,
      'модель_мови': process.env.E3_MODEL, 'ядро': mode});
    await page.goto(`${origin}/index.html#${hash}`);
    await page.pause();
    await page.screenshot({path: path.join(run, 'картка.png')});
  } finally { await browser.close(); }
})().catch(error => { console.error(error); process.exitCode = 1; });
JS
run_rc=$?
kill "$bridge_pid" 2>/dev/null || true
wait "$bridge_pid" 2>/dev/null || true
test "$run_rc" -eq 0
```

Сирі запити й відповіді — `"$run/записи"/*.json.gz`. Перший пошук вердиктів, які треба звірити з карткою:

```bash
zgrep -lE 'K-SHO-04|shoes_cut_leg_line|K-COL-01|one_lightness_level_reads_flat' "$run/записи"/*.json.gz
```
