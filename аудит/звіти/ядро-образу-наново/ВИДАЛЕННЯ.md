**Самим перемиканням жоден із 53 модулів старого шляху не знімається.** У них 41 296 рядків.

## Обсяг і відтворення

Вимір на `adb13cf9b1e7dca5d0c221e857d72fe89320c507`, Python 3.12.14 та Node 24.19.0.
Повтор з кореня на цьому зрізі з файлами звіту й залежностями `джерела/package-lock.json`.

```sh
npm ci --prefix джерела --ignore-scripts --no-audit --no-fund
python3 -I аудит/звіти/ядро-образу-наново/вимір_видалення.py --json /tmp/н7.json
```

У тимчасовій копії скрипт фіксує `ЯДРО_П = true`, лишає в точці `зібратиОбразиП` єдиний виклик ядра і вирізає
старе модельне обрання палітри. Для Python перейменовує один файл за раз і запускає кожен сценарій у свіжому процесі.
Для показу випускає один script із того самого шаблону, піднімає DOM і перевіряє дії. Для воркера виконує локальний
передзапит на зібраному файлі й на результаті складання з джерела. Окремі входи функцій Python відрізняють
їхні помилки від загального збою запуску `bridge.виклик`. У контроль іде той самий каталог, той самий показ і ті
самі твердження. Фікстури моделі детерміновані. У чотирьох руках ядра руки 1–2 отримують складені відповіді,
руки 3–4 — зафіксовані відповіді с5. Купівля й каталог читають вибірку з brief. У показі мережа відсутня,
відповіді моста на межі дає фікстура.

Чотири мірила відтворено за §§ Е1–Е4 і таблицею методів Fable. Межа тієї лічби — плоский Python-маніфест
`status.МОДУЛІ_ПРОДУКТУ`, нині 209 файлів. Залежність від `внутрішня_мова` — зворотна досяжність по імпортах
верхнього рівня. Найбільше коло — сильно зв'язана компонента зі вкладеними імпортами, без окремого запуску
`__main__`. Параметри рахуються без `self`, довжина — за межами AST разом з коментарями й докстрінгом, від 300
рядків включно. Після вилучення граф рахується заново. У частинах показано, скільки їхніх файлів входить до
найбільшого спільного кола, і цей стовпчик підсумовується до загального числа. [Звіт Fable #4308](https://github.com/mightyrochy/kod-shi-data/pull/4308)

Гіпотеза: окремо треба прогнати повну збірку з Pyodide, решту станів усіх екранів, повний каталог і живі відповіді
моделей. У цій батареї виміряно дії з названими фікстурами. Серед червоних вилучень є потрібна логіка та завчасні
імпорти читачів, обидва блокують пряме видалення файла. Зняття зайвого імпорту потребує наступної проби.
