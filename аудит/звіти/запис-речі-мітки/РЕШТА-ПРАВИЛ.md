# Решта правил реєстру

Ця таблиця доповнює [основну таблицю](МІТКИ.md#3-правила-та-межі-рахунку). Id походять із [повної таблиці зведення](../../../джерела/аудит/ЗВЕДЕННЯ.md#повна-таблиця). Для формулювань використано [довідник правил](../../../джерела/аудит/ПРАВИЛА.md) і теми, названі в зведенні. Вироки стосуються запису речі. Поза ділянкою запису лишаються окремі правила профілю, процесу, набору образів та підготовки даних. Їхній вирок «не покривається» стосується цієї пропозиції.
