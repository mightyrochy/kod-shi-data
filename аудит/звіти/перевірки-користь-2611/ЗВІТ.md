# Що дали перевірки за два тижні (12.11 00:00 – 26.11 00:00 UTC)

Наряд менеджера 26.11 `Перевірки-користь-вимір`; виконавець — сесія Claude. Лише читання й підрахунок: код, правила й дошку не змінено.
Висновку про правило тут нема — його робить менеджер. Кожне число нижче дає `порахувати.py` з таблиць цієї теки (повний друк — `числа.txt`, розділи 1–7 за тими ж номерами).

## Перша сторінка — простою мовою

- **Обсяг.** За два тижні вирішено 1234 PR: 1144 злито, 90 закрито без злиття. Це 658 документів, 326 приладів і проб, 160 змін самого продукту (+ закриті без злиття: 25, 41, 24).
- **Кого перевіряли.** Окремий вердикт «ПЕРЕВІРЕНО / ДОРОБИТИ» мають 96 із 160 змін продукту (60 %), 50 із 326 приладів (15 %) і 1 із 658 документів. Рецензію Codex (підсумок у PR) мають майже всі: 1135 із 1144 злитих.
- **Скільки вердиктів і які.** У таблиці 226 рядків; 152 мають явне слово вердикту в звіті, ще 60 — «ПЕРЕВІРЕНО» лише в темі коміту злиття (рушій там не названо), 14 звітів слова не мають. Серед явних: ПЕРЕВІРЕНО — 102, ДОРОБИТИ — 39, КОЛО (друга доробка) — 7, ЗАБЛОКОВАНО — 4. Перший вердикт по PR був «доробити» у 32 % випадків (39 зі 120).
- **Що знайшли.** Зауважень усього 569: 67 блокуючих у вердиктах, 272 рядки дошки «виявлено: перевірка» (ще 54 рядки дошки за вікно збігаються з блокуючими, тож «перевірка» дала на дошці 326 рядків), 230 коментарів Codex у рядках коду. За змістом (без Codex, 339): екран жінки — 38, хибна відповідь продукту — 71, прилад/проба/вимір/звіт — 183 (54 %), процес/оформлення — 47.
- **Скільки вад (екран жінки + хибна відповідь) зупинено.** З 109 таких зауважень (без Codex) 18 виправлено до злиття (десять — Claude, по чотири — Codex і agy); 9 злито попри вердикт «доробити» без нового коміту; 50 — рядки дошки про PR, що злито (у 44 рядок датовано днем злиття); 5 — PR закрито без злиття; решта — давні чи без визначеного PR. 93 із 109 досі «ВІДКРИТО» на дошці.
- **Що пройшло крізь.** Із 121 рядка дошки «живий / власник» за вікно 61 мають «внесено: #PR»; у 26 рядках (14 PR) цей PR мав вердикт ПЕРЕВІРЕНО, і всі 14 PR злито; 25 з них — екран жінки. Тестувальниця в цьому вікні рядків не дала.
- **Ціна.** 118 сесій перевірки Claude коштують 344,71 USD (без 5 сесій «оцінка прогону» — 22,79 USD). Ділення всієї цієї суми на 18 зупинених вад — 19,15 USD на ваду (верхня межа: сесії перевіряли й те, що вад не мало); лише на ті десять, що зупинив Claude, — 34,47 USD. Codex і agy: токени й гроші не виміряно, є лише число перевірок.
- **Що не змогли виміряти** — розділ «Не виміряно» нижче; найважливіше: рядок дошки не каже, яка модель його дала, і «внесено» не завжди означає PR вади.
- Файли: `вердикти.csv` (кожен вердикт: PR, ризик, рушій і модель, вердикт, коло), `зауваження.csv`, `пройшло_крізь.csv`, `додаток.md` (20 випадкових зауважень дослівно), `зібрати.py` + `порахувати.py`.

## Не виміряно (причина)

1. **Модель, що дала рядок дошки «перевірка».** Рядок має «виявлено: перевірка» без рушія; файли дошки сесій згортає CI. Тому зауваження за рушієм лічено лише для блокуючих вердиктів.
2. **Вердикти сесій без звіту-файлу.** 29 PR зі згадкою в файлах дошки сесій перевірки не мають вердикту в таблиці (звіт лише в тілі PR чи не збережено). Claude-звіт «перевірка-р2-2511» (приймання чотирьох чернеток Codex) PR-вердиктів не дає — не лічено.
3. **«Внесено».** У рядках дошки це інколи PR вади, інколи PR звіту чи доданого рядка; для джойну взято PR із вердиктом, інакше перший #N у тексті. 14 рядків (а)/(б) PR не визначено; на «пройшло крізь» це може давати і хибно-позитивні, і хибно-негативні зв’язки.
4. **Клас Codex-коментарів** — за шляхом файлу; «продукт» не розділено на (а) і (б); чи коментар врахували, у даних нема (прапорець нерозв’язаності збігається з наявністю знахідки).
5. **Доля «виправлено до злиття»** — за комітом у PR після дати вердикту (`сире/коміти_pr.tsv`), не за змістом коміту: коміт міг бути іншим за зауваження.
6. **Вартість Codex і agy**, а також частки токенів Claude на конкретні вади; витрат за PR перевірки в сесіях нема (сесія перевіряє пачку).
7. **Час між вердиктом і злиттям** — дата вердикту з коміту додавання звіту (UTC), час злиття точний; різниця до години.
8. **Рядки дошки поза датами 12–25.11** і PR, закриті/злиті раніше за 12.11, не лічено; один PR із вердиктом лежить поза вікном.
9. **Рушій 60 вердиктів «ПЕРЕВІРЕНО» з тем комітів злиття** не названо, тому в розрізі за рушієм вони окремим рядком.
10. Статус 20 рядків дошки «перевірка» (з них 11 у (а)+(б)) формат не розпізнав — ні «ВІДКРИТО», ні «ЗАКРИТО».

## Метод і відтворення

Читання: `git log`/`git show`, `gh api` лише GET для списку PR вікна, їхніх файлів, коментарів і підсумків Codex (`сире/*.tsv`); дошку читав із `аудит/БЕКЛОГ.md` і `аудит/дошка/**`. Клас PR: «продукт» — файли `джерела/` верхнього рівня (крім `прилади`, `проби`, `тест_*`) і `zhnyvarka/`; «прилад» — CI, хуки, `джерела/прилади`, `джерела/проби`, `ohliad-*`, `аудит/адаптери`, скрипти в `аудит/`; решта — «документ». Вікно: злито або закрито 12.11 00:00 – 26.11 00:00 UTC.

```
python3 -I аудит/звіти/перевірки-користь-2611/зібрати.py     # збирає CSV (потрібен gh і історія з 11.11)
python3 -I аудит/звіти/перевірки-користь-2611/порахувати.py  # читає лише CSV: числа.txt, додаток.md (seed 26112026)
```
