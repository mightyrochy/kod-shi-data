# Ноутбук — середовище й правила ноутбучної сесії

Роль прогону, каталогу й фото; якщо наряд править код — ще `аудит/ВИКОНАВЕЦЬ.md`. Запускає й вимикає обгортка за
позначкою диспетчера (`аудит/адаптери/gemini/ЧЕРГА.md`); запускача нема (власник 28.10) — порожні пробудження палили
ліміт Claude. Автор наряду ноутбука читає потрібний розділ.

## Середовище

- DESKTOP-6N11SA4, Windows, RTX 4090 16 ГБ; репозиторій `C:\Users\Admin\kod-shi-data`; LM Studio (`MODEL_URL` типово
  `http://127.0.0.1:1234/v1`), ComfyUI. Тут — живі прогони стенда, розбір каталогу, очне приймання фото.
- Повної копії репозиторію собі не робиш (власник 29.10): працюєш і пишеш вивід лише в теці, яку дала обгортка, без
  обгортки — у `git worktree` клону `C:\Users\Admin\kod-shi-data` лише з потрібними наряду теками
  (`git sparse-checkout`); нових клонів, архівів і тек ні в корені профілю, ні в `C:\tmp`, ні деінде не створюєш — 29.10
  там знайшли ~110 ГБ нічиїх копій: `C:\tmp` — 72,6 (171 тека сесій, 31 ГБ за тиждень), корінь профілю — ~35 (власник:
  «це все неконтрольоване копіювання репо»).
- Windows: `PYTHONUTF8=1 PYTHONIOENCODING=utf-8` — інакше `build_артефакт.py` падає на cp1251; `node` — з
  `~/.lmstudio/.internal/utils`; Playwright — `NODE_PATH=C:\Users\Admin\kod-shi-test-node\node_modules`; `.ps1` — з BOM.
- PowerShell для користувача `Admin` — `RemoteSigned` (власник 26.10): `.ps1` з репозиторію, зокрема стенди обгортки,
  запускаються без `-ExecutionPolicy Bypass`. Системну політику, `PSExecutionPolicyPreference` і обгортки на Bypass не
  чіпаєш — запобіжник відхиляє їх як послаблення захисту (26.10). Задачі обгортки свої скрипти запускають з Bypass
  процесу (`аудит/адаптери/gemini/m9v/1_адмін.ps1`).
- Пуш із частково склонованого репозиторію — `git push --no-thin -u origin <гілка>`, без `GIT_NO_LAZY_FETCH=1` (з ним
  пуш рветься: «could not fetch … from promisor remote»). Історію запушених комітів не переписувати.
- Avast «Вебзахист» вимкнено, git — на `http.sslBackend schannel`; увімкнути його власнику нагадує диспетчер, коли
  обгортка вимкнула ноутбук.
- Вікно сесії на мосту — 200 тис. токенів: довгий прогін — частинами, з пушем після кожної.
- Сервіси наряду піднімає сама сесія й наприкінці гасить своє — заздалегідь їх ніхто не запускає: запущене не сесією для
  неї чуже (класифікатор не дає його зупинити), а ComfyUI тримає відеопам'ять, якої бракує моделям.
  - LM Studio — `lms server start` (сам відкриває застосунок), далі `lms load` моделі наряду (нижче).
  - ComfyUI — лише для SAM чи перевдягання, сервер без вікна на :8000 (Comfy Desktop :8188 не потрібен: :8000 бачить ті
    самі моделі): з теки `C:\Users\Admin\ComfyUI-Installs\ComfyUI` фоном (`Start-Process`)
    `ComfyUI\.venv\Scripts\python.exe -s ComfyUI\main.py --port 8000 --base-directory C:\Users\Admin\ComfyUI
    --disable-auto-launch` з порожнім
    `SSLKEYLOGFILE` — Avast підставляє його в кожен процес, і Python ComfyUI падає на старті. Шляху нема —
    «НОУТБУК ЗАБЛОКОВАНО».

## Лист (п.6)

Локальна сесія Claude на ноутбуці хмарній — `claude -p --cloud <id з аудит/СТАН.md> --output-format json` (текст —
stdin, першою — мітка відправника; `"ok":true` — доставлено); не вийшло чи адресат локальний — `ListAgents`, потім
`SendMessage(to=<назва з ListAgents дослівно чи local_…; дві однакові — з міткою [ref]>, summary=<3–8 слів>,
message=<суть — першим рядком>)`, прочитання якого не підтверджується (власник 24.10).

## Моделі (п.15, п.16)

- Ролі стенда: `MODEL` — модель-стилістка й функції коду, `MODEL_MOVA` — мовна модель; MamayLM — лише `MODEL_MOVA`.
- Стилістка — `qwen/qwen3.5-9b`. Вантажити заздалегідь: `lms load
  qwen/qwen3.5-9b --context-length 81920 --gpu max --parallel 1 -y` — незавантажену LM Studio вантажить сама з
  контекстом 4096 і `parallel 4`, а промпт складання — ~48 тис. токенів.
- Обидві моделі разом у 16 ГБ не вміщаються (разом qwen падає або мовні виклики тягнуться 30–300 с): лише почергово,
  через проксі `аудит/ноутбук_стенд_2/проксі_почергове.js` (:1235) — qwen 57 344, MamayLM 16 384, перемикання ~5 с,
  прогін 4 рук ~18 хв. Впалу модель LM Studio перезавантажує з 4096 і `parallel 4` — після збою дивитись `lms ps`.
- Розбір каталогу — MamayLM; рядок `features` — до 30 слів (`СТЕЛЯ_СЛІВ=30`): відтінок, посадка, тканина, крій.
  MamayLM не вміщається разом із SAM (ComfyUI): під час розбору вимір кольору — лише CPU (ATR, `--лише-atr`), SAM —
  окремим прогоном на вільній карті.

## Кроки кожного наряду

1. Перевір доступність каналу результату з наряду способом адаптера; нема — блокер одразу, бо кінець наряду
   ніхто не побачить. Під обгорткою канал — останній рядок відповіді: його читає обгортка.
2. `netstat` потрібних портів і `lms ps`: зайнято чужим — одразу «НОУТБУК ЗАБЛОКОВАНО: …» з точною дією власникові.
   Чужих процесів не вбивай і чужих моделей не вивантажуй — класифікатор дозволів відмовляє (і проксі на новому порту
   теж), а широкий `pkill` блокує й наступні безпечні команди; зупиняти — лише своє, за PID. Завислий ComfyUI вбиває
   власник, коли класифікатор не дає.
3. За 1–2 хв після кожного фонового запуску звір, що процес живий (PID, свіжий рядок логу, `nvidia-smi`): фоновий `cd`
   губиться, прогін не стартує, а сесія чекає.
4. Першим комітом у гілку прогону — наряд дослівно (`<тека>/НАРЯД.md`): seed сесії й лист губляться разом із сесією й
   стисненням, і прогін стоїть без наряду. Після першої сцени звір `git ls-remote origin <гілка>` з локальним HEAD:
   скопійований `run.sh` попереднього прогону може пушити в чужу гілку (`BR=`).
5. Останній крок: зупинити свої проксі й ComfyUI (за PID), `lms unload` моделей, які завантажила сесія, прибрати
   створені нею дерева (`git worktree remove`) і вивід, якого нема в PR, звіт каналом наряду — «НОУТБУК ГОТОВО <гілка>
   <SHA>» чи «НОУТБУК ЗАБЛОКОВАНО: …». Ноутбук не вимикай — вимикає лише обгортка за позначкою (п.18).
