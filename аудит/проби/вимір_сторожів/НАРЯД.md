# Вимір сторожів обгортки з журналів ноутбука (дошка 12200, 12204)

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`, адаптер — `аудит/НОУТБУК.md`. Коду продукту й файлів
`аудит/адаптери/gemini/` не міняєш; лише читаєш журнали й пишеш звіт.

**Навіщо.** Рішення менеджера 01.11 (`аудит/корені/ПК-межа-без-джерела.md`, «Рішення менеджера 01.11 — питання PR
#2685»): `codex_stall_minutes`, `claude_hang_minutes`, `agy_turn_minutes` лишаються, але значенням — з виміру, без
запасу: найбільший проміжок між подіями у здоровому прогоні (для `agy` — найдовший хід) за всіма журналами ноутбука.
PR #2685 (обгортка без меж без джерела) не зливається, доки цього виміру нема. Поточні числа 60 / 120 / 120 хв узято
без джерела.

**Що зробити:**
1. **Прогони.** Усі наявні на ноутбуці прогони трьох рушіїв (усі вони — до #2685):
   - Codex — `C:\Users\gemini\gemini-runs\<id>\codex.events.tsv`;
   - Claude — `runs\<id>\events.tsv` теки `claude-run` (шлях — `аудит/адаптери/gemini/НАЛАШТУВАННЯ.md`, «Рушій Claude»);
   - `agy` — теки `C:\Users\gemini\gemini-runs\<id>\` (час початку й кінця кожного ходу — з журналу прогону й `wrapper.log`).
   Здоровий прогін — той, що закінчився ГОТОВО (не `STALL`, `HANG`, `INTERRUPTED`, `QUOTA*`, `AUTH`, помилка). Тека чи
   файл недоступні з твого облікового запису — не обходиш правами: «НОУТБУК ЗАБЛОКОВАНО: <шлях і відмова>».
2. **Вимір.** Для кожного здорового прогону — найбільший проміжок між сусідніми подіями (Codex, Claude) чи найдовший хід
   (`agy`), у хвилинах з двома знаками. Для кожного рушія — максимум за всіма здоровими прогонами, з id прогону, датою й
   двома подіями (чи ходом), між якими він. Скільки прогонів усього, здорових, без часових міток. Нехай рушій має 0
   здорових прогонів з мітками — так і пишеш: «не виміряно: <чому>», числа не вигадуєш.
3. **agy `-p` (12204).** `agy --help` — дослівний уривок про `-p`, `--print-timeout` і його типове значення. Далі один
   хід `agy -p` без `--print-timeout` на завдання, що триває довше 5 хв (наприклад, виконати `Start-Sleep -Seconds 420` і
   відповісти «готово»): чи обірвав його `agy` і на якій хвилині. Квота `agy` на 0 % — пишеш це й пункт пропускаєш.
4. **Звіт.** Гілка `claude/вимір-сторожів-обгортки` від `origin/main`. Файл `аудит/корені/ПК-межа-без-джерела-вимір.md`:
   таблиця «рушій | поле | вимір, хв | прогін | дата | між чим | прогонів усього / здорових / без міток», уривок
   `agy --help`, результат п.3, `git rev-parse origin/main`, час UTC виміру. Сирі дані — `аудит/корені/ПК-межа-без-джерела-вимір.tsv`
   (рядок на прогін: рушій, id, дата, кінець, найбільший проміжок / хід, хв). Першим комітом — цей наряд дослівно
   (`аудит/проби/вимір_сторожів/НАРЯД.md`), другим — звіт і видалення `аудит/наряди/вимір-сторожів-обгортки.md`.
5. Запуш гілку, `git ls-remote origin claude/вимір-сторожів-обгортки` = локальний HEAD; PR-чернетка з тілом останнього
   коміту (PR не продукту — рядка «ЖИВИЙ ПІСЛЯ» нема). Останній рядок відповіді:
   `НОУТБУК ГОТОВО claude/вимір-сторожів-обгортки <повний SHA>`.
