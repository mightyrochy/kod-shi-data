# Команди та налаштування

Робоча тека — корінь репозиторію. `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`,
`NODE_PATH=C:/Users/gemini/kod-shi-test-node/node_modules`.
`NODE_OPTIONS` і `PYTHONPATH` обгортки збережені; Chromium працює з `--disable-gpu`.
Версії, перевірка предка, відсутність змін записувача/стенда/проксі від призначеного SHA — `СЕРЕДОВИЩЕ.json`.

```powershell
git merge-base --is-ancestor 1b77b2048ad1896b660c1f562a32145847f06563 origin/main
git worktree add --detach --no-checkout ../tmp/збірка 1b77b2048ad1896b660c1f562a32145847f06563
git -C ../tmp/збірка sparse-checkout init --cone
git -C ../tmp/збірка sparse-checkout set
git -C ../tmp/збірка checkout --detach 1b77b2048ad1896b660c1f562a32145847f06563
```

Збірку не перебудовували: `build.txt` і `const ЗБІРКА_ПОКАЗУ` —
`263404595a84dcfd369ba67ff7a0c3e471897034`. Пізніше викладено `джерела/` у тому самому дереві
для читання приладів; `index.html` не змінено.

```powershell
python аудит/проби/записати_сцену.py ../tmp/збірка C:/Users/gemini/pyodide аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034/ж2_довга_розмова_слова --сцена ж2_довга_розмова_слова
python аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034/помічниця_після.py ../tmp/збірка
python аудит/проби/записати_сцену.py ../tmp/збірка C:/Users/gemini/pyodide аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034/ж1_оціни_образ_6б --сцена ж1_оціни_образ_6б
```

Другу й третю команди послідовно запускав `наступні_сцени.py`; stdout/rc — `команди.jsonl`
і `команда_*.txt`. Додаткове питання помічниці повторено після виправлення порожньої довідки
у її окремій пробі: перша спроба не викликала модель, доказ — `помічниця_після_1.json`;
друга — `помічниця_після.json`, HTTP 200, rc=0. Це не повтор сцени розмови.

Для пулу перед запуском встановлено `MODEL_CTX=52000`, а до наявного `NODE_OPTIONS`
дописано `--require "<абсолютний шлях з / до вікно-52000.cjs>"`.
Preload задає почерговому проксі фактичні контексти Qwen 52224 і MamayLM 16384.
Сторінка міряє проти 52000. `результат.json` містить початкове CTX=57344 записувача;
ефективне CTX дочірніх процесів видно в `повтор.json` та `проксі.txt`, де сервер підтверджує
`context_length=52224`, `parallel=1`. Код записувача, проксі й продукту не змінено.

```powershell
python аудит/проби/записати_сцену.py ../tmp/збірка C:/Users/gemini/pyodide аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034/б1_концерт_стримано --сцена б1_концерт_стримано
```

Спроби до фінального запису збережено:

- `б1_концерт_стримано_спроба1`: до старту стенда проксі впав через `\` у шляху `NODE_OPTIONS`;
  `команда_б1_концерт_стримано.txt` містить traceback. Моделей і карток немає.
- `б1_концерт_стримано_спроба2`: сервер округлив запитаний контекст 52000 до 52224,
  а проксі вимагав точного збігу; HTTP 503 з конфігурацією — у `проксі.txt`.
  Власний стенд PID 54892 (батько 51000, команда з унікальною текою цього наряду)
  зупинено до карток; rc=4294967295, записувач прибрав власні моделі й проксі.
  Сам preload цієї спроби — `вікно-52000_спроба2.cjs`.
- Фінальний запуск просить підтримувані рушієм 52224, зберігаючи `MODEL_CTX=52000`.
  Чужих процесів не зупиняли. Жодну завершену сцену не переганяли.

Початкові запити відтворено без моделі з модулів призначеної сторінки у справжньому Pyodide:

```powershell
python джерела/прилади/знімок_мосту.py pyodide --сторінка ../tmp/збірка/index.html --входи аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034/б1_концерт_стримано/виклики_моста.jsonl --вихід аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034/пул_до_скорочення.jsonl --pyodide C:/Users/gemini/pyodide
```

Це додатковий вимір початкових кандидатів, а не заміна прогону з моделями.
Завершальні команди та їхні rc записані у звіті:

```powershell
python аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034/аналіз_записів.py
node аудит/проби/нова_база.js аудит/проби/автоживий-263404595a84dcfd369ba67ff7a0c3e471897034
```
