# Механіка запису спроби 3

Це браузерне проходження через видимі поля й кнопки. Скрипт керування не викликає
функцій продукту для підстановки паспорта, відповідей, палітри чи готових карток.
`evaluate` використано лише для читання видимого DOM і реквізитів полів.
Кольори ж2 вставлено у видиме поле «Відповідь чату», виміри — у поля знайомства.

Chromium запущено через Python Playwright; збережено додані обгорткою NODE_OPTIONS
і PYTHONPATH. Власний проксі — дочірній процес керівного скрипта, порт 1237,
REST v1 LM Studio на 1234. Процес LM Studio не перезапускався.
Проксі є незмінений `аудит/ноутбук_стенд_2/проксі_почергове.js`.

Адреса сторінки містить параметри локального моста, обох моделей та їхніх контекстів.
Міст виконує реальні запити до `/v1/chat/completions` власного проксі:
переносить system/messages, температуру й max_tokens; блоки зображень переводить
між форматами HTTP API; для локального Qwen задає `reasoning_effort=none`, як стенд.
Текст відповіді не переписується й не доповнюється. Жодної сценарної заглушки,
повтору записаних відповідей чи підміни невдалого виклику немає.
Запити до платних хмарних API браузер блокує. Фото крамниць і ресурси сторінки
можуть завантажуватися з мережі; Pyodide 0.26.4 віддається з наявного кеша ноутбука.

`транспорт.jsonl` — лише час, модель і HTTP-статус, без промптів та оцінок.
Ранній попередній запит до завершення власної збірки записаний під початковою
назвою теки в журналі транспорту; його екрани перенесені до `підготовка-CI-збірка/`.
Базовий перший запит відрізняється часом надсилання 12:24:44 UTC.

Скрин — кадр 390×844 без збільшення до висоти сторінки; прокручування записане
окремими кадрами. JSON поруч — дослівний DOM-текст усієї доступної прокрутки,
а не твердження, що весь текст помістився одночасно в кадр. `хід.md` зберігає
той самий текст і UTC. Тайм-аут керування браузером не є відповіддю продукту;
успішний DOM-кадр не підміняє відсутнього PNG після тайм-ауту.

Дані не є судом над якістю образів. Якісні висновки, зіставлення з паспортами
коренів і рядки дошки залишаються окремій сесії судді за п.5 наряду.
