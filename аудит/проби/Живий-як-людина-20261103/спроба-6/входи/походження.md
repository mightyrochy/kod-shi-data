# Штучні фото

Усі чотири зображення створено вбудованим інструментом imagegen у цій сесії. Після створення кожне переглянуто: видно всю людину з одягом і взуттям, окреме фото містить тільки джемпер. Це вигадані дорослі жінки. Оригінальні PNG скопійовано без змін; CLI та платні API не запускались.
