# Синтетичне фото власних речей ж2

Файл: `образ-ж2.png`. Створено вбудованим інструментом image_gen за навичкою imagegen,
без CLI й без нового API-ключа. Це вигадані речі, не фото реальної людини.
Зображення перевірено оком: усі п'ять названих груп речей є, людей немає.
Оригінал скопійовано без редагування.

Запит генерації дослівно:

> Створи одне фотореалістичне фото для тестування застосунку стилістки. На світлому однотонному підлозі акуратно розкладено один цілісний жіночий образ (flat lay), усі речі повністю в кадрі, не перекривають одна одну: чорні прямі штани до щиколотки, молочний тонкий в'язаний светр з круглим закритим вирізом без декору, пара чорних шкіряних лоферів без підборів, сіре вовняне пальто довжини до коліна з відкритим передом, невеликі прості срібні сережки. Природне нейтральне денне освітлення, точні матеріали й кольори. Без людей, без частин тіла, без манекена, без тексту, без логотипів, без сумок чи інших речей. Уживання: синтетичний вхід для кнопки «Оціни мій образ», це не рекламний макет. Одна фотографія, без колажу.
