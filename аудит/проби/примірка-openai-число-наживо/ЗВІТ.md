## Команда

```
# збірка стенда (як `Живий-через-міст/прогін.sh`), потім:
STOR=/tmp/стенд PYODIDE=/tmp/pyodide node аудит/проби/примірка-openai-число-наживо/прогін.js <тека>             # без PAID — безкоштовна частина
PAID=1 STOR=… PYODIDE=… node аудит/проби/примірка-openai-число-наживо/прогін.js аудит/проби/примірка-openai-число-наживо
STOR=… PYODIDE=… node аудит/проби/примірка-openai-число-наживо/контроль_маски.js аудит/проби/примірка-openai-число-наживо
```
Запит — той самий формат, що шле сторінка: `містП('приміряння', …)` дає промпт, `модельЗадачіП(зміст, …, 'gpt-image-2.6-sunburst', …)` — виклик
(блоки: її кадр base64, річ base64, промпт). Скрипт сам обриває більше двох POST з `gpt-image-*`.
