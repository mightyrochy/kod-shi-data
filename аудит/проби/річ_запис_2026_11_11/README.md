## Що перевіряємо

Назва береться з `name` моделі, у канонічній формі — `name.free_text`, у сирій парі — `name.value`.
Цитата `quote` не підміняє назви навіть без відповіді моделі на це поле. Розгортання вкладеного запису
не створює назву з цитати; загальний читач вільного тексту також не перетворює `name: {quote}` на назву.
У показі кожна власна назва перекладається окремо, лише з контекстом цієї речі. Опис, спосіб носіння
й інші речі не входять у цей виклик. Повтор і перевірка відповіді спільні з рештою текстів картки.

Корпус приладу: **122 вхідні записи** 07.11, з них **5 записів із 7 картками її речей**.
`повтор-до.json` та `повтор-після.json` містять усі ці записи й картки до перекладу показу.
Порівняння всіх полів дає рівно **8 змін**: 4 назви записів і ті самі 4 назви карток;
ідентифікатори, слоти, ознаки, кількість речей і решта полів збігаються:

| ДО | ПІСЛЯ |
|---|---|
| лляною сукнею Амора з vilni.store | Амора |
| моєї спідниці (два записи) | спідниця |
| у мене є білі кеди, хочу піти в них | білі кеди |

Три назви моделі зору — `Blouse`, `Trousers`, `Necklace` — збережені в записах.
Нуль приладу перекладу доводить незалежність назви від опису при підміненому виклику моделі,
а не якість живого перекладу цих трьох назв.

## Відтворення

З кореня репозиторію, без мережі й викликів моделей:

```text
python -X utf8 джерела/прилади/корінь_річ_запис_речі.py --звіт ../tmp/запис.json
python -X utf8 джерела/прилади/річ_запис_її_річ.py
python -X utf8 джерела/проби/річ_назва_14491.py
python -X utf8 джерела/проби/річ_назва_межа_14491.py
python -X utf8 аудит/проби/річ_запис_2026_11_11/повтор.py ../tmp/повтор.json
node аудит/проби/річ_запис_2026_11_11/знімок.cjs ../tmp/повтор.json ../tmp/картка.png
```

У Windows штатний запуск частини приладу ДО падає з «трасування неповне»: її трасувальник порівнює
імена кадрів із префіксом `str(джерела) + '/'`, тоді як Python дає зворотну риску після теки.
`віконні_шляхи.py` запускає **незмінений** прилад із нормалізацією лише `co_filename` модулів продукту,
включно з дочірніми процесами Python. Код інструкцій, дані, прилад і правило підрахунку не змінюються:

```text
python -X utf8 аудит/проби/річ_запис_2026_11_11/віконні_шляхи.py джерела/прилади/корінь_річ_запис_речі.py --звіт ../tmp/запис.json
```

Середовище власної перевірки: Windows, Python 3.12.10, залежності показу з `npm ci --ignore-scripts --no-audit --no-fund`,
`PYTHONUTF8=1`. Архівні входи відновлені через sparse-checkout; зокрема корпус 07.11, 144 HTML, б1,
`аудит/тести/сирі_2026-09-26/`. Для AST-реєстру усі п’ять змінених або доданих Python-функцій відсутні в `pipeline.py@ac8c2ca`,
тому запис про свідому зміну не додається.

повтор корпусу це показав, варіант знято до остаточного виміру. Канонічна назва й сира пара тепер приймаються обидві.

й без `name` губив слот. Протокол ДО — 0, перший ПІСЛЯ — 1 збій, після відділення читача кодів — 0;

попередньому ПІСЛЯ, усі 7 карток збережені. Повтор повного приладу на остаточному коді `ae090297087` завершено: **0 місць**, код 0, 144 HTML і весь корпус її речей.
Початкове перенаправлення stdout PowerShell дало UTF-16, тому скрипт повтору тепер пише JSON явно в UTF-8.

Свіжий каталог і живі моделі не запускали. Власні проби й нуль приладу не є незалежним прийманням
чи живим закриттям кореня. П.1–3 класу, брак джерел крамниць за Cloudflare й попередні знахідки паспорта лишаються.
