# Проба «назва відтінку → код» (наряд `Річ-колір-вимір-назва-в-код`, 17.11.2026 UTC)

Чи приводить вільна назва відтінку від сильної моделі, перекладена мовною моделлю в координати без фото, до свотча,
який власник сам визнав чи підібрав. Продукту, каталогу, приладу кореня й теки `річ_колір_модель_кодує/` не змінено
(звідти лише читаються `блоки.py`, словник і лічба контролю).

- `запити.py` → `запит_<варіант>_<набір>.txt`: (А) Манселл H V/C з інтервалом; (Б) номер рядка словника 267 блоків
  (чинний шлях вибору); (В) CIELAB LCh з інтервалом через опорний відтінок і зсуви модифікаторів, опорні точки шкал
  пораховано кодом із renotation. Набори — `sproba2` (40 речей мірила, 49 свотчів) і `sproba1` (40 речей, 48 свотчів).
- `відповідь_<варіант>_<набір>.json` — сирі відповіді шести свіжих субагентів (по одному на варіант і набір), кожен
  бачив лише свій запит: 2 виклики інструментів — прочитати запит, записати відповідь. У `відповідь_В_sproba1.json`,
  № 7, перекладач сам повідомив про зайвий ключ `"número": null` — лічба його не читає.
- `лічба.py` → `лічба_sproba2.tsv`, `лічба_sproba1.tsv`, `звіт.md` — лічба кодом, без очей і без суду моделлю;
  визначення ознак і причин — у шапці скрипта. Вивід детермінований (два запуски побайтово тотожні).

Крок 5 «Візерунок»: `запит_мотив_<набір>.txt` (ті самі 40 назв; запис — вид мотиву своїми словами, розмір, напрям
смуг, основа, мотив і окремим полем фактура; переліку класів продукту перекладач не бачить) → `відповідь_мотив_<набір>.json`
(два свіжі субагенти, по одному на набір) → `лічба_мотиву.py` → `лічба_мотиву.tsv`: вид перекладача й сама назва через
`verify.клас_мотиву` (шлях продукту), мірка — вердикт власника «принт» з `лічба_<набір>_власник.tsv`.

| | `sproba2`, 12 речей | `sproba1`, 10 речей |
|---|---|---|
| вердикт власника «принт» (п/н/з) | 8 / 1 (25) / 3 (16, 29, 36) | 9 / 1 (22) / 0 |
| вид перекладача → клас продукту | 8 (з визнаних 5) | 2 (з визнаних 1) |
| → лише «принт» | 0 | 1 (13 «графічний принт») |
| → жодного класу | 3: 12 «квіти», 30 «написи», 36 «пальмове листя» | 7: «квіти» 4, «смуга» 2, «клітка» 1 |
| перекладач: візерунку нема | 1: 10 — «твід з різнокольоровими нитками» — фактура | 0 |
| сама назва → клас / «принт» / нічого | 7 / 0 / 5 | 2 / 1 / 7 |

Перелік, що покрив би всі 22: чинні класи смужка, квітковий, клітинка, горох, анімалістичний — з формами коренів
«квіти» (5 речей; і «квіточки» в назві 12), «смуга»/«смугу» (2 + назва 18), «клітка» (1), — і три нові види: «написи»,
«листя» (рослинний), «графічний» (кожен по 1). Фактуру перекладач виніс окремо в 23 з 80 назв обох наборів; клас продукту
вона дає лише «мереживо» (`sproba1` № 36: продукт читає мереживо мотивом, перекладач — фактурою). Причина «н»/«з» —
лише факти: вердикт сторінки стосувався кольорів принту моделі, а не виду; назву (з видом) у `sproba2` визнано в усіх
12. № 25 «н»: колір принту «молочний» — поза назвою «сіро-коричнева твідова клітинка»; № 22 (`sproba1`) «н»: «графіт» —
поза назвою «у тонку темну смужку»; № 16 «з»: «молочний» — основа, а не мотив; № 29 «з»: «темно-синій», «блакитний» —
мотив; № 36 «з»: «коричневий» — мотив, «хакі» — поза назвою. Переліку продукту не змінено; корені, яких він не знає, —
дошка 16468.
