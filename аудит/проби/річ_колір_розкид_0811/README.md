# Перевимір дельти за правилом розкиду (крок «розкид», #3315)

Код — гілка `claude/Річ-колір-вимір-розкид` (перевимір почато на 15725ed04, доміряно на c719d6e8 — злиття `main` без
змін виміру; `частка.py` — ac547aafa09e61f44c42ef1cee6157e3cb7a4c2d). Дані — ця гілка 43dd34ad (`річ_колір_перезбір_0411/дельта.json.gz`, фото).
Хмара, ATR на процесорі (Leffa ONNX), 1508 придатних вимірів дельти; SAM-кадри (20) хмара не відтворює — ноутбук,
наряд `аудит/наряди/Річ-колір-вимір.md`, абзац «Виконавець (08.11)».

- `перевимір.json.gz` — `мета`, `записи` (новий запис кадру `жнива_кадри.записати_вимір`), `звірка` (маска й hex
  до/після, код до/після, поправка, C і U, уражений, відтворено, причина спаду).
- `частка.txt` — вивід `частка.py`: частка кадрів з кодом з виміру ДО → ПІСЛЯ, причина спаду.
- `зберегли_код.tsv` — уражені й відтворені кадри, що зберегли код з виміру (сукупність мірила очима).

Відтворити: `python3 -I аудит/проби/річ_колір_розкид_0811/частка.py аудит/проби/річ_колір_перезбір_0411 аудит/проби/річ_колір_розкид_0811/перевимір.json.gz`
