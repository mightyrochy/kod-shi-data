# Перевимір дельти за правилом розкиду (крок «розкид», #3315)

Правило — суворе прочитання (рішення менеджера 08.11 на знахідку, PR #3331): код з виміру — слово вікна коду самої
точки виміру, лише коли весь розкид (поправка тла від ×1,00 до виміряної, C ± U за будь-якого тону) лежить у цьому
вікні; інакше «невідомо», і річ лишає вікно крамниці. Попередній прогін цього каталогу (123ccbde, «найтісніше вікно
розкиду») замінено.

Код — гілка `claude/Річ-колір-вимір-розкид` f2e3e3b014c4c359b6a1ef7c0834fcc7ac8c0dfb (увесь прогін, з доміром тим
самим кодом; `частка.py` — там само). Дані — ця гілка 43dd34ad (`річ_колір_перезбір_0411/дельта.json.gz`, фото).
Хмара, ATR на процесорі (Leffa ONNX, onnxruntime 1.29.0 CPU), 1508 придатних вимірів дельти; SAM-кадри (20) хмара не
відтворює — ноутбук, наряд `аудит/наряди/Річ-колір-вимір.md`, абзац «Виконавець (08.11)».

- `перевимір.json.gz` — `мета`, `записи` (новий запис кадру `жнива_кадри.записати_вимір`), `звірка` (маска й hex
  до/після, код до/після, поправка, C і U, уражений, відтворено, причина спаду).
- `частка.txt` — вивід `частка.py`: частка кадрів з кодом з виміру ДО → ПІСЛЯ, причина спаду.
- `зберегли_код.tsv` — уражені й відтворені кадри, що зберегли код з виміру (сукупність мірила очима).

Відтворити: `python3 -I аудит/проби/річ_колір_розкид_0811/частка.py аудит/проби/річ_колір_перезбір_0411 аудит/проби/річ_колір_розкид_0811/перевимір.json.gz`
