# Вердикт її словами без «Вдягнеш?» — ДО і ПІСЛЯ

Наряд `Прогін1-вердикт-її-слова` (вада 1 `аудит/проби/живий-як-людина-1/вади.md`, дошка 14899). Знімки 390×844
(масштаб 2) зібраної сторінки; той самий прогін із чотирьох карток, вона пише в поле першої картки «Сукня гарна, але
для новорічної вечірки замало блиску — я б додала сережки й узяла туфлі на нижчому підборі.» і тисне «Записати
вердикт», не торкаючись ні «Вдягнеш?», ні «Це саме твоє?»:

- ДО — `index.html` збірки `main` 47ab37fc94b2a767f24e359515d2290cb8443ca1: під кнопкою «Обери відповідь на
  «Вдягнеш?»», «оцінено 0 з 4» (`ДО-1-картка.png`); у «Усі образи» всі чотири «ще без вибору», журнал «Ще порожньо»
  (`ДО-2-усі-образи.png`); «Зберегти всі вердикти файлом» — «Поки нема чого зберігати», файлу нема (`ДО-3-файл.png`).
- ПІСЛЯ — `python3 build_артефакт.py . <вихід> показ-повний` (каталог повний, байткод CPython 3.12.1) з гілки наряду:
  «Записано.» і згорнуте «Твій коментар», «оцінено 1 з 4», перехід на наступну неоцінену (`ПІСЛЯ-1-картка.png`;
  на знімку повернуто на першу); перший образ у «Усі образи» — «записано словами», журнал «перший образ · записано
  словами» (`ПІСЛЯ-2-усі-образи.png`); файл збережено, «вердиктів 1» (`ПІСЛЯ-3-файл.png`), сам файл —
  `ПІСЛЯ-вердикти.json`: `коментар` — її слова, `вердикт_людини` нема, `питання_поля` = `start`, `ребра_чому` —
  «без відповіді на «Вдягнеш?» — слова без оцінки носіння…».

Міст «вердикт», «мова» й перекладач підмінено (офлайн, без моделей): прочитання слів моделлю й дія коментаря — питання
живого прогону. Відтворити: `node знімок.js <шлях до зібраного html> <префікс виходу>` (Playwright із середовища;
збоїв сторінки 0).
