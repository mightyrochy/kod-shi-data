# Слова підпису й нижня межа відсортованої черги

Вибірка над 181 місцем (сід 77) не прийнята: `палітра_нейтраль.py:293`,
`палітра_специфікація.py:97`, `колір_річ.py:799` — три хибні місця.

На всьому Python-обсязі писачі й читачі визначили поля лише підпису:
`вироджено`, `пара_виміряно`, `через`. Імена цих полів не записані у приладі як вилучення.
Для `вироджено` читачі — копія того самого поля та додавання в `примітка` (`колір_світлота.py:475,503–504`);
у JS показу такого поля немає. Скалярний псевдонім слів знімається лише за наявності текстового читача
й відсутності читача рішення. Форматоване поле, яке веде вибір коду, не знімається.

Перевірка на справжніх AST:

| `палітра_специфікація.py:97` | лише поле пояснення; знімається |

Для сортування перевіряються напрямок, той самий чистий ключ, сталість його замикання й незмінність порядку черги.
