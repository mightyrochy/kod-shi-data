# Крок «один колір речі» — 14.11.2026 UTC

Наряд `Річ-колір-вимір-один-колір` (рішення менеджера 14.11, паспорт `Річ-колір-вимір`, «Що лишилось» п.1).
Код з виміру — лише там, де вимір бачить один колір речі (`джерела/surface.py`):

1. **Тон.** Слово з дугою тону (молочний, бежевий, коричневий…) — лише за тону, який вимір бачить (C* > U) у дузі
   слова, і на низькій хромі теж (виняток «дуга судиться з C* ≥ 10» `слово_з_lab` знято лише для коду з виміру).
   За невідомого тону код — лише нейтраль без дуги, чия хрома C ± U вся в її вікні (як і доти).
2. **Візерунок.** Вимір сам бачить кілька великих кольорів (`візерунок` «двоколірний» чи «принт») — код головного
   сегмента не колір речі: «невідомо», межі розкиду головного сегмента лишаються частковим виміром.

Нових порогів нема: U — `невизначеність_хроми`, межі візерунка — ті, що вже дають `візерунок`.
