Що міряє кожна вада (поле `видно` у `<дерево>_факти.json`):

- **9** — на першому екрані видно поле запиту, дужки чи англійські слова, або нема «Скопіювати запит».
- **12** — після введення довгого відгуку (16 рядків) «Записати вердикт» не вміщається у вікні цілою чи перекрита.

- **Т1** — після запису четвертого образу рядок пейджера не каже «Вердикт на образ 4 записано».
- **Т2** — при записаних вердиктах згорнутий вибір вивантаження каже «Поки нема чого вибирати».
- **Т3** — «Ошатне» змінюється, поки відкрито аркуш макіяжу після дотику «хай обере стилістка» (хід плиток — 8 с).
