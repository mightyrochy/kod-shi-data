## Зміна рішення

П'ять викликів координатора та рук проходять через `модельРукиП`: текст, фото,
стеля відповіді й вікно їхнього рушія перевіряються перед транспортом.
Попередня межа побудови пулу береться з `loaded_context_length` без стелі відповіді;
після складання повного промпта правило бачить також його сталу частину.
Стала 43 400 у вході браузера прибрана; Python-дефолт для інших клієнтів не змінено.

Правило знімає рядки з кінця найчисленнішого типу, зберігає кожний тип,
порядок решти та всі номери речей, на які посилається решта даних запиту.
`showcase` узгоджується з кандидатами, вердикти всіх образів залишаються.
З тверджень знімаються лише вже визначені порожні поля. Для опису зменшується
роздільність копій фото, кожна річ і підпис фото залишаються. Початкові дані не мутуються.
Назви й кількості скорочень записуються в спробу планувальника.

Початкова поправка оцінки тексту 0,92 → 1,1 за відношенням рушій/оцінка до 1,09
на записах б1 (джерело — паспорт кореня). Поправка з `usage` зберігає найбільше
виміряне відношення, без занижувального обмеження. Фото враховуються клітинками
28×28 із заголовків PNG/JPEG, як у жнивах; нечитабельний кадр — оцінка 1 400.

## Перевірки та повтор

Windows: `PYTHONIOENCODING=utf-8`, **`PYTHONUTF8=1`**. Перед тестом показу
байти фікстури `seed3_15_ВЕРДИКТ_V1_ОБРАЗИ_V1.txt` відновлено до LF, як записано
у відомій підготовці Windows (12278). Перший запуск гейтів без `PYTHONUTF8`
обірвався у §120: читач stdout дочірнього процесу читав UTF-8 як charmap,
`UnicodeDecodeError` дав `stdout=None`. Це обмеження запуску, код приладу не змінено.

З теки `джерела` пройшли: `python стенд_знімок.py --дим`,
`python тест_живого_шляху.py` (6/6), `python тест_протоколу.py`, `python audit_contracts.py`.
`PYTHONUTF8=1 python прилади/розділи_гейтів.py`: **575 пройдено, 0 впало, 0 без входу**, код 0 (`гейти.txt`).
`NODE_PATH=node_modules node тест_показу.js <зібраний index.html>`:
925/925, 74 розділи, код 0 (`показ-збірки.txt`). Нові звірки — початкові пул і ремонт,
повне вікно зі стелею, кожний тип, усі образи та їхні речі, межа з налаштування,
роздільність двох фото зі збереженням вихідних кадрів. Заглушки старих тестів стадій
