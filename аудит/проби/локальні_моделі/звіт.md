**Висновок по моделях.**
- `gpt-oss-20b` — не пройшла: наряд зрозуміла хибно («вже вирішено»), жодної правки, прилад 27.
- `qwen3.5-9b` — не пройшла: шаблон чату в LM Studio несумісний із запитом Claude Code (500 до першої відповіді); потрібен
  інший шаблон чи проксі, що зводить системні повідомлення в одне.
- `devstral-small-2507` — не пройшла: у 16 ГБ вікно 40 960 замале для запиту Claude Code (системний запит + наряд + файли
  понад 59 тис.), а ширше не влазить; без правок.
- Порівняння з `797a217a8` за батареєю не відбулося: правок у жодної моделі нема, батарея на базі лише для довідки не
  ганялась (окремі кроки `стенд_знімок.py --дим` ~10 хв, `тест_живого_шляху.py` — понад 10 хв; у python 3.10, а КОД.md
  вимагає 3.11).

**Не зроблено й чому.** Моделі родини Qwen3-Coder (30B-A3B, ~18 ГБ) у 16 ГБ без частичного винесення на CPU не вміщаються,
тому не завантажувались; `codex --oss` на ноутбуці не встановлено. Інших моделей із викликом інструментів і вікном ≥ 64 тис.
у наявному наборі нема (gemma-4 / lapa / mamaylm — стилістка й мова, не код).

Вад продукту, знайдених побіжно, нема — дошка (рядки 13721–13725) не змінюється.

Гілки `проба/*` видалено локально, `lms unload --all` виконано, дерево повернуто на `origin/main`.
