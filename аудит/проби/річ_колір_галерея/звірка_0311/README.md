## Батарея

Середовище: Windows, Python 3.12.10, Node 22.23.4; у CI Python 3.11. Залежності показу
встановлено штатною командою `npm ci --ignore-scripts --no-audit --no-fund` із `джерела/`.
Фікстури додано через sparse-checkout із кореня дерева:
`git sparse-checkout add '/аудит/проби/б1/' '/аудит/проби/поверхня_212/'`.
Перший виклик sparse-checkout із `джерела/` завершився відмовою Git через робочу теку;
повтор із кореня виконався успішно.

Команди батареї — з `джерела/`, `PYTHONUTF8=1`, `NODE_PATH` — абсолютний шлях до
`джерела/node_modules`. Усі виконуються послідовно до завершення, включно з кроками
після можливого провалу. Команди, коди виходу й підсумкові рядки — `підсумок.txt`.

```text
python стенд_знімок.py --дим
python тест_живого_шляху.py
python тест_протоколу.py
python прилади/розділи_гейтів.py
python audit_contracts.py
node тест_показу.js
python проби/кадри_групи_5697.py
python проби/кадри_поверхня_запис.py
python проби/кадри_поверхня_читач.py
```

Додатково з кореня: `python джерела/прилади/згорнути_дошку.py --лише-перевірити`.

продовження змін немає; повторні 14 проб AST не запускалися, їхній попередній
