# Відсутні входи для решти перевірки

- Повні масиви `E_чисті` та `E_над` після `вето_покриття` для кожного образу. Для суду потрібні, зокрема, `край_джерело`, `довжина_виробу_см`, площа та її межі, `lab`, фактура й ознаки принта. Із 43 образів з верхнім шаром два мають точну заяву про брак довжини. Для решти 41 повних входів п.17 немає.
- Первинний `_усі_зн` до агрегації. Для п.18 потрібні `запит_у_каталог.слот`, `цільова_L`, `цільова_L_темніше`, `цільова_L_світліше`, інші осі колірних вікон і первинні стани K-COL-01, K-COL-CONF, K-COL-JOIN, а також пізні `записи` для `позначити_без_входу`. Архівні зведення п.18 не зберігають одиничних вікон.
- Ефективний `сц`, `входи_палітри` з `вікна` та `бракує_вибору`, вектор `реєстр`, `входи_чекліста` аксесуарів, `без_акценту` та `контекст_правил` для окремого образу. Архів зберіг `день`, опис нагоди, підсумкові клітинки й окремі явні поля.
- Повний `суд_` саме оцінки з фото. Потрібні фото-ID, виміри й стан речей, `образ`, `запасні`, `сцена`, `суд.findings`, `суд.blockers`, `зміни`, `не_на_фото` і повний `без_входу` із `черга_на_вхід`, `утримано` й даними про обличчя. Для `промпт_оцінки` потрібні `питання` й `мова_тексту`, для `промпт_допиту` також `попередня` та `питання_оцінки`. У вже звірених 106 архівних обмінах повних таких тіл 0.

Повне порівняння тіл запитів, картка й продуктове Р3 відкриті.
