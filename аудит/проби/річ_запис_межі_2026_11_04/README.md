ДО — поля `факти_з_картки` старого коду, включно з метаданими; це наявність,
а не правильність. ПІСЛЯ назва й опис читаються зі спільного HTML-читача:
селектор рецепта обмежує товар, селектори його назви й опису працюють лише
всередині межі. Метадані не підставляються замість відсутнього тексту.
Браузерна картка користується тими самими фактами; метадані зберігають ціну,
наявність, фото й крихти. Текстові бренд, SKU, матеріал і розмір варіанта,
а також ідентифікатори з непідтвердженого JSON-LD більше не переносяться.
Покриття цих додаткових полів на новому повному каталозі тут не оцінено.

`поля-до.json.gz` містить вихідні поля, `поля-після.json.gz` — результати
кожної URL, селектори, джерела тексту, SHA256 вхідних HTML і файлів продукту.
Наявність тексту не доводить його якості: сама крамниця Wear Me в трьох
HTML залишає в блоці опису тільки «Опис:». Ці поля виключені з приймальної
лічби: **110/117**, вище порога 100. Вердикти й URL — `очі-описи.json`.

Відтворення з кореня:

```powershell
$env:PYTHONUTF8='1'
python -X utf8 аудит/проби/річ_запис_межі.py --вихід ../tmp/поля.json.gz
python -X utf8 аудит/проби/річ_запис_браузер.py --поля ../tmp/поля.json.gz --вихід ../tmp/браузер
python -X utf8 джерела/прилади/корінь_річ_запис_речі.py --звіт ../tmp/походження.json
python -X utf8 zhnyvarka/тест_межа_зліпка.py
```

## Межі й невдалі спроби

- Рецепт MustHave називає спільного предка основного товару й портального опису;
  окремий селектор виключень до читання прибирає інші дочірні секції й комплект
  рекомендованих речей. Це перевірено також синтетичним прикладом у Chromium.
- Maxa має дубльований атрибут `class` на секції товару. BeautifulSoup бере
  останній, Chromium — перший. Селектор `section[id^="product-"]` вибирає той
  самий вузол у всіх трьох HTML та в браузері; селектор `section.product`
  в офлайн-браузері не знаходив товар.
- Перший браузерний повтор через `set_content` не мав початкової URL й упав
  на відносній адресі фото. Повтор через локальну відповідь на початковій URL
  з `charset=utf-8` усунув цю перешкоду проби. Скрипти крамниць вимкнено,
  решта запитів відхиляється; мережевого жнивного прогону немає.
- Локальне ім'я `п` у JS зіткнулось зі службовим ім'ям спостерігача приладу
  (`TypeError: п.чисте is not a function`). Перейменовано локальну змінну на
  `предок`; прилад і його помічники не змінені.
- Проміжний повний прилад дав **4 → 1**: із широкого мікроданого Product
  через `dom.text` до складу й ціни дійшов текст на п'яти сторінках Alot і
  Brenda. Ці поля переведено на факти підтвердженого блоку; доданий тест
  зберігає власні склад і ціну та відсікає чужий сирий текст зліпка.
- Три HTML Andretan є сторінками розділів (`/catalog/…/color-…`), а не блоками
  вибраних речей. Назва з метаданих не заповнює цю втрату. Четверта порожня
  назва серед 143 — FromUs `/ua/store/mayki/mayka_10/`: чинне розпізнавання
  сторінок відкидає `/store/` до читання DOM. Цей окремий факт дописано в 6977;
  ним не змінювали розпізнавання сторінок у цьому кроці межі.
