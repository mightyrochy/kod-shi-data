# Лічба викликів хмарного прогону

Спільний `аудит/проби/драйвер_хмарного_прогону.py` бере теку, JSON-список трійок сцена/режим/прохід, номер і число воркерів та SHA. Без ZHYVA використовує журнал `сервер_claude.py` з `Тестовий-прогін-хмара-1711`, як попередній драйвер. Старі записи не змінено.

Під ZHYVA лічаться файли `VIDPOVIDI/seed<сід>_<номер>_<тип>.txt`, що містять заголовок `── ВІДПОВІДЬ (`. Стенд у `записатиВиклик` створює такий файл для кожної записаної відповіді виклику; текст приміряння має заголовок `КАДР`, тому не входить до лічби. Це кількість записаних відповідей, а не обов’язково всіх розпочатих викликів при обриві. Ціна, вихідні токени і підсумок не-200 з серверного журналу під ZHYVA не лічаться: значення null, причина в полі `причина`.

ДО: чотири записи помилково мали 0 викликів, 0 USD і 0 вихідних токенів. ПІСЛЯ: лічба записаних відповідей 26, 28, 30, 28; відсутні величини — null.

`python3 -X utf8 джерела/прилади/тест_хмарний_прогін_лічба.py` (код 0):

```text
ж4_робота_срібні_сережки__п1: 26
ж4_робота_срібні_сережки__п2: 28
ж4_робота_стримано__п1: 30
ж4_робота_стримано__п2: 28
Ran 3 tests in 0.023s
OK
```

CI автоматично підхоплює `джерела/прилади/тест_*.py`. Приклад нового прогону на двох сценах (JSON `сцени.json` у теці прогону):

```json
[["ж4_робота_стримано", "повне +фото", "п1"], ["ж4_робота_срібні_сережки", "повне", "п1"]]
```

```sh
ZHYVA=sonnet python3 -X utf8 аудит/проби/драйвер_хмарного_прогону.py аудит/проби/новий-прогін аудит/проби/новий-прогін/сцени.json 0 1 SHA_ЗБІРКИ
```

Модель, мережу й повний прогін не запускали; USD і токени під ZHYVA не вимірювали. Тест сервера перевіряє лічбу з синтетичного журналу, не запуск сервера.
