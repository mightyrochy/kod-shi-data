## Метод і межі виміру

Беруться підібрані власником свотчі, інакше — лише свотч із визнаним вердиктом «п».
Невизнаний колір запасним еталоном не стає. sRGB → Lab D65 → зворотний Bradford C → Munsell H/V/C.
Межі — **932 елементарні ділянки 267 блоків** із `джерела/дані_корпусу/ISCC-NBS_вікна.txt`,
прочитані чинним `лабораторія/колір_сім_ї_межі.py`. Родина не визначає нового вердикту;
історичні 27/40 збережені в `родини_спроба3.json` із джерелом 24676d7271281ab7f95ed2d336b4fe57fb038cf7.

Для двоколірної потрібна взаємно однозначна відповідність обох свотчів різним позиціям кодів;
порядок неважливий. Для однотонної перевіряється основний код. На спільній грані приймаються
обидва блоки; H=1 та H=101 — той самий шов. Координати не округлюються перед перевіркою,
допуск до меж не додається. «Лише сусідній блок»: точна перевірка хибна, але кожному свотчу
можна зіставити той самий або суміжний по двовимірній грані блок. Дотик ребром чи точкою
не зараховується; відстань до центроїда не використовується.

Обернення спирається на [Colour 0.4.6, renotation](https://colour.readthedocs.io/en/v0.4.6/_modules/colour/notation/munsell.html)
та прямий перенос C → Bradford D65 з `лабораторія/колір_сім_ї_контури.py`.
Штатний обертач округлює майже цілі V й не збігається для двох майже білих свотчів.
Тому V береться без округлення з ASTM-люмінансу, а H/C уточнюються числовим оберненням
саме прямого методу модуля. Допуск числового залишку не розширює жодного блоку.

**Явне доповнення області:** `#110902`, `#141318`, `#191919`, `#1f0a13` мають V<1, де прямий метод
модуля не визначений. Для них `блоки.py` обертає трикутну інтерполяцію між нейтраллю C та
сусідніми табличними вузлами C=2 повної renotation тієї самої версії Colour; між рівнями V —
інтерполяція за ASTM-люмінансом. Це лабораторне доповнення, у продукт його не внесено.
Немає екстраполяції чи затискання V до 1. Для білих це обернення дає тільки старт числового
розв'язання; остаточні координати підтверджує прямий метод модуля.
Для всіх **49 свотчів** зворотний залишок Lab < **7,15×10⁻⁷** — числова перевірка, не поріг кольору.
Чотири темні залежать від названої інтерполяції; окремого людського приймання її не було.
Навіть зарахування всіх чотирьох речей не дасть жодній моделі 38/40.

## Словник

267 кодів, усі українські назви без латини, усі Lab скінченні; порожніх hex і заглушок (50;0;0) немає.
Вхідні назви й центральні Munsell-зразки — з таблиці спроби 3; належність кожного зразка перевіряється
за файлом ділянок, родина — з `колір_сім_ї_вікна.md`, Lab — через пряме перетворення модуля.
`назва_en` зберігає канонічну назву джерела, не підміняє українську й не входить до промпту.

«Центроїд» у назві стовпця означає центральний зразок словника: геометричного центроїда
необмежених ділянок ISCC–NBS немає. Для **24, 65, 114, 124, 157** вихідні зразки не проходять
пряме перетворення (V<1 або непридатний XYZ). Генератор обрав визначену точку **власного блоку**;
оригінал — у `munsell_джерело`, підстава — у `центроїд_метод`. Це не змінює меж або лічби.
Lab не обрізається до гамуту; hex для екрана дає єдиний `colorspace.hex_з_lab`.

## Принт: назва проти еталону

`принт_оцінка.tsv` містить 12 визнаних власником назв, обидві відповіді й явну оцінку **виконавця**:
**11/12** для qwen3-vl та **10/12** для qwen3.5 проти історичних 8/12 назв хмарної сесії.
Це оцінка виду мотиву, а не нові голоси людей і не незалежне приймання точності назв.
Наявність непорожнього рядка більше не означає правильності.

- Річ 10: «смужка» не відповідає твіду з різнокольоровими нитками; «клетка з яскравими вкрапленнями»
  не підтверджена назвою власника — консервативно не зараховано обом.
- Річ 16: «зебра» відповідає еталону, «абстрактне листя» — ні.
- Річ 30: обидві назвали текст/написи; міста й каліграфія qwen3.5 еталоном не підтверджені.
  Зараховано вид мотиву; ці додані деталі й точність кольору до числа не входять.
- Поза 12: qwen3-vl дала «ромби» речі 37 без принту у визнаній назві — одна непідтверджена
  позитивна відповідь. У qwen3.5 таких відповідей поза 12 немає.

Висновку «100% точності принту» немає.

## Підготовлений вхід наступної спроби

`наступний_вхід.json`: усі **208 вибраних кадрів** 40 речей у первинному порядку —
202 локальні файли з SHA256 та 6 початкових URL. Нових кадрів не добирали, двома першими галерею
не обмежували. Для URL перевірено структуру запиту на фікстурі; доступність і вміст крамниці
треба перевірити наступній сесії. Збій отримання зупинить прогін, а не вилучить кадр мовчки.

Один промпт і розмір до 640×640 для обох моделей, JPEG quality=85, `temperature=0`, **`max_tokens=2000`**
— саме так у коді й маніфесті. Промпт англійською містить канонічний повний словник з українськими
назвами; спеціальні відповідності «92 — айворі», «73 — пісочний» тощо вилучено.
Модель одержить тип речі й зображення; назви еталону, свотчі, ключі й відповіді людей до запиту не йдуть.

Без параметрів скрипт лише перелічує; `--підготувати` готує маніфест і перелічує.
Модель запускається лише явним `--прогін МОДЕЛЬ --вихід НОВИЙ_ФАЙЛ`.
Майбутня GPU-сесія сама завантажить модель і вивантажить після прогону за договором ноутбука.
Історичне «max_tokens=3500» не підтверджене: у коді спроби 3 було 2000, метаданих фактично виконаних
запитів немає. Наступний запуск запише фактичні параметри й хеш входу.

## Відтворення й перевірка

З кореня репозиторію, Python 3.12; локально залежності встановлені в окреме середовище tmp задачі:

```powershell
python -m pip install -r аудит/проби/річ_колір_модель_кодує/вимоги.txt
python аудит/проби/річ_колір_модель_кодує/прогін.py --словник --підготувати
python аудит/проби/річ_колір_модель_кодує/перевірити.py
python джерела/прилади/згорнути_дошку.py --лише-перевірити
```

`перевірка_спроби4.json`: версії, хеші входів, 267 блоків, **1101 пара сусідів**, звірена незалежним
обходом повного розбиття, 49 обернених свотчів і складання запитів на всі 208 кадрів без модельного API.
Шість URL замінено локальною фікстурою лише для звірки структури — це явно зазначено в артефакті.
Попередження Colour про MacAdam — діагностика бібліотеки, не умова вердикту; вони не приховані.
Продукт і його показ не змінювалися: їхня батарея та браузерний знімок до проби не застосовні.
Власна звірка не є незалежною перевіркою.
