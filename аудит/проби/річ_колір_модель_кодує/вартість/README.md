історичних SHA-256 для цих URL вхід не мав, тотожність байтів прогонам 6–7 не встановлено.
Кожен кадр підготовлено так само, як у `../прогін.py`: RGB, вписування в 640×640, JPEG 85, без обрізання.

**Окремий запуск CLI на кожну річ**, усі її кадри одним запитом. Однакове прохання українською назвати відтінок
і принт своїми словами, без словника та кодів; текст прохання збережено в кожному сирому вимірі.
Запуски послідовні, у тимчасовій теці поза репозиторієм, із `--ignore-user-config`, `--skip-git-repo-check`,
`-s read-only`, `-m gpt-6.1-sol`, `model_reasoning_effort="high"`.
Сесії читання отримували лише тип речі й зображення з нейтральними іменами файлів; назв людей, свотчів,
ключів та відповідей попередніх моделей їм не передавали. У JSONL усіх 53 запусків є лише `agent_message`,
жодного виклику інструментів. Фактичні модель і режим кожного запуску підтверджено `turn_context`.
Назви тут не судили й із людськими відповідями не звіряли; це вхід для окремого судді.

## Квота

Джерело — `rate_limits.primary` власного журналу Codex: `window_minutes=10080`,
`resets_at=1795428981`. Перед пілотом і після всіх 53 речей `used_percent=33.0`, тобто залишок **67% → 67%**.
Початковий показ знято з поточної керівної сесії до першого читання, кінцевий — з останньої сесії читання;
обидва сирі покази — `квота.json`. Усі проміжні покази запусків також 33.0.

**Не виміряно: різниця показів не перевищує крок показу.** Однакові округлені покази не означають нуль витрат.
Лічильник спільний для акаунта, тож витрати керівної та інших сесій також не відділено.
Частка тижневої квоти на річ, кількість тижневих квот і календарних діб на каталог — **не виміряно** (`null`
у `підсумок.json`). З токенів чи історичного залишку 70% їх не виводимо. Повторних модельних прогонів для
штучного зсуву показника не робили. Механізми лічильників описує
[офіційна документація OpenAI App Server](https://learn.chatgpt.com/docs/app-server).

## Відтворення

З кореня репозиторію, без моделі:

```powershell
python аудит/проби/річ_колір_модель_кодує/вартість/лічба.py --каталог
python аудит/проби/річ_колір_модель_кодує/вартість/лічба.py
```

`вимір.py --підготувати` готує тимчасові зображення; `--усі` виконує лише відсутні читання,
а `--набір ... --номер ...` — одне нове читання. Вже наявний вимір не перезаписується.
Сирі дані й назви закомічено; зображення й журнали CLI лишаються тимчасовими.
