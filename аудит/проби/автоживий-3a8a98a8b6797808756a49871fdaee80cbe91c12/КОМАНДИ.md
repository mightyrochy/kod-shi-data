# Команди

Усі команди виконано з кореня робочої копії. Пуш, бандл і PR — обгорткою.
Дочірні процеси штатного записувача очікуються до завершення; GPU-прогони послідовні.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
$env:NODE_PATH='C:\Users\gemini\kod-shi-test-node\node_modules'
# NODE_OPTIONS і PYTHONPATH обгортки не змінювалися.

git merge-base --is-ancestor cb3cf264298124a6ffb723ae1e862c1a75e4fbd2 origin/main
# rc=0
git worktree add --detach --no-checkout '../tmp/збірка-після' cb3cf264298124a6ffb723ae1e862c1a75e4fbd2
git -C '../tmp/збірка-після' sparse-checkout set --no-cone /index.html /build.txt
git -C '../tmp/збірка-після' checkout cb3cf264298124a6ffb723ae1e862c1a75e4fbd2
git -C '../tmp/збірка-після' sparse-checkout add /джерела/ '/аудит/проби/*.py' '/аудит/проби/*.js' '/аудит/проби/*.txt' /аудит/проби/жінки/ /аудит/ноутбук_стенд_2/
# rc=0; зібраний index.html не перезаписувався.

python -X utf8 '../tmp/збірка-після/аудит/проби/записати_сцену.py' '../tmp/збірка-після' 'C:\Users\gemini\pyodide' 'аудит/проби/автоживий-3a8a98a8b6797808756a49871fdaee80cbe91c12/б1_концерт_стримано' --сцена б1_концерт_стримано
# rc і фактичні параметри — б1_концерт_стримано/результат.json.

git merge-base 41270fb739ae2db33483ac14f7f9d86132155b37 7c9bc85a4fe3024000a873ceafefd88fdafc19c0
# rc=0: da74a751ea07d72191c690a1f68e9338c11b85ca
python -X utf8 аудит/проби/живі_до.py б1_концерт_стримано da74a751ea07d72191c690a1f68e9338c11b85ca
# rc=1: немає сумісного ДО; підбір-ДО-б1.txt.

git worktree add --detach --no-checkout '../tmp/збірка-до-б1' da74a751ea07d72191c690a1f68e9338c11b85ca
git -C '../tmp/збірка-до-б1' sparse-checkout set --no-cone /джерела/ '/каталог_*' /шрифти/ /build.txt '/аудит/проби/*.py' '/аудит/проби/*.js' '/аудит/проби/*.txt' /аудит/проби/жінки/ /аудит/ноутбук_стенд_2/
git -C '../tmp/збірка-до-б1' checkout da74a751ea07d72191c690a1f68e9338c11b85ca
# rc=0

python -X utf8 '../tmp/збірка-до-б1/джерела/build_артефакт.py' '../tmp/збірка-до-б1/джерела' '../tmp/збірка-до-б1/index.html' показ-повний
# Спроба 1, rc=1: потрібен CPython 3.12.1; збірка-ДО-б1.txt.
$env:LYUSTERKO_PYC_PYTHON='C:\Users\gemini\tools\python-3.12.1\python.exe'
python -X utf8 '../tmp/збірка-до-б1/джерела/build_артефакт.py' '../tmp/збірка-до-б1/джерела' '../tmp/збірка-до-б1/index.html' показ-повний
# Спроба 2: збірка-ДО-б1-2.txt.
```

HTTP-перелік моделей знято стандартним Python urllib для обох адрес:
`http://127.0.0.1:1234/api/v1/models` і `http://127.0.0.1:1234/v1/models`.
Повні відповіді HTTP 200, час UTC, netstat, nvidia-smi, доступність Pyodide й модулів
та параметри оточення — `середовище.json`.
