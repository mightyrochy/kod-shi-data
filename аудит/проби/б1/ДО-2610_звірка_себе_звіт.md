# Б.1 ДО-2610 — звірка судді з собою

Оцінювач: Codex `gpt-6.1-sol`, зусилля `high`; та сама модель і зусилля, що в первинній оцінці. Мірило — розділи «Оцінка» та «Звірка судді / З собою» у [б1_доречність.md](../б1_доречність.md).

Вхідна оцінка — `origin/gemini/Б.1-оцінка-ДО`, SHA `394d1355e966131468675093859eac20d3d9135e`; її злито у призначену гілку. [Сліпу вибірку](ДО-2610_звірка_себе.md), знімки кожної картки й тексти переглянуто без первинних вердиктів. [Повторні відповіді](ДО-2610_звірка_себе_відповіді.md) зафіксовано комітом `d9be54cb27aeb165a30f6cfc523cba0b7efc3e3c` до відкриття [первинної оцінки](ДО-2610.md). Після її відкриття відповіді не змінено. Публікацію комітів виконує обгортка за адаптером цього запуску.

ДО → ПІСЛЯ цього наряду: згода судді з собою була невиміряна; тепер отримано наведену нижче парну звірку. Це вимір повторюваності оцінювання на незмінених картках ДО, а не вимір зміни продукту.

Розбіжності спрямовані однаково: первинне «ні» стало повторним «так». Причини показують відмінність у застосуванні мірил: перша оцінка відхилила явні суперечності матеріалу, кольору, довжини чи крою, повторна погодилася з придатністю загального комплекту для події. Повторні відповіді збережено як результат сліпої оцінки, а не виправлено за першими.

За мірилом незгода з собою є нижньою межею шуму судді; меншу за неї різницю часток не читають як зміну продукту. Ця вибірка не встановлює точності судді щодо думки людей і не замінює звірку з людьми. Збіг «так/ні» також не означає збігу причин.

Межі доказу: режим вихідних карток `FOTO=0`; на знімках немає фотографій речей, тому оцінено видимі назви й описи, а не фактичні матеріали чи теплоізоляцію. Нових вад продукту цим нарядом не шукали; вад поза мірилом наряду не знайдено.

## Команда й фактичний вивід

Запуск із кореня репозиторію, PowerShell. Команда зіставляє відповіді з первинною таблицею за сценою, повтором і рукою; перевіряє повноту та відсутність дублів вибірки.

```powershell
$OutputEncoding = [System.Text.UTF8Encoding]::new($false)
@'
from pathlib import Path
import re

base = Path('аудит/проби/б1')
first = {}
for line in (base / 'ДО-2610.md').read_text(encoding='utf-8').splitlines():
    p = [x.strip() for x in line.split('|')]
    if len(p) == 9 and p[1].startswith('ж') and p[2] in ('1', '2', '3') and p[3] in ('1', '2', '3', '4') and p[4] in ('так', 'ні'):
        key = (p[1], int(p[2]), int(p[3]))
        assert key not in first
        first[key] = (p[4], p[5])
text = (base / 'ДО-2610_звірка_себе_відповіді.md').read_text(encoding='utf-8')
parts = re.split(r'^## (\d+)\. (\S+) / повтор (\d+) / рука (\d+)\s*$', text, flags=re.M)
rows = []
for i in range(1, len(parts), 5):
    number, scene, repeat, hand, body = parts[i:i+5]
    current = re.findall(r'^Доречно: (так|ні) · Причина: (.+)$', body, flags=re.M)
    assert len(current) == 1
    old, old_reason = first[(scene, int(repeat), int(hand))]
    new, new_reason = current[0]
    rows.append((number, scene, repeat, hand, old, old_reason, new, new_reason))
assert len(first) == 108
assert len(rows) == len({r[1:4] for r in rows}) == 20
same = sum(r[4] == r[6] for r in rows)
total = len(rows)
print(f'ЗВІРКА Б.1 З СОБОЮ: згода {same}/{total} ({100 * same / total:g} %); розбіжностей {total - same}')
print(f'Незгода: {total - same}/{total} ({100 * (total - same) / total:g} %)')
print()
print('| образ · сцена / повтор / рука | суддя | суддя вдруге | збіг |')
print('|---|---|---|---|')
for n, scene, repeat, hand, old, old_reason, new, new_reason in rows:
    print(f'| {n} · {scene} / {repeat} / {hand} | {old} | {new} | {"так" if old == new else "ні"} |')
print()
print('Розбіжності з причинами обох оцінок:')
for n, scene, repeat, hand, old, old_reason, new, new_reason in rows:
    if old != new:
        print(f'\nОбраз {n} · {scene} / повтор {repeat} / рука {hand}\n\n- Суддя — {old}: {old_reason}\n- Суддя вдруге — {new}: {new_reason}')
```
