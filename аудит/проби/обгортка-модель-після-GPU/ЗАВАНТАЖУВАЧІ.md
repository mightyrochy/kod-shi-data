```powershell
git grep -l -I -E 'LMS_MODE|lms load|unload|проксі_почергове' origin/main -- '*.py' '*.js' '*.ps1' '*.sh'
```

Тести з підробною моделлю, документаційні згадки й суто порівняння джерел відділено
нижче. Це інвентаризація коду репозиторію, не вимір усього диска ноутбука.

«Прибирає» у другій колонці — штатний кінець; у третій — примусове знищення всього
дерева. «Після латки — так» стосується запуску всередині наряду з умовою `gpu`:
спільний знімок обгортки охоплює HTTP, CLI і JIT. Самостійний запуск скрипта поза
GPU-нарядом цього захисту не набуває.
