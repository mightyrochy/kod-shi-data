# Команди прогону

Усі команди виконано з робочої копії наряду, без пушу; публікація — обгорткою.

```powershell
git sparse-checkout add '/аудит/проби/' '/аудит/ноутбук_стенд_2/'
git merge-base --is-ancestor 32736b6ea78ca066ff88cb5fd3f00dfd12e461cd origin/main
# rc=0
git worktree add --detach --no-checkout '../tmp/збірка' 32736b6ea78ca066ff88cb5fd3f00dfd12e461cd
git -C '../tmp/збірка' sparse-checkout set --no-cone '/index.html' '/build.txt'
git -C '../tmp/збірка' checkout --detach 32736b6ea78ca066ff88cb5fd3f00dfd12e461cd
# rc=0; build.txt=13df83ada4a17a82b3fb0d9c95b30a037787827b
python 'аудит/проби/живі_до.py' б1_концерт_стримано 32736b6ea78ca066ff88cb5fd3f00dfd12e461cd
# rc=1: ДО режиму «повне» на коді-предку нема; порівняння не виконано.
```

Прилад ДО перевірив 20 refs; несумісний режим — 0, без доказу режиму — 0,
поза предками чи без SHA — 0. Порожній план не містить порівняльного питання,
тому додаткового живого ДО не запускали.

Точні команда живого прогону й код виходу — `команда_прогону.json`;
перевірки передумов, середовище та їхні коди — `передумови.json`.
Сервер уже слухав :1234 (PID 43760); :1235, :8000 та :8188 були вільні.
CLI `lms` у PATH відсутній; застосовано передбачений приладом HTTP API.
`NODE_OPTIONS` і `PYTHONPATH` обгортки збережено.
