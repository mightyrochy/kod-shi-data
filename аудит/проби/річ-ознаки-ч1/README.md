# Річ-ознаки-обличчя, Ч1: власні перевірки часткового кроку

База — `b694ac2d2469b4191978e4e716ac2a912715dd58`. Початковий повний прилад дав 172 місця,
з них 46 у шести файлах Ч1 і 126 поза ними; у наряді було 169 / 43. Причину цієї відмінності
цей крок не встановив. Прилад, його база й храповик не змінені.

Остаточний код — `c6220194517716c1e111f76f6b8670c6f691d666`. Прилад: **172 → 150**, свої
**46 → 26**, решта **126 → 124**, код 0, 883,42 с. Ціль Ч1 — 0 — не виконана; крок
не готовий до злиття. Незростання числа підтверджене, повного зеленого CI чи храповика не заявлено.

Ч1 застосовує походження зі спільного запису перед числовими рішеннями. `model_hex` не дає
виміряних рис для осей, тонових дуг, персонального звуження, кольору очей, бюджету хроми та
похибки камери. Схеми без виміру лишаються варіантами без персональних ваг. Її відповідь про
метал лишається окремим доступним джерелом. Суд читає рівень контрасту самої палітри, включно
з утриманим, замість окремої старої копії зі специфікації.

Внутрішні числові заповнювачі осей під кодом `withheld` лишені для сумісності з читачами поза
Ч1. Власні вікна їх не використовують для персонального звуження, на дроті позиції — `None`.
Повне вилучення заповнювачів потребує зміни спільного запису й сусідніх читачів. Це залишок,
а не виконання інваріанта всього кореня. Знахідки — 12897–12898.

Остаточні числа приладу й перелік власних місць — `прилад.json` та `підсумок.json`;
повні виводи — `до.txt`, `після.txt`. `після-перед-судом.txt` — попередній зріз до останньої
правки суду. Його зовнішній збирач завершився з кодом 1: парсер не врахував CRLF після
повного виводу приладу з підсумком 150. Парсер виправлено; цей збій не видається за зелений
храповик. Остаточний прилад запущено наново на числовому коді разом із правкою суду.

Власний повтор `читачі.py` на ж1–ж9: 36 поєднань профілю й джерела,
89 → 0 порушень утримання, включно з позиціями осей на дроті. `самозвіт.py`:
27 відповідей про метал, порушень 0; на 27 фізичних поєднаннях профілю й джерела осі й вікна
L/C збігаються з ДО. Абсолютний колір очей утримується також при довірі нижче `MIN_TO_EMIT`.
Це перевірки виконавця на записаних профілях, не незалежне чи живе приймання.

Повтор записаних входів мосту — `повтор.py`, сцени `палітра_її` (109) і `плитка_робота` (62).
Для ДО шість початкових модулів узято через `git show` у теку задачі й додано до шляху імпорту
перед незміненими модулями; `Ч1_КОД_ДО` вказує цю теку. Для ПІСЛЯ працює код робочого дерева.
Каталог розпаковано зі штатного архіву; змінено лише шлях кеша кольорів до теки задачі.
Винятки, відмови моста й неприйняті відповіді рахує `підсумок.py`, окремо від самого числа
викликів. Відхилені відповіді не зараховані як успішні образи. Нових звернень до моделей немає.

Первинна батарея й проби сім'ї — `батарея.json` та окремі журнали. Два початкові збої через
`None` у старому читачі суду виправлено сумісним внутрішнім форматом; повторний дим зелений,
повтор живого шляху — 6/6 (`остаточні.json`). Перевірка узгодженості рангу, суду й пулу —
45 варіантів, 0 розбіжностей значень і довіри.

Батарею **не завершено**: після підтвердження зовнішнього блокера мірила зупинено її чергу
та власний процес K-PAL-03 (`батарея-зупинка.json`). Завершено 8 із 41 запланованих запусків;
K-PAL-01 пройшов. K-PAL-02 не знайшов знахідки «акцент не від очей» при утриманому кольорі
очей; журнал збережено, зеленим цей випадок не зарахований. Решта сім'ї — залишок перевірки,
а не пропущені успішні тести. Джерело зупинки — межі наряду: прилад і сусідні читачі не
належать Ч1, тоді як власне мірило лишається 26, а не 0; це не обмеження денного темпу.

Повний прогін гейтів на проміжному коді — 573/575. Звірка фізичної домінанти повторена
на остаточному коді окремо (`домінанта.py`, `домінанта.log`) і пройшла. Інша звірка
(`прилади/розділи_гейтів.py:4669`) очікує `обидва` за утриманої температури; Ч1 віддає
`None`. Цей файл за межами наряду й не змінений. Зеленого повного CI голови не заявлено.

Перший показ обірвався через відсутній архів б1 у sparse checkout. Потрібну теку додано,
фікстури на час повтору відновлено в LF, потім повернуто первісні байти. Повтор показу —
927 звірок у 74 розділах, усе зелене (`показ-повтор.log`). `pc_R-PC-10` і поділ pipeline
також пройшли; решта результатів поділу — в батареї.
