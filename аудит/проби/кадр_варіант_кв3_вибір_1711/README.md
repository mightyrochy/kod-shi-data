## Що змінено

`zhnyvarka/вибір_кольору.py` — спільний розбір різної розмітки: свотчі з фото та CSS-зразками,
контейнери з окремими опціями, радіокнопки, кнопки кольору з сирими ключами, перехід посиланням
або буквальним `location.href`. Контейнер не стає ще одним свотчем через перший кадр чи заглушку.
Посилання на інші сторінки відділено від варіантів цієї сторінки; параметр варіації тієї самої сторінки
не стає сестрою. Відносні адреси враховують `<base href>`, `aria-checked="false"` не є активним вибором.

Один `переліки_кольору` використано свідченням одного кольору, писачем власника й перевіркою кольору
голови списку. Сирий ключ активної кнопки звіряється з `TREE` оферт; їхні власні фото або DOM із
`data-offer-id` та відповідним id товару можуть довести галерею. Усі кадри мають належати обраним
офертам; неповна прив'язка, інший товар чи спільний кадр різних кольорів лишаються «невідомо».
Читач приймає нове джерело `картка:вибір_кольору`, звіряючи адресу, товар, сирі id та кожен кадр.
Колір пікселів і слово назви власника не визначають. Модуль внесено до оновлення запускача й відбитка рецепта.

## Вибірки для іншої родини моделей

Усі вердикти в обох таблицях позначено **«не перевірено»**. Зерно переліків — `20261117`; вибір кадру у другій частині —
`Random(20261117 + номер)`. У кожному рядку є точна адреса, id, файл відповіді в кеші, SHA256 HTML і
його gzip-обгортки, вся фактична галерея, кадр для перевірки та запис власника. Кеш:
`C:/Users/gemini/gemini-data/кадр_варіант_кв1_канал_1411/системні_CA`.

- `вибірка_без_вибору.tsv`: 40 записів, щонайменше три на кожну з 11 крамниць; решта — зерном з
  об'єднаного залишку. Вхід — усі 3 757 появ причини «нема свідчення», включно із супутніми причинами
  браку Product чи id. Для кожної сторінки перевірка відповідає окремо: один колір і всі кадри — ця річ
  у цьому кольорі. Крамниця з кількома кольорами у вибірці не приймається.
- `кандидати_один_колір.tsv`: ці 11 крамниць із джерелом нульової лічби елементів кольору та посиланням
  на вибірку. **У чинний `zhnyvarka/один_колір.tsv` вони ще не внесені:** незалежних вердиктів немає.
  Після очей прийняті крамниці вносяться як дані з джерелом тим самим правилом; код для цього не змінюється.
- `вибірка_з_вибором.tsv`: 40 нових прийнятих читачем записів із вибором кольору. Щонайменше один
  на кожну пару «джерело доказу / крамниця», решта — зерном з об'єднаного залишку. Це включає також
  джерело з явною галереєю оферт. Питання — чи кадр справді цього варіанта; приймання — 38/40 і більше.
  Менше — розбір не прийнято, відповідні записи мають лишитися невідомими.

Умовний приріст від прийняття **всіх** 11 кандидатів окремо наведено в `порівняння.json`.
Це розрахунок на тих самих фактах із тимчасовим дозволом переліку лише всередині проби, без запису
продуктових даних; він не зарахований до ПІСЛЯ. Сам дозвіл не усуває брак Product, id чи кадрів.

кешу й виходом `../tmp/кв3-до`. Повтор перевіряє SHA256 вхідного знімка та повноту всіх 13 882 відповідей;
не викликає HTTP-транспорт. Порівняння звіряє id й адреси, збереження всіх доведених записів і їхніх галерей.

`порівняння.json` — первинні й усі причини; `крамниці.tsv` — розріз прийнятих записів;
`записи.jsonl.gz` — усі 13 882 стани ДО/ПІСЛЯ, фактичні галереї, записи власника та результат читача кожного кадру.
Маніфести й лічби ДО/ПІСЛЯ збережено поруч. Це докази писача й читача, не вимір пікселів і не незалежні очі.
