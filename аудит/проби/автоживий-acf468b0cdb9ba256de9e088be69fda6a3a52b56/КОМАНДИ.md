# Команди й умови запису

Усі команди запускалися з кореня робочої копії, PowerShell. Пуш, бандл, PR і доставку виконує обгортка.
`НАРЯД.md` — дослівна копія вхідного файла. Нових моделей або залежностей не встановлювали.

```powershell
git branch --show-current
git rev-parse HEAD origin/main
git merge-base --is-ancestor 237f172f9b364d84707879f254ff43249df4a14a origin/main
```

На старті HEAD і origin/main — `237f172f9b364d84707879f254ff43249df4a14a`, перевірка предка — 0.
Призначена гілка — `gemini/автоживий-acf468b0cdb9ba256de9e088be69fda6a3a52b56`.

```powershell
git worktree add --detach --no-checkout 'C:/Users/gemini/gemini-runs/w/20261104-022101-208b02863225/tmp/live' 237f172f9b364d84707879f254ff43249df4a14a
git -C 'C:/Users/gemini/gemini-runs/w/20261104-022101-208b02863225/tmp/live' sparse-checkout set --no-cone '/*' '!/*/'
git -C 'C:/Users/gemini/gemini-runs/w/20261104-022101-208b02863225/tmp/live' checkout --detach 237f172f9b364d84707879f254ff43249df4a14a
```

Ці три команди — 0. Сторінка береться з цього дерева, стенд і його місцеві залежності — з незмінених файлів робочої копії.
Відбиток сторінки й SHA256 є в `знімки/доказ.json` кожної сцени.

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONIOENCODING='utf-8'
$env:NODE_PATH='C:\Users\gemini\kod-shi-test-node\node_modules'
python аудит/проби/записати_сцену.py 'C:/Users/gemini/gemini-runs/w/20261104-022101-208b02863225/tmp/live' 'C:/Users/gemini/pyodide' 'аудит/проби/автоживий-acf468b0cdb9ba256de9e088be69fda6a3a52b56/ж1_весілля_гостя' --сцена ж1_весілля_гостя
python аудит/проби/автоживий-acf468b0cdb9ba256de9e088be69fda6a3a52b56/виконати_план.py
```

Перша сцена стартувала перед запускачем. Він дочекався її `результат.json`, не запускаючи вдруге.
Інші точні команди та їхні коди записані в `done.txt`. Сам записувач запускає проксі й стенд,
чекає завершення, прибирає свої процеси та вивантажує лише власні екземпляри моделей.
`NODE_OPTIONS` і `PYTHONPATH` обгортки збережені; Chromium працює з `--disable-gpu`.

Доступність моделей підтверджено HTTP 200 від `http://127.0.0.1:1234/api/v1/models`
і `http://127.0.0.1:1234/v1/models`. CLI `lms` у поточному PATH відсутній;
використано передбачений приладом `LMS_MODE=http`, без доступу до профілю Admin.
Контекст і `parallel=1` підтверджуються відповідями REST API, записаними проксі.

Після першої сцени `git ls-remote origin 'gemini/автоживий-acf468b0cdb9ba256de9e088be69fda6a3a52b56'`:
код 0, рядків немає — гілка ще не публікувалася обгорткою.

Повторне читання записів, без inference:

```powershell
python аудит/проби/автоживий-acf468b0cdb9ba256de9e088be69fda6a3a52b56/оглянути_записи.py
python аудит/проби/автоживий-acf468b0cdb9ba256de9e088be69fda6a3a52b56/витягти_дріт.py
```

Результат цих читань — `факти.json` і `дріт_витяг.json`; первинні записи не змінюються.
Внесення пошкоджених полів у ж7 виконується окремим кроком; до його виконання helper-файли не є доказом сцени.
