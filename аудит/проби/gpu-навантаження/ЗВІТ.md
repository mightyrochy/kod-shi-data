# GPU: діагностику заблоковано доступністю вимірів

Наряд: `аудит/наряди/gpu-навантаження-хто.md`, база
`bbc87e297c357187afbbe16221fd94c61f590f2b`.

Статус: **ЗАБЛОКОВАНО**. Процес і рушій навантаження не встановлено.
Потрібен запуск диспетчером у середовищі з доступними лічильниками GPU Engine
та станом інтерактивного сеансу. Причину недоступності цих даних не встановлено.

## Виміряно

Сирий знімок: [raw.json](raw.json), від `2026-11-01T15:07:47.5959347Z`
до `2026-11-01T15:07:48.1296590Z`. У заголовку самого `nvidia-smi` час
локальний (17:07:47), часові мітки JSON — UTC.
Команди та спосіб збору: [перевірити-доступ.ps1](перевірити-доступ.ps1).

| Джерело | Результат |
|---|---|
| `nvidia-smi --query-gpu=utilization.gpu,memory.used,memory.free --format=csv,noheader` | 44 %, 2490 MiB зайнято, 13559 MiB вільно |
| `nvidia-smi pmon -c 1 -s u` | GPU 0, поля PID і навантаження процесів — `-` |
| Повний `nvidia-smi` | RTX 4090 Laptop GPU, WDDM, Display Active On; список процесів: `No running processes found` |
| `Get-Counter '\GPU Engine(*)\Utilization Percentage'` | Помилка `c0000bb8`; топ-10 PID/рушіїв недоступний |
| `Get-Counter -ListSet '*GPU*'` | Помилка `c0000bc8`, наборів лічильників не знайдено |
| CIM `Win32_PerfFormattedData_GPUPerformanceCounters_GPUEngine` | 0 екземплярів |
| CIM `Win32_PerfRawData_GPUPerformanceCounters_GPUEngine` | 0 екземплярів |
| `quser` | `No User exists for *`; стан та простій користувача не отримано |
| Сеанс процесу вимірювання | 0, 64-бітний PowerShell |
| `Get-Process dwm,explorer` | `dwm` PID 2288 і `explorer` PID 17492 у сеансі 1 |
| `GetForegroundWindow()` | 0; повноекранність інтерактивного вікна не визначена |
| `GetLastInputInfo()` | Успіх, tick 0 у сеансі вимірювання; простою користувача сеансу 1 не доводить |

`last_input_error` у сирому файлі не інтерпретується: Win32 last-error
після успішного виклику може містити попереднє значення.
Відсутність PID у `nvidia-smi` не доводить відсутності процесів GPU;
порожній `quser` не доводить відсутності активного користувача.

## Межі результату

ДО: наряд повідомляє про 43–45 % GPU без установленого процесу.
ПІСЛЯ: окремий знімок підтверджує 44 %, але процес і тип рушія невідомі.

Десятихвилинну серію з кроком 30 с не виконано: обов'язкові джерела
недоступні вже на перевірці доступу; за правилом блокера роботу зупинено.
Стабільність навантаження без дій користувача та навантаження у простої
робочого столу **не виміряно**. Порогових рекомендацій немає.
Налаштування Windows, обгортку та чужі процеси не змінювали.
Наряд залишено, бо мірило не виконане. Вад поза мірилом не встановлено.
