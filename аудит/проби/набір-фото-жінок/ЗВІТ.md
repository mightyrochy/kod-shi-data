# Звіт про набір фото жінок для перевірок

База — `912ee4bbbcd3fedbf468429d1041187a11d87a57`. У теці набору було 0 фото. Додано 6 пар, разом 12 JPEG.
Походження, зіставлення зі стендом і задуманий колорит — у [маніфесті](МАНІФЕСТ.md).

## Що перевірено

- 12 з 12 JPEG повністю декодуються в Pillow. Розмір кожного кадру — 760 × 1024 пікселі. Усі файли мають різні
  відбитки SHA-256 і розмір від 82 730 до 229 103 байтів. Це нижче за межу 4 МіБ, зазначену в
  [коді воркера](../../../джерела/worker_джерело.js).
- На всіх 6 повноростових кадрах видно постать від голови до взуття, на всіх 6 портретах видно обличчя, волосся й очі.
  Спільну зовнішність у кожній парі звірено візуально.

Відтворення перевірки файлів із кореня репозиторію, з Python і Pillow:

```bash
python3 - <<'PY'
from hashlib import sha256
from pathlib import Path

from PIL import Image

тека = Path("аудит/проби/набір-фото-жінок")
профілі = ("ж1", "ж2", "ж3", "ж4", "ж7", "ж8")
види = ("повний-зріст", "портрет")
файли = sorted(тека.glob("*.jpg"))
assert {файл.name for файл in файли} == {
    f"{профіль}-{вид}.jpg" for профіль in профілі for вид in види
}

відбитки = set()
розміри = []
for файл in файли:
    дані = файл.read_bytes()
    assert 0 < len(дані) < 4 * 1024 * 1024, файл
    with Image.open(файл) as кадр:
        кадр.load()
        assert (кадр.format, кадр.mode, кадр.size) == ("JPEG", "RGB", (760, 1024)), файл
    відбиток = sha256(дані).hexdigest()
    assert відбиток not in відбитки, файл
    відбитки.add(відбиток)
    розміри.append(len(дані))

print(f"{len(файли)} JPEG, {min(розміри)}–{max(розміри)} байтів")
PY
```

## Що відкладено до приймання диспетчером

Контроль «та сама людина» за [попередньою пробою](../примірка-openai-маска-на-фото/ЗВІТ.md) і читання кольорів
[шляхом портрета](../../../джерела/показ/кольори.js) цією сесією не виконано. Код портретного шляху бере зони від
моделі зору, а вимір обраних зон викликає через міст. Нижче наведено задум, з яким належить порівняти результат
під час приймання.

| Профіль | Контроль маски на фото | Задуманий колорит портрета | Вимір коду і збіг із задумом |
|---|---|---|---|
| ж1 | відкладено | світлий теплий, пшеничне волосся, сіро-зелені очі | відкладено |
| ж2 | відкладено | теплий смаглявий, каштанове волосся, оливково-зелені очі | відкладено |
| ж3 | відкладено | дуже світлий рожевуватий, чорне волосся, сіро-блакитні очі | відкладено |
| ж4 | відкладено | глибокий темний, чорне волосся, темно-карі очі | відкладено |
| ж7 | відкладено | світлий холодний, сріблясто-сиве волосся, блакитні очі | відкладено |
| ж8 | відкладено | світло-середній нейтральний, чорне волосся, карі очі | відкладено |

Числа приймання фотографій і портретів залишаються невиміряними. Платних викликів, запусків моста й продуктових
сцен у цій сесії не було.
