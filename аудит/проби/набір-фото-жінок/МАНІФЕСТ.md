# Набір фото жінок для перевірок

У кожному рядку два окремі кадри однієї вигаданої дорослої жінки. Пари згенеровано вбудованим засобом ChatGPT ImageGen
у Codex Cloud за текстовими описами. Для кожної жінки генератор створив один диптих. Його панелі вирізано окремо й
збережено як JPEG sRGB. Реальних фото чи зразків облич генераторові не передавали.
