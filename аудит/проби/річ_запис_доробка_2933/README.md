## Що змінено

Python-читач і браузерний `ЗЛІПОК_DOM` визначають власника заголовка серед
вкладених меж рецепта або мікророзмітки Product. Обгортка без власного
заголовка звужується до товару; вкладений товар з іншим власним заголовком
не підміняє основний і вилучається перед читанням опису та інших полів.
Сусідні неоднозначні товари, зокрема без заголовків, не стають довільним
останнім збігом. Python читає власний заголовок до захисту його предків
у `прибрати_чуже`.

Прилад кореня, його база, рецепти, HTML вибірки й храповик не змінені.
Виправлені обидва місця того самого механізму — Python і JS; браузерна
картка читає спільні HTML-факти. Нових текстових джерел чи метаданих немає.

## ДО → ПІСЛЯ

Точне відтворення перевірки містить основну сукню й вкладену рекомендацію.
ДО **всі три виходи** — HTML-факти, браузерна картка і Chromium — повертали
чужу спідницю та її опис; код проби 1 (`зауваження-до.json`). ПІСЛЯ всі
повертають **основну сукню й опис основної сукні**, чужого тексту у зліпку
немає; код 0 (`остаточна-01.txt`).

Остаточні **12 тестів пройшли** (`остаточна-02.txt`): збережені попередні
10 тестів і додані перевірки власника вкладеної межі та неоднозначності
без заголовків. Матриця вкладених товарів охоплює рецепт/мікророзмітку,
h1/h4, наявний/відсутній власний опис, обгортки одного товару й вкладені
товари з класом рекомендації та без нього. Чужі товари стоять перед
основним заголовком; точне відтворення окремо перевіряє рекомендацію після.
За відсутності власного опису поле лишається порожнім, чужий SKU не береться.

`поля-до.json.gz` і `поля-після.json.gz` містять поля кожної URL й SHA256
HTML та коду. `зіставлення.json`: **жодної зміни назви, опису чи межі**

Пороги 133/143 і 100/117 збережені. Збіг текстів також зберігає попередні
110/117 після виключення трьох самих міток Wear Me, описаних у
`../річ_запис_межі_2026_11_04/очі-описи.json`; нового незалежного огляду це не замінює.

Chromium відтворив **144 сторінки**, **139 отриманих назв збіглися** з

за вихідними URL, скрипти крамниць вимкнені, зовнішні запити відхилені.
Підміна з синтетичного відтворення на цій вибірці не проявлялась і ДО;
корпус доводить збереження полів, окрема проба — усунення підміни.

заголовків. `вкладення-до.txt` зберігає провал початкового коду на матриці
з основним заголовком перед вкладеними товарами; остаточна матриця сильніша.

Незалежного приймання, нового каталогу й живого прогону не виконували.
