## Команди для незалежного відтворення

Скрипти скопійовано без змін. `SHA256SUMS` фіксує їхні відбитки й відбиток знеособленого звіту. Перед виконанням скопіюйте три скрипти у приватну тимчасову теку. Вони пишуть у неї локальні файли з повними даними. До репозиторію додано тільки код та знеособлений розклад.

З кореня копії, що містить цей пакет і Git-об’єкти обох SHA:

```sh
umask 077
tmp_n2="$(mktemp -d)"
src_n2='аудит/проби/приймання-2511-кодекс/н2-бюджет-38f3'
(cd "$src_n2" && sha256sum -c SHA256SUMS)
cp "$src_n2"/archive_inputs.py "$src_n2"/catalog.py "$src_n2"/measure.py "$tmp_n2/"
git worktree add --detach "$tmp_n2/code" 38f3a7952bec9700eff6f50a51f993238d923bf0
cd "$tmp_n2/code"
PYTHONPATH=джерела python "$tmp_n2/catalog.py"
PYTHONPATH=джерела python "$tmp_n2/measure.py"
```

Попередні виконані команди відрізнялися лише каталогом скриптів `/workspace/scratch/n2-4678-fibre` і вже наявною чистою робочою копією на `38f3a795…`. Модельні ключі, зовнішні фото й транспорт відсутні в цьому вимірі. Ліміт `25 334` збережено.
