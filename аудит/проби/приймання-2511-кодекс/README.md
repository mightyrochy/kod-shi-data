# Незалежні офлайн-пакети приймання, 25.11

Менеджер Codex зберіг результати незалежних виконавців для диспетчера і наступного оглядача. Це синтетичні входи та підставні відповіді, без викликів моделей, сцен/replay, браузера, CI, особистих фото або матеріалів сліпого раунду.

- `вирок/`: #4676, база 912ee4bbbcd3fedbf468429d1041187a11d87a57 → кандидат 35e8d02e5e7ab6e65b1c17d5fe116d5ffdfe6027. Три штатні проходи й повні промпти, каталоговий шов та утримання на похибці. Уточнення в кінці звіту обов'язкове: факт уже є в check.findings, помилковий саме passed. Наступне рішення про стан «утримано» — #4692, коментар 7154045926; його реалізація тут не перевірена.
- `кадр/`: #4687, база f0d1b453cad614e95c8abbdd4b2cd0766714a90d → кандидат 1e580d34e3530f632d1dbbf885437ef00062f9a4. Три випадки через штатний Python, JS і JSDOM; призначення src не є мережевою доставкою. Зняття прапорця за першим кадром лишається відкритим окремо.

Архіви розпаковуються в окрему тимчасову теку. Вони містять скрипти, входи/виходи та відбитки, а не повні checkout продукту. Для відтворення потрібні точні джерела за SHA і наявні залежності, як описано всередині. Не запускати їх як живі сцени або підміняти ними Р2/Р3. Моделі, фото-доставка та екранне приймання відкриті.
