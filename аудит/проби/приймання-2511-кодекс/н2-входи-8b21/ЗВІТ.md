# Незалежна перевірка станів світлоти й відлуння

Голова #4678 `8b21aaf2d97f2bd9e7f71e3c75bdc26d0039989e`, база `21af8c2ca3a501be99cb9bfbaefefef3730b69c7`. Вісім попередніх складів пройшли мірило. Одна додаткова пара виявила втрату утриманої заяви K-COL-01 при переході від фото-виміру до магазинного інтервалу.

GitHub compare показав зміни лише в `джерела/ядро/дані/чеклісти.json`, `знання.py`, `суд.py`, `тести/тест_н2.py`. Усі чотири файли отримані за точною головою, Git blob ID звірені й наведені у manifest.json.

## Прийнято

| Склад | Фактичний результат на голові |
|---|---|
| Верх і низ, взуття й сумка мають вимір L*=40 | У всіх 4 варіантах площі та сама заява. У вироку одна `one_lightness_level_reads_flat` на верх і низ, пункт «суджено, 1». |
| Лише низ змінено на L*=85 | Усі 4 варіанти порожні. Пункт «суджено, 0». |
| Лише сумку змінено на L*=85 при низі L*=40 | 2 варіанти з твердженням і 2 без нього. Пункт «немає входу, джерело_площі», зайвої заяви немає. |
| Червона сумка, колір взуття невідомий | «немає входу, колір (shoes)», без сироти. Сіре взуття дає одну `accent_orphan` на сумці, червоне — одну `accent_echoed` на взутті та сумці. |
| Дві червоні поверхні | K-ACC-10 просить `заявлена_колона`, пункт A12 збігається з цією вимогою. |
| Сіра сумка серед сірих речей, окремо змінено лише її волокно | Кольорового акценту не виникає в обох випадках. |

Проходи йшли через штатні Ч2, Ч3, Ч5 та Ч6. Реальний старий суд викликаний один раз на образ. Старі стани в логах використані лише як контрольні спостереження. `ядро/знання.py:346–356,449–455` витягує структуровані знахідки разом з `без_входу`. У розбіжному переборі саме вилучена знахідка K-COL-01 має `без_входу=вхід_правила` та код `areas_not_measured`. Окремий контроль з вимірами, заміненими на перекривні магазинні інтервали верху та низу, дав `cannot_tell_lightness_structure` і `colour_word_shop` із тим самим прапором. У Н2 причина — «вимір світлоти». Це читання кодів заяв, без копіювання станів старого чекліста. Обернення порядку груп, пунктів та правил не змінило жодної перевіреної проєкції.

## Залишок K-COL-01

Мінімальний прийнятий Ч5 образ має дві речі: сукню та прикрасу. За класами слотів є одна вагома поверхня. Колір прикраси виміряний. У першому контролі виміряний і колір сукні. У другому для сукні вказано інтервал зі слова крамниці, без точки Lab. Обидва каталожні входи прийняті штатними читачем і пулом.

У **кожному** випадку один допустимий варіант повертає ту саму утриману `one_weighty_surface` на сукні. Знанням достатньо лічби поверхонь, бо для однієї поверхні порівняння світлоти між речами не визначене (`джерела/колір_світлота.py:157–175`). Н2 передає цю заяву з вагою 0 при фото-вимірі. При словесному вікні адаптер губить її на обох SHA. На базі пункт відмічав брак входу. На голові пункт повідомляє «суджено, 0», отже результат уже неможливо відрізнити від чотирьох справді порожніх варіантів.

Причина в `ядро/дані/правила.json:20` та `ядро/знання.py:375–391`: для всіх трьох кодів гілки світлоти діє одна вимога про наявний Lab. Саме утримання не має прапора `без_входу`, а вікно з крамниці має визначений тип кольору. Через це `ядро/знання.py:400–426` ставить «суджено» і лічба після відсіву дає нуль.

**Вузьке мірило доробки:** для `one_weighty_surface` засвідчити одну вагому річ та адресу в цьому складі. На обох входах у Вироці має лишитися одна та сама утримана заява на сукні з нульовою вагою. Інтервал не стає числовим виміром. Чотири порожні варіанти, справжня розбіжність та брак світлоти на перекривних вікнах зберігають уже перевірені результати. Решта кодів і приймання Н2 до цього висновку не входили.

## Відтворення

Для бази використати `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=/шлях/база/джерела python check.py --base > /tmp/n2-base.json` та base.json. Обидві команди завершилися з exit 0. Перевірки у скрипті фіксують одночасно прийняті результати й відтворений дефект на вказаній голові. У логах є коди справжніх варіантів, вилучені сигнали браку та адреси синтетичних речей. Авторську повну батарею і Pyodide тут не запускали.
