# Локальна відмова JS від Н2

Кандидат `1f75a7298b6f470118c06731f42fb86b5262eb5c`, база `782c81cceb6a0ec7c343b3f94ab3af399cd07603`.

`node reproduce.mjs` виконує лише точні потрібні фрагменти з кандидатного дерева, з підставним профілем вікна, синтетичним текстом і забороненою імітацією черги. У частині Python використовуються точні функції обміну й перетворення збою, а будівник і сторонні поняття підставні. Мережі, браузера, моделей або checkout немає. Файл `observed.json` містить збережені результати двох уже виконаних локальних контролів. Для JS транспорт недосяжний при нульовій черзі. Збережений відтворювач також явно лічить транспорт.

`sources.json` містить SHA кандидата, точні рядки джерел, Git blob SHA й SHA-256 кожного фрагмента. `SHA256SUMS` фіксує цілісність пакета.
