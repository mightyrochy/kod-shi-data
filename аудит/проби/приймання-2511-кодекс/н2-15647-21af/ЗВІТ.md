## Команди

Підготувати дві теки джерел за `manifest.json` та `manifest21.json`. У `tree` розпакувати точний `каталог_повний.xml.gz` у `каталог.xml`, покласти `стенд_кеш_кольорів.json` як `кеш.json` і залишити за репозиторними шляхами фікстуру та профіль. Перший запуск зберігає вихід штатного читача локально. Наступний подає той самий вихід через підтримуваний протоколом вхід-список.

```sh
python3 -B run.py tree 4e9b6de1160fc46290e8b7a356efc58d07ee2b9a
python3 -B run.py tree21 21af8c2ca3a501be99cb9bfbaefefef3730b69c7
node дані_показу.cjs tree 4e9b6de1.json
node дані_показу.cjs tree21 21af8c2c.json
python3 -B знеособити.py 4e9b6de1.json > 4e9b-доказ.json
python3 -B знеособити.py 21af8c2c.json > 21af-доказ.json
```

Обидві парні Python-команди завершилися з кодом 0. Python-блокування сокетів увімкнено до імпортів, JS-перетворення даних виконано без браузера. Архів доказів містить лише скрипти, маніфести, знеособлену мірку й короткі журнали.
