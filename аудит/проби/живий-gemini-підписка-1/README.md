# Живий прогін Gemini за підпискою

Спроба 6 продовжує серію за вікнами квоти. Ситуацію `с4_побачення_19_30` Flash уже пройдено двічі у спробі 5; її не повторюють. Поточний стан, перелік зробленого й решти, квоти та порти — [спроба 6](спроба_6/README.md), машинний запис — [стан.json](спроба_6/стан.json).

Порядок: решта сім ситуацій `gemini-3.8-flash-low`, потім вісім `gemini-4-hydrogen-low`; кожна — два проходи. Після ситуації квота має лишати щонайменше 10 % п’ятигодинного й 20 % тижневого вікна для початку наступної. Нижче цих меж — ГОТОВО для поточної частини, решту диспетчер ставить після скидання. Наряд дослівно — [НАРЯД_СПРОБА_6.md](НАРЯД_СПРОБА_6.md).

Жінка — скрипт без моделі, що дослівно повторює слова й натискання першого прогону (слово власника 14.11 07:08 UTC). Невідповідність новому екрану записується у `розбіжності.md`; нових слів скрипт не створює. Слова про образи стосуються образів першого прогону й не є оцінкою образів Gemini. Суддю призначає диспетчер окремо.

У теках [Flash](gemini-3.8-flash/) та [Hydrogen](gemini-4-hydrogen/) — ситуації зі знімками кожного кроку 390×844, ходом і підсумками; `стенд/записи/` — кожен сирий вхід і вихід моделі та первісні фото із SHA256; `руки.md` — відповідність карток рукам і правила поломок руки 2. Продукт — лише рука 1. `зведення.json` містить лічбу запитів, токенів, фото, HTTP-статусів attico.ua, відповідність тексту й читання файлів.

Транспорт використовує підписку agy, без платного ключа й моста власника. Текст сторінки передається дослівно між маркерами, фото — файлами з посиланнями `@NN.ext`; agy читає їх через `read_file`. Порівняно з мостом тестувальниць, agy додає системний контекст, інструменти й доручення адаптера; стелі — 660 с зовні й 630 с CLI проти типової 85 с моста. Ліміт `max_tokens` сторінки фіксується, але не обмежує CLI. Low — найнижче доступне зусилля цих моделей; його еквівалентність налаштуванню API не доведена.

Уся серія продовжується на тій самій готовій CI-сторінці, що й с4: вихідні джерела `8dafc1113ba09cdc5459cead2c0878fbc14b2b37`, main `855d862368d2ad8e120fd7b083ec5b854c8728e8`, SHA256 сторінки `890864aa7b59a89da48560a83f50f4123ad8131031b0acbf156bce2909b2ca94`. Файл відновлено у тимчасовій теці з цього main й перевірено за SHA256; код продукту не змінюється. Поточний новіший main окремо записано у стані спроби 6.

Дані й обмеження попередніх спроб збережені: [спроба 5](СПРОБА_5.md), [спроба 4](СПРОБА_4.md), [спроба 2](СПРОБА_2.md), [спроба 1](СПРОБА_1.md). Початковий прогноз 90 в.п. спільної квоти був оцінкою з однієї ситуації; наряд /6 замінив очікування всього ресурсу продовженням по вікнах.
Спостережені обриви з рядками консолі й посиланнями на сирі входи та відповіді: [Flash](спроба_6/gemini-3.8-flash/збої.md). У с3 обидва проходи скинув 300-секундний сторож мовчання браузерного worker; на цьому етапі бракує траси внутрішнього кроку до HTTP, тому глибша причина не встановлена. Ці дані стосуються зафіксованої збірки серії. Карток і відповідності рукам у цих двох проходах немає.

Завершена частина Flash: вісім ситуацій по два проходи, 360 обмінів моделі зі статусом 200, 117 введених і 13 пропущених реплік із 130 записаних; дослівність і порядок підтверджені. Усі 188 доступних фото збережено з SHA256 і успішно прочитано; ще 5 фото повернули 404, 3 — 403. Браузерні запити attico.ua: 200 — 0, 403 — 20. [Повна перевірка Flash](спроба_6/gemini-3.8-flash/перевірка_даних.json) не знайшла прогалин або пошкоджених JPEG. Усі завершені виклики інструментів agy — read_file. Обриви worker: с3, проходи 1 і 2; с7, прохід 1. Відсутнім карткам рука не приписується. [Версії середовища](спроба_6/середовище.json): agy 1.5.9, Node v22.23.5, Python 3.12.10; Chromium headless із --disable-gpu через обгортку. Браузер бере лише index.html і кеш Pyodide; попередження про відсутній build.txt збережено в консолі.

Hydrogen: [збої за журналом](спроба_6/gemini-4-hydrogen/збої.md), [перевірка першої пари](спроба_6/gemini-4-hydrogen/перевірка_після_с1.json). Перша пара с1 має 31 записаний обмін і 19 доступних фото, усі успішно прочитані; у другому проході скинувся worker після 300 с без повідомлень, активного HTTP/CLI-виклику на той момент у повному журналі не було. Траса внутрішнього кроку до HTTP відсутня; глибшу причину з цих даних не встановлено.
