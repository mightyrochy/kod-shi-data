## Походження та прибирання

Чисте тимчасове дерево призначеного SHA; предок `origin/main`, rc=0.
Продуктові зміни від попереднього виміряного коду — одна пачка #2080

реалізація продукту та правила не змінювалися.

Обидві моделі за нарядом: qwen/qwen3.5-9b, MamayLM;
HTTP-проксі, фактичні контексти 57344/16384 і parallel=1 підтверджені
в `проксі.txt`. Node v24.22.1, Playwright/Chromium з профілю gemini.
Адміністратора, чужих профілів, входів чи платних API не використовували.
Власні проксі/стенди завершені, власні екземпляри вивантажені;
:1235 і :8765 не слухають, LM Studio :1234 лишився працювати.

що жодного з чотирьох перелічених власних PID уже немає.
`git ls-remote` гілки повернув порожній результат, rc=0:
