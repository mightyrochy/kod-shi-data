# Зворотний переклад: запис кодом → опис речі словами

Перед тобою записи вигляду речей одягу кодом (будова й значення осей — `аудит/звіти/опис-речі-кодом/в2/запит_перекладу.md`;
колір — фішка атласу Манселла: тон, світлота/хрома). Фото й вихідних описів ти не бачиш. Для кожного запису напиши
одне-два речення українською — опис кольору й вигляду речі, як його сказала б стилістка, що бачила річ: назва кольору
з відтінком і підтоном (наскільки їх видно з фішки), візерунок, поверхня. Лише те, що каже запис; чого запис не каже —
не вигадуй.

Відповідь — один JSON-об'єкт у файл, названий у дорученні: ключ — номер запису (`з001`…), значення — опис рядком.
