# Огляд повних очищень за розміром

Наряд: `розбір-заміна-руки-2-c71cc075-доробка`, 12273. Огляд охоплює модулі продукту в `джерела/`; проби,
прилади, лабораторія та батареї не є продуктовими кешами. Команда:

```
python -X utf8 аудит/проби/заміна-кеш-12273/огляд_кешів.py
```

| Місце | Чи втрачається ще потрібний запис у виклику заміни |
|---|---|
| `міст_пакет.КЕШ_ПАКЕТА` та `_СЛІД_ПАКЕТА` | Так, підтверджено записом: контрольний ключ будувався повторно після робочого. Повне очищення замінене на LRU двох записів; контрольний об'єкт зберігається в локальній змінній до зміни контексту. |
| `міст_пакет._ПАРИ_КОЛЬОРІВ` | Очищення на вході в `цінність_пулу`, до обходу пар; усередині обходу очищень немає. Пакет зберігає готову цінність, повторне читання контрольного пакета її не обчислює. Витіснення ще потрібного запису всередині поточного виклику заміни не встановлене. |
| `вибір_палітри._ПАМ_ЯТЬ` | Ключ не містить `не_ця` та `вже_були`; ці зміни заміни не створюють нового ключа переліку. `перелік` повертає готовий об'єкт. Перебудова того самого ключа через очищення в поточній заміні не встановлена. |
| `мовний_шар._ПРОФІЛЬ_ПАМ_ЯТЬ` | Кеш профілю в окремому мовному ендпойнті; побудова пакета його не викликає. Відтвореного витіснення ще потрібного профілю в одному виклику немає. |

Окремо переглянуто очищення без умови розміру: кеші файла каталогу, кодів, назв, фото, таблиці та показу оферів
переходять на іншу версію файла/каталогу. `кеш_входу.за_входом` і додані за запитом речі вже витісняють по одному
запису. Скидання тіні поломки й звіту семплера — стан обчислення, а не кеш виходу.
Додатковий збіг `вердикт_моделі.пари = {}` — створення локальної мапи порівнянь образів, не очищення кеша.

Для підтвердженого класу на шляху заміни: повних очищень пакета та його сліду **2 → 0**. Інші три умови очищення
за розміром лишено: сам збіг форми не доводить втрату запису, потрібного далі в тому самому виклику. Нових доведених
вад поза шляхом мірила цим оглядом не встановлено.
