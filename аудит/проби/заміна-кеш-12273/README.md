# Заміна речі: кеш контрольного й робочого пакетів

Наряд `розбір-заміна-руки-2-c71cc075-доробка`, рядки 12273–12274. Вихідний запис — коміт
`6c44a6c5edac74caeb499ebee919bc71a763d181`, збірка `c71cc075fdaca37a3df5b1419fc035acd0035024`,
сцена `ж4_робота_стримано`, сід 3. Попередні розбір і перевірка: #2764, `23866bfbe419c4ec459b7124e82d34e919d27004`,
та звіт Argon `1bf6328a`.

У раунді 0 руки 2 повне очищення кешу викидало щойно збудований контрольний пакет. Повторний запит для виміру пари
будував його знову. Окремо підготовка заміни додавала початковому входу відхилену річ і речі щойно показаного збору:
жереб руки повторно рахувався вже за іншим контрольним пулом.

Кеш тепер витісняє один найдавніше використаний запис разом зі слідом. Ендпойнт зберігає контрольний об'єкт до
увімкнення поломки; заміна не рахує невикористаний у її виході вимір пари. Знімок карток передає початкові `не_ця`
та `вже_були` для контрольного пулу. Робочий пакет зберігає поточні відхилення й попередні речі. Нормалізацію драпінгу
виконує наявна межа моста; нового нормалізатора немає.
