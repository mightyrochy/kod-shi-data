# Збої та відповіді кроків

Повний запит і сира відповідь лежать разом у кожному наведеному JSON обміну. Червоні звірки з номерами рядків — ЧЕРВОНІ.md.

Межі висновків: HTTP 501 приміряння повертає сам стенд локальної текстової моделі; залежні від картинки звірки цього шляху не вимірюють її створення. not_delivered у журналі опису має нульову відповідь, бо виклик із кадрами не доставлено; окремої сирої відповіді неіснуючого виклику немає. Повтор без кадрів має власний запис. Відсутні зображення на плитках зафіксовано DOM-звіркою; повних HTTP-відповідей сховищ фото цей прилад не зберігає, тому причину невідкритого фото крамниці з них встановити неможливо.
