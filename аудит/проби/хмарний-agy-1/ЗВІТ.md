## Висновок

Рішення менеджера 15:38 і 15:40: частину `agy` закрито без задачі. Вхід хмарній машині Google у плагін GitHub не
просимо: без `--print` кожну задачу довелося б ставити рукою, тож новий доступ на запис нічого не дає процесові.
Повертаємось, коли довідка нової версії `agy` покаже `--print` для `--remote-agent`.
