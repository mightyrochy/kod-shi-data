# Проба рушія Claude на ноутбуці

**Проблема.** Рушій Claude (`claude_run.ps1`, задача `claude-run` під власником) перевірено лише стендом заглушок у
хмарі; живого `claude -p` з позначки черги, з LM Studio й ComfyUI, ще не було.

**Ціль.** Один наряд без запускача й листів: позначка → `claude -p` → звіт у гілці → рядок обгортки диспетчерові.

**Що зробити** (коду продукту не чіпати):
1. Кроки 1–3 `аудит/НОУТБУК.md`; канал результату — останній рядок твоєї відповіді (його читає обгортка). Порти
   `1234` і `8000` чи модель у `lms ps` зайняті чужим — одразу «НОУТБУК ЗАБЛОКОВАНО: <що зайняте, дія власникові>».
2. LM Studio: `lms server start`; дочекайся відповіді `GET http://127.0.0.1:1234/v1/models` (до 2 хв); `lms server stop`;
   порт `1234` вільний.
3. ComfyUI: сервер без вікна на `:8000` точно за `аудит/НОУТБУК.md` (фоном, без `SSLKEYLOGFILE`); дочекайся відповіді
   `GET http://127.0.0.1:8000/system_stats` (до 3 хв); зупини свій процес за PID; порт `8000` вільний.
4. Гілка `claude/проба-рушія-claude` від `origin/main`. Файл `аудит/проби/claude_рушій/проба.md`: `git rev-parse
   origin/main`, `whoami`, `claude --version`; для кроків 2–3 — час початку й кінця (UTC, `[DateTime]::UtcNow.ToString('s')`),
   HTTP-код відповіді, PID, `nvidia-smi --query-gpu=memory.used --format=csv` до й після; порти наприкінці.
   Першим комітом — цей наряд дослівно (`аудит/проби/claude_рушій/НАРЯД.md`), другим — `проба.md` і видалення
   `аудит/наряди/проба-рушія-claude.md`; тіло коміту — «Що змінено / Перевірено» за `аудит/ВИКОНАВЕЦЬ.md`.
5. Запуш гілку, `git ls-remote origin claude/проба-рушія-claude` = локальний HEAD; PR-чернетка з тілом останнього
   коміту. Останній рядок відповіді: `НОУТБУК ГОТОВО claude/проба-рушія-claude <повний SHA>`.

**Мірило.** ДО: наряд ноутбука — запускач і лист. ПІСЛЯ: диспетчер отримав `GEMINI ОБГОРТКА: ГОТОВО
claude/проба-рушія-claude <SHA40> МОДЕЛЬ cc-claude-sonnet-5-5-medium`; `проба.md` має відповіді обох серверів і вільні
порти наприкінці; issue #1856 під час прогону показував позначку, модель і хвилини.
