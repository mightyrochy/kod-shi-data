# Чекання без моделі

**Проблема.** Чекання тримає модель: на кожну подію (CI голови PR, звіт ChatGPT) диспетчер ставить сторожа — окрему
сесію Claude (`аудит/ДИСПЕТЧЕР.md`, «Сам ставиш лише механічні сесії»), що платить холодний старт, а її лист однаково
будить диспетчера. Claude — 95 % тижневого ліміту: механіка з'їдає ліміт ролей, що лишились (ПК-6, `аудит/КАРТИНА.md`,
розділ 5).

**Ціль.** Модель не чекає: подію чекає команда без моделі й будить сесію один раз, коли подія настала; сторож-сесія
лишається лише там, де без моделі не перевірити.

**Підказка.** Фонова команда Claude Code повертає сесію, коли завершилась (перевір, чи живе вона між ходами в хмарі й
що з хмари досяжне без GitHub API); на ноутбуці — цикл із `git ls-remote` чи `gh`. Правки правил про сторожів
(`аудит/ДИСПЕТЧЕР.md`, `CLAUDE.md` п.13) — у цьому ж PR, наряд їх дозволяє; PR із правилами — менеджерові на погляд
перед злиттям.

**Мірило.** ДО: сесій-сторожів за добу (`list_sessions`). ПІСЛЯ: 0 сесій, що лише чекають. Рядків дошки нема;
`аудит/ПРОДУКТ.md` не зачіпає.
