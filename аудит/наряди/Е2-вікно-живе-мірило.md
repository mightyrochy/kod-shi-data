# Живе мірило кореня Е2-вікно: рука 2 з речами в п'яти запитах б1 на вікні 57 344

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`, живий — `аудит/проби/живі_порядок.md`, стенд —
`аудит/НОУТБУК.md`. Наряд самодостатній; корінь — `аудит/корені/Е2-вікно.md`, «Що лишилось», п.3.

**Чому.** Прилад кореня Е2-вікно — 0, але рука 2 з речами наживо не підтверджена (дошка 11670): записи ремонту руки 2
цих п'яти запитів — HTTP 400 без відповіді моделі, повтор записів дає ту саму відмову. Показати може лише живий прогін.

**Що зробити.**
1. Перший рядок звіту — SHA `main` у момент старту; код — саме він.
2. П'ять рядків `run.sh` з `аудит/проби/б1_доречність.md`, «Прогін», у цьому порядку: `б1_концерт_сміливо`,
   `б1_сніг_вихідні_стримано`, `б1_зима_звично`, `б1_дощ_зустріч_стримано`, `б1_дощ_зустріч_звично`; сід 3,
   `MODEL_CTX=57344`, `OTSINKA=0`, без `FOTO`. Перед кожним — `nvidia-smi`: відеокарту тримає інший процес — чекай;
   rc=124 через спільну GPU — той самий прогін наново; інший rc=124 — «не виміряно» з причиною.
3. Для кожного запиту з записів прогону: чи рушій відмовив через вікно (HTTP 400, рядок про перевищення вікна) — так/ні;
   чи рука 2 віддала речі — так/ні з шляхом до відповіді; `usage.prompt_tokens` кожного виклику руки 2 з відповіді
   рушія (не оцінкою); рядок `промпт скорочено до вікна` / `prompt shrunk` у stderr — є/нема.
4. Вихід кожного прогону — коміт і пуш одразу; підсумок — `аудит/проби/б1/Е2-вікно-3110.md`: SHA, моделі, таблиця п'яти
   запитів (rc, відмова через вікно, рука 2 з речами, токени, скорочення, шлях записів).

**Мірило.** П'ять із п'яти мають записи (або «не виміряно» з причиною); у підсумку — рядок
`ЖИВИЙ ПІСЛЯ: б1, запити 06, 19, 25, 10, 17, сід 3, MODEL_CTX=57344 — рушій відмовив через вікно <N> разів, рука 2 з
речами <M> з 5`; `згорнути_дошку.py --лише-перевірити` — 0 помилок.

**Межі.** Код продукту не правиш, образів не оцінюєш, рядка 11670 не закриваєш (закриває перевірка за підсумком). Нова
вада — рядок дошки з номером 11888–11890, файл `аудит/дошка/<гілка>.md` («виявлено: живий; внесено: <наряд>»).

«ЗАБЛОКОВАНО: <що>».
