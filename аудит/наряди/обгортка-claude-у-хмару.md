# Claude на ноутбуці — лише для того, що без ноутбука неможливо

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`, адаптер свого рушія, обгортка —
`аудит/адаптери/gemini/ЧЕРГА.md`. Етап Е0 `аудит/ПЛАН.md` («машина працює»). Зміна в `аудит/адаптери/gemini/` — за
`аудит/ДИСПЕТЧЕР.md` (М.9-Г: рушій ноутбука — латкою). Наряд дав диспетчер (машина — його ділянка, #2186).

**Слово власника.** 26.10 10:23 (журнал, «Ноутбук — лише обгорткою»): наряди ноутбука — ті, що потребують його
відеокарти й програм, код і документи — хмарні сесії. 29.10 ~09:35 (чат диспетчера): «Чому взагалі всі сесії Claude
почали запускатися через обгортку? Обгортка потрібна лише для сесій з якими поганий зв'язок.»

**Факти (`main` 29.10).**
- У черзі 131 позначка `cc-`: 124 — `автоперевірка-*` (читання коду), 1 — автоживий (`-gpu`), решта — каталог і проби.
- `Get-ReviewModels` (`НАЛАШТУВАННЯ.md`, «Одна перевірка й спільний живий прогін»): робота `gpt-*` → Claude з
  `ланцюг.json` (`cc-claude-sonnet-5-5-medium`, тобто `claude -p` на ноутбуці); Gemini, `cc-*`, невідомий → Codex.
  Codex на квоті до ~04.11, тож перевірки роботи Gemini й Claude стоять.
- Кожен `claude -p` — окрема копія репозиторію в слоті (диск, наряд `обгортка-ресурс-слотів`), той самий ліміт Claude,
  що в менеджера й диспетчера; на батареї ноутбука перевірка стоїть.
- Позначки перевірок голів, яких уже нема (PR злито, закрито чи голова змінилась), лишаються в `gemini-queue/`.

**Ціль.** Обгортка запускає на ноутбуці лише рушіїв, яких з хмари не досягти (Codex, `agy`, локальні моделі), і Claude —
лише для нарядів, яким потрібен ноутбук (відеокарта `-gpu`, LM Studio, фото, локальні програми). Кожна нова голова PR
усе одно отримує одну перевірку іншого постачальника.

**Підказка.**
1. Рецензент ланцюга — інший постачальник із тих, що є зараз: робота `gpt-*` → `agy`; робота Gemini → Codex, на квоті —
   Claude у хмарі; робота `cc-*` → `agy`. Claude у хмарі: або сесія з ноутбука (`claude --cloud`, перевір наживо, чи
   сесія справді хмарна й без копії на диску), або рядок обгортки «ПОТРІБНА ПЕРЕВІРКА CLAUDE #PR <SHA40>» диспетчерові,
   який запускає хмарну перевірку. Рішення й доказ — у PR.
2. Позначка `cc-` без `-gpu` і не з переліку нарядів ноутбука (`ланцюг.json` чи `смуги.json`) — рядок
   «ЗАБЛОКОВАНО <гілка> CLAUDE_NOT_LAPTOP», копії не створює.
3. Позначки перевірки голови, якої вже нема в PR, — прибрати разом із ланцюгом (не вручну), рядком у зведенні обгортки.
