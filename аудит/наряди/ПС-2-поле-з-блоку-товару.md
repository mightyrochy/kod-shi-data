# Поле речі — лише з блоку цього товару

Річ (`аудит/ПЛАН.md`), поломка ПС-2 (`аудит/дошка_поломки_системи.md`: 22 рядки, 7 відкритих). Роль — ВИКОНАВЕЦЬ,
ядро — `AGENTS.md`, код — `аудит/КОД.md`. Діагноз — розбір дошки на `main` 27.10: перевір на свіжому `main`.

**Що зараз.** Складальник не обмежує джерело поля блоком цього товару (`фід_розбір.py`, `жнива_розбір.py`,
`extract.py`): межу блоку задає селектор, окремий для кожної крамниці, а без нього евристика бере сусідній текст.

**Що зробити.** Одна межа блоку товару для всіх полів. Поле, знайдене поза блоком, — не значення, а «нема» з причиною;
крамниця без межі блоку — рядок у звіті жнив, а не евристика.

**Мірило.** На повному свіжому каталозі: полів, узятих поза блоком товару, — ДО N → 0 (вибірка зі звіркою сторінки);
крамниць без межі блоку — перелік. Вхід моделі змінено — ЖИВИЙ ПІСЛЯ (Е1).

**Межі.** Як ядро.
