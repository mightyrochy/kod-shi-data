# SAM під обгорткою без прав адміністратора

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`, середовище ноутбука — `аудит/НОУТБУК.md`, обгортка —
`аудит/адаптери/gemini/ЧЕРГА.md`. Рішення менеджера 28.10 ~21:20 на блокер наряду 5.3. Наряд самодостатній.

**Що зараз.** Маска речі береться так: ATR → SAM → запасна (`джерела/жнива_маски.py`, `джерела/жнива_v2.py`). SAM —
це GroundingDINO + SAM у ComfyUI на 127.0.0.1:8000. Наряд 5.3, спроба 1 (гілка `gemini/5.3-повний-обхід-каталогу`,
906c6861), під користувачем `gemini` отримав `PermissionError [WinError 5]` на `C:\Users\Admin\ComfyUI-Installs\ComfyUI`:
ComfyUI ставили під `Admin`, тому під обгорткою SAM недосяжний. Обхід 5.3 і кольори на CPU цього наряду не чекають.

**Ціль.** SAM доступний процесам користувача `gemini` без руки власника. Допустимий будь-який із двох шляхів:
1. **Своє середовище.** ComfyUI, або лише GroundingDINO + SAM без ComfyUI, ставиться в профіль `gemini` разом із
   вагами, з тим самим контрактом маски, що в `жнива_маски.py`. Відеокарта доступна будь-якому користувачу. Ваги
   беруться з відкритих джерел; нові секрети й платні API заборонені.
2. **HTTP до сервера на :8000.** Якщо сервер ComfyUI на 127.0.0.1:8000 піднімається без руки власника (як LM Studio
   на :1234), `gemini` звертається до нього через HTTP і не читає теку `Admin`.

Спершу виміряй, який шлях здійсненний: місце на диску, відеопам'ять поруч із MamayLM, а для другого шляху — хто
піднімає сервер. Обери дешевший. Відеокарта — одна смуга (`аудит/НОУТБУК.md`): SAM не тримає відеопам'ять, коли
вона потрібна живому прогону.

`.github/` і `аудит/адаптери/gemini/` не змінюєш (М.9-Г). Якщо без змін у них не обійтися, роби латку в
`аудит/латки/sam-без-адміна/` з README і SHA-256. Зміни в середовищі ноутбука опиши так, щоб їх можна було повторити:
команди, шляхи, розмір ваг.

**Мірило.** Відсоток речей з маскою `маска.джерело = SAM` на тій самій вибірці 5.1, під обгорткою:
ДО — 0 (ComfyUI недосяжний) → ПІСЛЯ — понад 0, з тим самим контрактом запису. Плюс одна річ, на якій ATR дає
порожню маску, а SAM — непорожню (знімок маски у звіті). Батарея `аудит/КОД.md` — зелена.

**Недосяжність.** Якщо обидва шляхи недосяжні без адміністратора, у звіті має бути вивід помилок для кожного
шляху. Перший рядок — «ЗАБЛОКОВАНО: SAM без адміністратора недосяжний — <чому>». Тоді менеджер піде до власника.
