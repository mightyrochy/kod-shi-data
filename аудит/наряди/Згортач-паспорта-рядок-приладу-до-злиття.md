# Згортач паспортів: рядок файлу гілки, який храповик прочитає як зіпсований «прилад:», — червоний у PR, а не на main

**Проблема.** PR пише зроблене в паспорт кореня файлом гілки `аудит/корені/<корінь>.d/<гілка>.md`; після злиття CI
згортає його в `аудит/корені/<корінь>.md` (`джерела/прилади/згорнути_паспорти.py`, кроки `zbirka.yml`). Храповик

початку рядка чи не тим регістром і зі шляхом після двокрапки, вважає помилкою формату й червонить корінь. У PR
храповик читає лише сам паспорт, а файлу гілки — ні, і `згорнути_паспорти.py --лише-перевірити` цього формату не
звіряє. Факт 16.11: файл гілки PR #4057 мав заголовок

82f48da9e6cc4d6a26c805f59b9525fa1ce62056 був зелений, після злиття (9329f680) і згортання (263b63ba) джоб «храповик
кореня» падав у кожному PR — #4080 (c301bff6), #4081 — з текстом «корінь Е2-опора-пояснення: паспорт — рядок
«### Прилад: пропущені місця (16.11, крок `claude/прилад-Е2-о» — не формат «прилад:»/«база:» з початку рядка»;

**Що зробити** (лише `джерела/прилади/` і їхні стенди; паспортів, коду продукту й нарядів не чіпати; `.github/`

   храповика; другого переліку «схожих» рядків не заводь.
