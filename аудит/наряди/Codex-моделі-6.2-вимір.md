# Які моделі GPT-6.2 приймає Codex акаунта власника і чи доходять вони до відповіді

Менеджер 18.11 11:46 UTC: власник 18.11 надіслав у чат менеджера новину — OpenAI випустила GPT-6.2 Astra і GPT-6.2
Sol, доступні в Codex за підпискою; ідентифікаторів стаття не називає, про Terra — нічого. `аудит/МОДЕЛІ.md` зараз
називає `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-astra` (ім'я `gpt-6.1-astra` акаунт не приймав — вимір 14–15.11:
«The 'gpt-6.1-astra' model is not supported when using Codex with a ChatGPT account», жоден прогін не дійшов до
відповіді). Рішення про таблицю моделей — менеджера й власника; до нього таблиця чинна без змін. Потрібен лише вимір.

**Ціль.** На ноутбуці, у Codex з акаунтом ChatGPT власника, тим самим способом запуску, яким рушій Codex запускає
обгортка (та сама команда й ті самі параметри моделі й зусилля):
1. Версія Codex CLI і перелік моделей, який показує сам Codex (вибір моделі чи його файл переліку) — дослівно.
2. Для кожного імені — `gpt-6.2-astra`, `gpt-6.2-sol`, `gpt-6.2-terra`, кожного іншого імені 6.2 з переліку п.1 і
   старих `gpt-6.1-sol`, `gpt-6.1-terra`, `gpt-6-astra` — один короткий прогін із запитом «Відповідай одним словом:
   так»: прийнято чи ні (текст помилки дослівно), чи дійшла відповідь рушія, секунди.
3. Для кожного прийнятого імені 6.2 — рівні зусилля low, medium, high, xhigh, max: по одному такому ж короткому
   прогону, прийнято чи текст помилки дослівно.
4. Частка тижневої квоти Codex до й після виміру.

**Мірило.** Таблиця «ім'я · зусилля · прийнято · відповідь дійшла · с · текст помилки» з рядком на кожен прогін п.2
і п.3 — у `аудит/проби/Codex-моделі-6.2/ЗВІТ.md` (PR не чернеткою, документ без коду CI зливає сам) і коротко листом
«НОУТБУК: ВИМІР CODEX 6.2 #PR — <прийняті імена й рівні; які старі працюють>» диспетчерові
session_01FPQuiXLUBboTLpBn6M45M4 (канал — `аудит/НОУТБУК.md`, «Лист»). Чого не вдалося виміряти — «не виміряно:
<чому>», без здогаду.

**Межі.** Один короткий прогін на пару «ім'я · зусилля», без повторів і без нарядів продукту на нових моделях.
`аудит/МОДЕЛІ.md`, обгортку, `смуги.json` і чергу не міняєш. Підписки, оплати, кредитів і налаштувань акаунта не
чіпаєш: модель, що просить доплату чи підтвердження, — текст дослівно в таблицю, без згоди. Прогону на відеокарті
вимір не зупиняє й не відкладає: береш, коли ноутбук на зв'язку.
