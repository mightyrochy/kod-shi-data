# Обгортка: межа без джерела не діє (корінь ПК-межа-без-джерела, «Вниз» 2)

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`. Наряд на обгортку (ставить диспетчер). Гілка
`claude/obhortka-mezha-bez-dzherela`. Корінь — `аудит/корені/ПК-межа-без-джерела.md`: «Напрямок» («Обгортка: межа з
порожнім джерелом не діє — ні попереднього значення, ні типового з коду; захист від кривих даних — відмова рядком, а
не мовчазна стеля»), «Рішення менеджера 31.10» (HANG і STALL — з поміткою виміру `events.tsv`; «до 5 повернень» —
знімається; слотам стелі нема; код, що без джерела бере попереднє значення, — клас п.4, окремий наряд диспетчера).
Над цим коренем зараз інших сесій нема.

1. **Місця.** `python3 джерела/прилади/корінь_пк_межа.py` на свіжому `main` (8fb9b217 і новіші) друкує в коді обгортки
   30 місць п.4: `claude_run.ps1:48,50,51`, `gemini_run.ps1:46–51` (типові параметрів), `queue_lanes.ps1:37–44`
   (`Ceil`, `Defaults`, `LaneDefaults`), `queue_lanes.ps1:248` (гілка «без джерела — попереднє»),
   `wrapper_chain.ps1:590,595` (`review_hours` 24 / 168). Лагодиш причину — код бере число без джерела — у всіх місцях
   обгортки, через які йде мірило, не рядок за рядком: поле без `джерело` в `смуги.json` / `ланцюг.json` → межі нема
   (для стелі, тайм-ауту, повторів), а для механізму без «нема межі» (період опитування) — відмова рядком у журналі
   обгортки з назвою поля, не типове з коду. HANG / STALL лишаються лише з джерелом-виміром у полі (форма v2, «вимір
   ДД.ММ …»), як вирішив менеджер; `MaxRetakes` 5 — знімається. Захист від кривих даних (не число, від'ємне) —
   відмова рядком, без мовчазного обрізання до `Ceil`.
2. **Дані.** Значення, яким дає джерело рішення менеджера чи вимір, — у `смуги.json` / `ланцюг.json` з полем
   `джерело`; без джерела поля не вигадуєш (не підводиш число під слово). Що лишилось без джерела й без «нема межі» —
   «ЗНАХІДКА» диспетчерові з переліком полів.
3. **Мірило.** На голові PR прилад кореня: код обгортки п.4 — 0 (було 30), загальне число не росте (храповик); проби
   обгортки (`аудит/адаптери/gemini/перевірка/`, `джерела/прилади/тест_корінь_пк_межа.py`) зелені; у PR — рядок на
   кожне з 30 місць: що стало. Живий запуск обгортки — на ноутбуці після ввімкнення (диспетчер ставить позначку),
   доти рядок дошки — не вище ЧАСТКОВО. Паспорт — «Стан і що лишилось» дописано.
