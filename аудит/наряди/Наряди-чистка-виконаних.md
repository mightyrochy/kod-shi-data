# Тека нарядів: прибрати виконані, відкликані й зупинені

Технічний наряд диспетчера. Роль — ВИКОНАВЕЦЬ за `AGENTS.md`, `аудит/ВИКОНАВЕЦЬ.md` і `GEMINI.md`.

**Що відомо.** В `аудит/наряди/` 80 файлів; чинних (у черзі чи в роботі) — близько десяти. Решта — наряди, чий крок
давно злито, відкликано чи зупинено: вони засмічують теку, а «сила:» в їхніх шапках суперечить `аудит/МОДЕЛІ.md`.

**Що зробити.** Для кожного файла теки визнач одне з трьох і запиши рядком у таблицю в описі PR
«файл — рішення — доказ»:

1. **лишити** — назву наряду згадано в `аудит/СТАН.md`, в `аудит/ПЛАН.md` (крім розділу «Зупинено») чи в паспорті
   `аудит/корені/*.md` як крок, що йде чи чекає; або є відкритий PR з гілки `…/<назва наряду>`; або на файл посилається
   код чи прилад (`.github/workflows/`, `аудит/адаптери/gemini/*.ps1`, `джерела/прилади/`, `аудит/проби/*.js`) — так
   лишаються, зокрема, `автоживий.md` і `автоперевірка.md`;
2. **видалити** — є доказ, що крок закрито: злитий PR з гілки з назвою наряду (`git log origin/main --grep` за назвою чи
   номером, `gh pr list --state merged --search`), рядок «Зупинено» плану або запис про відкликання в стані чи журналі
   передач; доказ — номер PR чи файл і рядок;
3. **сумнів** — доказу закриття нема й чинним він не названий: файл лишаєш, у таблиці пишеш, чого бракує.

Видаляєш лише файли з рішенням 2 (`git rm`). Нічого іншого не міняєш.

**Межі.** Лише видалення файлів з `аудит/наряди/`; жодного файла правил, стану, плану, коду чи приладів не чіпати;
змісту нарядів, що лишаються, не правити. Прогонів, моделей на відеокарті й викликів платних API нема. Цей файл наряду
видали тим самим PR.

**Мірило.** ДО → ПІСЛЯ: число файлів у теці; у таблиці PR — рядок на кожен із 80 файлів; для кожного видаленого названо
доказ, який диспетчер відтворить однією командою; `grep -rn '<назва видаленого>.md'` по `.github/`, `аудит/адаптери/`,
`джерела/`, `аудит/СТАН.md`, `аудит/ПЛАН.md` — порожньо.
