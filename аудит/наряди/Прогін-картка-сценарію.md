# Вади прогону: картка сценарію з незрозумілими й зайвими рядками (вада 21, 15272)

Роль — ВИКОНАВЕЦЬ, ядро — `AGENTS.md`, код — `аудит/КОД.md`. Гілка `claude/Прогін-картка-сценарію` від свіжого `main`,
PR-чернетка. Вади — `аудит/проби/живий-як-людина-1/вади.md` (розділ 1, номери нижче) і
`аудит/проби/живий-як-людина-2/вади.md`; це те, що жінка бачила в живому прогоні «як людина», тож вони йдуть першими
(`аудит/ПЛАН.md`, «Як працюємо»). Перепис екрана (#3703) цих місць не чіпає: причина — у Python, поза
`джерела/показ/`. Файли екрана не правиш — там «ЗНАХІДКА» з доказом. Кореня з паспортом нема: одинична вада етапу.

**Крок.** Картку сценарію складає паспорт нагоди — `джерела/паспорт_нагоди.py:163`, `джерела/паспорт_основи.py:269`:
жінка бачить рядки, яких не казала й не розуміє (вада 21); нагода «Весілля» лишається без плитки весілля, а «Реагенти
на дорогах» стоять при теплій смузі (15272). Рядок картки має джерело — її слово чи факт, який вона може перевірити
(дата, погода її міста); висновок коду без такого джерела на картку не йде. Шукаєш від писача картки всі такі рядки, а
не два названі. Вада 23 (місце, що повторюється) вже злита #3759 — не чіпаєш. `джерела/мовний_шар.py`,
`джерела/внутрішня_мова.py` — інші наряди.

**Мірило.** Тестовий прогін у хмарі на сценах без фото, ДО → ПІСЛЯ на тих самих сценах: рядків картки сценарію без
джерела в її словах чи перевірному факті — N → 0 (перелік ДО — у тілі PR); «Весілля» має плитку весілля; «Реагенти на
дорогах» з'являються лише за морозу (так/ні). Батарея й проби `аудит/КОД.md` не гірші. Остаточно — третій прогін «як
людина»: вади 21 не видно.

**PR.** Зроблене, невдале й що лишилось — у тіло PR і в паспорт кореня, якщо він є; вада — рядок у
`аудит/дошка/claude/Прогін-картка-сценарію.md`. `ЖИВИЙ ПІСЛЯ` — рядками в тілі PR, сцена на кожну ваду. Лист
диспетчерові: «ГОТОВО #PR <повний SHA> — вад кроку K, на тестовому прогоні видно ДО → ПІСЛЯ; вад знайдено: N (рядки)».

**Рішення менеджера 15.11 (15420, РІШЕННЯ ПОТРІБНЕ).** На шляху без розмови код мусить щось припустити, щоб зібрати
образ. Припущення, від якого залежить добір, з картки не ховаємо — прихований вплив гірший за видимий: рядок лишається,
каже її мовою, що це припущення й чому («так зазвичай для побачення», «бо така річ на фото»), і вона може його
змінити дотиком, як свій рядок. Припущення, від якого добір не залежить, на картку не йде. «Типово для речі з фото»
— не її мова: переписати. Це наступний крок цього наряду, окремим PR після злиття #3848.

**Рішення менеджера 15.11 (де робити крок 15420).** Слова «типово для речі з фото» й «— типово для нагоди» пише не
Python, а малювач картки на екрані (`джерела/показ/випадок.js:226`, `:537`, `:547`; `голос_помада.js:564–575`), і #3703
ці файли саме переписує. Крок робить той самий виконавець після злиття #3703, на свіжому `main`, і для цього кроку
заборону на файли екрана знято в межах малювача картки сценарію (у #3703 — `показ/екран/сценарій.js`,
`показ/випадок.js`); решта екрана — далі «ЗНАХІДКА». У #3703 кроку не додаємо: перепис іде на перевірку таким, як є.
Що робить крок: нагода для речі з фото лишається на картці словами «бо така річ на фото», і її можна змінити дотиком;
типове місце добору не міняє (`сценарій.py:424`, `дистанція.py:188`), тож з картки йде. Мірило те саме: на шляху без
розмови рядків картки не її мовою — N → 0, тестовий прогін у хмарі на сценах без фото ДО → ПІСЛЯ.

**Рішення менеджера 15.11 (15417, 15418).** Заборону на файли екрана в цьому наряді ставили через перепис #3703; його
злито, тож для решти мірила наряду її знято: нагода поза плитками стоїть обраною (15417), «Реагенти на дорогах» поза
морозом не видно (15418) — у `джерела/показ/екран/сценарій.js` і, якщо поле там, у `показ.html`. Крок — новому
виконавцеві, одним PR; спроба попереднього — `аудит/проби/Прогін-картка-сценарію/екран_знахідка.diff`. Причину на
