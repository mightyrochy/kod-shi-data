**Як.**
1. Перед правкою файлу — `python3 джерела/прилади/лічба_коментарів_історії.py <файл>`: адреси збігів.
2. Знімай із коментаря й докстрінга посилання на рядок дошки, PR, дату, живий прогін, «було»; пояснення «що й чому»

3. Код не змінюється. Байти поза коментарями не чіпай: кодування, BOM, LF/CRLF, кінцевий newline, відступи; без
   форматерів, `ast.unparse` і переписування файлу цілком — лише точкові правки рядків коментарів.
4. Перевірка кожного `.py`: AST без докстрінгів тотожний `main`. Скрипт — поза репозиторієм (`../ast_same.py`, теку вище клону):
   ```
   import ast, subprocess, sys
   def tree(src):
       t = ast.parse(src)
       for n in ast.walk(t):
           b = getattr(n, "body", None)
           if isinstance(b, list) and b and isinstance(b[0], ast.Expr) \
                   and isinstance(b[0].value, ast.Constant) and isinstance(b[0].value.value, str):
               n.body = b[1:] or [ast.Pass()]
       return ast.dump(t)
   f = sys.argv[1]
   old = subprocess.run(["git", "show", "origin/main:" + f], capture_output=True, check=True).stdout
   print(f, "AST тотожний" if tree(old) == tree(open(f, "rb").read()) else "AST РІЗНИЙ")
   ```
   `python3 ../ast_same.py <файл>` — кожен файл «AST тотожний». Для `.js`/`.html` — `git diff` зачіпає лише
   рядки коментарів.
5. Лишений збіг (не історія: номер речі `#N·MM`, hex-колір `#111111`, число на кшталт `0.09`) — переліком із
   причиною в тілі коміту. Рядки «a → b» без дати — переліком у тілі коміту.
