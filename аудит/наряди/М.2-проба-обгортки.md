# Проба обгортки Gemini без руки власника

**Проблема.** Ланцюг М.2 (позначка черги → прогін `agy` → бандл → пуш `gemini/*` → рядок диспетчерові) перевірено
лише статично в хмарі; на ноутбуці не проганявся. Найчастіший обрив — хід `agy` кінчається раніше за роботу.

**Ціль.** Один прогін без руки власника від позначки до рядка диспетчерові «GEMINI ОБГОРТКА: ОПУБЛІКОВАНО …».

**Що зробити** (коду продукту не чіпати; гілку не зливають):
1. У PowerShell на передньому плані `Start-Sleep -Seconds 400` — довше за типову межу ходу `agy` (5 хв) — і дочекайся
   кінця. Фоном не запускай.
2. Створи `аудит/проби/gemini_обгортка/проба.txt` з трьох рядків: вивід `git rev-parse origin/main`, вивід `whoami`,
   час кінця кроку 1 (UTC, `[DateTime]::UtcNow.ToString('s')`).
3. Видали цей файл наряду й закоміть усе одним комітом; тіло коміту — «Що змінено / Перевірено» за
   `аудит/ВИКОНАВЕЦЬ.md` (вад поза мірилом нема — так і напиши).

**Мірило.** ДО: рук власника на прогін — 2. ПІСЛЯ: 0; диспетчер отримав рядок обгортки з повним SHA, гілка
`gemini/М.2-проба-обгортки` на GitHub має один коміт із `проба.txt`, у ній `whoami` — `…\gemini`.
