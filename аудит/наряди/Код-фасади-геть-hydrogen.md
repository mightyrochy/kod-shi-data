# Один прохідний модуль — геть (вимір Gemini 4 Hydrogen на коді)

Ти — виконавець (`аудит/ВИКОНАВЕЦЬ.md`; адаптер — `GEMINI.md`), код — `аудит/КОД.md`. Наряд диспетчера 28.11 за рішенням
менеджера 28.11: один вимірний наряд коду для `gemini-4-hydrogen-high`, межу `аудит/МОДЕЛІ.md` («лише малі наряди»)
знято на цей один наряд (`аудит/КАРТИНА.md`, «Нові моделі `agy`»). Метод і мірило — наряд `аудит/наряди/Код-фасади-геть.md`
(прочитай цілком); тут — лише твоя частина: **один** модуль, один PR.

**Що зробити.**

1. На свіжому `main` запусти `python джерела/прилади/група_залежності.py` — він дає прохідні модулі (без власних `def` і
   `class`), їхніх споживачів і найбільшу групу взаємної залежності. Візьми прохідний модуль із найменшим числом
   споживачів; `реєстр_правил` і `colorspace` не бери. Модуль, чий споживач є серед файлів відкритих PR коду
   (`git fetch origin 'refs/pull/*/head:refs/remotes/pr/*'` не треба — перелік файлів дає
   `git log origin/main..origin/<гілка> --name-only` для гілок `codex/*` і `claude/*`, оновлених за добу), пропусти й
   візьми наступний.
2. Кожен споживач у продукті, приладах і пробах імпортує ім'я з модуля, де воно визначене. Прохідний модуль видали тим
   самим комітом разом із записом у `status.МОДУЛІ_ПРОДУКТУ` і в переліку файлів збирача. Жодної правки, крім рядків
   імпорту; назв модулів і функцій не міняєш.
3. Мірило (те саме, що в `Код-фасади-геть.md`): прохідних модулів було → стало; імпортів продукту через цей модуль → 0;
   найбільша група до → після; вихід коду на записаних сценах побайтово той самий, порівняних сцен не 0 (записи —
   `аудит/проби/нічні/`, найсвіжіша тека); батарея `аудит/КОД.md` зелена; сторінка збирається
   (`NODE_PATH=джерела/node_modules LYUSTERKO_CATALOG=повний python джерела/build_артефакт.py джерела <тека>/index.html показ-повний`).

**Межа.** Не більше 2 млн токенів на наряд. Батарея не зеленіє після двох спроб виправлення — зупинись: рядок
«ЗАБЛОКОВАНО: <що падає, файл:рядок>» і кінець.
