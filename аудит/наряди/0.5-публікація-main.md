# Публікація `main` не губиться

**Проблема.** Р13 Д.1: стан підтверджують записом, а не чинним артефактом. Крок публікації `zbirka.yml` пропускає збірку
як застарілу, коли `main` пішов далі («main X вже новіший за джерела Y — застарілу публікацію пропущено»), а наступний
push поза `paths` збірки не запускає: `index.html` і згорнута дошка чекають випадкового push коду. 20.10 збірку 84d12e7b
пропущено о 10:44 UTC, бо `main` уже був 43e3c56d; виправила лише наступна збірка (#1490). Рядок дошки — 8651.

**Ціль.** Збірку, пропущену як застарілу, публікують на новішій голові, якщо новіші коміти не чіпають `paths` збірки;
чіпають — публікує їхня власна збірка, як нині. Права М.4 (код PR без права запису, публікація лише з `main`) не
змінюються.

**Підказка.** Найменша зміна в кроці публікації `.github/workflows/zbirka.yml` (цикл спроб push): перед пропуском звір
`git diff --name-only` джерел і нової голови з `paths`; поза ними — перенеси коміт публікації на нову голову й пушни тим
самим циклом. Конфлікт (дошка, `аудит/БЕКЛОГ.md`) — пропуск із записом у summary, не силовий push. Штамп лишається SHA
джерел — звір, хто його читає (0.1). Без нових гейтів, повторної збірки й `workflow_dispatch`; спершу прочитай дифф
М.4 (#1490).

**Мірило.** Відтворення скриптом у тимчасовому репозиторії з локальним `origin` (у PR, не в `main`): push коду, потім
push поза `paths` до публікації — ДО: пропущено, ПІСЛЯ: опубліковано на новій голові зі штампом джерел; push коду
поверх коду — як ДО, публікує новіша збірка; конфлікт — пропуск без силового push. CI голови зелений; після злиття
диспетчер підтверджує перший реальний збіг (ЖИВИЙ ПІСЛЯ).
