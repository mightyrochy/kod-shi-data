# Корінь Е3-місце-речі — крок модуля: ярус і відкриті зони в записі

Паспорт — `аудит/корені/Е3-місце-речі.md` («Рішення», 10.11 менеджер; також 08.11 — КОЛО #3352, читач бере елемент,
річ чи запис). Роль — ВИКОНАВЕЦЬ, ядро — `AGENTS.md`, код — `аудит/КОД.md`.

**Крок.** Лише модуль `джерела/місце_речі.py` і його стенд; читачів (`композитор_слоти`, `outfit.зони_речі`,
`зони_вето_з_кодів`) не переводиш — це наступні частини ч-композитор і ч-специфікація після злиття цього кроку.
1. Ярус: факт у `ФАКТИ_СЛОТА` модуля — верх → «верх», низ → «низ», верхній шар → «верх»; решта слотів ярусу не має
   (`None` з причиною). Пише `записати`, з джерелом; публічний читач ярусу в модулі приймає елемент, річ чи запис
   (форма — як у `бік_межі`, хибна форма — виняток). Таблиця під іншим ім'ям чи функцією в читачі — не правка.
2. Зони: запис речі несе кожну зону її крою (коди картки: виріз, рукав, тип) як «відкрито», «закрито» чи «невідомо» з
   джерелом; запис шару — «розстебнуто» (так, ні, невідомо) з джерелом (слово стилістки чи вимір маски кадру). Річ не
   під шаром — «відкрито»; під шаром — з крою шару й «розстебнуто»; чого джерело не знає — «невідомо». Тип «розстебнуто»
   не дає. Поле картки `розстібнуте` — факт виробу лише для крою без застібки: перевір його писача й запиши в PR.
3. Стенд модуля: три форми входу й хибна форма для читача ярусу; заміри приймання нижче.
