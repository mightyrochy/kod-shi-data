# Зображення примірки — через API OpenAI за кредитами з підписки

Роль — ВИКОНАВЕЦЬ, ядро — `AGENTS.md`, код — `аудит/КОД.md`, продукт — `аудит/ПРОДУКТ.md`, «Примірка». Джерело — запис
журналу 19.11.2026 14:05 UTC: текст — Claude (сусідній наряд `Модель-текст-на-Claude`), зображення — OpenAI. Підписка
ChatGPT Pro дає $100 кредитів API на місяць (лист OpenAI 17.11); самого Codex ними не оплатити — це API зображень.

**Що є.** Примірку малює `gemini-nano-banana-2.1` (`МОДЕЛЬ_КАРТИНКИ` у `джерела/показ/приміряння.js`), маршрут обирає
ім'я моделі; міст (`джерела/worker_джерело.js`, `ПРОВАЙДЕРИ`) знає `claude-` і `gemini-`. Що на примірці та сама
людина, тримає код за маскою, а не промпт.

**Ціль.** Третій провайдер моста — лише для зображень: модель `gpt-image-…` за іменем, ключ — секрет Cloudflare Worker
(ім'я секрету — у звіті, його кладе власник), сторінка й далі шле й читає один формат. Типова модель картинки цим
нарядом не міняється.

**Кроки.**
1. До коду — чинна документація OpenAI, а не пам'ять: який шлях API приймає її фото й фото речей як опорні зображення
   (редагування), яка модель це вміє (сторінка цін 19.11: `gpt-image-2.6-sunburst`, `gpt-image-2.6-flare` — $8 входу й
   $30 виходу за млн токенів зображення; ціни за одне зображення там нема), скільки токенів — одна примірка. Нема
   підтвердження в документації — «ЗНАХІДКА» з посиланнями, без коду.
2. Маршрут у мості одним визначенням провайдера, тим самим кодом ключа, стелі часу й заголовків, що в двох наявних;
   відповідь — у форматі, який уже читає `приміряння.js`.
3. Ключа в сесії нема, і його не просять: до ключа — стенд на заглушці відповіді за документованим форматом (дим).

**Мірило наживо — після ключа.** Ті самі речі й тестові фото стенду (особистих фото в репозиторії нема й не буде) на
Nano Banana 2.1 і на моделі OpenAI: ціна однієї примірки (токени × ціна), час, чи річ та сама (ΔE00 у масці речі, як у
`Річ-примірка-проба-шуба`), вердикт судді щодо крою, знімки. Типову модель картинки обирає менеджер за цими числами.
