# Кожна відповідь моделі в Python — через реєстр схем

Етап Е2 (`аудит/ПЛАН.md`), частина `Е2-договір-модель-код` (п.1–2), поломки ПС-13, 15, 16, 24 і каталожна частина ПС-11
(`аудит/дошка_поломки_системи.md`: що, де в коді, рядки дошки). Роль — ВИКОНАВЕЦЬ, ядро — `AGENTS.md`, код —
`аудит/КОД.md` (причина — механізм: одна точка й лічба обходів).

**Що зараз** (`main` 29.10; звір). Одна точка є — реєстр `схема_відповіді.py` із `схеми_розбору.py`: образи, вибір,
доповнення, опис, рука без коду, вибір речей, дві заміни (ці — без форми відповіді), вердикт; мовний хід і кінцева
відповідь — `language_contract.py`. Поза нею: `річ_з_фото.py` (`речі_з_json` — свій повтор формату) і
`каталог_розбір.py` (`схема_відповіді()` — лише `response_format` LM Studio; запасного ходу без нього, схоже, нема —
перевір). Вибір палітри, приміряння й помічницю ще не перевіряли. Переліку меж (п.1 наряду Е2) нема — лише неповний
коментар у `показ/міст.js` (:438–441).

**Що зробити.**
1. Перелік усіх викликів моделей у Python і JS будує прилад з коду, а не рука: хто кличе, яку схему чекає код, чи є один
   повтор і запасний хід, чи виклик зайвий, бо це може порахувати код (ПС-24 — виклики без бюджету). Цей перелік і є
   лічбою обходів.
2. Кожну межу Python поза реєстром — у реєстр: одна схема, перевірка нею, розбіжність — моделі словами на один повтор,
   далі — запасний хід коду без зупинки й мовчазної втрати. `response_format` — лише прискорення, не умова: стилісткою
   може бути будь-яка модель (власник 27.10).
3. Каталог (ПС-11): поле з дослівною цитатою не приймається лише тому, що цитата є в тексті, — код звіряє цитату з кодом
   поля, а що не звірити, лишається «невідомо», а не здогадом.
4. Тут не правиш: межі JS — `Е2-межі-показу`, ремонт формату в `від_моделі` — `Е2-від-моделі-без-ремонту`.

**Мірило.** ДО → ПІСЛЯ: відповідей моделі, розібраних у Python поза реєстром, — ПІСЛЯ 0; зайві виклики названо й
прибрано або лишено з причиною. ДО з живого — серія 2 (`аудит/проби/б1/ДО-2710.md`). ПІСЛЯ — відтворення записаних
прогонів (Е1) і рядки `ЖИВИЙ ПІСЛЯ` спільного прогону: 0 зупинок і 0 втрат через формат на цих межах.

**Межі.** Як ядро. Файли — межі Python поза `міст_відповіді.py` і `мовний_шар.py`. Спільні з гілкою 2.13 (#2118) — після
її злиття: перетин перевір (порядок — диспетчер).
