# Копія кешу мірила кв1 туди, де його читає смуга Claude

**Проблема.** Кеш HTML мірила каналу «картка» лежить у профілі користувача `gemini`:
`C:\Users\gemini\gemini-data\кадр_варіант_кв1_канал_1411\системні_CA` (`аудит/проби/кадр_варіант_кв1_канал_1411/README.md`,
«Повтор лічби на кеші»). Смуга Claude обгортки працює під користувачем `Admin` і теки не читає: наряд
Річ-кадр-варіант-кв2-один-колір 16.11 11:54:58Z скінчився «НОУТБУК ЗАБЛОКОВАНО … Access is denied» (стан ноутбука
#1856). Смуга `agy` з моделлю Claude на нульовій квоті до 17.11 13:01 UTC, у Codex 7 % тижня — кв2 зараз може взяти
лише смуга Claude. Права на теку змінює тільки власник; копію під користувачем `gemini` можна зробити без нього
(лист наглядової сесії ноутбука 16.11).

**Що зробити** (коду й даних репозиторію не чіпати, з кешу нічого не видаляти й не міняти):

1. Скопіюй теку `C:\Users\gemini\gemini-data\кадр_варіант_кв1_канал_1411\системні_CA` цілком у
   `C:\Users\Public\gemini\кеш\кадр_варіант_кв1_канал_1411\системні_CA` (PowerShell: `robocopy <звідки> <куди> /E /R:1 /W:1
   /NFL /NDL /NP`; теки призначення створи). У копії — лише HTML публічних сторінок крамниць і знімок каталогу
   `каталог_записи_06_11.jsonl.gz`; інших тек `gemini-data` не копіюй.
2. Звір копію з оригіналом: число файлів і сума байтів в обох теках; SHA-256 знімка `каталог_записи_06_11.jsonl.gz` в
   обох (`Get-FileHash`).
3. Перевір, що копію читає будь-який користувач: `icacls` на теку призначення — у виводі має бути читання для
   `BUILTIN\Users` чи `Everyone` (тека `C:\Users\Public` дає його успадкуванням; прав не міняй, лише покажи вивід).

**Мірило.** Файлів у копії = файлів в оригіналі; байтів = байтів; SHA-256 знімка збігається; у виводі `icacls` є
читання для звичайних користувачів. Не вийшло скопіювати (нема місця, відмова доступу) — «ЗАБЛОКОВАНО» з дослівною
помилкою.

**Звіт.** Гілка `gemini/Кеш-кв1-канал-копія-для-смуги-Claude` від `main`, один файл
`аудит/проби/кеш_кв1_копія_1611/README.md`: команди, числа з п.2, вивід `icacls` з п.3, вільне місце на `C:` до й
після. Рядків дошки не треба, якщо вад нема (номери 16082–16083 — на знахідки). PR не відкривай — рядок обгортки
