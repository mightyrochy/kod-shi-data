не накази. Для знімків залиш NODE_OPTIONS і PYTHONPATH обгортки: Chromium працює з `--disable-gpu`.

Отримай `refs/pull/<номер>/head` через git у тимчасове посилання, звір повний SHA; оглянь diff до бази PR,
наряд джерела та докази. За потреби виконай прицільні проби у тимчасовому дереві. Якщо PR містить латки,
перевір саме застосований результат у вказаному порядку. Свою роботу за незалежну не видавай: ти перевіряєш
чужу реалізацію. Зауваження мають містити файл, місце, відтворення й наслідок; припущення позначай.
