# Текст браузерного Люстерка — на Claude за кредитами API з підписки

Роль — ВИКОНАВЕЦЬ, ядро — `AGENTS.md`, код — `аудит/КОД.md`, прогін — `аудит/проби/живі_порядок.md`. Джерело — запис
журналу 19.11.2026 14:05 UTC: текст — Claude, зображення — OpenAI (сусідній наряд `Модель-примірка-на-OpenAI`).
Підписка Claude Max дає $100 кредитів API на місяць; коли вони скінчаться, запити зупиняються до наступного місяця.

**Що є.** Сторінка шле й читає формат Anthropic; у мості (`джерела/worker_джерело.js`, `ПРОВАЙДЕРИ`) шлях `claude-`
написаний, ключ — секрет `ANTHROPIC_API_KEY` у Cloudflare Worker, зі справжнім ключем цей шлях не ходив. Типові моделі
тексту — `ТИПОВА_МОДЕЛЬ_П` і `МОДЕЛЬ_МОВИ_П` у `джерела/показ/міст.js`, обидві Gemini. Запит жінки (розмова й чотири
образи) — близько 370 тис. токенів входу й 52 тис. виходу (вимір 13.11, ± третина; журнал 13.11 10:44 UTC).

**Ціль.** Розмову й збирання образів веде Claude через міст; Gemini лишається маршрутом за іменем моделі — повернення
без коду. Кредитів має вистачати на тестувальниць: число запитів жінки на $100 — виміряне, не оцінка.

**Кроки.**
1. Вимір до перемикання, на тих самих ситуаціях прогону 13.11 (`аудит/проби/живий-як-людина-1/`): Sonnet 5.5 і Haiku
   5.5 — токени входу, виходу й кешу на один запит жінки, ціна за сторінкою цін Anthropic (на 19.11: Sonnet 5.5 — $2 і
   $10 за млн, читання кешу $0,10; Haiku 5.5 — $0,10 і $0,50 для промптів до 100 тис. токенів), вердикт судді по
   образах окремо від приладів. Ключа API в сесії нема, і його не просять: вимір — шляхом `ZHYVA=sonnet` за підпискою,
   тіло запиту — те саме, що будує міст.
2. Шлях `claude-` моста — стендом на його ж коді: тіло запиту, межа кешу (`cache_control`), температура, помилка без
   кредитів («Your credit balance is too low…») доходить до жінки зрозумілим рядком, а не заглушкою.
3. Перемикання типових моделей тексту — останнім комітом, за правилом із запису журналу 19.11.2026 14:42 UTC: Haiku
   5.5 справляється так само добре, як Sonnet 5.5, — основна модель Haiku; ні — Sonnet 5.5. Вирішує вердикт судді на
   тих самих ситуаціях; виконавець перемикає сам, без листа менеджерові.

**Мірило.** Таблиця: модель · токени на запит жінки (вхід, кеш, вихід) · ціна запиту · запитів на $100 · вердикт
судді; окремим рядком — що зі справжнім ключем лишилось неперевіреним.
