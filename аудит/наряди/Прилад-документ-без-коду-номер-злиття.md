# Докстрінг приладу самозлиття згадує нумерацію злиттів, якої правила не ведуть

Наряд диспетчера (прилади) за листом менеджера 26.11; докази — `аудит/звіти/правила-диспетчера-2611/ЗНАХІДКИ.md`,
знахідка 11. Роль — ВИКОНАВЕЦЬ, код — `аудит/КОД.md`.

**Проблема.** `джерела/прилади/документ_без_коду.py`, докстрінг, абзац «Мітка «злити»»: «тіло — тіло PR як є (номер
злиття диспетчер пише в тілі PR сам; CI його не вигадує)». Нумерації злиттів нема в жодному правилі
(`аудит/ДИСПЕТЧЕР.md`, «Стан і зведення»: «Злиттів, тактів, номерів злиттів … там нема — вони в `git log` і PR»);
диспетчери за цим рядком вели номер злиття в стані.

**Що зробити.** Прибрати з докстрінга згадку номера злиття (лишити «тіло — тіло PR як є»). Пошук того самого по
`джерела/`, `.github/`, `.claude/` (`grep -rn 'номер злиття'`): інші місця в коді — тим самим PR; у файлах правил —
«ЗНАХІДКА» диспетчерові, не правка.

**Мірило (без моделі).** `grep -rn 'номер злиття' джерела .github .claude` — ДО N, ПІСЛЯ 0 (сирий вивід — у PR); тести
приладу (`тест_документ_без_коду.py`) зелені; поведінки коду PR не міняє (дифф — лише рядки докстрінга/коментарів).
CI голови зелений.

**PR.** Чернетка від `main`, гілка `claude/прилад-документ-без-коду-номер-злиття`. Кінець — «ГОТОВО <SHA>» диспетчерові.
