# Обгортка: Codex без меж моделі й розміру

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`. Наряд самодостатній.

**Навіщо.** Власник 26.10 08:46: «Ми працюємо новим каналом кодекс, не через легасі, тут ніяких обмежень ні по моделях
ні по розміру задач немає і бути не може.» Правила вже такі (`аудит/CHATGPT.md`), а код
`аудит/адаптери/gemini/gemini_run.ps1` ще обмежує:

- зусилля — `-cmatch '^(.+)-(low|medium|high|xhigh)$'` (:244): позначка `gpt-…-max` іде як назва моделі з «-max»;
- час — `$TurnMinutes = 120`, `$TotalMinutes = 180` (:35–36), дедлайн усього (:684): велику задачу Codex обриває;
- роль — промпт «Ти — виконавець за `AGENTS.md` і `аудит/ВИКОНАВЕЦЬ.md`» (:496) і для наряду перевірки, тож перевірку
  дають нарядом зі звітом у коміті (`аудит/наряди/перевірка-1812.md`).

**Що.**

- зусилля Codex — будь-яке, яке приймає `codex exec` (`-c model_reasoning_effort=…`), `max` теж; не приймає — рядок
  «ЗАБЛОКОВАНО» з кодом відмови, без тихої підміни;
- для рушія `codex` — без межі часу всього: зупиняє лише завислість (нема нових подій `--json` довше за поріг; поріг — з
  наявних прогонів, у PR);
- роль агента — з рядка «Роль — …» наряду (ВИКОНАВЕЦЬ чи ПЕРЕВІРКА за `аудит/ПЕРЕВІРКА.md`); нема — виконавець, як
  тепер;
- поведінка `agy` — без змін.

**Мірило.** На ноутбуці, як вирішить диспетчер (`аудит/НОУТБУК.md`): позначка `gpt-6.1-sol-max` доходить до «GEMINI
ОБГОРТКА: ГОТОВО … МОДЕЛЬ gpt-6.1-sol-max» чи до «ЗАБЛОКОВАНО» з кодом відмови `codex exec` (тоді в PR — найвище
прийняте зусилля); з `-TotalMinutes 5` прогін Codex на 10+ хв не обривається, доки йдуть події; одна позначка `agy`
— як до правки. Вивід — у PR.
