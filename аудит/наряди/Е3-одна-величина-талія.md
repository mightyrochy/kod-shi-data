# Корінь Е3-одна-величина, частина «талія»: виражена талія — одне визначення з бази знань

Паспорт — `аудит/корені/Е3-одна-величина.md` (талія — «Проблема», «Рішення менеджера 31.10» і «Рішення менеджера
02.11 — питання PR #2841 (талія)»: як застосувати каскад); етап Е3 `аудит/ПЛАН.md`;
рядок дошки 11995; `аудит/ПРОДУКТ.md` п.8. Роль — ВИКОНАВЕЦЬ, ядро — `AGENTS.md`, код — `аудит/КОД.md`. Частина —
застосування вирішеного 31.10, тож іде паралельно з кроком кореня (наряд `Е3-одна-величина`) за файлами без перетинів
(ядро, «Причини»); після #2786, бо той правив `fit.py`, `hypergraph.py` і `силует_*`; інші спільні файли — порядок дає
диспетчер.

**Що видно.** Виражену талію визначають пороги WHR у `fit.зони` (0.78 для `талія_виражена`, голі 0.75 для ярлика X і
0.80 для H, 0.85 для O) і ще один у гіперграфі (`whr_без_вузької_точки` 0.90, `hypergraph.py`, `силует_реєстр.py`),
жоден не з бази знань. Ж8 (84/64/88 см) за FFIT — Rectangle без вираженої талії, а код дає ярлик X і `талія_виражена:
True`.

**Ціль** — рішення 31.10: межа — FFIT бази знань у дюймах, як опубліковано (тема-1 §2: «all FFIT thresholds are in
inches, exactly as published»); межі WHR коду знімаються; ярлик маршруту, `талія_виражена` на дроті й рампа гіперграфа
читають одне визначення.

**Мірило.** Прилад `джерела/прилади/корінь_е3_одна_величина.py`: ДО — місця талії на `main` після #2786 (перевір),
ПІСЛЯ — їх 0, усього менше, храповик у CI. ЖИВИЙ ПІСЛЯ — сцени живого мірила паспорта для талії: `ж8_зима`,
`ж7_театр`, `ж6_театр` і сцена ж4 (повне збирання) — маршрут фігури в брифі й картках, `waist_defined` на дроті й
рампа гіперграфа однакові для тієї самої жінки й збігаються з визначенням бази; ДО на ж8 — ярлик X і
`талія_виражена: True`, на ж4 — O.

**PR.** Паспорт правлять паралельні сесії кореня, тож зроблене, невдале й що лишилось — у розділ «Підсумок» цього

- ЗАБЛОКОВАНО: потрібне рішення менеджера про застосування FFIT до наявних маршруту й рампи. Тема-1 §2 визначає категорії каскадом, а не одну межу для всіх тіл: для Hourglass різниця стегна−талія ≥ 10″, для Bottom Hourglass ≥ 9″ за додаткових умов, у тому числі високого стегна; Spoon має іншу умову. Тому просто застосувати одну з цих меж до всіх тіл — нове рішення. У темі також немає способу перевести дискретні категорії FFIT у безперервну напругу якоря чи зіставити Rectangle з наявними окремими маршрутами H і O. Наряд забороняє приймати нове продуктове рішення або вигадувати межу.
- Не вдалося визначити за наявним рішенням, як поводитися без виміряного високого стегна і як зберегти розрізнення H/O без знятих меж WHR. Чекає на відповідь менеджера; після неї лишаються реалізація, лічба місць талії ДО → ПІСЛЯ, повтори сцен і окрема жива перевірка.
