# «Опис без фото» вирішує виклик, що пише пояснення, — доробка #4184 (16357, 16358)

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`, код — `аудит/КОД.md`. Наряд диспетчера (доробка за
перевіркою 1711-1240, `аудит/перевірки/1711-1240.md`, і рішенням менеджера 17.11 15:00 UTC на «ЗВЕДЕННЯ 14:54»:
`аудит/корені/Е2-опора-пояснення.d/менеджер/зведення-1454-1711.md`). Корінь — `аудит/корені/Е2-опора-пояснення.md`,
етап Е2. Гілка — нова `claude/Е2-опора-пояснення-кадри-руки-3-4-доробка` від свіжого `main`, один PR-чернетка.

**Проблема.** Після #4184 (злито 9f006806) прапор «опис написано без кадрів» (`описБезКадрів`) у руках 3–4 ставить
будь-який виклик моделі без фото, зокрема допоміжний `item_list_prompt` (`перелікРуки` → `к.модельПРуки`), який кадрів
не несе за будовою. У бойовому шляху перелік є завжди, тож прапор для рук 3–4 — завжди true, хоч прозу написано з
кадрами (16357). Рішення менеджера: це хибне твердження про походження, внесене злиттям; доробка — першою, до
наступного кроку кореня. Звірки `тест_показу.js` цього не бачать: у їхній сцені нема `перелік_прози`, тож
`стадіяРукБезКаталогу` не викликає `перелікРуки` (16358).

**Ціль.** Чи писано пояснення без кадрів, вирішує лише той виклик, що пише пояснення (прозу руки, опис, опис після
заміни), — одним місцем; допоміжні виклики факту не змінюють.

**Мірило.** ДО → ПІСЛЯ шляхом продукту, з переліком (`перелік_прози` є, `перелікРуки` викликається):
1. рука 3–4, кадри прози дійшли, перелік без кадрів — `описБезКадрів` true → false;
2. рука 3–4, проза без жодного кадру — true → true;
3. руки 1–2 — шість сцен `аудит/проби/Е2-опора-пояснення-кадри-від-початку/картка_без_фото.js` без змін;
4. перелік усіх викликів `модельПРуки` і тих, що ставлять прапор, — у PR: кожен — «пише пояснення» чи «допоміжний»,
   допоміжних, що ставлять прапор, N → 0;
5. `тест_показу.js` зелений, і його сцени рук 3–4 ідуть шляхом із переліком (16358);
6. прилад кореня не росте (0), батарея `аудит/КОД.md` зелена.
Рядок `ЖИВИЙ ПІСЛЯ` — сцена функції на зібраній сторінці, де видно твердження картки; якщо картка рук 3–4 рядка не
показує взагалі (фото речей нема), назви в PR, де жінка чи журнал бачать прапор, і постав питання на те місце.

**Межі.** Напису рядка, будови картки, `аудит/ПРОДУКТ.md`, рішення #4186 (руки 3–4 без фото на картці рядка не
дістають) не міняєш. Причину на шляху мірила лагодиш сам; поза шляхом — «ЗНАХІДКА» з доказом.

**Кінець.** «ВИКОНАВЕЦЬ: ГОТОВО #PR <повний SHA> — мірило ДО → ПІСЛЯ; вад знайдено N» диспетчерові; файл наряду видали
тим самим PR.
