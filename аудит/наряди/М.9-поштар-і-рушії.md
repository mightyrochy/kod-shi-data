## Частини — кожна окремим PR на межі коміту

**А. Доставка й квота.** Скрипт прогону ноутбука (як `частина.sh` 5.4) наприкінці сам кладе обчислений рядок кінця
(«НОУТБУК ГОТОВО <гілка> <SHA>» чи «НОУТБУК ЗАБЛОКОВАНО <гілка> <код>») у теку вихідних; обгортка доставляє його
`Send-Line` з повтором і станом «надіслано / спроби» — сесії не треба жити до кінця 12-годинної частини. Перед нарядом
Gemini — квота як дані: `agy -p "/usage" --output-format json` (0 ходів); група моделі з 0 % — наряд не береться, рядок
диспетчерові з групою й часом скидання; залишок — у рядку кінця наряду. Мірило: ДО — 2 загублені листи 24.10, 429 наряду
3.6 (23.10); ПІСЛЯ — кожен кінець прогону дає `ok:true` чи «ЗАБЛОКОВАНО» за ≤ 2 хв, прогонів на 0 % — 0.

**Б. Спостерігач замість сторожів (М.1).** Опитування `gh` раз на хвилину: коментарі #963 і PR нарядів Codex (нові й
правлені — правка не сповіщає) лише від `mightyrochy` і `chatgpt-codex-connector[bot]`, стан CI голів відкритих PR
від `mightyrochy`; рядок диспетчерові — лише на зміну (номер, id коментаря, автор, «новий/змінено», SHA, стан CI).
Перенос diff Codex без моделі: відповідь бота з diff → `git apply --check` у чистому worktree від `main` → гілка
`codex/<наряд>` → пуш → PR-чернетка; не застосувався — рядок із кодом причини, а переносить сесія, як тепер
(`аудит/CHATGPT.md`). Мірило: ДО — сесії-сторожі й сесія Claude на кожен перенос (зведення диспетчера 24.10); ПІСЛЯ —
правку коментаря видно за ≤ 2 хв, diff, що застосовується, — без сесії Claude.

**В. Рушії — після дій власника (їх пише диспетчер).** Gemini CLI (`gemini`) — другий рушій тієї ж черги під тим самим
ізольованим користувачем: його квота спільна лише з Code Assist (https://docs.cloud.google.com/gemini/docs/quotas), чи
окрема від agy — перевір `/stats`; обгортка бере рушій, де лишилась квота. Локальний Codex — третій рушій з явною
моделлю й зусиллям (`codex exec -m <модель> -c model_reasoning_effort=<рівень> --json -o <файл>`; моделі —
`аудит/МОДЕЛІ.md`, https://learn.chatgpt.com/docs/models): хмарний Codex із GitHub — лише GPT-5.6 Sol (модель задає
OpenAI), локальний — gpt-6.1-sol чи Astra. Лише в ізоляції ОС: окремий користувач Windows без прав адміністратора,
запуск — обгортка, яку встановлює власник, пуш — обгортка після тих самих перевірок, що для Gemini. Сесія Claude
