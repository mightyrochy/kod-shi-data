# Проба локальних моделей ноутбука на коді

Роль — ноутбук (`аудит/НОУТБУК.md`), ядро — `AGENTS.md`. Основа — `аудит/МОДЕЛІ.md`, абзац «Локальні моделі ноутбука на
коді» (менеджер 06.11 за словом власника 06.11): чи може модель з LM Studio на RTX 4090 16 ГБ робити механічну частину
кореня так, як її зробила хмарна сесія. Мірило — умова власника для економії (`аудит/МЕНЕДЖЕР.md`, «Витрати»). Карта —
спершу прогонам: позначка цього наряду має умову `gpu`, обгортка дає карту лише вільну.

**Спроба 2 (07.11).** Звіт першої (`аудит/проби/локальні_моделі/звіт.md`, #3264) пробував лише вже встановлені моделі:
`gpt-oss-20b` правок не зробила, `qwen3.5-9b` упала на шаблоні чату, `devstral-small-2507` не вмістила запит у вікно.
Це не доказ, що ціль недосяжна (менеджер 07.11; власник 06.11 08:11: «Треба пробувати. Встановлюй в LM studio все що
тобі потрібно»). Цього разу п.1 обов'язковий: став нові моделі. Перепробуй щонайменше: Qwen3-Coder 30B-A3B з частиною
шарів на CPU (вікно ≥ 64 тис.); шаблон чату qwen, що зводить кілька системних повідомлень в одне (у LM Studio — свій
prompt template моделі), для qwen3.5-9b чи Qwen3-Coder; `codex --oss`, якщо ставиться без покупок і секретів. Ціль
знімає лише доказ недосяжності з джерелами для кожного шляху, а не «не вмістилось» без спроби винесення на CPU.

**Крок.**
1. Місце: `Get-PSDrive C` до завантажень — у звіт. Моделі підбираєш і ставиш у LM Studio сам (`lms get`): одна-дві, що
   з контекстом не менше 32 тис. токенів уміщаються в 16 ГБ карти й уміють виклик інструментів (наприклад, родини
   Qwen3-Coder, Devstral, gpt-oss — вибір і причину запиши). Місце після завантажень — у звіт.
2. Повтор злитої механічної частини: наряд `аудит/наряди/Е3-одна-величина-ч8.md` на коміті
   `9de5818e3cc8f9c19409d5079510983ae2050dae` (батько злиття #3148, `797a217a8`). У своїй копії — гілка
   `проба/<модель>` від цього коміту (нових клонів і тек не створюєш, `аудит/НОУТБУК.md`). Рушій — Claude Code з
   локальною моделлю (`ANTHROPIC_BASE_URL=http://127.0.0.1:1234`, `/v1/messages`, LM Studio від 0.4.1) чи
   `codex --oss`; запит — «Ти — ВИКОНАВЕЦЬ, наряд — `аудит/наряди/Е3-одна-величина-ч8.md`, прочитай і виконай; без
   пушу». Пушити гілки `проба/*` не можна.
3. Порівняння зі злитим `797a217a8` для кожної моделі: прилад частини з наряду ч8 (число місць), батарея з
   `аудит/КОД.md`, яку можна прогнати на ноутбуці (код виходу кожної), `git diff --stat` проти `797a217a8` (файли,
   рядки), вади, які бачиш у диффі (що зламано чи не зроблено), час від запиту до кінця, пік `nvidia-smi
   --query-gpu=memory.used --format=csv`.
4. Наприкінці — `lms unload --all`, повернись на `origin/main`, гілки `проба/*` видали локально.

**Не робиш.** Продукту, приладів і обгортки не міняєш; платних API нема; моделі не публікуєш; живих прогонів не
запускаєш.
