# Скасований job «злиття» самого самозлиття навіки блокує злиття за міткою

Наряд диспетчера (прилади CI), вимір 26.11. Роль — ВИКОНАВЕЦЬ, код — `аудит/КОД.md`.

**Проблема.** `.github/workflows/samozlyttia.yml`: job `злиття` має `concurrency: самозлиття-документа`,
`cancel-in-progress: false`, тож коли в черзі групи з'являється новіший запуск, старший очікувальний GitHub скасовує.
Скасований check run «злиття» лишається на голові PR. `джерела/прилади/документ_без_коду.py`, `перевірки_голови`,
пропускає лише check runs власного запуску (`свій_запуск`) і витіснених запусків подій `pull_request`. Скасований
check run запуску самозлиття (подія `workflow_run` чи `pull_request_target`) він рахує, і голова ніколи не стає зеленою.

Факт 26.11: на голові #4303 6313160f мітку «злити» поставлено о 07:24:34. Job «злиття» запуску 45775095836 скасовано
о 07:25:22. Рішення запуску 45776906042 о 07:39:34: «#4303 `6313160f`: не зливати (мітка) — … перевірка «злиття»:
cancelled». Те саме стоїть на #4764 026acd3e: job «злиття» запуску 45774686194 скасовано о 07:22:25.

**Ціль.** Check runs будь-якого запуску процесу самозлиття (`samozlyttia.yml`) не входять у «перевірки голови»: це не
CI голови, а сам крок злиття. Решта правила зеленої голови не змінюється.

**Мірило.**
1. Тест `тест_документ_без_коду.py`: голова з check run «злиття» = cancelled із запуску самозлиття (інший id, ніж
   `свій_запуск`) і рештою зеленого — `перевірки_голови` дає `True`. Той самий cancelled check run з запуску процесу
   `pull_request` (не самозлиття) — як і раніше, `False`.
2. Самоперевірка приладу (`--рішення` друкує «самоперевірка: випадків N, вад 0») — вад 0.
3. Після злиття — на першому PR із міткою, чий job «злиття» скасовано, рішення не називає «перевірка «злиття»: cancelled»
   (звіряє диспетчер у підсумку job).

**Межі.** Не чіпати `.github/workflows/` (самозлиття такого PR не зіллє; зміна приладу без процесу досить). Як
розпізнати запуск самозлиття — з даних, що прилад уже має (шлях процесу запуску чи назва check suite), без нових
викликів API, якщо можна.
