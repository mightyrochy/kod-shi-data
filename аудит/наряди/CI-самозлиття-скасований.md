# CI: самозлиття не зливає документ, якщо на голові лишився скасований запуск-попередник

Роль — ВИКОНАВЕЦЬ, ядро — `AGENTS.md`. Файли — `джерела/прилади/документ_без_коду.py` (`перевірки_голови`,
`рішення_pr`), `.github/workflows/samozlyttia.yml`. Ядро, «Документ без коду зливається сам».

**Факти (13.11, диспетчер).** #3564 (документ: `аудит/витрати/…`, наряд), голова 84816add, переведено з чернетки
о 01:08. Повтор «рядок ЖИВИЙ ПІСЛЯ у тілі PR» на події `ready_for_review` — запуск 43342649116 `success`; попередній
запуск того самого процесу на тій самій голові — 43342612064 `cancelled`. Решта перевірок голови — `success`/`skipped`.
Запуски самозлиття 43342660278, 43342664633, 43342831196, 43342933625, 43343118608 — `рішення` `success`, `злиття`
`skipped`; підсумок рішення: «#3564 `84816add`: не зливати — перевірка «рядок ЖИВИЙ ПІСЛЯ розбирається»: cancelled».
Злив диспетчер (f69964dd). Те саме на голові #3596 8e16269f (переведено з чернетки): є і `cancelled`, і `success`
check run «рядок ЖИВИЙ ПІСЛЯ розбирається». Отже кожен документ, що був чернеткою чи чию голову перезапустили
(правка тіла PR, повтор), CI сам не зіллє ніколи.

**Гіпотеза (не виміряно).** `check-runs?filter=latest` віддає останній check run з кожного check suite, а кожен запуск
процесу — свій suite; скасований попередник лишається в списку поруч із новим `success`.

**Кроки.**
1. Причина з виміру: що віддає API для голів 84816add і 8e16269f (check runs, їхні suite, запуски процесів), і яке
   правило «останній запуск кожного процесу / кожної перевірки» відкидає саме витіснений попередник, а справжній
   `cancelled`/`failure` останнього запуску лишає «не зливати».
2. Мінімальна правка в приладі (і процесі, якщо треба). Без нових секретів, `workflow_dispatch`, auto-merge і ширших
   `permissions`.
3. Мірила:
   - (а) тест у `тест_документ_без_коду.py` на дані обох голів: витіснений `cancelled` + новіший `success` того самого
     процесу — «зливати»; останній запуск `cancelled` чи `failure` — «не зливати»; старі тести зелені, actionlint чистий;
   - живе — диспетчерове: документний PR, переведений з чернетки, CI зливає сам.
4. Рядки дошки 14850–14852 — `аудит/дошка/claude/CI-самозлиття-скасований.md`.
