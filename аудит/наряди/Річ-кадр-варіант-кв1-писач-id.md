# Корінь Річ-кадр-варіант, кв1: писач дістає id товару зі сторінки

Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`, код — `аудит/КОД.md`. Крок паспорта

пункт «Наступний крок — писач дістає id товару зі сторінки». Наряд поставив диспетчер 15.11.

**Що є.** Вимір каналу «картка» (`аудит/проби/кадр_варіант_кв1_канал_1411/README.md`, `лічба.tsv`): із 13 882 записів
власника кадру доведено 21, «невідомо» 13 782. Головна причина — «нема id у фактах і дозволеного запасного id»: 7 408
як основна, 10 130 з перетинами. Писач каналу — `_власник_сторінки` у `zhnyvarka/жниварка.py`, читач —
`доказ_варіанта` у `джерела/фід_власник_кадру.py` (обидва вже в `main`, #3747). Збережені відповіді всіх 13 882
сторінок лежать на ноутбуці: `C:/Users/gemini/gemini-data/кадр_варіант_кв1_канал_1411/системні_CA/`
(`відповіді/<id>.json.gz`, знімок `каталог_записи_06_11.jsonl.gz`); як повторити лічбу без мережі — README виміру,
розділ «Збережені відповіді та повтор».

**Крок.** Знайди за збереженими HTML, де на сторінках цих крамниць лежить id товару, який писач зараз не дістає
(JSON-LD `productID`/`sku`, атрибути форми кошика, `data-product-id`, вбудований JSON платформи тощо), і навчи писача
його діставати — один шлях у писачі для всіх крамниць, не адаптер на крамницю. Читача не послаблюй: доказ без id
лишається «невідомо»; параметр відстеження (`sc_content`, 15253) — не id.

**Мірило.** Повтор лічби виміру на тих самих 13 882 записах без мережі (`вимір.py --без-мережі` зі сховищем вище, дерево
— голова твоєї гілки): «нема id» 7 408 → число ПІСЛЯ, доведених 21 → число ПІСЛЯ, за крамницями. Числа ДО і ПІСЛЯ, команди
й нову `лічба.tsv` поклади в `аудит/проби/кадр_варіант_кв1_писач_1511/` (README з поясненням, де розійшлось), рядок
«Зроблено» — у паспорт. Прилад кореня `python3 -W ignore джерела/прилади/корінь_річ_кадр_варіант.py` не має зрости.

**Межі.** Мережі до крамниць не потрібно й не ходиш: лише кеш. Продуктових файлів (каталог, записи, збагачення, факти
власника) не перезбираєш і не комітиш — перезбір окремим кроком, доки доведених менше половини каналу (рішення
менеджера 13.11 у паспорті). Адаптерів на крамниці без Product і розбору кількох свотчів не робиш. Кешу нема чи він
неповний — «ЗАБЛОКОВАНО: <що саме нема>». Гілка `gemini/Річ-кадр-варіант-кв1-писач-id`, PR-чернетка з кодом.
