# Один прохідний модуль — геть (вимір Gemini 4 Neon на коді)

Ти — виконавець (`аудит/ВИКОНАВЕЦЬ.md`; адаптер — `GEMINI.md`), код — `аудит/КОД.md`. Наряд диспетчера 28.11 за словом
власника 28.11 16:50 UTC: «потрібно перевіряти неон, він має бути розумніший». Це вимірний наряд коду для
`gemini-4-neon-high`, того самого класу, що й `Код-фасади-геть-hydrogen`: Hydrogen двічі зупинився на ньому (PR #4976),
а Codex цей модуль (`accessory`) доробив у #5027. Метод і мірило — наряд `аудит/наряди/Код-фасади-геть.md` (прочитай
цілком); тут — лише твоя частина: **один** модуль, один PR.

**Що зробити.**

1. На свіжому `main` (уже з #5027) запусти `cd джерела && python3 прилади/група_залежності.py` — він дає прохідні
   модулі (без власних `def` і `class`), їхніх споживачів і найбільшу групу взаємної залежності. Візьми прохідний модуль
   із найменшим числом споживачів; `реєстр_правил` і `colorspace` не бери. Модуль, чий споживач змінюють відкриті гілки
   коду, пропусти й візьми наступний: файли гілки дає `git diff --name-only origin/main...origin/<гілка>` для гілок
   `codex/*` і `claude/*` з комітом за останню добу.
2. Кожен споживач у продукті, приладах і пробах імпортує ім'я з модуля, де воно визначене. Прохідний модуль видали тим
   самим комітом разом із записом у `status.МОДУЛІ_ПРОДУКТУ` і в переліку файлів збирача. Назв модулів і функцій не
   міняєш.
3. Функцію, яку досягав лише реекспорт видаленого модуля (на ній зупинився Hydrogen), видаляєш тим самим PR, якщо в
   репозиторії нема жодного її виклику. Якщо її кличе лише проба — лишаєш і кажеш у звіті, як «НІХТО» стало 0. Що
   видалив і чому — рядок у звіті.
4. Мірило: прохідних модулів було → стало; імпортів продукту через цей модуль → 0; найбільша група до → після; вихід
   коду на записаних сценах побайтово той самий, порівняних сцен не 0 (записи — `аудит/проби/нічні/`, найсвіжіша тека);
   `cd джерела && python3 досяжність.py` → «НІХТО» = 0; батарея `аудит/КОД.md` зелена; сторінка збирається
   (`NODE_PATH=джерела/node_modules LYUSTERKO_CATALOG=повний python джерела/build_артефакт.py джерела <тека>/index.html показ-повний`).

**Межа.** Не більше 2 млн токенів на наряд. Батарея не зеленіє після двох спроб виправлення — зупинись: рядок
«ЗАБЛОКОВАНО: <що падає, файл:рядок>» і кінець.

**Вихід.** Гілка `gemini/Код-фасади-геть-neon` (обгортка). Тіло останнього коміту — звіт: модуль, числа мірила ДО →
ПІСЛЯ, команди й коди виходу, а ще вимір рушія: фактична модель (що каже `agy`), токени входу й виходу (якщо CLI їх дає;
ні — «не віддає»), час від старту до останнього коміту, скільки разів падала батарея до зеленої. Порівняння з
Hydrogen (#4976: 5,7 хв, «НІХТО» = 4, зупинка) і Codex (#5027) зведе диспетчер.
