# Показ без копій таблиць Python

Корінь Р05 «одне поняття — кілька копій» (`аудит/КАРТИНА.md` §2, К-2), п.19 `аудит/СТАНДАРТ_КОДУ.md` «одне джерело»,
крок 3.9 `аудит/ПЛАН.md` — залишок 2.8. Роль — ВИКОНАВЕЦЬ (`аудит/ВИКОНАВЕЦЬ.md`), ядро — `AGENTS.md`, адаптер — свого
середовища. Гілка `<префікс середовища>/3.9-показ-без-копій-python` від `main` після злиття #1784. Показ і збірку
правлять також 2.12-Б — зливаються по одному. Дошка: прямий 7520 (запис — у `аудит/дошка/menedzher/f2-2510.md`); нові
рядки — номери від диспетчера, у `аудит/дошка/<гілка>.md`.

**Проблема.** Показ тримає ручні копії таблиць Python (`main` eed9d09b): `ОПАДИ` (`джерела/показ/випадок.js:23`;
джерело — `сценарій.ОПАДИ_КОДИ`, таблиця внутрішньої мови), `ЗОНИ_ВЕТО_П` (`:131`; `внутрішня_мова.ЗОНИ_ВЕТО`),
`КАТЕГОРІЇ_ВЕТО_П` (`:158`), `ГАМИ` (`показ/воркер_міст.js:36`; `вибір_палітри.ГАМИ`), `БЮДЖЕТ_ТОКЕНІВ_П = 43400`
(`показ/стадії_збирання.js:16`; бюджет — у `build_артефакт.py:735`), `ВЕЛИКІ_СЛОТИ` (`показ/картки.js:457`) і літерал
`['метал','білий','нейтралі','барви']` у п'яти місцях (`випадок.js:669`, `профілі.js:131`, `:434`,
`фото_профіль.js:156`, `:216`). Копії вже розійшлися: `ВЕЛИКІ_СЛОТИ` показу — без «комплект», а в Python їх дві
(`суд_від_моделі.py:970`, `різноманітність_пулу.py:174`). Гейт `джерела/прилади/розділи_гейтів.py:3847` читає
`ЗОНИ_ВЕТО_П` регуляркою з JS — перевіряє копію, а не джерело. 7520: `ПОЛЯ_ПЛИТОК` (`паспорт_основи.py:269`) без опадів,
тож ручна плитка опадів не впізнається як ручна (`поля_рукою({"опади":"сніг"}, {"опади":"rain"})` → `[]`). Спроби кроку
2.8 (#1440, #1441) писались до розбиття показу (#1603) і тепер конфліктують у 43–44 файлах.

**Ціль.** Кожна таблиця, яку показ бере з Python, має одне джерело: показ отримує її з Python — у воркері через Pyodide
чи модулем, який генерує збірка CI (вибір і причина — у PR); ручних копій у JS нема, у Python таблиця теж одна. Гейт
копії читає таблицю або зникає разом із копією. Поведінка показу не змінюється, крім названого: яка з копій
`ВЕЛИКІ_СЛОТИ` правильна для показу і що міняє вибір — у PR.

**Мірило.** ДО/ПІСЛЯ: ручних копій таблиць Python у `джерела/показ/` (перелік вище, повний — пошуком, команда в PR) N →
0; регулярок гейтів, що читають копію в JS, 1 → 0; знімок 0.2 тотожний або кожна різниця названа з причиною; тест показу
(`джерела/тест_показу.js`) і знімки 390×844 ті самі; 7520 — закрито з ДО/ПІСЛЯ або лишено з причиною.

**Підказка.** #1440 (58e08fc1) і #1441 (80f72515) — довідка, не основа: підхід (переліки з Python, гейт із таблиці)
звідти, код — заново на розбитому показі; їхні 7521, 7560, 7570 не переносяться, обидва PR закриваються без злиття,
гілки лишаються (менеджер 25.10). Python у показі вже двома шляхами: збірка пакує модулі (`build_артефакт.py`), воркер
вантажить Pyodide без пакетів (`показ/воркер_міст.js`).
