## Фактичне ДО

Штатну повну збірку ДО зроблено на `42d185b23a07162c71d038b8c9db038dd2eaa4f0`. До актуальної бази 0ccb змінилися лише документи: blob `джерела/показ.html` на обох — `e5fa805ab3c10c22d8136a3f2f17358b63883a1a`. Збірка ПІСЛЯ відповідає виробничому blob `10ddd4814c0bfedede20e4f699d8606ab9e031e3` фінальної голови; після її створення додано лише один рядок дошки.

Перед вибором компонента прочитано актуальні remote PR та коментарі #1034, #1041, #1049, #1052. Аркуш «Мета», руки, прийняті #1038/#1049/#994/#1000 не змінювалися. Перевірено один перегляд, масового сканування інших прийнятих UI не було.

Native Chromium 151, viewport 390×844, mobile/touch. Сценарій `probe.cjs`: наявний архівний запис через IndexedDB → справжня бібліотека → картка → наявний перегляд. Тільки поле картинки фікстури заповнено локальним synthetic bitmap 360×540 з canvas (кольорові прямокутники); це не фото людини й не оцінювання фото чи моделі. Pyodide і шрифти — наявні локальні залежності; сторонні запити перехоплюються та блокуються. Модельні/фото API 0.

| Звірка | ДО | ПІСЛЯ |
|---|---|---|
| Відкривач | img, tabIndex −1, AX image «приміряний образ» | native button «Відкрити образ на весь екран» |

| Фокус після відкриття | BODY | кнопка «Закрити» |

| Escape | закриває, фокус на фоні | закриває, фокус на відкривачі |
| Кнопка / картинка / тло / Escape | pointer-поведінка наявна | 4/4: точне повернення фокусу, inert і overflow |

Для точного відновлення ПІСЛЯ кожен із чотирьох шляхів починається з наявного `#бік inert="probe-existing"` та body `overflow:clip`: усі атрибути inert прямих дітей body після закриття побайтово дорівнюють початковому масиву, overflow знову clip, відкривач активний. Власний тестовий inert прибирається після сцени. Значення й поведінка інших компонентів не змінені.

## Очима

Переглянуто `before/card-390x844.png`, `before/open-390x844.png`, `after/opener-focus-390x844.png`, `after/open-390x844.png`. На картці весь synthetic bitmap у межах екрана, відкривач має видимий контур 2 px. На весь екран показано ту саму картинку й кнопку ×; фокус на × видно. Картки ДО/ПІСЛЯ перед відкриттям байтово однакові. Кадри відкритого перегляду відрізняються видимим фокусом, зсувів картинки немає.
