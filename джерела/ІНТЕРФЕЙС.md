# Інтерфейс показу v3 — «Полотно й нитка», уночі «Музейне золото»

Що це: візуальна система `джерела/показ.html` (єдина сторінка продукту), зроблена за
посібником «Стильна, не банальна українська айдентика для інтерфейсу Люстерка».
Код збирання, міст, протокол і тести не змінювались: правка лежить у `<style>`,
у розмітці шапки й трьох рядках JS, які підставляють кольори з токенів.

## 1. Принципи (з посібника — у код)

| Елемент посібника | Де в інтерфейсі | Правило |
|---|---|---|
| Fixel Text (MacPaw, OFL) | увесь текст інтерфейсу: поля, кнопки, підписи, статуси | `--текст`; Regular/Medium/SemiBold з jsDelivr (`gh/MacPaw/Fixel`), `font-display:swap` |
| Kyiv\*Type Titling (Растворцев, freeware, NoDerivates) | `h1`, `h2`, `h3`, `.знак`, `.мітка` — лише кеглі ≥ 17 px | `--дисплей`; вісь `CONT` через `--контраст` (h1 480, h2 360, h3 260) |
| Kyiv\*Type Serif | «голос стиліста» в картці: `.текст-образу`, `.задум` | `--голос`; `CONT` 140; ніде в інтерфейсі |
| Arsenal (OFL) | запасний у стеку та для листів/документів | не вантажиться сторінкою |
| Мережка (Полтавщина) | роздільник секцій `.розділ::before`, `.вердикт`, `.мета`, панель дії, журнал | `--мережка`: дві нитки + прутики, 5 px; ніколи не площиною |
| «Біле по білому» | фактура порожніх станів: слоти фото, вікна очікування, площина сцени, `.порожньо-текст` | `--фактура`: восьмикутна зірка 32 px, непрозорість 0.06 (удень) / 0.055 (уночі) |
| Скіфсько-мозаїчне золото | ОДИН акцент: поточний вузол нитки поступу, нитка під знаком, `em` у заголовку, фокус, чип «вдягну як є», головна кнопка вночі | `--золото` удень бронза `#8B6B2C`, уночі `#D6B45C`; ≤ 10 % площі; ніколи під фото |

| «Намисто» (принцип Banda) | чипи — намистини `border-radius:999px`; вибрана — чорна з двома крапками «ї» | принцип модульного нанизування, не графіка Banda |
| Витинанка (принцип Gunia) | силует порожніх станів (`--витинанка`: вазон, симетрія від згину), зубчастий край колажу | лише контур/маска, не тло під товаром |
| Геометризовані іконки (Український інститут) | `svg.і`: `stroke-linecap:square; stroke-linejoin:miter` | без заокруглень у вузлах |
| Бойчукізм | площини без тіней, колаж без нахилу | жодного `box-shadow` як тіні |
| Motion | «нанизування» карток і речей (`нанизати`), «затягування» мережки в лоадері (`човник`), нитка під знаком | усе під `prefers-reduced-motion: reduce` |
| Наративні гліфи | «ї» — маркер вибраного (чипи, плитки), крапки «візьмемо», буліти «як носити» | мікродеталь, не декор |

Чого свідомо нема: синьо-жовтої пари, тризуба, вишиванки-«пікселя», борщівської
чорної вишивки як патерну (жалобна семантика), e-Ukraine (статус для комерції
не підтверджений), Oksana (комерційна — купує власник), музейних оцифрувань.

Тема: системна за `prefers-color-scheme`; кнопка в шапці (`#тема-кнопка`) пише
`data-тема` на `<html>` і запам'ятовує в `localStorage('люстерко-тема')`;
`<meta name="theme-color">` оновлюється разом.

## 3. Форма: як зроблено вікно

`clip-path: polygon(…)` ріже і межу, тому кайма малюється окремим кільцем —
`::after` (у `.рамка` — `::before`, бо `::after` там туман) із
`clip-path: polygon(evenodd, зовнішній контур, внутрішній контур на 1 px)`.
Кільце не ловить дотиків (`pointer-events:none`) і стоїть над вмістом. Якщо
браузер не знає `evenodd` у `polygon()`, кільця нема, а форма є (`@supports`).
Фокус на скошених елементах — усередину: `outline-offset:-3px`, золотом.

## 4. Що НЕ можна ламати

- усі `id` розмітки та класи, які ставить JS, — контракт із `тест_показу.js` і
  гейтом `id↔розмітка` збирача; список класів JS — у `build_артефакт._гейти_js`;
- рядок «Основа — головний колір» на екрані палітри — обов'язковий шматок збірки;
- шрифти в `шрифти/` не перепаковувати (NoDerivates) — див. `шрифти/ПРО_ШРИФТИ.md`;
- фото речі та колаж — без орнаменту, без кольору, без фактури за ними.

## 5. Пороги з посібника (перевірити на живих людях)

- золото на картках знижує клікабельність (A/B) → лишити його лише у вузлі
  нитки, знаку та чипі «вдягну як є»;
- скіс погіршує тач-таргет (< 44 px) або ріже фото → зменшити `--ск` до
  декоративного кута лише в шапці картки;
- орнамент над/за фото відтягує око (5-second test) → переносити у службові зони.

## 6. Перевірка

```
cd джерела
python3 -c "import build_артефакт as b; b._гейти_js(open('показ.html',encoding='utf-8').read(),'ЗАГЛУШКА','показ',обовʼязкові=('Основа — головний колір',),заборонені=(),ліміт=10**8)"
NODE_PATH=node_modules node тест_показу.js          # jsdom-батарея по шаблону
LYUSTERKO_CATALOG=повний python3 build_артефакт.py . ../index.html показ-повний   # усі гейти, разом із батареєю по збірці
```

Знімки в Chromium (390×844, обидві теми) робились скриптом у робочій теці
сесії; сторінка-прев'ю — шаблон із підставленими плейсхолдерами й без вантажу.
