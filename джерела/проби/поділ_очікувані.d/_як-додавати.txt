# ЦЕ ОДИН ФАЙЛ РЕЄСТРУ ПОДІЛУ. Реєстр — тека `поділ_очікувані.d/`, і `поділ_спільне.очікувані` читає
# ОБ'ЄДНАННЯ всіх `*.txt` у ній. Один запис — один рядок:
#     <модуль-до-поділу> | <новий_модуль>::<ім'я> | <sha> [<sha> …] [| нота]
# Порожній рядок і рядок із «#» — не запис; журнал цього рядка дошки теж тут, рядками «#». Проба бере
# МНОЖИНУ ключів, тож порядок файлів, порядок рядків і повторений ключ на вердикт не впливають.
# ЯК ДОДАВАТИ: заведи (або редагуй) ЛИШЕ СВІЙ файл `рядок-NNN.txt` — тоді дві гілки ніколи не правлять
# той самий файл і не конфліктують на жодному злитті, зокрема на кнопці GitHub. ЧУЖІ ФАЙЛИ НЕ ЧІПАТИ:
# щоб дописати sha до чужої пари, НЕ прав її рядок — постав СВІЙ рядок із тим самим ключем у своєму
# файлі (дублікат ключа нешкідливий: проба бере множину).
#
# ЧОМУ ТЕКА, А НЕ ОДИН ФАЙЛ. До 24.09.2026 реєстр був одним файлом `поділ_очікувані.txt` із
# `merge=union` у `.gitattributes`. Union діє лише на ЛОКАЛЬНИХ злиттях: серверне злиття GitHub
# драйвера з `.gitattributes` не бере, і кнопка «Merge» давала конфлікт — #251 зливався локально
# чисто, а GitHub показував `mergeable: false, dirty`. Тека знімає це без жодного драйвера:
# різні файли конфліктувати не можуть ні локально, ні на сервері.
#
# Реєстр очікуваних AST-розбіжностей проб `поділ_*_ast.py`. ОДИН ЗАПИС — ОДИН РЯДОК:
#     <модуль-до-поділу> | <новий_модуль>::<ім'я> | <sha> [<sha> …] [| нота]
# Порожній рядок і рядок, що починається з «#», — не запис. Порядок рядків не важить:
# проба бере МНОЖИНУ ключів другого поля для свого модуля (`поділ_спільне.очікувані`),
# тож і повторений ключ нічого не міняє. Саме тому файл зливається ОБ'ЄДНАННЯМ
# (`.gitattributes`: `merge=union`) — паралельні гілки, що додають свої рядки, не конфліктують.
# Через це: НЕ пересортовувати й НЕ переформатовувати файл цілком, НЕ правити чужі рядки.
# Свій запис — своїм рядком (тримати сортування «модуль, ключ», щоб рядок ліг на своє місце);
# свою примітку — четвертим полем свого рядка або рядком «#» у журналі в кінці файла.
# ─── журнал реєстру (дописувати рядком у кінець; один запис — один рядок «#») ───────────────
# Очікувані AST-розбіжності проб поділ_*_ast.py: пара «модуль::ім'я» → sha комітів, які свідомо змінили цю функцію/константу ПІСЛЯ поділу (докстрінги/except-хвиля і подальші правила, що торкнулись тих самих імен). Список узятий з git log -p кожної гілки поділу проти БАЗА-коміту проби. Будь-яка розбіжність поза цим списком — проба падає й називає ім'я.
