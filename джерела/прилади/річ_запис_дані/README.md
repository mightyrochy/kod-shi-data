# Входи безмережевого повтору

Сторінки — незмінна вибірка PR #2514: `аудит/проби/річ_запис_каталог_2026_10_30/вибірка_п3.json`
і його `html/*.html.gz`, 144 адреси / 48 крамниць; джерело й спосіб добору — README того виміру.
Прилад читає HTML, адресу та ідентифікатор; історичні назва/опис/склад із таблиці входами жнив не стають.

Залежності збережено для храповика: його середовище має Python і Node, але не виконує pip/npm install.

| Файл | Походження | Ліцензія |
|---|---|---|
| beautifulsoup4-4.12.3-py3-none-any.whl | PyPI, beautifulsoup4 4.12.3 | MIT, `beautifulsoup4-4.12.3.dist-info/licenses/LICENSE` усередині wheel |
| soupsieve-2.6-py3-none-any.whl | PyPI, soupsieve 2.6 | MIT, `soupsieve-2.6.dist-info/licenses/LICENSE.md` усередині wheel |
| acorn.cjs | npm acorn 8.14.0, незмінний `package/dist/acorn.js` | MIT, `acorn-LICENSE` поруч |

Wheel читаються zipimport без розпакування. Необов'язкові транспорти requests/curl_cffi та lxml під час імпорту
жнив недоступні: використовуються штатні гілки без транспорту й `html.parser` на обох деревах храповика.
Сторінки, скрипти сайтів, CSS, картинки й API з мережі не завантажуються.

JS з `ЗЛІПОК_DOM` виконується Node на структурному DOM збереженого HTML. Селектори обчислює SoupSieve;
cloneNode зберігає походження вузлів. Це повтор HTML без верстки: innerText має значення textContent,
а не результат CSS/layout браузера. Результат позначеного JS звіряється зі звичайним JS на тому самому дереві;
так само звіряються факти, канонічний запис та офер браузерного збирача Python. Невідомий селектор чи
розбіжність значень завершує прилад помилкою, не зеленим нулем.

Поля чинного HTML-шляху беруться зі справжнього дерева XML `записати_каталог` до перетворення на байти.
У старого браузерного збирача межа — його офер `картка_з_dom`; вкладені сирі `ld`, `og` і зліпок `текст`
не лічаться самі собою. Читання з них лишається місцем, якщо його мітка дійшла в назву, опис, склад або
інше поле офера. Решта ключів офера й довільні вкладені поля не обмежуються переліком назв.

Штатна відмова на вході зберігається в протоколі лише якщо звичайне й позначене виконання однаково
відмовилися; поля, яких не створено, не рахуються. Це не доказ справності такого входу.
