# Archive

Files in this folder preserve older project material.

They are useful for recovering context, but they are not active source-of-truth
documents unless a current control file explicitly promotes a conclusion from
them.

Active source-of-truth files:

- `PROJECT_STATE.md`
- `PROJECT_LEDGER.md`
- `WORKFLOW.md`
- `ROADMAP.md`
- `DECISIONS.md`
- `SESSION_LOG.md`

Archived files should not be deleted during cleanup. Keep them here with clear
names and dates.
