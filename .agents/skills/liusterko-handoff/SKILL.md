# Передача доручення або справ Люстерка

Працюй у репозиторії, указаному в дорученні. Прочитай його `AGENTS.md` і
`CLAUDE.md`; у `аудит/ПЕРЕДАЧА.md` — тільки потрібні записи. Claude Opus 5.5
на max лишається головним керівником; dot координує виконавців OpenAI під ним.
Передавай погоджені рішення, нове продуктове рішення адресуй керівнику.

Для нового доручення запиши коротко:

- мету, відповідального виконавця й окремого приймальника;
- джерело явного погодження та посилання на рядок `аудит/БЕКЛОГ.md`;
- окрему робочу копію, гілку, точний baseline SHA і дозволені файли;
- критерії приймання, потрібні перевірки, обмеження та наступний крок.

`аудит/БЕКЛОГ.md` — єдина дошка: не заводь ще одну. Якщо погоджене нове
доручення ще не має рядка, передай це координатору; не вигадуй номер чи згоду.
Нова задача починається у свіжій сесії; уточнення того самого доручення —
в поточній. Не надсилай його іншій сесії без авторизації власника.

Для передачі справ додай фактичні commit/гілку/PR або познач «не закомічено»,
змінені файли, зроблене, результати перевірок з обмеженнями, відкриті питання,
докази й один наступний крок. Не відновлюй старі доручення з історії самостійно.

У Codex/Cloud здавай результат відповіддю в поточному чаті або файлом/PR
за явною авторизацією. `create_trigger`/`fire_trigger` — інструменти Claude:
не імітуй їх і не повідомляй інші сесії без людського дозволу.

Якщо використовуєш локальний `джерела/передача.ps1`, звір формат JSON у
`AGENTS.md`: `Prepare` записує наряд, `Export` готує промпт. Скрипт не є
хмарним диспетчером; підготовлений файл не доводить запуск Cloud чи підключення
GitHub. Для хмари перевір фактичний доступ і результат у відповідному сервісі.

Квоти Claude й ChatGPT передавай окремо з джерелом і часом. Невідоме —
`unknown`/`null`; токени CLI не перетворюй на відсоток підписки. Відсутня,
прострочена чи невідома квота саме Codex не дозволяє локальний `Run` Codex.
Невідома квота Claude не блокує інфраструктурну роботу, яка не викликає
Claude. Не купуй доступ, не переходь на платний API й не став повторні
запуски чи merge на таймер.

Локальні записи `.agent-runs/` залишаються локальними. У публічний PR передавай
лише перевірений опис і дозволені докази без секретів та локальних логів.
Передача закінчується дорученням/контрольною точкою; виконання й приймання
потребують своїх фактичних результатів.
